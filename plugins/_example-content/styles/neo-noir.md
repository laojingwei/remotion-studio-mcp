# 黑色电影（neo-noir）

> 一句话：一束硬光切开黑暗，人站在光与影的分界线上，说的每句话都有第二层意思。
> 参照（只学语法）：1940s 美国黑色电影的打光、王家卫的霓虹湿度、David Fincher 的冷调控制。

## 本质 / 不是什么

- 本质：**照度极低**，画面大部分是黑的，信息只靠一两块被硬光照亮的区域给。观众要"凑近看"，这本身就是紧张感的来源。
- 不是：不是"调暗 + 加蓝滤镜"。没有硬光形状的黑只是灰，看起来像压坏的视频；霓虹和烟雾是**副产品**，不是本体。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 侧逆光剪影 | 人脸半边亮半边死黑，边缘一条亮轮廓 | 秘密、抉择、审讯 |
| 百叶窗投影 | 斜条纹落在墙或人物身上 | 监视、被困、隐私 |
| 湿地面反光 | 地面吃光，霓虹拉成竖条 | 城市、夜、孤独 |
| 单点暖光 | 整个冷画面只有一盏琥珀色灯 | 唯一的希望 / 唯一的谎 |
| 大面积负空间 | 人物只占画面 1/5，其余全黑 | 渺小、被环境吞没 |
| 烟 / 雾 | 让光束可见（丁达尔） | 回忆、延迟、不确定 |

## 这个风格最俗的版本

- 画面：全片压蓝 + 城市夜景空镜 + 雨 + 霓虹招牌，人物从头到尾看不见脸。
- 声音：低频轰鸣 + 爵士萨克斯。
- 翻掉的办法：**至少一处给足光**——让观众看清一次眼睛。全程藏脸不是神秘，是不耐烦。

## 技术路线

- 底色用近黑而不是纯黑（`#0B0D10` 左右），纯黑在压缩后会糊成一片，细节全丢。
- 主光只有一个方向，硬边；柔光只用于补一点点暗部信息（不超过主光的 1/5）。
- 3D 场景：`look: "dramatic"` + 低 `exposure` + 高对比，`envMapIntensity` 压到 0.3–0.5，靠一盏 directional 出形。
- 2D 版式：深底 + 极窄的强调色，文字只在大片黑里浮着。

## 配色

- `background #0B0D10` / `surface #161A1F` / `text #E8E6E1`（不是纯白，纯白在黑底上刺眼）
- `primary #C8A15A`（琥珀，唯一暖色） / `accent #8C1F28`（暗血红，救命用，一屏不超过一处）
- 规则：**暖色只出现在"人物真正在意的那个东西"上**。它出现在哪，观众的眼睛就落在哪。

## 字体

- 标题：窄体无衬线（Oswald / Bebas 类），字距略紧，全大写。
- 正文：等宽或打字机（Courier 类），字号偏小——文档感、证据感。
- 不要用圆润字体，圆角会立刻把气质拉回"友好"。

## 运动

- 缓动以 `easeInOut` 为主，慢；**避免弹跳**（back 曲线在这个风格里是错的）。
- 镜头只做缓推（`scale 1 → 1.04`）和极慢横移，一次片子里不超过两次。
- 转场用 `fade` / `wipe`，时长给足（20–30 帧）；不要用 `flash` / `glitch`，那是赛博的语言。

## 画面怎么活

停顿时的微动必须来自光源本身：
- 光斑极缓慢地漂移（像有人在外面走过挡住了灯）
- 烟雾缓慢翻滚
- 湿地面反光轻微抖动

幅度都要小到"不确定是不是在动"。这个风格一旦有明显运动，就变成了动作片。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 缓推 | 逼近真相 / 压迫 | 关键台词、结论 |
| 静止 + 光变 | 时间流逝、局势变化 | 等待、回忆 |
| 极慢横移 | 扫视现场 | 铺陈环境、证据罗列 |

## 坑

1. **全片太暗，手机上什么都看不见。** 交付前必须在最小亮度下看一遍。黑要给"有形状的黑"，不是均匀的黑。
2. **暖色用太多。** 一屏出现两处以上琥珀，强调就失效了。
3. **把"氛围"当成内容。** 画面很酷但没讲事——黑色电影的酷来自"有人在隐瞒什么"，不是来自雨。
