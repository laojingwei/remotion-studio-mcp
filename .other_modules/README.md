# .other_modules

别人的开源项目，按需下载到这里。**不进仓库**（`.gitignore` 已忽略），clone 下来是空的。

- 需要某个工具时：让 agent 读 `.workbuddy/skills/external-tools/SKILL.md`，它会告诉你下载哪一个、怎么校验。
- 也可以自己下载（zip 或 git clone），目录名要和 skill 里登记的一致。
- 这里的代码是第三方代码：**只跑文档里写明的那条命令**，不要执行其他脚本。

| 工具 | 目录名 | 用途 |
|---|---|---|
| [anatomy](https://github.com/wheresryan22/anatomy) | `anatomy/` | 等轴测技术插图（用一台真实机器解释一个概念），产出 SVG |
