# 字幕新闻（caption-news）

> 关掉声音也看得懂的新闻片：实拍与原件是地面，巨大的字幕是主角，一块一块砸进来，关键词压在一块蜜黄上。
> 参照（只学语法）：2010 年代中期字幕优先的社交新闻（NowThis、AJ+）、把大字压在实拍上的横版解释片（Bloomberg Quicktake）。不抄它们的台标、字体、配色比例、片头与镜头，片子里也不点名。

## 本质 / 不是什么

- 本质：**静音优先**——每一拍都要只靠画面和字幕看懂；旁白只给速度，不给信息。
- 本质：**字幕就是镜头**——一行中文放得极大，分 2–3 块砸入，一个关键词落在黄块上；下面一行英文。实拍是选来垫在这行字下面的。
- 本质：**证据上屏**——每个数字都带着出处：来源标签滑进来；关键数字先在原件上被划亮；每一段 CC BY 素材在角上挂署名，像新闻的「视频：」。
- 本质：**帧 4 有钩子**——全片最大的数字在开头 0.15 秒内落地，并滚到它的值。
- 本质：**只有一次转折**——坏消息的钩子被一个改变其含义的事实回答，剩下的每一拍只解释这个转折，一拍一个新事实。
- 不是**数据故事片**：图表是实拍之间的短插页，不是全片，更不是仪表盘。
- 不是**电视新闻包**，也不是 keynote：没有主播、没有通栏跑马灯、没有演播室、没有滚动条，也没有页眉、居中标题加项目符号和翻页。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 一屏一句，砸进来 | 中文 88px 分 2–3 块，逐块从 1.3 缩到 1 落定 | 任何主题 |
| 一个关键词压黄块 | `#FFC21A` 从左擦到右 0.12s，字转墨色 `#0E0E0C` | 数据、对比、结论 |
| 帧 4 的大数字 | 开场 0.15s 内最大数字滚到值，后面跟中文单位 | 有爆点的新闻 |
| 数字带出处 | 黄块下 `#F7F5EF` 的"来源" + 暗色标签：`USDA NASS · 2026.08.03`、`… · 第 13 页` | 统计、报告 |
| 原件被划亮 | 白纸微斜 1–2° 在暗桌上，荧光笔从左扫过 0.3–0.5s | 政策、合同、报告 |
| 账本卡 | `#151512` 纸面，每 54px 一条 4.5% 白线，x 78/86 一道红双线 | 数字、账、对比 |
| 计分板对切 | 两半之间 4px 黄线先落下，坏的一半去色压暗偏红 | 前后、正反、涨跌 |
| 三格依次亮 | 632px 三块、12px 缝，0.1s 错开升起，念到哪个哪个描黄 | 三种原因、三条路 |
| 定格提问 | 0.14s 白闪，1.0→1.12 顶一下，饱和度掉到 45%，黄角标记合拢 | 转折点 |
| 比例靠变暗说 | 黄线横扫实拍到那个百分比，扫过的部分转灰变暗 | 一切「X% 的…」 |
| 角上的素材署名 | 右上 19px，压在 50% 暗片上：`视频 作者 · CC BY 3.0` | 所有 CC BY 素材 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 字幕砸入 + 黄关键词最容易认，也最快用滥；第二支换「原件划亮」「计分板对切」这类证据型信号。
- 实拍必须是真素材（用户的、可授权的）：**不许用生成图当实拍**；拿不到就退回原件页 + 账本卡，画面照样成立。

## 这个风格最俗的版本

- 画面：深色实拍上白字逐句弹出，一个黄底关键词，中间插一张柱状图，结尾居中 logo。
- 声音：一段无版权的 120 BPM 电子铺底 + 一堆 whoosh，旁白赶着字跑。
- brief 的 style 一栏写明翻掉了哪几条，或为什么刻意保留。保留时把力气花在「一次转折」和「数字的出处」上——这两样才是它和普通字幕视频的分界。

## 适配

- 用途：竖屏/横屏信息流新闻、政策与统计的解释、行业数据的短视频版。
- 内容：有一个反直觉事实、且每个数字都能追到出处的主题；需要静音观看的场景（通勤、地铁、会议室投影无声）。
- 时长：35–90 秒最顺，超过 2 分钟要再给一次转折，否则节奏会变成念稿；16:9 按 1920×1080 设计，9:16 是**另一套版式**，不是裁切。

## 技术路线

- 层极少：实拍/原件底 → 底部渐变 → 账本卡或图表 → 字幕块 → 角标。全部用 `add_element` 叠，`add_scene` 分镜，一个镜头一个 scene。
- 字幕用 `set_subtitles` 落底（保证可读与导出），逐块砸入的动效在本工具里用 `add_element` 文字块复刻，两条时间线必须逐拍对齐；本工具不承诺字幕组件自带你这种分块动画。
- 计数器：本工具不承诺内置滚动数字，用文本元素逐帧改值近似，靠 `preview_frames` 抽帧核对临界帧不抖。
- 定格：把该帧截成图片元素压住画面，再叠白闪、顶推和角标记。
- 素材进 `upload_asset`；画风落 `set_theme`/`apply_style`；旁白 `tts_narration`。先 `preview_frames` 逐拍看静帧（字号、断行、出处是否同框），再 `render_preview_clip` 看动（切点是否踩拍、有没有空白首帧）。

## 材质与渲染

- 版式是 1920×1080 的固定分区：实拍满幅出血，**不许把竖屏素材左右补黑边塞在中间**；字幕卡左边对齐 x=120，中文基线 y≈948，英文基线 y≈1014，一种语言一行、永不折行。
- 频道标：左上 x=96 y=52，高 46px，黄块 + 虚构频道名 + 中英小字主题。来源标签在它下方 y=108，36px，白"来源" + 暗色标签，只出现在数据与原件镜头，0.2s 滑入。
- 素材署名在右上 19px、压在 50% 暗片上；下三分之一 x=120 y=742、高 96px，黄条 + 标签 + 一行英文，只给地点、日期、人物，**不给主句**。
- 渐变：底部 0→84%（自 y=560 起）+ 左下角一团柔暗径向；顶部 200px 内 55%→0，垫在频道标与署名下；数据卡用更浅的一版，从 y=820 起。
- 图表与信息图在画面中线右侧，右侧出血到边；它们的标题与出处放左上，**永不居中**。
- 图表与原件：折线逐段画出来，关键点给更大的圆点 + 0.7s 扩散环 + 块标签；柱从左一根根长（如果第一根是重点，就让它更慢更长）；原件页按 220dpi 当白纸铺在暗桌上（±1–2° 轻斜、软影、暗角）慢慢推，荧光笔框按原件坐标量（1 pt = 3.0556 px），本工具不做混色就退成 40% 透明黄，从左扫 0.3–0.5s，读出的数字在纸旁重排成黄块；地图用 Albers 投影、同一色相五级、无数据的州 `#5E5C55` 并给"未单列"图例，主角州黄描边 + 引线 + 标签，镜头朝它推近。
- 9:16：字幕放在 1080×1560 的实拍带下方（横素材可放大 ≤1.5×），分块在这版里叠成两行（一行规则只属于 16:9），频道标与来源标签移进顶部安全区。
- 调色统一一条：`contrast(1.07) saturate(0.92) brightness(0.98)` + 6% 暖色柔光层（原件 4%）；母版留一点轻颗粒。
- 放大上限：现代实拍 ≤1.5×（上传前按最终尺寸裁好、锐化），照片 ≤1:1，档案素材 ≤2.5×；推近不许越线——已经是 1.5× 的 720p 素材就**不要推**。
- 字幕、数字、图表永远是矢量，不用放大后的实拍凑；台标用裁切去掉，**绝不拿字幕盖住它**；可辨认的私人信息（电话、蜂箱上的名字、车牌）打码；带硬字幕的镜头直接弃用。
- 素材授权：先问用户有没有自己的实拍、照片、原件、数据（连同权利）；画面上只走 CC0、公有领域、CC BY（作者/标题/许可写进画面署名），**不用** CC BY-SA、"no known restrictions"、来源不明的转载、上色或"修复"版。美国联邦机构（USDA、USGS、NASA、NOAA、NARA）雇员作品属公有领域，但要确认没署承包商；Internet Archive 只取页面明写 PD/CC0/CC BY 的条目，1931 年前美国作品即 PD；地图形状用 Natural Earth。
- 人：可辨认的私人不给特写、不给慢动作，公众人物与新闻当事人可以；下载前先告诉用户要取什么、从哪取、什么许可。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 墨底 | `#0E0E0C` | 卡面文字、暗部、被划亮后反转的字 |
| 账本纸 | `#151512` | 数据卡纸面（比墨底浅一档，仍属暗部） |
| 象牙 | `#F7F5EF` | 字幕、正文，其他一切 |
| 灰 / 死灰 | `#8D8B83` / `#5E5C55` | 标签与单位 / 不重要的柱、无数据的州 |
| 蜜黄 | `#FFC21A` | 重点、增长、高亮——一屏只有一处 |
| 红 | `#FF4A3D` | 亏损、尖峰、那个坏数字 |

- 黄不是装饰，是**论点**：一帧里黄只允许出现一次（关键词块、或那个决定性数字、或那条分隔线）；红只给"坏"和"转折的尖峰"，一屏最多两处，且不许落在本身是红色的物体上。
- 频道名可以换主色，但**全片只许一个强调色**，换上就替掉黄，不能黄加另一个。

## 字体

- 中文：极粗无衬线，字幕 88px（裁决句 110px），字重要 900 级。本工具用 `"Inter Tight"` 打头、中文落到 `"Microsoft YaHei"` 加粗近似原字族的 900 字重（本工具没有 Noto Sans SC，不承诺完全一致）。
- 英文：`Inter Tight` 500，33px，象牙；数字用 800 + 定宽数字格，滚动时才不抖。图表标题中文 ≤6 个字（一个镜头里要读得完），配一行灰色英文。
- 每行中文 ≤ 约 14 字；写不下就拆成两条字幕，**不是**缩字号。
- 字幕停留 ≥1.8s，理想是旁白时长 + 0.6s；中文是能在这段时间读完的转述，英文是口播原句（数字用阿拉伯数字），不是中文的翻译。

## 运动

- **切点锁 120 BPM 半拍网格**：所有切都在 0.5s 的整数倍上。实拍 1.5–3s；数据卡与原件 3–4.5s；带对比的镜头要停到每一项都完整在屏 ≥2.5s。
- 字幕**跨切**：一句话可以跨两个镜头（画面换、字不换）；即使镜头 1.5s 一换，字幕最多约 2.5s 才换一次。**读的时间定字幕钟，不是镜头长度。**
- 砸入：每块比前一块晚 0.12s；1.3→1 用 0.13s 的 back 曲线（回冲 1.6），不透明度 0.04s 内到满；关键词的黄块 0.12s 从左擦到右，字同时转墨色。
- 英文行：0.18s 内淡入并上浮 10px，比第一块晚 0.1s。
- 允许的转场只有这几种：硬切（默认）；转折与定格处 1–2 帧白闪；卡片带速度线从右滑入 0.18s；对切从分隔线张开；三格 0.1s 错开升起；元凶处 0.3s ease-out 顶到 ~1.25×；以及照片从地图轮廓里长出来的遮罩转场。
- 节奏底线：每个镜头 0.5s 内必须有一个强动作；任何一帧不许平超过 1s（滚动计数、划线、荧光笔扫过、慢推都算活）；转折之后给一次 2–3s 的屏息；全片两处真空。

## 画面怎么活

- 事实的顺序固定：**实拍（感觉）→ 卡上的数字 → 说这句话的原件那一行 → 后果**。数字和它的来源标签必须同框。
- 每换一个事实，上一拍的结论留在画面里当参照：观众永远知道自己在看第几个数、离结论还差几步。
- 屏息段落用"只有字幕没有旁白"的一拍——这是这个风格的原生招，专门留给转折之后。
- 图表和地图自己在动：折线逐段画出来、柱从左一根根长、地图上的州一个一个被填色，画面就不需要靠镜头运动续命。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 硬切到下一张脸/下一只手 | 事情在推进，来不及解释 | 事件、现场、时间紧 |
| 0.3s 顶推 + 圈出 + 引线标名 | 就是它，元凶 | 病虫害、零件、责任人 |
| 定格 + 白闪 + 饱和度掉到 45% | 停一下，这是问题 | 转折、反常识 |
| 黄线横扫、扫过处变暗 | 比例、占比、"只剩这些" | 百分比、损失面 |
| 从分隔线张开对切 | 两件事被放在一起量 | 前后、方案、涨跌 |
| 三格错开升起、逐个点亮 | 三条并列的原因/路径 | 归因、选项、步骤 |
| 卡片从右滑入 + 卡内极慢推（×1.025–1.03） | 下面是账，别走神 | 数据、明细 |
| 地图推入 → 该地照片从轮廓里长出来 | 从统计回到地面 | 地域差异、产地 |

取景：贴得近、主体偏中心、实拍不留呼吸空间；第一帧就要有可读主体，0.5 秒内第一个强动作。转场就是切，不做叠化、不做翻页、不做 3D 翻转。

## 声音调色板

- 旁白：一个人，语速快，`tts_narration` 语速 1.1–1.17（再快就开始念错专名），压缩过，比音乐高约 8dB；数字在文本里写全（"一百三十万箱"，不写"130 万"）。
- 音乐：120 BPM，采样音色的小编制——底鼓踩拍、踩镲在反拍、八分音符电贝斯、十六分音符马林巴固定音型、反拍颤音琴和弦、钟琴点缀、大数字上铜管短促断奏、转折用定音鼓 + 吊镲。人声下压约 45%。
- 结构：帧 4 给钩子重音；进转折前**硬停进静音**（只留自然声和一个问句）；转折落在铜管大调重击；威胁段转半速 + 低弦；尖峰前军鼓推进；裁决前第二段短静音；裁决给带钟声的大和弦。
- 拟音：每一处图形动作都有声——字幕块砸入（click + 闷响）、计数器哒哒（每 45ms 一下）、卡片滑入的 whoosh、荧光笔的吱声、定格的快门、大数字上的印章闷响、标签的 pop、地图填色的细 tick、地图推入的 riser。
- 自然声：主体场地的原声（蜂群、车间、街道），定格前 0.3s J-cut 先进，结尾垫在底下，**不许压到听不见**。母版 −14 LUFS，真峰 −1.2 dB。

## 原生手法

1. **帧 4 钩子**：一句 kicker，然后黄块里一个巨大数字 0.45s 滚到值，再给单位和主体词。
2. **分块砸入 + 唯一黄关键词**：一句一行，2–3 块，关键词只一个。
3. **比例靠变暗**：黄线扫过实拍到那个百分比，扫过的转灰变暗，数字出现在暗的那一侧。任何"X% 的…"都能用。
4. **原件说了算**：荧光笔划亮 PDF 上那一行，数字随即在纸旁变成黄块重排。
5. **定格提问**：画面停在观众正想问的那一帧，音乐切成静音。
6. **账本对切**：两个计数器并排赛跑，都停稳之后才盖章给出差值。
7. **点亮三格**：三种方式 / 三个原因，念到哪个哪个亮。
8. **顶推 + 圈**：顶到元凶，画圈，拉引线标中文名 + 拉丁名。
9. **地图落地**：地图推入一个区域，然后该地的照片从这块轮廓里长出来。
10. **黄色账本页划过**：黄纸从左 45% 擦过实拍（账本换成黄色那版），标题砸下，英文标题与日期戳跟上，页面往左擦走，标题直接变成频道标。

## 变化空间

- 每一支由 agent 决定：主题、那个转折、把哪些手法花在哪里、素材、虚构频道名与它的主色（一屏一个强调色的规矩不变）、标题。
- **三种结构**：倒金字塔 + 中段转折（坏数字 → "真的吗？" → 原件说的相反 → 为什么）；三条清单、第三条翻盘；数字倒计时，最后一个才是关键。
- **三种开场**：帧 4 最大数字；第一秒划亮原件标题；定格在事件现场 + 一个问句。
- **三种结尾**：实拍上两段式裁决字幕、静音之后音乐回来；回到钩子那个数字、重新读一遍；最后一张数据卡的关键点变成收尾字幕。

## 坑

- **字在镜头里读不完** → 图表标题压到 ≤6 个汉字；装饰性日期戳必须在别处还能读到；会变字的标签（计数器）要按最终值检查宽度。本工具不承诺自动读时检查，改用 `preview_frames` 逐条抽帧数。
- **16:9 里中文折成两行** → 立刻像 PPT。改：拆句成两条字幕。
- **旁白赶着切点跑** → 话尾贴着切点会显得仓促。改：提语速（≤1.17）或把句子改短；TTS 还会在同音字上翻车（"requeen the weak" 念成 week、"varroa mite" 成 might），换写法（"给老群换新王"、"varroa 螨"）并逐条听回放。
- **用词与素材都要对得上源材料** → 报告说"压力源"就不能说"杀手"，四个季度亏损相加不是"年度净亏"；说明性画面（别处的蜂场）不许挂它没有的地名，照片的年份写进署名。
- **转场首帧是空的** → 对切/三格/片头要在切点前 0.1–0.15s 就开始动，保证第一帧已有画面。
- **台标还在** → 裁掉，绝不用字幕盖；盖上去比露着更业余。
