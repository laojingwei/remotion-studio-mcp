# 积木玩具（brick-toys）

> 一句话本质：一个积木世界搭在真实桌面上——微距镜头、定格动画，魅力来自玩具世界与真实房间之间的落差。
> 参照（只学语法）：桌面定格积木片、微距玩具摄影（柔光箱打亮光泽塑料、浅景深、把真实器物当风景）。不照搬任何角色、场景、音乐，**不出现任何品牌名**。

## 本质 / 不是什么

- 本质：**硬边塑料积木搭在真实表面上**——木桌、餐桌、窗台。有光泽的 ABS、每块顶面都带圆凸点、分模线与接触阴影把接缝压暗。
- 本质：**微距 + 逐格**。镜头贴得很近，景深很浅，动起来是一格一格换姿势，不是连续的弹。
- 本质：**落差**。玩具是饱和塑料，房间是自然的低饱和的木头、纸、陶瓷、日光。玩具越小，房间越真。
- 本质：**被玩过**。手印、划痕、翻倒、散落的零件；不是货架上的样品。
- 本质：**火、烟、水、光、天气、天体都拿积木搭**——板、圆砖、半透明件，逐格抖动或重搭。没有粒子系统，没有软渐变。
- 不是 `soft-3d-toy`：那是圆角哑光、黏土/潮玩、挤压拉伸的弹簧动画、渲染出来的可爱。这里是**硬边、高光泽、绝不形变**。
- 不是 `pixel-diorama`：没有像素、没有等距棋盘、没有漂浮小岛。这里的地面是**一张真实的桌子**，镜头是斜的、贴的、浅的。
- 不是精致的玩具产品渲染：没有无缝背景、没有完美打光；有灰尘、有指纹、有挡在镜头前的零件堆。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 凸点顶面 | 每块顶面一排圆凸点，根部一圈细唇边，边缘一道亮线 | 组合、接口、标准 |
| 硬塑料高光 | 清漆面把光反成一块干净的亮斑，分模线上一道细亮 | 品质、工业、精密 |
| 接缝被压暗 | 砖与砖之间一条深缝，凸点根部一圈暗 | 堆叠、层级、结构 |
| 真实房间在背后虚掉 | 杯子、绿植、键盘化成一片色块，只有积木是实的 | 小与大、玩具视角 |
| 真道具当风景 | 键盘当城市路网、绿植当丛林、咖啡渍当洪水 | 隐喻、把大问题缩小 |
| 逐格的手感 | 两帧换一个姿势，光轻微闪，每帧有极小位移 | 手工、耐心、怀旧 |
| 吸附落位 | 零件沿弧线飞入，"咔"一下带一粒凸点的过冲 | 拼装、上线、组合 |
| 塌成一堆零件 | 整座绕底边倾倒，散件各自落地、弹一下躺平 | 失败、重启、拆解 |
| 俯视的规划 | 正上方看一块底板，零件像地图一样排开 | 规划、分类、布局 |
| 拉开才看见是玩具 | 一直以为是世界，后拉才发现是桌上的一小块 | 规模、自嘲、年终 |
| 半透明件透光 | 橙/黄/透明件做火、灯、水、玻璃，边缘亮 | 能量、夜晚、天气 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 凸点、吸附、塌落这三样最容易被认出来，也最容易被用滥——第二支片子换一组。
- 先定真实表面和它上面的两三个真道具，再决定搭什么；反了就会做成"没有房间的积木"。
- 角色是用砖拼出来的（1×1 柱做腿、2×2 砖做躯干、圆砖做手臂、圆 2×2 做头盔），凸点上没有字母，**不用任何商标与小人剪影**。

## 这个风格最俗的版本

- 画面：白桌子上一个积木小人站上积木火箭，"3、2、1"倒数，火箭喷出积木火飞走，最后一句"想象力无限"。
- 声音：木琴 + 口哨 + 一段上扬的铜管，全是"可爱"。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么刻意保留。保留时把力气花在**房间的存在感**（木纹、窗光、灰尘）、**一次真的塌落**和**最后那次拉开**上。

## 适配

- 用途：讲"一块块搭起来"的东西——从零到一、系统怎么组成、拆开看里面、失败后重搭。
- 内容：产品与系统架构、创业与团队、教学拆解、组织重组、复盘、儿童与创造力（小心做成广告）。
- 时长：15–45 秒最舒服；超过 60 秒要换 2–3 个真实表面，否则一张桌子会闷。
- 不适合：要庄重、要权威、要堆大量文字的题；也不适合需要真人出镜的片子。

## 技术路线

- 主体：`add_scene(type="scene3d")`，先 `get_guide("scene3d")` 看 `graph` 写法。几何只有 14 种组合体：砖 = `box` + 顶面凸点（`cylinder` 小柱 + 一圈薄唇），圆砖用 `cylinder`，板用矮 `box`，玻璃件用 `material.type="physical"` 的 `plane`/`box`。
- **尺寸守住**：1 单位 = 1 个凸点间距 = 8 mm；砖高 1.2、板高 0.4、倒角约 0.045 个凸点；**1 米 = 125 凸点**。真道具按这个比例摆，桌面尺度才不会错。
- 两个硬上限决定了怎么省：**一场最多 48 个节点**（砖墙别一块块堆，整面用一块 `box` + 凸点 `map` 贴图，只把镜头会凑近的 3–5 块做成真几何）；**每个节点最多 8 段 `anim`**（逐格动作因此靠"每 2 帧一段"只能演约 0.7 秒，长动作要拆幕，或把角色拆成躯干/双腿/双臂几个枢轴各担一段）。
- 真实表面：桌面 = 大 `plane` + 木纹 `map`（先 `upload_asset`），粗糙度按木头上调；真道具能用实拍图就用实拍图（`upload_asset`，放 `plane` 上或 2D 层），拿不到就做**剪影/色块**，不许画成插画。
- 光：本工具没有面光源，柔光箱的矩形高光是做不出来的。退一步：用内置程序化棚拍环境（天空梯度 + 主柔光 + 冷侧板 + 地面反弹）打底，再加一盏 `directional` 主光从一侧偏上定影子（暖白，阴影范围按镜头收紧才脆），环境强度压到约 0.45 保持对比——**不用暖钨丝环境**，白砖会变橙。
- **景深怎么近似**：`post` 里没有光圈，`scene3d` 也没有真 DOF。做法是三层——背景用 `background.mode:"image"` 放一张本来就浅景深的真实房间/桌面照；前景在下缘压 1–2 个 `filter` 模糊过的元素（虚掉的零件、虚掉的桌沿）；焦点永远落在角色头部或被放下的那块砖。近景多虚、中景少一点、全景最少。
- **定格怎么近似**：没有 step 缓动。角色与积木按 12fps 给姿势（24fps 工程就是**每 2 帧一个关键帧**，段间 `linear`，中间不插值）；相机、焦点、火、飞行器保持连续——相机也步进就成了抖，不是手感。每格再给极小扰动：位移 0.1–0.3 个凸点、旋转 0.5° 以内；每 6–10 格让主光亮度闪 2–3%。
- 验收：`preview_frames` 逐拍看静帧（重点看接缝的暗、凸点的高光、影子够不够脆）→ `render_preview_clip` 看动。配色字体先 `set_theme` / `apply_style` 定死；旁白 `tts_narration`，字幕 `set_subtitles`，音效与 BGM `add_audio`；2D 层只放字幕、标题和必要读数（`add_element`），不许压住被放下的那块砖。

## 材质与渲染

- **目标规格（照着这个方向调）**：ABS + 强清漆（clearcoat ≈ 0.85，清漆粗糙度 ≈ 0.07）；粗糙度带淡淡指纹与划痕（底 ≈ 0.17，划痕最高 ≈ 0.65）；边缘倒角要能挂住一道高光。
- **本工具能做的**：`metalness` 0.05 上下、`roughness` 0.15–0.22 才有"硬塑料"的锐高光；底板改成 `roughness` 0.5 以上（哑光），否则整块板把环境反成一片彩色糊。没有清漆层、没有倒角、没有 AO 开关：倒角靠凸点底部一圈薄 `cylinder` 唇边 + 强侧光近似；接缝的暗靠**砖间留 0.02 个凸点的缝**和贴地阴影，别声称开了 AO。
- 环境：中性日光影棚（内置程序化环境或室内 HDR，`envIntensity` 0.4–0.5），绝不用钨丝室内。
- 后期与采样：`post` 里 tone mapping 保守、`exposure` 1.0 左右、`bloom` 只喂半透明件和灯（0.1–0.2），轻微冷调、柔和对比、饱和度 +10%，**白必须读成白**，不能发奶。源规格 2× 超采样（渲 3840×2160 出 1080p），本工具没有该开关，改成**把镜头推得更近、把凸点做大**，让细边不落在采样极限上。
- **特效即积木**：火 = 橙黄板与圆砖逐格换形；烟 = 灰白圆砖堆起再拆；水 = 半透明蓝板；闪电 = 透明件 + 一格全亮。没有粒子、没有软渐变蒙版。

| 用途 | 值 | 含义 |
|---|---|---|
| 红 | `#C91A09` | 最饱和的主角：主体结构、警示 |
| 蓝 | `#0055BF` | 第二主色：水、天空、机械 |
| 黄 | `#F2CD37` | 亮点、光、发现 |
| 绿 | `#237841` | 生长、通过、植物 |
| 白 | `#F2F2EE` | 墙、纸、留白 |
| 黑 | `#1B2A34` | 结构、剪影、字 |
| 木桌 | `#C8A87B` | 真实表面，低饱和 |

- 一套玩具色 + 白黑灰 + 砂色/藕粉这类柔和色；**一个搭建物一个主色，最多加一两个配色**；角色和主角物件用最饱和的那几个。
- 真实世界保持自然低饱和：木头、纸、陶瓷、日光。饱和只属于玩具——落差的另一半靠房间的安静。
- 半透明件（橙、黄、透明、蓝）只给特效：火、光、水、玻璃。
- 白要偏冷分级，别被桌面的暖反光染成奶油。

## 字体

- 源用一款圆润的 OFL 字（Fredoka 一类）。本工具字库没有圆体，**改用 `Archivo Black`**：块面、粗、方，像拼出来的；中文用 `Microsoft YaHei` 粗。字距略松，标题一行不超过 8 个字。
- 标题像"被放上去的一块砖"：按 12fps 弹出（每 2 帧跳一下），不淡入、不缩放；副标题一行用一个砖色（红或黄）。
- 字幕挂在**玩具元素**上：底部低处的圆角深色胶囊（全片唯一允许的圆角，其余一律硬边）+ 文字旁一个小砖块图标（或一块印字的小板）；白字压深底，最多两行。第二个说话人（无线电、设备、旁白）换一个图标颜色或标签。
- 阅读时间 ≥ max(1.8 秒, 语音 + 0.6 秒)；字幕不许压住正在被放下的那块砖。

## 运动

- 角色与积木：**12fps 逐格（一拍二）**；相机、焦点、火、飞行器：**24fps 连续（一拍一）**。
- 积木沿弧线飞入，**吸附**时有一粒凸点的过冲，约 4 帧内回到 0；每一下吸附都是声轨上的一声"咔"（过冲写成中间关键帧，比 `easeOutBack` 可控）。
- 角色用**大而可读的姿势**保持几格：双臂成 V 是自豪、双手上抛是惊慌、低头是难过、跳一下是高兴。走路腿摆 ±0.55 弧度带一点上下颠；四肢绕关节转，**任何地方都不弯**。
- 倒塌用**预演算的好看刚体**：先绕底边倾倒，再各自受重力（比真实小的重力更好看），回弹 ≈ 0.3，有摩擦、最后躺平；一次算好，每次都一样。
- 允许极小的不完美（每格一点位移、光一点闪）；**砖永远不拉伸、不挤压、不变形**。全片都步进会像掉帧：只让人和砖步进，相机和光保持连续。

## 画面怎么活

- 画面靠"搭"推进：一块被放下 → 结构长高一点 → 换机位看它 → 再放下一块。每 2–3 拍要有一次落位、一次飞入或一次塌落。
- 待机时活的是房间：窗光缓慢移、灰尘在光柱里飘、主光轻微呼吸；**积木本身不动**（它们是硬的），动的是光和镜头。
- 每次落位都把上一步的结果留在画面里（阶梯式长高），观众始终知道搭到哪了；只有"等一块砖掉下来"和沉默允许静止。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 单块砖/单个凸点的极微距，房间在背后虚掉 | 玩具就是整个世界 | 开场；一个关键细节；一个零件 |
| 贴到角色视线高度的低角度 | 小角色变得英勇 | 野心；骄傲；对抗庞然大物 |
| 从整张桌子的高角度宽景 | 规模揭示：原来一直是玩具 | 总结；反讽；搭完了 |
| 低而宽的孤独构图，角色缩在角落 | 渺小、失败 | 挫折；等待；失去 |
| 正面近景，手与砖都在焦点上 | 亲密、决定 | 一个选择；一次修补；一件礼物 |
| 撞击时手持抖一下 | 物理冲击 | 倒塌；抵达；碰撞 |
| 跟着移动的物件横移，目的地在画面前方 | 奔向目标的动量 | 旅程；比赛；发射 |
| 正上方俯视 | 秩序、布局、地图 | 计划；分拣零件；从上看一座城 |
| 从真道具拉到积木（或反向）的变焦 | 一帧里两个尺度 | "大世界，小造物者"；对比 |
| 绕着搭好的成品转一圈 | 骄傲、检视 | 产品；纪念碑；成果 |

取景：画面边缘别堆零件（零件堆最爱挡镜头）；每个镜头都查头顶空间；**每个真道具都要对着每一个机位查一遍**——给这个镜头摆的东西会溜进下一个镜头的背景。
切点落在拍上或小节上，一次吸附可以当切点。**不用通用叠化**；转场可以是：一块砖贴上镜头挡住、沿桌面甩一下、从一个场景拉出去落进下一个。

## 声音调色板

- 乐器：小型、原声、俏皮——钟琴、玩具钢琴、拨弦、尤克里里、口哨、拍手、口风琴；规模揭示时来一下铜管或弦乐上扬；悬念用一记心跳鼓。**按画面剪**（卡小节、按小节跳切、接缝处音色相近），不是垫一条循环。
- 拟音（可合成）：失败前的塑料吱嘎、极小的塑料脚步、一堆零件同时落下的哗啦、**积木咔哒**（短瞬态 + 2.9 kHz 与 4.6 kHz 附近的共振）、落在木头上的闷响、翻零件堆的沙沙、抛出的 whoosh、发现时的一声铃、砖在纸上滑、马达与引擎用滤波噪声做。
- 沉默是工具：失败或意外时把音乐**直接切死**，只留房间底噪和一个小真实声音（钟表、冰箱、远处的鸟）；大时刻之前也可以撤掉音乐，只留一记脉冲或倒数。
- 人声：温暖的讲述者，句子短、留气口；次要声音过设备滤波（带通约 380–2800 Hz + 轻饱和），可加提示音。混音：人声压缩、音乐在人声下压约 40%、整体 −14 LUFS。

## 原生手法

- **拼起来**：情节本身就是一次搭建，零件沿弧线飞入、咔一声归位。适合：公司拼出第一个产品；一条街一间间长起来；一道菜一样样凑齐。
- **碎了不心疼**：塌掉的东西变成零件，零件再变成别的东西。适合：失败后的转向；回收；团队重组。
- **桌上的玩具**：真道具在玩具尺度下变成风景。适合：键盘当城市路网；绿植当丛林；咖啡渍当洪水。
- **手工定格**：12fps 的姿势、极小的不完美，连火和水都是积木做的。适合：用积木火焰讲一道菜；积木火山做科学演示；天气报告。
- **重搭成别的**：同一批零件被重新排列，变成另一个东西。适合：一次转行；改造前后；一个词重新拼。
- **规模揭示**：一路后拉，直到整个世界变成桌上的一小块。适合：一个仍然很小的雄心；年终回顾；孩子的想象。

## 变化空间

- 结构：**一本图录**（一拍一个搭建物，回答同一个问题，最后排成一排）；**两个搭建者**在桌子两端，作品往中间长；**一次拆解**（成品被一块块拆开，讲里面是什么）。
- 开场：一只手把一箱砖倒在桌上，零件堆自己塌成第一个形状；先给一个真道具（杯子、手机），再变焦到它脚下的小世界；正上方看一块空底板像地图一样被填满。
- 结尾：**剩下一块**被捏在特写里，问题没答；房间灯灭，只有一扇积木窗还亮着；一只**真人的手**伸进来把角色拎走。
- 每支由 agent 决定：结构、有没有角色、真实表面与道具、开场、结尾、镜头路径、节奏、调色（在配色逻辑内）、音乐。

## 坑

- 用了暖钨丝环境 → 白砖发橙。改：中性影棚环境 + 轻微冷调。
- 大底板上了清漆式的锐高光 → 把环境反成一片彩色糊。改：底板改哑光。
- 第一次渲出来平、边缘还毛：光太均、没 AO、采样不足、相机还在步进。改：主光 + 低环境、砖间留缝和贴地阴影、把凸点做大、相机回连续。
- 光圈感开太大 → 中景主角也糊了。改：按景别收，近景最虚、全景最实。
- 快速升起或飞走的物体变成一个点贴在空墙上。改：跟拍它，把目的地留在画面里。
- 用球面切出来的弧形透明件会消失在圆柱件里。改：用开口圆柱面板（半圈 `cylinder`，`side:"double"`）。
- 真道具摆在后面某个镜头的轴线上，溜进背景。改：每个机位都对着道具表查一遍。
- 随机抖动被当作材质或颜色索引时会出负值 → 材质未定义直接崩。改：夹到 0 以上。
- 做成了"没有房间的积木"：背景是纯色无缝。改：桌面木纹、真道具、窗光，至少留一样在焦外。
