# 纸片立体书（popup-book）

> 一张真实书桌上摊着一本硬壳书，翻开后纸世界从页面里弹起来：米白粗描边的纸片小人，在真台灯下投出镂空的影子，被真镜头拍虚。
> 参照（只学语法）：Sabuda / Reinhart 的立体书机关（V 折、后向前立起、拉条）、平面剪纸角色加打字气泡的电子游戏语法、微距「桌上一座小世界」摄影。不照搬角色、logo、UI 和音乐，片子里也不点名。

## 本质 / 不是什么

- 本质：**两个世界同框**。真实世界按人的尺度——写实桌面、HDRI 房间光、几件真物件（杯子、笔、手）、微距浅景深、软接触阴影；纸的世界只从桌上那本硬壳书里翻出来。
- 本质：**纸是平的，光是实的**。纸片是平的、饱和的、带描边的卡通；让它变真的是光、镜头和影子——镂空形状的影子、真实镜头的虚化。
- 本质：**落差就是卖点**：3–5 cm 的小人站在 0.3–0.5 m 宽的页面上，旁边是一只真实的水杯。**一切都是机关**：弹起、折、卷、抽拉、绳吊；没有软体，纸从不「咕叽」一下。
- 不是 `paper-cut`（纸艺分层）：那是**整个世界都是纸**——4–8 层卡纸、层间投影、没有真实房间。这条必须有一间真实的房间，纸只是桌上那一小块；少了真实世界的一半，风格就塌回纸艺分层。
- 不是纸雕灯箱、不是背光剪纸剪影（没有一色镂空、没有逆光），也不是 3D 卡通（没有任何东西被建模成圆的，看着立体的部分都是几张平卡加折角）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 两个世界同框 | 真实桌面与书在焦外，纸世界在焦内，两者共用一个镜头 | 虚拟与现实、构想与落地 |
| 米白粗描边 + 灰卡纸边 | 纸片外一圈米白边，再外面一圈灰，切口看得出厚度 | 任何主题（近乎身份证） |
| 弹起的立体卡 | 卡片绕下边缘立起、由后向前依次站住 | 开场、新章节、新场景 |
| 镂空剪影影子 | 影子是角色的剪影形状，不是矩形 | 真实感成立与否的证据 |
| 微距浅景深 | 角色实、桌面半虚、房间大虚，焦平面在眼睛 | 小与大、亲密感 |
| 硬壳书与卷页 | 布封面烫金、书页块有页边线、一张内页卷着 | 版本、章节、翻篇 |
| 拉条机关 | 百叶翻、棍上太阳、滑条、绳吊件 | 变化、开关、预测 |
| 页面边缘 | 角色跨出去/真实物件跨进来 | 打破第四面墙、产品落地 |
| 真物件演一个角色 | 台灯当太阳、杯子当塔、真时钟当时间 | 日常、居家、真实时间 |
| 单向月牙阴影 + 手抖轮廓 | 每张纸只有一块硬月牙影，形状绝不完美 | 纸感、童书感 |
| 跨页一色族 | 每翻一页换一个主色，红/黄/金反复出现串联 | 章节、季节、阶段 |
| 打字气泡与评级 | 白卡气泡、墨线、尾巴指向说话者，字母蹦出来 | 教程、问答、小胜利 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- **第一行是身份证**：没有「两个世界同框」，这就不是这条风格，是 `paper-cut`。任何一支片子里必须看得见真实桌面、真实光或真物件至少一整拍。
- 影子和景深是同框的技术证据，缺一个也会退回纸艺分层；保底先做这两条，再谈别的。十二条不要全上，全上就变成机关博览会。

## 这个风格最俗的版本

- 画面：一页绿草甸立起来，小人走两步，翻页换成赭石沙漠，最后书合上，封面打出片名。
- 声音：music box 铺底 + 翻页 swish + 打字 blip，全套照搬一遍。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么刻意保留。保留时把力气花在「真物件参与剧情」和「镜头怎么进出纸世界」上。

## 适配

- 用途：品牌故事、产品「从纸上到现实」、教程与讲解、儿童内容、活动开场、年度回顾。
- 内容：需要**落差**的主题——虚拟与现实、草案与成品、小与大、计划与现场。纸世界负责「本来想的样子」，真实房间负责「实际的样子」；不适合精确数据、严肃新闻、暗调惊悚，也不适合要「高级留白」的极简品牌片。
- 时长：15–90 秒最舒服。超过 90 秒要改成多跨页结构，一页一个色族，靠翻页分段。

## 技术路线

- 三层，各管一件事：**房间层**（桌面、书、真道具，`upload_asset` 一张实拍或渲染好的底图，`add_element` 放进去当底；要视差就 `add_scene(type="scene3d")` 当背景板）；**纸世界层**（`add_scene(type="scene3d")` 里摆一组平卡：正面图案、背面素纸、三角龙骨）；**光与镜头层**（影子、景深、bloom、暗角、暖化）。
- 立体感靠「平卡堆叠 + 折角」，不靠建模：前卡、后卡、夹在中间的层，一片就是一张图。
- 影子拿不到真正的镂空剪影时：把每张卡的 alpha 单独出一张，收缩 1–2 px、填成统一暗色（比纸面暗 45–60%）、沿光方向偏移、按离页面高度加模糊，当独立元素压在页面下方。矩形影子必须删掉。
- 景深拿不到真镜头时：按 z 分三档虚化——角色与近处弹起件实，桌面半虚，房间背景大虚；焦平面永远在角色眼睛上，换焦 = 换哪一档是实的。色调保持中性，不要电影感的强对比，纸色是这条风格的命，任何 LUT 都不能把它挪走。
- 先静帧后动：`preview_frames` 逐拍看卡的边缘、影子方向、纸色；`render_preview_clip` 只看运动和节奏，别拿它定颜色。
- 落地：`set_theme` 定色板与字体，`apply_style` 套本风格 preset；旁白 `tts_narration`，字幕 `set_subtitles`，音效与 BGM `add_audio`。

## 材质与渲染

- **真实单位（米）**：页宽 0.3–0.5 m，角色 3–5 cm，近平面几毫米。为了这一点，纸片不能是「一张 1080p 的图缩一缩」，而要按比例画。
- **纸**：250–350 g/m² 卡纸，厚度 0.3–0.5 mm；弯折半径约等于 1 个纸厚（≈1 mm），所以折痕是一条锐线，不是圆弧。翻页的卷曲半径 2–4 cm。
- **剪边三层**：深棕轮廓 → 灰卡纸边（略向下偏移 = 厚度）→ 宽米白描边 → 一层共用纸纹压在最上（`source-atop`，很淡）。
- **墨**：只用一种深棕，**绝不用纯黑**；粗轮廓 + 细细节线；圆角连接。阴影 = 一块硬月牙（先填阴影色，再偏移填本色），不做渐变。形状用低谐波噪声抖动过，不要完美几何；脸尽量简单（两个点 + 一条线）。
- **弹起件**：正面画、背面素纸，同 alpha；任何「3D」都是几张平卡（前后层、三角在龙骨上折）。
- **书**：布封面 + 烫金标题（粗糙度/金属度贴图）、书页块带页边线、一张卷起的内页；硬壳 = 布面 + 2–3 mm 灰板；弹起时立起的封面板与下页成 **~90°**，书脊被机关撑住，摊不到 180°。
- **房间**：HDRI 环境 + 柔化背景、真木或布、几件真道具；台灯 2700–3000 K 当主光，窗光 5000–5500 K 当冷侧补光，比大约 3:1。
- **接触阴影**：贴页处硬、离页 2–3 mm 就迅速变软，模糊半径 ≈ 离页面高度的 1.5 倍。
- **景深**：f/2.8–f/4、1:2 微距，景深只有几毫米到 1 cm；焦平面在角色脸上，桌面往后 10 cm 就已经虚透。后期 bloom → 暗角 → 暖化，三步都很轻，纸的高光不许爆。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 画布底（台灯照到的桌面） | `#EFE3CE`，暗部到 `#3B2E24` | 字幕条、封面底；真实世界偏暖，给纸让出亮度 |
| 纸面米白 | `#FBF4E4` | 描边、书页、气泡卡 |
| 墨 | `#3B2A1E` | 唯一的线色，绝不纯黑 |
| 卡纸灰 | `#8C7F72` | 切口厚度、卡背 |
| 主色（每跨页换） | `#4F8FA8` | 天蓝草甸；也可是粉紫 + 薄荷、赭石 + 绿松石 |
| 强调红 | `#D2452F` | 一页最多两三处，跨页反复出现 |
| 强调金 | `#E0A93C` | 烫金标题、太阳、少数光点 |

饱和的童书色，**绝不荧光**；真实世界保持自然略暖，纸才有得跳。**一跨页一个主色族**，翻页同时换色；红、黄、金三个强调色贯穿全书，用来把散页缝成一本。故事之外（未开始、已结束）的页面失去颜色：石墨画在奶油底上。夜晚只换纸面的画法，真实台灯始终是暖的。

## 字体

- 圆润无衬线：有 Fredoka 用 Fredoka，没有退到 `Inter`；中文用站酷快乐体，退到 `Microsoft YaHei`。厚重展示体：Lilita One，退到 `Archivo Black`——封面、横幅、动作字用。
- 故事书衬线：IM Fell English，退到 `Georgia`——标语、片名下方那行小字。
- **字幕**：底部居中、约 40 px、奶油色 + 粗深棕描边 + 柔影；第二语言小一号放下面；停留 ≥ max(1.8 秒, 语音 + 0.6 秒)。
- **气泡住在纸世界里**：白卡、墨线、尾巴每帧指向说话者；过冲弹入，逐字打出、字母带 blip。
- **标题是纸物件**：卡纸牌用绳子吊下来、晃两下停住；书的封面本身就是片名。动作字（斜体展示体、渐变、双描边、放射线）少用，像游戏评级一样克制。
- 中文字体按用到的字子集化，改一次文案重新子集化一次；拉丁字体塞进中文字体的字体栈里。

## 运动

- on ones，60 fps（平滑的微距镜头值得这个帧率）；所有量都是 `t` 的纯函数。
- 纸动得**僵**，生命来自缓动：弹起用 `back()` 过冲（1.4–1.8），绳吊件用弹簧 `{2.0–2.6, 0.6–0.8}`，角色用挤压拉伸。
- **弹起由后向前**：延迟随离读者的距离增加；远件向后躺，近件向前折、面朝下；单件 0.35–0.55 秒，每层错峰 40–80 ms。收起来严格同顺序。
- 植物和轻道具绕底部摆 0.01–0.02 rad，别摇成海草。角色是平面卡按**量化姿态**切换（走相位、手臂、眼、嘴、视线、眨眼）；走相位跟着已经走过的距离，脚不许滑。
- 转身 = `scale.x` 翻转，**绝不用 `rotation.y`**。跳跃走抛物线，两端挤压，落地一蓬纸粉。
- 翻页：多段长条，弯曲沿长度积分，像真的纸一样卷，不是整片旋转。**房间绝不动**——房间一动，真实世界就变成布景，落差全没了。
- 禁：叠化、整页缩放转场、UI 那种弹跳缓动。

## 画面怎么活

- 一个机关接一个机关：弹起 → 立住 → 抽拉 → 换页。每个动作都配一个纸声。
- 真实世界永远在动一点点：台灯的光在纸面上有呼吸，窗外光斑缓慢爬过桌面，杯子里的水面晃一下，笔滚半圈。
- 影子跟着那盏「看不见的灯」走；纸片被气流吹得轻晃；书脊的阴影压在立起的封面板上。每一拍至少一个机关在动或刚停稳；只有「书静置」允许完全静止——那是用来做停顿的，别拿去填时长。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 平视微距横移、浅焦 | 站在角色这一侧、和它们一样高 | 走路、对话、追逐 |
| 上摇到跨页的 3/4 俯视 | 机关、地图、全局 | 翻页、换场景、讲计划 |
| 从人眼高度下降推近 | 进入书里那个尺度 | 抵达、进入系统某一部分 |
| 推到脸上 | 情绪 | 一个愿望、一次害怕、一个决定 |
| 从书里反打，拍虚掉的房间 | 页面之外的世界很大 | 好奇、外部威胁、读者在看 |
| 焦平面在纸与真物件之间来回 | 纸和现实碰上了 | 因果、真实产品落进纸故事 |
| 俯视摊开的跨页 | 棋盘、示意图、两栏对照 | 路线、中缝两侧的对比 |
| 拉条上的固定机位 | 机关本身即事件 | 前后对比、数数 |
| 起吊拉远、书变小 | 尺度、距离 | 余波、总结、时间过去 |

角色在焦内，房间物件当虚前景或虚背景；近处弹起件不要挡在镜头路径上。转场只有三种：翻页、合书再开、纸声上硬切。**书里永远不许叠化**。

## 声音调色板

- **纸拟音是签名**：翻页的 swish、卡纸的闷响、弹起的 snap（短正弦扫频 + 一点沙沙）、折与压痕、拉条滑动、脚步是极小的敲击带沙沙、百叶翻动、落线的 tink、书脊的吱呀、合书的闷响。每一个都能从页面的动作表里对出来。
- **角色说话 = 打字 blip**：一个角色一套波形和音高，每隔一个字母一声。**旁白**是一位温暖的说书人，句子像图画书；念的音和屏幕上的字可以分开。
- **音乐**：古怪、原声或玩具感——music box、拨弦、单簧管、钟琴、尤克里里、玩具钢琴、鼓刷。可选做法：真实房间里的段落换一条更暖的；把版权曲按小节内剪，让结尾落在画面事件上；用拉条的咔哒声当节拍源。
- **环境声与沉默**：房间底噪 + 一只时钟（这条风格里时钟很值钱）；纸世界每一跨页一条床。沉默 = 书静置、只剩房间底噪，用在关键翻页之前，或者一次犹豫。
- **混音**：人声高通 + 压缩，明显高于音乐；音乐在说话下平滑闪避；每条通道的 SFX 限幅；整体 −14 LUFS。

## 原生手法

- **书打开**：吱呀一声，封面板立起，世界由后向前弹起来。适合项目启动、开学第一天、一本食谱。
- **翻页 = 换场**：旧件折回去的同时新件弹出来。适合流程各阶段、农场的四季、传记的各章。
- **拉条机关**：百叶翻、棍上太阳、滑条、合页门、绳吊件。适合预报、旧办法与新办法、锁被打开。
- **纸当角色**：揉皱、抚平、重折、撕开、贴胶带。适合错误变成教训、回收、被否的草稿变成终稿。
- **页面的边缘，真物件演一个角色**：纸与房间互相跨越（角色走进桌上的手机、真物件掉进故事、画的东西成真）；台灯当太阳、杯子当塔、真时钟当真实时间。适合产品在家里、读者的存在、跨过第四面墙。
- **打字气泡与评级**：适合教程、小测验、一次小胜利。

## 变化空间

书、房间、角色（可以没有）、跨页与机关、开场、结尾、相机路径、每页的色族，全由 agent 定。

- **三种结构**：年鉴（一跨页一个月或一个阶段，每个机关都留在原地继续动，整本书越翻越热闹）；两本书面对面（角色隔着缝隙交换东西）；同一跨页反复拉（每拉一次是「怎么做出来」的一步）。
- **三种开场**：从翻到一半开始（一页已经卷起，我们直接落在第三章）；贴着中缝（低机位，第一件纸片从镜头上方升起）；先只有机关（拉条自己在滑，角色还没出现）。
- **三种结尾**：书合上（纸件逆序折回，一小口气流，然后静止）；只留一件立着（其余全折回去，只留下那张「就是它」的卡）；书架（镜头在很多本书里找到这一本）。

## 坑

- **绕 Y 轴一转就露馅**：正面转过去看见卡边，再转就看见空白背面 → 用 `scale.x` 翻转。负缩放还会交换正反面材质 → 镜像的道具另画一张。
- **单平面容器把内容挡住** → 后卡 + 前卡，内容夹在中间。
- **贴着镜头的前景弹起件糊满画面** → 挪开它，或者收小光圈（f/5.6）。
- **矩形影子毁掉一切** → 每张卡的影子必须是镂空剪影；薄卡上阴影偏移要小、贴图要大，否则起痤疮。
- **翻页转到背光就发黑** → 自发光的贴图必须等于颜色贴图。
- **ACES 会把纸色挪走** → 用中性色调映射；每一版都拿色卡对一次。
- **预览里纸边发毛、纸纹消失** → 多半是预览被降采样了；用 `preview_frames` 出全分辨率静帧再判断，别拿预览片定稿。
- **每帧重画角色** → 只在姿态变化时换图；姿态做成有限几张切片，切换而不是重绘。
- **中文字体子集漏字、拉丁字形缺失** → 改完文案重新子集化；拉丁字体放进中文字体的字体栈里。
