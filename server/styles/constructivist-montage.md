# 构成主义蒙太奇（constructivist-montage）

> 本质：档案影像、照片、文件全被印成同一张红黑双色海报，沿 −18° 斜轴切碎、放大、并置，论点由剪辑给出，不由插画说明。
> 参照（只学语法）：1920 年代苏联蒙太奇电影（城市交响、分屏、计数与机械节奏；A+B 生出概念的"理性蒙太奇"）与构成主义海报／摄影蒙太奇（红／黑／纸、陡斜轴、照片剪影配几何块、字即结构）。不照搬任何镜头、版式、口号与字形设计，也不在片中点名。

## 本质 / 不是什么

- 本质：**证据被重剪**。每张图都是关于真实主体的真实材料（档案胶片、照片、文件），论点来自它们怎么被切、怎么被排。
- 本质：**一张印出来的纸**。所有素材转入同一套双色印刷（暖墨→纸），红是唯一的颜色，且永远作为"印上去的元素"压在顶层。
- 本质：**节拍就是剪辑师**。切、砸、擦、计数都落在 120 BPM 网格（或配乐速度）上；段落靠把镜头长度减半来加速。
- 本质：**字是结构**。字与数字是梁：骑在 −18° 的带上、做成实心块、竖着叠。不做漂浮字幕。
- 本质：**集体大于个人**。人群、手、机器、许多小人；单张脸永远不是主角。
- 不是 `kinetic-brutalist`（当代粗野动态排版，靠字重与动势）：这条是 1920 年代构成主义，靠**斜轴 + 红黑双色 + 档案素材的机械重排**。
- 不是 `risograph-print`（孔版印刷，同为双色）：重点不是印刷工艺与错版，是**论证结构**——素材被切碎、旋转、放大、并置来提出一个论点。
- 不是 `editorial-collage`（杂志拼贴的层次）：这里不许装饰性拼贴，每一块素材都要承担论证。
- 不是数据故事片或 keynote：没有居中标题加项目符号、没有翻页、没有页眉条，数据以被标记的文件、计数器、量出来的条出现在构图里；不是瑞士动态图形（不对称、斜、没有留白网格与装饰性细线）；不是装饰艺术或 60 年代间谍片头（无金、无细线、无爵士）；不是博物馆幻灯片（档案从不"原样"摆在中间框里，它总被切、开窗、堆叠、计数）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 斜轴带 | 一根红或墨的实心带压过画面，字骑在带的中线上 | 工程、建设、进度 |
| 开窗的档案影像 | 矩形或平行四边形窗口里跑胶片，边是墨线 | 历史、城市、工厂 |
| 剪纸人 | 从照片里剪出的人，带 7px 纸白边，被叠成结构 | 劳动、集体、规模 |
| 被标记的文件 | 扫描件原句上压一条红荧光棒，旁边一个手画红圈 | 报告、公告、合同 |
| 计数器 | 四位数逐拍跳，只有停下的那个值是事实 | 人数、天数、层数 |
| 3×3 亮格 | 九格按螺旋一拍亮一个，最后一格是红的 | 清单、要件、步骤 |
| 摄影蒙太奇塔 | 楼层条从两侧交替砸入，每层下面一根墨梁 | 建筑、装配、累积 |
| 静默帧 | 纯墨画面正中一颗红铆钉 | 转折前、结论前 |
| 反转字块 | 纸色字压在红块或墨块上，没有一处居中 | 口号、结论 |
| 双色里唯一的红 | 整帧只有一样东西是红的 | 对比里的赢家 |

- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；斜轴带、剪纸人、计数器最容易被认出，也最容易被用滥，下一支换一组。
- 素材必须是真的（用户给的档案、可授权的公有领域文件）；拿不到就换主题，**不许用生成图冒充实拍**。

## 这个风格最俗的版本

- 画面：红黑底上一句斜着的大口号 + 一个齿轮或拳头图标 + 结尾 logo；声音是厚重的工业轰鸣 + 一记军鼓。
- brief 的 style 一栏写明翻掉了哪几条，或为什么刻意保留。保留时把力气花在"素材真的被切被排"和"计数走到那个数"上。

## 适配

- 用途：建设与工程史、工业周年、大型事件、劳动与集体协作、基础设施开通——任何"很多人、一个机械节奏"且背后有档案与文件的题目。
- 内容：需要一个能被证据支撑的结论（多少人、多少天、多少层、多少吨），并且这个数能被数出来。
- 时长：20–60 秒最舒服；超过 90 秒要拆段，每段给一次"计数停在锚点"的呼吸。

## 技术路线

- 建幕建元素：`add_scene` / `add_element`，把所有东西都当四类元素——带、窗、剪纸、字块——排在同一张画布上。斜轴靠整组旋转矩阵（−15°~−30°），不是逐个手摆。
- 画风落地：`set_theme` / `apply_style` 给底色、双色与字体；镜头内的双色化用 CSS filter 去色（`grayscale(1) contrast(1.15)`）+ 混合模式 + 两个专色层近似：底层纸色，墨色层 `multiply`，红色层只压标记物。做不到逐像素分色时，至少守住"这一帧只有纸、墨、红"。
- 静帧验收：`preview_frames` 逐拍看（每个切点一帧），确认斜轴一致、红没落红上；看动：`render_preview_clip`。
- 素材：`upload_asset` 上档案影像、照片、扫描件；旁白 `tts_narration`；字幕 `set_subtitles`；声音 `add_audio`。
- 运动模糊本工具不承诺：用硬停 + 卡拍 + 一次位移（≤0.2 秒）替代。
- 素材先问用户：影像、照片、文件扫描件（报告、手册、信件、会议记录）、数据。用户给的优先，档案只补空缺。
- 许可判据：Internet Archive 看 `licenseurl` 与描述——Public Domain Mark／CC0／CC BY 可用，**没有许可字段的不能用**；1978 年前的美国影片查片头片尾有无版权声明：1930 年及以前出版＝因年份进入公有领域，1978 年前无声明＝公有领域，有声明要查续展。Wikimedia Commons 可用 PD／CC0／CC BY（署名写全），**CC BY-SA 不用**。NARA／LOC／NASA 等美国联邦作品为公有领域，逐件看权利声明；"no known restrictions" 不够明确，必须告知用户或另找有明确声明的同一张图。开放获取博物馆（Met、Rijksmuseum、Smithsonian）仅在该物件页写明 CC0 时可用；"版权状态未定"不能用。避开 YouTube 搬运、无出处的二次上传、上色版与"修复"版。
- 下载前先告诉用户：什么东西、从哪、什么许可、为什么；`raw/` 控制在 1.5GB 以内；串行下载（Commons 限速）。记录每段用了哪几秒，列出署名。素材不是拍主体本身的（另一座城、另一个年份），标签就要写明它到底是什么。
- 事实：屏上与旁白里的每个数字、日期、说法都来自官方或一手来源（当时的报告、官方手册、政府记录），连同链接与原文措辞记下。计数器是图形，只有终值和有锚点的日期是事实；两份一手来源冲突时用其中一份并记下冲突。

## 材质与渲染

- **只有四类元素**：**带**（红或墨，沿轴）、**窗**（矩形或平行四边形，装胶片或照片）、**剪纸**（从照片里剪出的人，带纸白边）、**字块**。外加一层覆盖全画面的纸纤维。
- **印刷分级**（胶片、照片、文件同一套）：亮度 → 分位拉伸（胶片每条片一组分位，永不抽动，0.7 / 99.5；照片 0.8 / 99.4）→ S 曲线 `x + s·(x−0.5)·(1−|2x−1|)·2`，s = 0.32（文件 0.18，保住它自己的纸）→ 映射到墨→纸：`rgb = INK + (PAPER − INK)·g`。档案胶片在窗内保留 ±2.5% 的逐帧闪烁（`hash(frame)`），照片与文件不闪。
- **剪纸**：人像分割 → 阈值 0.5 → 中值滤波 → 取最大连通域 → 掩膜外扩 7px 纸白边。白边是这套媒介自己的样子，也顺手盖住分割边缘的错。合影很少分得干净：整张放进窗里用。
- **文件**：全分辨率扫描，从不重打。要被标记：红荧光棒在 `multiply` 下压住原句、手画红椭圆圈住标题、地图上画红圈。文件上的画（图表、地图）可从纸上揭下来复用，按其纸色抠：`alpha = (205 − 亮度) / 90`。
- **分辨率上限**：档案胶片在屏上 ≤ 源像素 2.5×，现代素材 ≤ 1.5×，照片尽量 ≥ 1 源像素／屏幕像素。720 线的胶片能填 1,700px 的窗，填不了整幅 1080p：开窗、拆条、虹膜，不要拉伸。
- **纸纤维**：固定种子的噪点画布以 α 0.5 叠在整帧上；胶片颗粒 4 只在最后输出时加。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 红 | `#D52B1E` | 带、楔、块、那个关键数字、标记棒、圈与引线、对比里唯一的赢家 |
| 墨 | `#141210` | 字、每层下面那根梁、窗框、暗底 |
| 纸 | `#EDE4D0` | 底、反转字、剪纸白边 |

- 所有影像都是墨印在纸上，此外没有别的颜色。**红从不压在红上**：红块落在红底上就改墨。
- 换底让切点落地：纸场 → 墨场 → 纸场。加速段里底色本身跟着每一刀在红／墨之间换。

## 字体

| 用途 | 字 | 尺寸（1080p） |
|---|---|---|
| 中文展示、口号 | Noto Sans SC 900（本工具：`Archivo Black` + `Microsoft YaHei` 粗字重近似） | 110–210px；竖排每字 170px |
| 数字、西文展示 | Oswald 600–700（本工具：`Inter Tight` 大写紧排近似） | 数字 230–440px；西文行 30–62px，字距 2–10px，全大写 |
| 出处、素材标签 | Space Mono Bold（CJK 回落 Noto；本工具用等宽） | 17–18px，压在墨或红标签上，内边距 6 |
| 字幕 | Noto Sans SC 700 40px 叠 Oswald 500 28px | 左下，墨条 90%，10px 红刻度 |

- 双语句对：中文一块，紧贴其下一行西文（或放到邻带上），每种语言一行，量过宽度。位置：沿 −18° 轴线骑在带上，或做成墨块／红块；**从不居中，从不做页眉**；数字可以比解释它的字更大。
- 标签：每个档案窗都带素材标签（`FILM · <片名> · <地点> <年份>`、`PHOTO · <作者> <年份>`），每个事实带来源标签（`来源 · <机构> <年份>`）。
- 字幕留在左下 960–1056px 的条里；旁白进行时关键内容保持在 y 930 以上。字幕 ≥ max(1.8 秒, 语音 + 0.6 秒)；屏上字按 CJK ÷ 4.5 + 其他 ÷ 15 + 1.5 秒估且整行在框内；对比段每一项在裁决前 ≥ 2.5 秒。

## 运动

- **网格**：画面与配乐同一速度（120 BPM：一拍 0.5 秒，一小节 2 秒）。每一刀、每一砸、擦与计数都落在拍、半拍或十六分上。
- **镜头长度**：素材 0.5–2 秒，一个镜头一个意思。段落按减半加速：0.5 → 0.25 → 0.125 秒，**不短于 3 帧**。停顿只留给阅读：字块、冻结、对比。
- **切法**：相邻两镜至少在方向（左砸／右砸）、明度（纸底／墨底）、几何（斜带／直立窗）里冲突一样。**不许两份纸质文件连着出现**。
- **没有东西静态超过一秒**：停顿时内部要有动作（窗里的胶片、计数器、慢推、画中画框）。例外只有三处：对比停顿、一次静默拍、片尾卡。
- **转场在媒介内部**（逐刀挑，不叠化）：*红擦*——260px 的红带在 72°（垂直于斜轴）上 0.25 秒扫过，下一场在它背后露出，落在重拍；*虹膜*——地图或照片上的红圈变成光圈，张开跑出影像；*砸入*——下一元素从画外沿轴进来，0.08–0.2 秒，ease-out，硬停，画面抖（幅度 3–18px，`exp(−14·Δt)`）；*闪切*——刀口或冻结上，一帧 50–80% 的纸盖过窗口；*硬切*——明度相反的两种底之间，卡在拍上；*跳近*——冻结里切到同帧 1.2× 裁切，标注跟着放大。
- **两次静默**：一次乐队全停、只剩现场原声；一次真正的半小节空——墨帧、一颗红铆钉——接最重的那一下。

## 画面怎么活

每一帧都在论证：一个数在长、一层梁刚砸下、一个红圈刚圈住句子里那个词。允许的静止只有三种：让人读字块、冻结上画标注、对比停住等裁决。此外每 0.5–2 秒必有一次机械动作，且动作总在交付信息（多一层、多一个人、多一个数），不是装饰性晃动。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 沿 −18° 斜轴横移 | 顺着一条结构走 | 楼层、进度、流水线 |
| 带与窗互相裁切 | 字与证据同处一个平面 | 标题、引用文件 |
| 砸入 + 硬停 + 抖 | 一件事被钉死 | 数字、年份、裁决 |
| 冻结 → 圈注 → 跳近 | 从整帧逼到那个细节 | 照片里的物、文件里的词 |
| 沿塔向上爬 | 累积、长高 | 建设、装配、规模 |
| 三条带反向漂移 | 同时发生的多种活动 | 城市、工地、人群 |
| 文件转 90° 立起 | 把纸上的图变成图表 | 数据、剖面、产量 |
| 3×3 螺旋亮格 | 逐一清点 | 要件、清单、步骤 |
| 反向拉远露出整张海报 | 收束、一次看全 | 结论、片尾 |
| 静默帧后接最重一击 | 转折 | 结论前、反转 |

取景：偏、斜、切边、贴得近；第一帧就要有可读的主体，0.5 秒内有第一个强动作。窗可以出画，字不行。

## 声音调色板

- **配乐**：原创机械固定音型（八分音符、小调，如 D–D–F–D–A–D–E–F），断奏大提琴 + 断奏巴松，拍上断奏大号／长号，十六分小鼓轻击，木琴给计数（每亮一格／每起一层一个上行音），圆号与小号短刺 + 一个铜管动机，段落转换用定音鼓滚奏，最重的一下用大鼓 + 锣。**不要钢琴加弦乐的铺底**。
- **现场原声与音乐交替**：有一段乐队全停，只有真实录音（铆钉枪、机器、人群）独自扛住剪辑，每段声音裁到与镜头同长；提前一拍进来（J-cut）。
- **每个"印刷动作"都有拟音**：砸 = 低频闷响 + 钢铁碰击；盖章 = 闷响 + 咔；擦与虹膜 = 呼啸；标记笔 = 滤波噪声摩擦；纸 = 带通沙沙；楼层与格子 = 有音高的金属碰。
- **层次**：环境声（真实现场／街道录音，比人声低约 20dB，静默段撤掉）；拟音在人声下压 35%；音乐在人声下压 70%（约低 10dB）；旁白压缩并按 RMS 校平。整体 −14 LUFS，峰值限 −1.8 dBFS，**首个采样点做 25ms 淡入**（AAC 会在首采样的一击上过冲）。
- **旁白**（有旁白时）：短陈述句、新闻片语速，一段格式里不超过一句；给 TTS 的数字写汉字，字幕里写阿拉伯数字。

## 原生手法

1. **文件被标记，不是被引用**：扫描件上那句原话压一条红棒，那个数字随后变成一个红块。
2. **文件变成图表**：纸上的画被揭下来、转个方向、按比例站在一条地平线上（顶端到地面 = 数值 × 每单位像素），红尺寸线、数字、名字；停住；再出裁决块，赢家染红。
3. **A + B → 概念**：两类图交替得越来越快（机器／手；一份告示／它排除的人），直到一张卡或一个数字说出这次碰撞意味着什么。
4. **数"很多"**：计数器由切点驱动；九格按螺旋逐格亮；塔一层一层起。
5. **人搭出结构**：剪纸人叠成他们造出来的那个东西（摄影蒙太奇）。
6. **静默，然后最重的一下**，进入结果。
7. **可复用格式**（一支片挑 3–5 个，不要全上）：标题包（红带砸入，窗裁到带边，数字每八分砸出一个）；下三分之一（92px 红条在 y≈760–850，0.14 秒砸入）；竖排标题（中文逐字叠，西文转 90°）；横梁上的日期（纸色字压在跨过影像的红带上）；分条（整帧转到斜轴，三条各两格，每拍换一格，条宽 ≤ 1,160px 守住 2.5×，中条一道红缝）；文档特写（斜页砸入，红棒压原句，旁边一个高槽跑快放）。
8. **其余格式**：过程阶梯（三窗沿对角线升高，0.75 秒一个，中间红三角，计数器爬到那个说法）；加速 + 计数（整幅窗倾斜 ±4–6°，底色红／墨交替，四位数每刀一跳）；多重曝光（红底上叠窗 ≤ 1,700px，第二段素材 `screen` 45%，剪纸 `multiply`）；"那个问题"（墨底上的文件标题，红圈，一个巨大的红问号）；结果构图（巨大数字在左，右侧一条高斜窗放完成的主体，相机沿它上摇，一张斜照片，一个红楔）。

## 变化空间

- 每支由 agent 决定：结构、用哪些档案与文件、用哪些格式（不是全上）、轴的角（**−15° 到 −30°**）、红的具体色相、速度（**100–140 BPM**）、有没有旁白（只有字卡也成立）、标志性的"建造"（一座塔、一跨桥、人群排成一个字、一张地图被填满）。
- 三种结构：**日历机器**（一个计数器跑完全片，在里程碑处停）；**文件提问、影像回答**（中段转向）；**一件东西穿过整个流程，然后给出整体的规模**。
- 开场与结尾各三种。开场：一根红带先砸进来再给窗；一个数字先占满画面，再去找它在哪份文件上；墨帧一颗红铆钉，然后整面砸入。结尾：塔封顶、人在顶上；计数停在最终值，红块把它重盖一次；回到开场那句被标记的话，现在它被红块回答。

## 坑

- **被放大的档案胶片**在 1080p 全幅上糊成一片 → 开窗、拆条、变焦守在 2.5× 以内；**逐帧分级会抽动** → 一条片只用一组分位。
- **字骑在带上跑出画** → 从带的中线定位（点 + 法线），不要目测。
- **红压红**：红底上的红答案块会消失 → 改成墨。
- **拿一张脸当英雄**：可辨认的劳动者只以群像、在工作、快切出现；不要慢动作，不要主角特写。
- **计数器被当成事实** → 只有终值和有出处的锚点是事实；计数器旁的说明必须与每一帧显示的数一致（说明在屏上时把计数停在那个值）。
- **数字没有单位** → 每个计数器都按同一版式带上单位（小时／层／人 MEN）。
- **墨字压在窗上** → 越过照片边缘那行字会掉进暗部；给它一个纸标签，或让它避开窗。
- **裁决盖住了被比较的东西** → 放在没有项的位置，且在停顿之后。
- **文件太多** → 每个文件镜头只标一句；一页三个高亮就变成 PPT 了。
- **加速段里的短标签**注定读不完 → 1/8 拍的刀口里不放字；把结果放到后面的停顿块里。
- **第 0 采样点的一击**在 AAC 里会过冲 → 前 25ms 淡入。
