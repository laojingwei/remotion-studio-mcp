# 五十年代扁平卡通（upa-50s-flat）

> 平涂的印刷色配一条会呼吸的细墨线，线永远差一点没闭合；每一块颜色都是单独一张赛璐璐、相对线条印偏几个像素，并且每两帧重摆一次，所以画面带着手工套色的颤动。
> 参照（只学语法）：UPA 五十年代初的短片（色与线分张赛璐璐、几何化的人、色平面背景、有限动画）、五十年代课堂教育片（直接对镜头说话、一图一句、编号卡片）、Charley Harper 与 Mary Blair 的原子时代补色、五十年代家电说明书（编号圆章、弧形箭头、圆形引注、放射线）。不照搬其中任何角色、画法、字形和音乐，片子里也不点名它们。

## 本质 / 不是什么

- 本质：**线是印上去的，色也是印上去的，而且没对准**。填色相对墨线向右下偏几个像素（约 2–5 px），这个偏移在二拍上以 ±1–2 px 抖动；镜头在滑移时，画面像手工套色一样轻轻颤。字也一样偏，只有需要极其干净的工程示意图时才关掉。
- 本质：**线是活的**。3–5 px 的墨带，宽度有 ±40% 的呼吸，线身带 12–25% 的断口——它永远不闭合。人物约 4 px，道具 3–4.5 px，平面图里的墙更粗、断得更多。
- 本质：**人是几何的**。蛋形或豆形的头，鼻子是脸部轮廓的一部分（不是贴上去的楔子），衣服两三个平涂色，四指卡通手套。身体是一张"被按住的画"：只有手臂、手、眼睛和嘴在动。
- 本质：**房间不画**。一场戏就是一个色平面 + 一条地面带 + 一条有缺口的水平线 + 一两个道具。它演示"怎么做"，不讲"为什么"——观众看完应该能自己动手。
- 不是 `flat-vector`：那是当代扁平矢量，干净、精确、对位完美、可以无限缩放。这里的色块**必须跟线错开**，而且这个错位每两帧重摆一次；对位一完美，风格就死了。
- 不是 `rubber-hose`：那是 1920–30 年代黑白管状肢体、世界会跟着弹、音乐驱动、热爵士。这里是 1950 年代彩色、有限动画、几何简化、冷爵士、带"现代艺术"气质——画面不弹，只有手在动。也不是白板讲解：白板是手写在平面上的，这里是**印**出来的。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 套色错位 | 色块整体向右下偏 2–5 px，二拍上抖 ±1–2 px | 一切（基底信号） |
| 断口墨线 | 3–5 px 墨带，粗细呼吸，线身有 12–25% 缺口，转角也不闭合 | 一切（基底信号） |
| 编号圆章 | 墨色圆盘 + 纸色数字，"咔"地盖在画面上，镜头从洞里钻过去 | 分步、规则条目、清单 |
| 圆形引注 | 一个圆 + 一条引线，把局部放大到画面里，数据落在圆上 | 手里的动作、屏幕、小零件 |
| 色块转场 | 一块颜色从侧面或底部推上来盖住画面，像翻说明书 | 换小节、给提示 |
| 被按住的角色 | 身体一动不动，只有手在做那一步 | 教学、装配、操作 |
| 编号卡片头 | 墨盘数字 + 宽字距"第 n 步 / 共 n 步" + 奶油色板的标题，二拍滑入 | 教程、流程 |
| 四指手套 | 手掌与四指合成一条外轮廓，指缝是细线 | 讲师、操作者 |
| 原子时代装饰 | 四角星芒、8–18 角爆炸形、约 30 瓣半透明放射线、回旋镖与腰子形、圆点阵 | 结果、强调、结尾 |
| 一色一平面 | 每场只有一个底色，墙面浅一档、地面深一档，道具浮在上面 | 空间、商品 |
| 平涂投影 | 深一档的同形色块 clipped 在形状内，绝不是渐变 | 体积、层 |
| 静止帧 | 完全停住 ≥ 3 秒，让人截图 | 总结、二维码、CTA |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；前两个（套色错位、断口墨线）是风格的地基，永远在场。信号从主题里选，不按顺序全上。
- 圆章、圆形引注、放射线这三样最容易一眼认出，也最容易被用滥——第二支片子换一组。

## 这个风格最俗的版本

- 画面：番茄红圆章数字"1 2 3"挨个弹出来，配一圈放射线，一个小人举起一根手指，背景是纯正的芥末黄平涂。声音：一整条轻快摇摆爵士从头铺到尾，每个动作都打一个点。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么刻意保留。保留时，把力气花在**手的那一个动作**、套色错位的节奏、以及最后那个静止帧上。

## 适配

- 用途：装机/使用指南、安全须知卡、配方与流程卡、App 上手引导、门店或活动告知。内容是能拆成 2–5 步、每步有一个"手上的动作"可说，观众看完要能照着做。时长：产品教程 30–40 秒（2–5 步）；规则卡 20–40 秒（3–6 条）；配方卡 30–45 秒；上手引导 20–30 秒；门店告知 15–25 秒。
- 不适合：需要真实界面细节的（用 `minimal-ui`）、需要可信数据曲线的（用 `data-motion`）、靠情绪和叙事推进的品牌片。

## 技术路线

- 建场：一场戏用 `add_scene`，里面**先放底色平面**（一条满幅色块），再放地面带、水平线、道具，最后放角色和字。所有元素用 `add_element`，分层顺序就是赛璐璐的张数。
- 错位：每块填色单独一个元素，相对它的墨线整体偏移（右下 2–5 px）。抖动值按 `floor(帧/2)` 取值，即同一组偏移值保持两帧——这才是"二拍"。别用逐帧随机的噪声，那是胶片抖，不是套色抖。
- 线：用描边路径画，宽度按元素类型取值（人物 4、道具 3–4.5、墙更粗），沿路径留出 12–25% 的缺口。缺口位置全片固定，不要每帧乱跑。
- 调性：`set_theme` / `apply_style` 定底色、墨色、三个补色；每场的底色在 `add_scene` 里单独覆盖。旁白 `tts_narration`、字幕 `set_subtitles`、素材 `upload_asset`、音效与 BGM `add_audio`。
- 验收：`preview_frames` 逐拍看静帧——**看色块与线是否错开、线是否真的没闭合**；再 `render_preview_clip` 看动，重点看二拍抖动是否被看成"卡"。

## 材质与渲染

- **套色赛璐璐**：填色 = 纯色块，右下偏 2–5 px，抖动 ±1–2 px 在二拍上重摆。文字也是。墨线 = 墨带，宽度呼吸 ±40%，断口 12–25%。手：手掌与四指**先描一条联合外轮廓、再填色**，指缝只走细线。
- **明暗**：一个平涂的深一档色块，clipped 在形状内部，绝不用渐变。投影 = 同一个形状向右下偏移、纸色、约 50% 不透明。
- **装饰**：四角星芒、8–18 角爆炸形、约 30 瓣半透明放射线、回旋镖与腰子形、圆点阵。颗粒很轻，是印刷的颗粒不是胶片的颗粒，且不许盖过线的断口。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 纸底 | `#F2E8D5` | 暖纸，全片的"印张" |
| 平面/卡片 | `#E7DBC2` | 墙面的浅一档、字幕卡、细节卡 |
| 墨 | `#241F1B` | 暖近黑，所有线与主字 |
| 次级字 | `#6E6255` | 说明、单位、注释 |
| 主色（珊瑚） | `#E2634B` | 商品或强调色，全片不变 |
| 副色（绿松石） | `#3E8E8A` | 讲师的衣服、次要形状 |
| 强调（芥末） | `#E0A32E` | 星芒、圆章、要点标记 |

- 每组示例：珊瑚/芥末/绿松石 压在奶油上；番茄/橄榄/粉蓝 压在燕麦色上；梅子/青柠/沙色 压在灰白上。都成立，只取一组。
- **一场只有一个底色**：墙面用浅一档，地面用深一档。**商品永远不放在它自己那个颜色上**；**讲师永远不放在他自己那个强调色上**。
- **商品全片只用一个颜色**；强调色（讲师的衣服、星芒、要点）是另一个色相，步骤的底色从剩下的颜色里轮换。没有纯色、没有霓虹——偏一点脏、偏一点灰，才对。

## 字体

- 三个角色，缺一不可：**五十年代手写体**做眉标（源站用 Oleo Script Bold，本工具可挑一款粗手写体或本机行楷 `STKaiti`）；**粗衬线（slab）**做标题、数字、小标题——印在墨色里、下面垫一块错位的彩色色板（`Georgia` / `Noto Serif SC` 顶住，拉丁优先 `Georgia`）；**几何无衬线**做正文、标签、注释（`Inter`，中文 `Microsoft YaHei`）。
- **字幕卡**：纸色圆角厚板，细墨边（它的色层也要错位），两端各一颗小转星，约 40 px 无衬线，底部居中。快速淡入 + 轻微上浮。停留 ≥ max(1.8 秒, 语音 + 0.6 秒, 字符数/12 + 1 秒)。
- **步骤头**：墨色圆盘 + 纸色数字、宽字距的"第 n 步 / 共 n 步"、奶油色板的步骤标题；**在二拍上滑入**。字宽要够：套色错位会让细字糊成一团，正文字号宁大勿小。
- **细节标签**：纸色卡片 + 星形项目符号，在动作那一拍弹到引注旁边弹出。数据落在画面上，永远不做成单独一页。

## 运动

- **二拍**：姿势、手型、套色抖动都在 12 fps 上变（每两帧一个值）。**镜头、圆形转场、箭头、平面路线、放射线走 24 fps**（逐帧）。这两种速率同时存在，是整个风格的呼吸。
- **身体按住、手在动**：换姿势只给一张中间帧。一个手的动作有四段——预备（往回拉或抬起）、快动作（0.15–0.25 秒，缓出）、跟随（回弹、停住、抬手离开）、**正好落在拍上**。
- **弹出**：圆章、标签、标题用 back-ease 缩放进来，约 0.25 秒，过冲要明显。
- **够到地面**：蹲姿用两段骨 IK 让手一直贴在物件上，物件动了手也跟着走；**绝不允许把站着的手臂拉长**。写字用手写体裁剪从左往右写出来，标题块在二拍上滑入。
- 禁止：叠化、手持晃动、平滑的 UI 弹跳、渐变色块。

## 画面怎么活

- 一个被按住的角色 + 一只在动的手，就是全片的发动机：每一"拍"只允许一个动作，且那个动作就是这一步本身。
- 静态的部件永远有一点点活气：星芒缓慢旋半度、放射线极慢地转、地平线的缺口一条条错开、圆点阵轻轻漂。
- 换步骤时底色整块推上来；同一场里颜色不动，动的是装饰和手。

## 镜头语法

镜头是"三脚架"，永不带手持。它是一套词汇表，不是一条路线；开场和结尾从主题里长出来。

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 缓慢推近（几个百分点） | 把眼睛收拢过来 | 台上的商品；一个结果落定 |
| 从圆章穿过去（圆形收放） | 数字**就是**门 | 换步骤；换规则 |
| 圆形引注 + 引线 | 同时给上下文和细节 | 手的动作；一个屏幕；一个小零件 |
| 带指向的手指的俯仰 | 手指领着画面走 | 最关键的那一个动作 |
| 推进设备、沿信号环横移 | 人 → 界面 → 设备 | 配对；连接 |
| 从圆形物体收进俯视图 | 圆对圆，功能对平面 | 按钮启动；开盖；旋钮 |
| 后拉并反向旋转（细节 → 平面） | 一条通道变成一张图案 | 路线、排班、花园、平面图 |
| 色块擦除（侧向、自下而上） | 翻说明书那一页 | 小贴士；总结；新卡片 |
| 双色块分屏 | 对 / 错，之前 / 之后 | 安全规则；升级前后 |
| 完全静止 ≥ 3 秒 | "这一帧是给你截图的" | 总结、CTA、二维码 |
| 收圆到一个物体 | 最后那个圆 | 收在商品、Logo、结果上 |

取景：主要对象 ≥ 画面高度的 1/3，且避开字幕带。转场只有三种——圆形、色块擦除、卡在拍上的切。**没有叠化。**

## 声音调色板

三层，永远都在。

- **音乐**：原创的西海岸冷爵士小编制——长笛或弱音小号、颤音琴（和弦、琶音、滑音、震音）、拨弦行走贝斯、鼓刷（要劲时换鼓棒打 ride）、钢片琴、邦戈鼓或响指。不要拉格泰姆、不要间谍片大乐队、不要钢琴加弦乐。三个可选做法：**每一步给它自己的一个颤音琴和弦**，总结时按条目一个个还回来；改律动密度（减半或加倍）而不是改速度；要收尾时整体升一个级。
- **沉默也是工具**：在最重要的那个动作之前把**所有东西**切掉（连环境声），让动作后的第一个声音（咔哒、倒水）成为这一步的重音。总结之前只留房间底噪。
- **按材质配拟音**：纸板吱呀与闷响、家电塑料的敲击与咔哒、地面刮擦、玻璃与陶瓷的轻碰、倾倒、盖圆章用弱音橡胶章、色块擦除用纸张"唰"、尺寸箭头用滑哨、"已连接"用上行的提示音、路线用笔尖划纸、圆形转场一声"唰克"。
- **环境**：暖房间底噪（低通棕噪，极轻）、一条卡在网格上的座钟滴答；设备开始工作时可以让马达嗡鸣接管。**混音**：J/L 切（台词在圆形转场之前就起，尾音还在响）；旁白压在最上层，音乐自动降约 8 dB，拟音不降，整体 −14 LUFS。
- **人声**：平静的课堂权威感，一句话只放一个短句（"第一步。靠墙放好。"）。每句都做耳语检查——口音会把关键词吃掉。本工具里音乐与拟音走 `add_audio`，旁白走 `tts_narration`，字幕走 `set_subtitles`。

## 原生手法

- **套色错位**：让一张信息卡变得手工、发暖。适合博物馆须知、银行 App 界面、酒店入住。
- **有限动画指眼睛**：身体不动，手是唯一的动作者，而这只手**就是**那一步（每步一个手的动作，卡在拍上）。适合穿缝纫机线、换自行车胎、调恒温器。
- **圆形引注就是特写**：这一步的数据落在圆里或圆上，卡在动作那一拍。适合量杯上的刻度、螺栓的扭矩值、键盘上的 PIN。
- **编号圆章**：标层级，也打开下一步——盖在正要退场的对象上，镜头从洞里穿过去。适合泳池的五条规则、登机清单、垃圾分类的各个阶段。
- **收尾把功能变成装饰**：一个真实过程（一条路线、一张浇灌时刻表、一张座位表）按区域一笔笔画出来，画完整体一看，是一块原子时代的印花布。适合喷淋覆盖、配送回路、一周用药。

## 变化空间

由 agent 决定：做的是什么、有没有讲师、哪几步、什么顺序、开场、结尾、镜头路径、配色、节奏、音乐。

| 用法 | 信息顺序 | 每层停留 | 时长 |
|---|---|---|---|
| 产品装机指南 | 品名 → 标题 → 步骤标题 → 动作拍上的细节 → 收尾 → 小贴士 → CTA | 标题 ≥ 4 秒；步骤标题贯穿整步；细节 ≥ 字符/12 + 1 秒；总结干净 ≥ 3 秒 | 30–40 秒，2–5 步 |
| 安全 / 规则卡 | 规则编号 → 规则 → 一句"为什么"；每条一个被按住的姿势、一个圆章、一个手势或一个图标 | 每条 3–4 秒 | 20–40 秒，3–6 条 |
| 配方 / 仪式卡 | 步骤 → 用量与时间 → 结果；侧视，引注打在手部，结果用俯视图案 | 每步 3–5 秒 | 30–45 秒 |
| App / 服务上手 | 屏幕动作 → 设定值 → 确认盖章；屏幕住在引注里 | 每动作 3–4 秒 | 20–30 秒 |
| 门店 / 活动告知 | 大标题 → 时间地点 → CTA；卡片之间用色块擦除 | 每卡 ≥ 3 秒 | 15–25 秒 |

- **三种结构**：没有商品的纯规则卡（一条规则 = 一个被按住的姿势 + 一个圆章）；桌面上的配方（侧视开始，俯视结束）；对/错分屏（每条规则在两个色块里各演一遍）。**三种开场**：先给已完成的结果，再说"这样做的"；用一个手势给出问题（手在插头上打滑）；一张编号清单盖上来，再一条条打开。**三种结尾**：一张清单自己打勾；手停在成品旁边；二维码在星芒里完全静止。

## 坑

- **路线绕开障碍** → 顺着商品的真实规则走；流线要绕开障碍、绝不交叉；一个区域一拍，不要一口气画完。
- **鼻子是个贴上去的楔子** → 从鼻梁绕过颅骨一条开放曲线，在鼻尖收口，鼻子属于脸部轮廓。
- **细胳膊从脖子上长出来** → 肩点放在躯干的角上，袖子是一条粗墨带、上面压一条彩带。
- **胖团子手指把手变成一朵云** → 先描所有部分、再填色（一条联合外轮廓），手指细、指缝走细线。
- **放大世界会让墨线变成三倍粗** → 特写一律画在圆形引注里，按原始尺度画。
- **细节字没有阅读时间** → 把数据放进细节、把上下文放进标题和旁白；字符/12 + 1 秒。
- **对位太完美** → 这是本风格唯一的死法。每块填色都必须错开，且必须每两帧重摆。
- **转场提前把下一场画出来** → 把局部时间夹到刚过起点，下一场只在转场到位之后才存在。
- **二拍抖动被做成逐帧噪声** → 会变成胶片抖，不是套色抖；值必须两帧一换。
- **一屏全是圆章和放射线** → 装饰一次只上一样，其余留给手和色块。
