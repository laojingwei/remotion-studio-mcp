# 水彩笔刷（watercolor-wash）

> 一张温热的纤维纸上，每一笔都是一支单独的笔刷在走，纸本身就是橡皮。
> 参照（只学语法）：博物学野外手账与植物图版（标本 + 注记）、横卷式一镜到底的连续画面、教科书里的样带（transect）图解——一个渐变横着读过去。只借语法，不照搬任何一幅具体作品、角色或版式。

## 本质 / 不是什么

- 本质：**最底下一张温热的、有纤维的纸**。它同时是白、是光、是橡皮——纸色的雾擦过去，东西就没了。
- 本质：**一切都是单独的笔刷**：一条宽度会变的带子压在半透明上，旁边跟着几条细的鬃毛轨迹，断成虚线（飞白）。笔交叉的地方变深，因为颜料是透明的。没有矢量描边，形体上那条更深的边笔是唯一的"线"。
- 本质：**东西自己画出来**，一笔一笔，先结构后细节（树干 → 枝 → 叶；轮廓淡彩 → 阴影 → 点缀）。
- 本质：**上面有一层注记**，是画家自己会用的那种手：带引线的标签、一个量出来的小数字、一个安静的标题。
- 语气：冷静、好奇、精确。数字是真的，配色可以承载数据。
- 不是**水墨**：这里给的是颜色不是墨阶，没有书法那种"一笔即姿势"的用笔。
- 不是**油画厚涂**（`painterly`）：没有厚颜料、没有刀刮、没有堆起来的高光。
- 不是**儿童绘本**：没有蜡笔、没有可爱的黑描边。
- 不是**给矢量插画贴一张水彩贴图**：纹理长在笔里，不长在图层上。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 纸的纤维颗粒 | 暖底、三层噪声、几千条短弧纤维、轻暗角 | 自然、季节、土地 |
| 飞白 | 笔画末端散成 3–9 条断续细毛，提前断 | 风、干土、速度、老去 |
| 积水边 | 同形状画三遍，边参差、边上更深 | 水、湿度、情绪 |
| 透明交叠变深 | 两笔交叉处颜色更深，不透光 | 层次、叠加、密集 |
| 留白即光 | 最亮处一个像素都没画，是纸 | 光、清晨、留白 |
| 手写注记 + 引线 | 手写体标签，一根线长到那个部位 | 标本、零件、器官 |
| 样带式横移 | 同一张纸上横向一路变过去 | 环境梯度、路线、时间 |
| 标本 + 注记 | 一个主角占住一角，注记在空处 | 器物、物种、食材 |
| 雾洗回纸 | 纸色层带波浪上升边，把世界抹掉 | 遗忘、结束、拆迁 |
| 颜料当数据 | 色阶量化成 4–6 档，横着读成渐变 | 污染、温度、密度 |
| 自画入 | 新东西是一笔一笔长出来的，不是淡入 | 建造、烹饪、生长 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 飞白、积水边、雾洗这三样一眼就认出来，也最容易用滥——第二个片子里换一组。
- 横移样带是这种风格最贵也最好用的一招，一支片子里只花一次。

## 这个风格最俗的版本

- 画面：粉蓝粉红的水彩晕染底 + 白色手写体英文 + 一朵水彩花 + 全部淡入。
- 声音：尤克里里 + 鸟叫 + 一声"叮"。
- brief 的 style 一栏写明这一支翻掉了哪几条，或者为什么刻意保留。保留时把力气花在"画出来的顺序"和"纸上的留白"上，而不是花在贴图上。

## 适配

- 用途：情绪段、温柔科普、自然/季节/地理/食物/身体结构的讲解、纪录片式的手账体。
- 内容：需要**慢慢长出来**、或者需要把一段渐变横着读完的主题。
- 时长：30–120 秒最舒服，一个主题一页纸。超过两分钟要换纸，别在一页上挤。

## 技术路线

- 分层：`add_scene` 建幕，`add_element` 放纸、水洗层、物体层、注记层；层与层之间做视差（近处动得快）。
- 纸：一张预生成的纸纹图（`upload_asset` 上传），永远最先画、单独一层。
- 笔刷：**本工具没有逐笔刷的颜料模拟**（湿扩散、纸纤维吸色做不到）。近似做法是——一个带宽度的形状沿路径画出来，上面叠 3–9 条细的断续线当鬃毛，整体用半透明 + 正片叠底。
- 水洗：同一个形状做 2–3 层，各层缩放/位移轻微错开、每层 1/3 不透明度，边缘自然变深。
- 落地配色用 `set_theme` / `apply_style`；字幕用 `set_subtitles`；旁白 `tts_narration`。
- 验收：先 `preview_frames` 逐拍看静帧（飞白在静帧上就该看得见），再 `render_preview_clip` 看动。

## 材质与渲染

- **纸**：暖底 + 三层平滑噪声（各 ±3.5%）+ 几千条短弧纤维 + 细颗粒 + 轻暗角，每帧第一层。
- **笔**：宽度按剖面走（`brush` / `leaf` / `even` / `tip` / `trunk` 五种），宽度再加约 ±22% 的噪声起伏；本体约 0.55–0.6 不透明度（有鬃毛时），上面叠 3–9 条鬃毛在 30–85% 不透明度，每条随机断点、随机提前结束——这就是飞白。一笔可以只画到任意比例，就成了移动的笔尖。
- **水洗**：同一个多边形画三遍，顶点各自抖动，每遍 1/3 不透明度，边就深了（积水边）。
- **纵深靠层**：几层视差的淡彩与物体；越远越小、越淡、越不饱和；层与层之间垫一条纸色的雾带。
- 画好的物体缓存成精灵图，只对"正在画/正在变"的逐笔画；一切都是时间 t 的纯函数，任何在渲染里现生成的笔都要固定随机种子。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 纸 | `#F3E8D2` | 暖棉纸；它同时是白和光 |
| 水洗底 | `#E7D8BC` | 比纸深一档的湿痕 |
| 墨 | `#2E2620` | 暖近黑，只给线、字、边、茎 |
| 浅褐 | `#8A7A66` | 次要线、远树、注记的轻笔 |
| 主色 | `#4E6E3C` | 主体的深绿，一场景只一个主色 |
| 次色 | `#9FB4C4` | 水与天的蓝灰 |
| 点缀 | `#C8442A` | 朱红，只给一个反复出现的元素 |

- **纸就是白**。永远不画纯白；光是不画的那块纸。
- **透明叠加**：更深 = 更多遍，不是更深的颜料压上去。一场景 3–5 个色相 + 墨，别再加。
- **墨**（暖近黑 `#2E2620` + 浅褐 `#8A7A66`）只用于线、文字、边缘和茎。
- 颜色可以承载数据或情绪：天、地、背景按位置或时间混合；色阶量化成 4–6 档读起来像颜料，连续的渐变读起来像软件。
- 一个点缀色（朱红、雨蓝）只留给一个反复出现的元素：一枚印章、一个标记、一个关键物。
- 三组现成例子：旱到湿——红赭 → 鼠尾草绿 → 麦秆黄 → 蓝灰 → 深绿；清晨港口——天 `#f3e2c8`、水 `#9fb4c4`、船体 `#5f7486`、浮标 `#c8442a`；菜园——土光 `#e8e0c0`、叶 `#8ea860`、阴 `#4e6e3c`、南瓜 `#d9632e`。

## 字体

- 标题与字幕用优雅衬线（Georgia / Noto Serif SC 兜中文）；注记用手写感（`STKaiti` 兜中文）；测量标签用等宽、宽字距（monospace）。
- 中文字体按实际用到的字给，字一多就要重新确认有没有掉字。
- **手写注记**画两遍、底下垫一圈纸色光晕，从左到右写出来；引线一边写一边长到它指的那个标本上。
- **字幕坐在纸上，不在框里**：底部居中，衬线斜体约 36px（最多两行、平衡断行），第二语言在下面约 2/3 大小，墨 78% 不透明度 + 纸色晕。
- 停留 ≥ max(1.8 秒, 语音 + 0.6 秒)；数字在旁白里念出来，屏幕上写阿拉伯数字。

## 运动

- **画出来是主运动**：一个物体的进度由它在屏幕上的位置或者一个提示点决定；一串物体的每一笔各分一段进度，所以结构先出现、细节后到。
- **摆动只发生在画完之后**：小幅水平斜切 `sin(1.15t+φ) + 0.4 sin(2.7t+2φ)`；树约 0.006，草 0.01–0.03。
- **笔刷边擦除**：波浪形竖向裁切揭示整场；线条按笔画进度长出来；标签从左往右裁开。
- **雾擦**：纸色的层，带波浪形的上升边。
- 会动的生物和事件可以对齐音乐的拍网格，让落点踩拍。
- 全部平滑缓动（`ss` / `eio` / `eo` / `ei`）；60fps 适合这种慢而流利的笔；什么都不许抖。

## 画面怎么活

一个东西 → 它被一笔一笔画出来 → 注记写上、引线长过去 → 相机滑到相邻的另一个东西 → 画它 → 旧的被雾洗掉或留在边角当参照。
画完的物体不再动，只有一点摆；生命力集中在"正在画"的那一段。观众永远知道现在在画什么、画到第几步。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 沿一个连续世界的长距离横移 | 一个渐变；一段旅程；因果 | 样带、路线、时间轴 |
| 沿一个物体的竖向俯仰 | 尺度、测量 | 一棵高树、一栋楼、一段深度 |
| 锁定一张纸，东西被画进来 | 研究、注视 | 标本图版、食谱、图解 |
| 缓慢推近一个细节 | 观察者凑上去 | 一颗种子、一只虫、一条手写注记 |
| 后拉到地图或图解 | 整体重新取景 | 事情发生在哪、一个系统 |
| 雾洗成白纸 | 章节结束、时间过去 | 季节、遗忘、离开 |
| 翻页 / 新纸滑过来 | 手账里新的一页 | 新的一天、新物种、新案例 |
| 锁定视角上让时间变化 | 生长、衰败、历史 | 季节循环、前后对比、深层时间 |

取景：纸边留得慷慨；一个画面一个主角 + 它自己的注记；标签不许压住主体。
转场：笔刷边擦除、雾、翻页，或者干脆一个连续的相机移动；**不许硬切，不许在两张无关的图之间叠化**。

## 声音调色板

- **音乐**：原声、温和——毡钢琴、指弹木吉他、木管、轻弦、钟琴、卡林巴、软垫。有授权的曲子可以按拍剪辑，画面再反过来吃它的拍网格。
- **拟音用场景自己的材质**：每一次画入一声纸笔沙沙（带通噪声 + 轻颤音 + 声像扫过）；注记是铅笔刮擦；印章一声软闷响；翻页声；再用主体自己的自然底噪和生物声（鸟、风、雨的滴答、水、虫、火噼啪）。
- **沉默**：笔松开——音乐退出去，只剩纸和房间；它框住一个刚刚画完的瞬间。
- **混音**：人声靠前（RMS 高出音乐几 dB），音乐在人声下压约 4dB、平滑包络，短的柔混响，最终 −14 LUFS。
- **旁白**：温暖、不着急的纪录片口吻，一句一个意思。

## 原生手法

- **画出来当揭示**：新东西一进画就一笔笔长出来。适合建造的阶段、一道菜的配料、一个身体的器官。
- **爆发**：整组东西在 ≤ 1 秒里一起画进来，用来顶一个高潮。适合节庆的人群、开满的田、亮起来的城。
- **调色板当数据**：天、地、背景按一个量混合。适合一条河的污染、随海拔的温度、一座城的噪声。
- **标本 + 注记**：一个主角配一行手写标签和一根引线。适合一套工具、一个产区的葡萄、一辆自行车的零件。
- **雾擦**：世界被洗回纸。适合遗忘、梦的结尾、被拆掉的场地。
- **地图在时间里**：一张画出来的地图，填充随着年份连续变化。适合语言的扩散、海岸线的后退、铁路网的生长。
- **画出来的转变**：物体交叉渐变到烧焦/潮湿/老化的精灵图，再长回来。适合野火与恢复、洪水、修复。

## 变化空间

每一支由 agent 决定：主体、结构、什么被画、配色的逻辑、有没有东西被测量、开场、结尾和相机。

- **三种结构**：一年的手账（一月一页锁住，后一页画在前一页上）；一个物体的解剖（单个标本拆成带标签的部件，每个部件一个画出来的特写）；一个配方或流程（从上往下画在一张很高的纸上，相机往下俯仰）。
- **三种开场**：先给一幅已完成的画，再倒着画回第一笔、然后正着画一遍；湿颜料扩散的特写，后拉看它变成了什么；白纸上一个手写的问题，用画来回答。
- **三种结尾**：页面留着没画完，笔提到半空；一个细节的特写，其余淡回纸；纸干了，被归进一叠别的页。

## 坑

- **屏幕外的水洗条太短** → 高形状被削成平顶，俯仰时露缝。改：条子远远超出画幅。
- **半透明水洗在画布边缘结束** → 压在别的层下面就是一道硬缝。改：延伸到画面外，用渐变淡回纸色。
- **初始化没走完就开始截帧** → 抓到空画面或半张纸。改：所有东西在初始化里建完再置就绪位，失败时先看页面的报错行。
- **笔刷生成器吃全局随机数** → 同一帧在并行渲染里对不上。改：每笔固定种子。
- **每帧几千笔** → 慢到渲染不动。改：画完的物体缓存成精灵图。
- **卡拍的动画在音乐剪辑变了之后没重推** → 落点全错。改：换音乐就重新算一次拍网格。
- **新加的中文字幕字掉进别的字体** → 一行字两种字重。改：改字后重设 `set_subtitles`，逐帧检查。
- **用水彩纹理铺底 + 矢量形状** → 一眼假，贴图感和笔触感永远是错位的。改：纹理只给纸，笔是形状本身。
