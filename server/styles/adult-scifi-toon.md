# 科幻情景喜剧卡通（adult-scifi-toon）

> 一支成人向 2D 电视动画：轮廓粗、等宽、每帧都在"煮沸"地抖，平涂色块配硬边阴影，两个人对同一件事给出完全相反的反应，中间隔着一台只会发光的机器。
> 参照（只学语法）：成人档科幻情景喜剧动画的对白喜剧节奏、反应特写、煮沸线、把科幻硬件当家用杂物。不照搬任何现成角色、剪影、配色组合、名字、口头禅、打嗝桥段、标志或传送枪造型。

## 本质 / 不是什么

- 本质：**一条抖的线 + 一块平的颜色**。轮廓近黑、略偏紫最好，角色与道具约 7px、背景细节 4–6px、圆角接头；**线宽在屏幕空间恒定**——特写是"按同样粗细重画一遍"，绝不把描边跟着放大。
- 本质：**没有一帧是死的**。每条轮廓在屏幕空间每约 7px 采一点，沿法线用低频噪声位移，振幅约 1.7px；**3 张循环的"煮沸稿"按 12fps 轮换**。保持姿态、背景、静物一起抖。
- 本质：**平涂 + 硬边阴影**。阴影是有明确形状的深色块，裁在填充内部，一个形一块、背离光源；辉光是 1–2 圈平涂半透明环，不是渐变；天空是平涂色带。
- 本质：**喜剧靠对话与反应**。即兴感的抢话、尴尬停顿、反应镜头、逐级升级、最后一秒反转。引擎是**极小的人生目标 + 荒谬巨大的科幻手段**：能解决一切的人拿它去办鸡毛蒜皮的小事，另一个人付情绪代价。
- 本质：**一个世界一套颜色**。每套 3–5 色，色相与明度都要和上一个世界拉得尽量开，让观众光看颜色就知道"跳了"；线色与眼白跨世界永远不变。
- 不是儿童卡通（干冷幽默、长停顿），不是日式动画（没有闪光大眼），不是矢量讲解片（这里的线会抖）。

与库里三条卡通的分界：

| 风格 | 线 | 色与光 | 表演核心 |
|---|---|---|---|
| 本条 adult-scifi-toon | 近黑偏紫、处处约 7px 等宽、12fps 煮沸 | 脏而饱和的平涂，硬边阴影块；辉光只归装置 | 对白驱动、反应特写、嘴的弹性变形 |
| rubber-hose | 1920s–30s，匀线但不抖，四肢是管子 | 黑白或单色，没有阴影分区 | 音乐驱动，圆弧动作，器物拟人 |
| cel-anime-80s | 日式，线有粗细变化与收笔 | 角色少数硬边色面 + 手绘背景层次 + 高光网点 | 有限帧、关键姿态、摄影台 |
| comic-pop | 粗墨线有起笔收笔，外粗内细 | 网点、四色错版、速度线 | 分格叙事、拟声字、定格冲击 |

四条不要混：本条禁分格边框、禁网点、禁毛笔式的粗细变化、禁高光反射与萌系大眼高光。**版权红线（不可让）**：绝不复制任何现成作品的角色、剪影、配色组合（例如白大褂尖发老头 + 黄 T 恤小孩）、名字、口头禅、打嗝桥段、标志，或任何现成传送枪的造型；自己造演员、道具和装置。片子里和文档里都不写那个原作名，一句"受成人档科幻情景喜剧动画启发"就够。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 煮沸的等宽线 | 粗细处处一样，每 1/12 秒换一张抖法 | 任何需要"手画且活着"的主题 |
| 硬边阴影块 | 背光侧一块明确形状的深色，边缘就是线 | 体积、光向、道具 |
| 白眼珠 + 小瞳孔 | 4–5px 的小点在巨大眼白里，厚眼睑、眼袋 | 面无表情、震惊、怀疑 |
| 弹性嘴 | 张口/宽度/嘴角/歪斜四个参数，带内腔、牙、舌；情绪由眉毛负责 | 台词、喊叫、咀嚼 |
| 一世界一调色 | 换世界＝整套颜色换掉，线色与眼白不变 | 平行版本、时期、方案 |
| 只会发光的装置 | 唯一发光物：疙瘩边、粗轮廓、转的螺旋臂、浅色核、绕飞火花、滴落 | 转场、跳跃、入口 |
| 科幻硬件当杂物 | 量子级的设备在干一件琐事 | 反差、讽刺、流程吐槽 |
| 怪但可爱的生物 | 恶心又可爱，不说话只出声，躲在家具后仍露脸和上半身 | 每个世界的见证者 |
| 世纪终端标签 | 点阵字一个个敲出来，颜色跟着世界走 | 说明、坐标、报错 |
| 冷场只抖不动 | 音乐硬切，人和物完全静止，只剩线在沸腾 | 反转之后、报价、遗言 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；信号从主题里选，不按顺序全上。
- 煮沸线、硬边阴影、白眼小瞳最容易一眼认出，也最容易被用滥——第二支片子里换一组。

## 这个风格最俗的版本

- 画面：白大褂老头和黄 T 恤少年站在发绿光的传送门前，酸绿的黏液往下滴，泡泡字标题"啵"地弹出来。
- 声音：一包卡通音效（boing、pop、打嗝）叠在没完没了的科幻嗡鸣上。style 一栏写明翻掉了哪几条，或为什么刻意保留；保留时就别动"煮沸线 + 反应特写"，把力气花在世界的颜色落差和那句反转台词上。

## 适配

- 用途：成人向的产品/技术科普喜剧化、几个平行版本的概念对比、内部吐槽片、角色向片头。
- 内容：两个反应相反的角色、一个荒唐但具体的小目标、一串能被颜色区分开的世界。
- 时长：30–90 秒最舒服；对白密度高，超过 2 分钟要拆成"几趟差事"。不适合真实人物表演、复杂手部连续动作、大段无对白的抒情；能力不足时砍动作、保反应特写和颜色落差。

## 技术路线

- 建幕建元素：`add_scene` 一幕一个世界；角色、道具、背景用 `add_element` 分件放——每个部件一个元素，才能单独抖、单独换嘴、单独换色。
- 煮沸：本工具没有逐帧重绘，用 **SVG 滤镜的位移噪声**（`feTurbulence` + `feDisplacementMap`）挂在整层上，按 **8–12fps 步进**切 seed，噪声尺度对应约 7px 采样、位移约 1.7px（按画布缩放换算），3 个 seed 循环。
- 线宽恒定：描边用不随缩放变化的写法（`vector-effect: non-scaling-stroke`），特写只放大图形，不动 `stroke-width`。
- 平涂与硬边阴影：纯色填充 + 同形状的深色块用裁剪/遮罩压在里面；**不用渐变、不用模糊**。
- 换世界：`apply_style` / `set_theme` 换整套调色板，线色与眼白写死不变。
- 看静帧：`preview_frames` 逐拍查线宽、阴影形状、脸有没有压到字幕带；看动：`render_preview_clip` 确认 12fps 步进没被平滑补间吃掉。
- 口型：`tts_narration` 出声，RMS 驱动张口、频谱重心驱动"扁/圆"，分析 24Hz、在 12fps 的作画时刻取样，尖叫时嘴量 ×1.5–1.9。字幕 `set_subtitles`，素材 `upload_asset`，音效与 BGM `add_audio`。

## 材质与渲染

- **线**：近黑偏紫，圆头圆角接头；不做粗细渐变，不做毛笔收笔。
- **填充**：全平。阴影是"略暗的同色系"一块，不是黑色叠加。天空与远景是平涂色带，最多三档，带与带之间是硬边。
- **辉光**：1–2 圈平涂半透明环，边缘干净；只有装置发光，别的东西一律不许发。
- **人物**：剪影在全黑填充下要能读出来；每个主角给一个荒谬的服装点子；避开白大褂 + 尖头发这个组合。
- **生物**：每个世界最多一只，恶心又可爱，不出台词只出声；确认躲在家具后仍露出脸和上半身。
- **装置**：疙瘩状的边、粗轮廓、转动的螺旋臂、浅色核、绕飞火花、滴落物；开着时给画面盖一层平涂半透明色。开启动作用约 12% 的过冲、back-ease 约 0.3 秒——过冲一大就会把演员吞掉。
- **屏内图形**：世纪终端样式的标签，点阵等宽字一个个敲出来，颜色跟着世界走。

## 字体

- **标题**：厚重展示字，12fps 步进弹进来，卡在音乐重音上；选一个有年代感但不是这个类型片头 logo 的款式——**酸绿 + 黏液滴落 + 抖动的泡泡字**三样凑齐就太像某一部具体作品了。
- **字幕**：底部居中，圆头重磅无衬线（源用法是 Baloo 2 ExtraBold，约 50px），白字 + 约 11px 黑描边，看起来像动画自带的字幕；左边一个说话人小药丸，用该角色的颜色、带抖的轮廓。本工具字库里最接近的是 `Inter Tight` / `Archivo Black` 加粗，圆头感靠描边与圆角端点补。
- **行宽与安全区**：一行超过约 1300px 换两行；两行重叠时旧的一行压到约 70% 不透明度。脸不要进底部约 170px 的字幕带，世界标签也别压在脸上。
- **时间**：旁白停留 ≥ max(1.8 秒, 语音 + 0.6 秒)；快对白用 max(音频 + 0.35 秒, 0.9 秒 + 字数 ÷ 17)。换世界之前、以及一个静默拍之前把字幕切掉，让静默落在干净画面上。

## 运动

- **角色 12fps（on twos）**：姿态、嘴、眨眼、走路循环、煮沸步进全部对齐到 12fps。**镜头、漩涡、飞出的道具、擦拭转场 24fps（on ones）**。每个手势先有预备，再有动作。
- **表演在移动之上**：保持姿态里做小变化（眼皮抽一下、瞳孔滑一下、咽口水、汗珠）。待机生命＝呼吸 ±1% 挤压，点头由语音响度驱动。
- 落地用衰减余弦挤压约 22%；从传送口飞出时拉长；"被吸进去"＝朝传送口中心缩小同时拉长。
- 慌乱抖动：12fps 的 3–6px 随机偏移 + 瞳孔打颤，幅度随慌乱增大；冷场里唯一还在动的是煮沸线。

## 画面怎么活

- 每个世界给一件小事：一个道具不听话、一只生物在看、一个读数在变。
- 每个荒谬画面之后立刻给一个反应特写——笑点活在脸上，不在事件上。
- 同构镜头跨世界重复：构图不动，只有颜色、道具、生物换了；一整条链是 说 → 被抢话 → 特写 → 升级 → 冷场 → 一句反转。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 中景双人 | 关系；谁怎么反应 | 对白、对峙、谈条件 |
| 硬切到特写 | 被打断；一张脸崩掉 | 被截断的台词、醒悟、撒谎 |
| 插入物件的极大特写 | 荒谬的细节 | 揭示、问题本身、错的结果 |
| 反应特写 | 笑点在脸上 | 每个荒谬画面之后 |
| 紧特写 + 一个字上短抖 | 慌乱 | 关键词、警报、尖叫 |
| 冲进传送口 → 漩涡擦除 | 离开一个世界 | 任何地点、时间、版本的跳跃 |
| 跨世界重复同一构图 | 只有世界变了 | 蒙太奇、对比、清单 |
| 在静止双人上极慢推近 | 冷场 | 反转之后的停顿、坦白 |
| 广角带装置和两个人 | 一次看全处境 | 回扣、陷阱、重新开始 |
| 过肩看向屏幕 | 读到坏消息 | 消息、读数、报错 |
| 两张脸之间甩镜 | 抢话的争吵 | 吵架、打赌、二次反应 |

规则：每个荒谬画面后面必须接一个反应特写；转场只走装置（漩涡擦）或硬切，**不用叠化**。开头结尾各自从主题里长出来，不套固定模板。

## 声音调色板

- **合成配乐，不需要采样**：类特雷门琴的主音（正弦 + 一点二、三次谐波，连奏滑音约 70ms，每个音头之后约 150ms 淡入颤音，弹簧混响）压在模拟贝斯、方波琶音、复古鼓机上；小调与半音线条适合主主题。
- **每个世界一种类型提示**（可选）：冲浪吉他；波尔卡手风琴；玩具钢琴摇篮曲；电梯 bossa（Karplus–Strong 尼龙吉他）；刷鼓 + 电颤琴；大号 + 滑哨；温暖 Rhodes + 一句"啊"；颤音弦乐给慌乱。手法：一个提示的第一拍就是切点；把速度对到剪辑网格；三段式变连发（同一个 stinger，一次比一次短）。
- **静默是包袱**：在揭示处和冷场处把音乐硬切，连混响尾巴一起切；只留房间底噪（日光灯嗡、钟表滴答、冰箱）。
- **拟音（合成）**：传送口开（次低频 boom + 下扫噪声 + 上扬漩涡）、嗡鸣、关上的 "fwump"、每次擦除的漩涡 whoosh、pop/boing、湿的 glorp/squish、吸溜、咀嚼、眨眼的 "blip"、点击哔、卡祖笛刺音、吱吱玩具。
- **人声**：两个人音色要相反——面瘫的那个低、平、慢（轻饱和 + 约 180Hz 的凸起做沙哑）；慌的那个更高更快（提存在感）。小生物可以说一两个词，升调。压缩、RMS 对齐、加短的早期反射让人声进房间。对白下音乐压约 −7dB；整体 −14 LUFS。

## 原生手法

- **平行世界**：每次跳＝新调色板、新提示、新生物。适合产品的几个版本、你可能过上的几种职业、同一座城的五个年代。
- **双人反差**：面瘫对慌乱，笑点在两种反应的差里。适合老手与新人、家长与孩子、AI 与它的用户。
- **三段式变连发 / 可疑地正常的世界**：两个慢慢来的错答案，然后一秒一个世界、用同一句拒绝词卡着拍切；或者模式突然被打破，平静本身就是笑话。
- **冷场反转 / 硬件当杂物 / 回扣收尾**：长静默后一句话交出价值观；能撬动世界的技术用来干一件琐事；最后一句重复第一句，故事闭环。

## 变化空间

- 结构三种：一个世界多种时钟（不出门，装置把人按一天里的时刻来回跳，一次比一次糟）；面试（一组评委面来自别的世界的候选人，每个配一种类型提示）；技术支持通话（分屏两个世界，一个声音遥控另一个世界的灾难）。
- 开场三种：已经在灾难中间（门早开着，有东西正在过来）；先看说明书（终端读数讲完装置才见到人）；落在错的世界（先从荒谬世界开始，很久以后才回家）。
- 结尾三种：困在别处（装置坏了，他们开心地住下）；观众（某个世界的生物把整片看了一遍并打分）；代价（安静的最后一镜，不搞笑）。前提、演员、世界、笑点、节奏、调色板全由 agent 自己定。

## 坑

- TTS 把连字符的结巴读成词 → 写音节（"坏、坏——坏掉了"），把读错的词改拼，名字要经得起低沉嗓音。
- 极短的音频会被识别听错 → 前后垫约 0.6 秒静音再对。
- 要一句真的抢话 → 被抢的那句先生成得比需要的长，在另一个声音插进来的地方把音频剪断。
- 弹性过冲会把演员吞掉 → 用温和的 back-ease，别用弹簧参数。
- 食物和液体没有提示（表面细节、滴落、热气）→ 会被读成别的东西。
- 方波合成的镲会混叠成 8–20kHz 的刺耳嘶声 → 用带通噪声加一点 FM。
- 低于 40Hz 的持续低频在笔记本喇叭上是隆隆声 → 收高一个八度。
- 音乐切了但混响尾巴没切 → 那不是静音。
- 用低帧率抽帧看片，抽到的帧可能偏 0.5 秒 → 别把抽帧错位当成镜头边界，用 `preview_frames` 单帧核。
