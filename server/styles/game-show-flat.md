# 综艺节奏扁平（game-show-flat）

> 一句话本质：把片子做成一局节奏游戏——全片一个固定快 tempo，每一次弹出、掉落、盖章、打字、镜头冲撞都落在（小节, 拍）上，并且同时是一次音效。
> 一句话参照（只学语法）：节奏动作派对游戏（cue → answer、回合卡、判定词）、日本综艺的厚描边字幕与条纹/放射布景、WarioWare 式关卡卡。不照搬它们的名字、角色、UI、关卡和音乐。

## 本质 / 不是什么

- 本质：**一切都在网格上**。全片只有一个快 tempo，不改速；每个 pop、掉落、盖章、打出的一个字符、镜头冲撞，都坐在一个（小节, 拍）上，并且同时是一次声音事件——配乐由画面自己的时间线生成，所以两者不可能漂。
- 本质：**一套画法，多套布景**。平涂、一条粗墨线、圆头、硬偏移阴影；每一回合换一个饱和底色和同色相花纹。
- 本质：**角色是玩具**。全体共用一套身体结构，靠颜色、肚皮补丁、一个头部配件和名牌区分；踩拍跳、被击中压扁、喊的时候举手。
- 本质：**一回合 = 一个可重复的动词 + 一次胜利**。主题拆成回合，每回合有一个能踩拍重复的动作，结束在一个一眼读懂的判定上；长度就是回合数（每回合 = 一张标题卡 + 它的小节数），旁白可选——这个风格能只靠短喊和字幕撑起一支片。
- 不是 **`flat-vector`**：那边无描边、靠色块和尺度穿行讲一个小世界，没有拍网格、没有角色音效；这里的黑描边、硬阴影、"每个动作都是一次声音"就是全部语法。
- 不是 **`kinetic-brutalist`**：那边字是唯一主角，靠尺寸与反色冲击；这里字只是贴纸和横幅，主角是角色与动作，且动作必须踩拍发声。
- 不是微游戏狂欢（没有 3 秒一关的计时、没有每关换画风），不是中世纪卡通（没有绘画肌理背景、没有角色表演），不是 keynote（没有慢揭示、没有渐变）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 厚墨描边 + 硬偏移阴影 | 角色与道具 8px 墨线、小部件 5–7px、圆角接头；同形状的墨色副本偏 10–14px 垫在下面 | 一切；玩具感 |
| 条纹 / 圆点 / 放射布景 | 饱和底 + 同色相浅一档的花纹：斜条纹（常缓慢滚动）、错位圆点（约 20% 白）、旋转放射 | 回合、年代、阶段 |
| 回合卡 | 一小节：回合号 + 名字 + 一个标签（年份、步骤），踩 jingle 飞进来 | 步骤、历史、目录 |
| 判定词 | 一个厚描边大词斜着砸在回合最后一拍 | 交付、通过、个人最佳 |
| 踩拍掉落的人群 | 一排角色一拍落一个，每人一个音高不同的 pip | 成员、配料、星球 |
| 打字机成绩单 | 逐字打出，末尾盖一个评级章 | 复盘、总结、评分 |
| 呼叫-应答 | 两半画面轮流来，四分音符加速到八分音符就是剧情 | 师徒问答、点单与回复、谈判 |
| 游戏化数据 | 领奖台、冲向目标的计数器、被锤的价格牌、按拍生长的柱 | 进度、销量、预算 |
| 缩略图槽位 | 演完的一段缩成小图落进底部槽，高潮时所有槽一起弹 | 年度回顾、发布清单 |
| 小节线硬切 + 白闪 | 没有叠化，切点在小节线上，一帧极短白闪；底部一条更深的地面带压墨线，角色站在上面 | 换回合、换布景 |

规则：
- 每支挑 2–3 个，至少一个不在「最俗的版本」里。
- 条纹、判定词、回合卡三样最好认也最易用滥，第二支片子换一组。
- 布景花色与角色颜色不能同色相：角色永远不穿和背景一样的颜色。

## 这个风格最俗的版本

- 画面：黄底橙色斜条纹，一个"第 1 关"大字弹出来，一个小人跳两下，结尾一个巨大的"完美！"，全片只有四个元素。
- 声音：一段通用的欢快 loop，每个动作配一个"啵"。
- brief 的 style 一栏写明这支片子翻掉了哪几条，或者为什么刻意保留。保留时把力气花在"回合的动词设计"和"判定词落点"上。

## 适配

- 用途：综艺感包装、排行榜与成绩单、功能回合制讲解、年度回顾、教学步骤、活动招募；不适合要沉静、要留白、要连续叙事的题材。
- 内容：能切成 3–8 个"回合"、每回合有一个可重复动作和一个明确胜负的主题；时长 30–90 秒最舒服（8–16 小节 × 2–4 回合），超过 2 分钟要把回合数压下来、每回合多给几小节，否则观众被连续重音打累。

## 技术路线

- 纯矢量：SVG 或 canvas 路径，1920×1080，平涂 + 一条近黑墨线；不加 WebGL 质感层，不加颗粒。
- 本工具：`add_scene` 建回合、`add_element` 放角色/道具/字幕牌，画风统一走 `set_theme`（或 `apply_style('game-show-flat')` 一次到位）。
- **先做一张节拍表**，再动手：一小节秒数 = 240 ÷ BPM。BPM 120 → 一小节 2.0 秒；128 → 1.875 秒；140 → 1.71 秒。按工程帧率换算（30fps 下 120 BPM 一拍 15 帧、一小节 60 帧）。这张表同时供元素入场帧、切点帧、`add_audio` 的音效时间码使用——只此一张，不另开手工清单。
- 静帧验收：`preview_frames` 看每个切点、每个判定词的定帧；动效验收：`render_preview_clip` 看一小节以上的连续段落，确认"动作与声音同点落地"。
- 每一帧的状态都由时间重算（Remotion 里就是 `t` 的纯函数），不允许"上一帧累积"式写法，否则并行渲染的冷启动帧会是初始状态。
- 字体落地：`set_theme` 换标题字体。源文件要的圆头重磅（Fredoka 700 / Noto Sans SC 900）本工具字族里没有，用 `Archivo Black` + `Microsoft YaHei` 粗体顶，描边靠"墨色底层 + 彩色上层"两层文字叠出来。
- 旁白 `tts_narration`；字幕 `set_subtitles`；音效与 BGM `add_audio`。

## 材质与渲染

- **无渐变、无模糊、无肌理、无柔和阴影。** 深度只有一种做法：硬偏移阴影——同形状的墨色副本偏 10px（贴纸、横幅）到 14px（卡片），彩色形状压在上面。
- **描边**：角色与道具 8px，小部件 5–7px，一个描边色（近黑），圆角接头与端点。
- **布景** = 一个饱和底 + 同色相浅一档的花纹（斜条纹、错位圆点、旋转放射）；底部一条更深的地面带，上面压一条墨线，把角色"放"在地上。
- **角色**：圆豆身体、短手连指手套、椭圆眼带一点高光、嘴可换成张开的；人类共用这套结构，更老的机器或年代靠更方的剪影区分。
- **UI 套件**：圆角卡、角上贴纸横幅、判定词、爆炸（星 + 环 + 速度线）、记分板。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 墨 | `#14100E` | 所有描边、硬阴影、判定词的底 |
| 白 / 奶油纸 | `#FFFFFF` / `#FFF6E6` | 大字填充、圆点花纹、卡片与纸道具 |
| 糖果黄 | `#FFD93D` | 判定词、大字 |
| 橘 | `#FF9F1C` | 布景、强调 |
| 粉红 | `#FF5D8F` | 判定词、角色 |
| 青绿 | `#2EC4B6` | 布景、对答的一侧 |
| 天蓝 / 蓝 | `#4CC9F0` / `#3A86FF` | 布景、夜场 |

- 糖果色约八个（黄、橙、红、粉、绿、青柠、天蓝、蓝），另备 2–3 个深色配更深的搭档，给夜场和决赛。
- **一个布景 = 一个色相**：背景、花纹、回合卡同色相，卡片颜色随它引出的布景变；相邻回合不共用色相。
- **角色颜色是身份**，全片不变，且绝不同色相于它站的背景。
- 大字白或黄 + 厚墨描边；判定词可以粉或黄。
- 示例布景：橘地 `#FFB870` + 条纹 `#FFA85A`；青绿 + 薄荷圆点；藏青 + 金色放射。

## 字体

- **展示**：拉丁与数字用重磅圆头无衬线（Fredoka 700 一类）；中文用黑体最重字重（Noto Sans SC 900 一类）；手写体只给手写道具（ZCOOL KuaiLe 一类）。本工具可用字族里退到 `Archivo Black` + `Microsoft YaHei` 粗体。
- **字幕牌（telop）**：白或黄填充 + 墨色描边 ≈ 字号的 14%，描边画在填充**下面**（`paint-order: stroke`）；标题逐字搭出来，每个字能单独 pop。
- **telop 就是字幕**：回合卡、角标、标签、道具上的字、判定词承担语义。横幅一行 ≤ 20 个汉字，牌子上 ≤ 12 个，拉丁约宽 1.6 倍。
- 有旁白时，字幕是底部同一套描边字幕牌，不是细的通用字幕条。
- 每块字保持 ≥ max(1.8 秒, 语音 + 0.6 秒)；判定词可以更短，因为它一眼就读完。

## 运动

- 全片一个固定快 tempo，任何段落都不改速。
- **待机 = 踩拍跳**：每拍一个抛物线（8–30px）；邻居踩反拍，人群就有波纹。
- **击中 = 压扁**：每次命中后一次阻尼抖动（约 30 rad/s，约 0.35 秒）；每个重拍来一小下压扁；喊的姿势是举手 + 张嘴，约半拍。
- **入场从天上掉**，ease-in，正好落在它那一拍，声音跟它同时落地；人群一拍或半拍掉一个。
- **出现的任何东西用 back-ease pop**（卡片、贴纸、印章、字），离场用 ease-in。没有缓慢淡入——东西要么在，要么"啵"地出现。
- **打字机**按拍的细分逐字出，每几个字符一个 click。
- **换场景在小节线上硬切**，带一帧极短白闪；淡入留到最后，能不淡就不淡。
- 没有任何动作离开网格：拍与拍之间的事件坐在细分上。

## 画面怎么活

- 一个回合里始终有东西在跳：人群的踩拍跳、条纹缓慢滚动、放射缓慢旋转、记分板每拍跳一个数、角上贴纸轻微摆动。幅度小，不抢台词。
- 落地和压扁是唯一允许"不精确"的地方，但它也必须从拍上起算。
- 只有两处可以静：大判定前的那一小节鼓点、以及"等判定"的半拍。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 拍打（以中心 0.8–5% 缩放，约 0.16 秒衰减） | 击中，让画面也感觉到 | 任何重音、砸下、倒数 |
| 一小节里连打好几下 | 画面跟着音乐呼吸 | 副歌、升级的花样 |
| 锁死正面全景 | 整个舞台是一块游戏板 | 铺陈花样、人群、记分板 |
| 小节线硬切 + 白闪 | 新回合、新布景 | 章节切换、前后对比 |
| 分屏舞台（两半、两套布景） | 两边互相应答 | 对决、人对机器、新旧 |
| 缩成缩略图（演完的一段缩进槽里） | 记忆、累积 | 回顾、"这些都是后来发生的" |
| 布景竖向滚动（从地面到天） | 赌注或规模在升 | 排行榜、成长、一摞东西 |
| 急推到一个道具（硬切 2× 取景，下一小节回来） | 这个细节就是笑点 | 价签、一个数、一张反应的脸 |

取景：舞台是一个正面、对称的台口；机位不动，动的是画框。同时进行的冲撞总和压在 0.06 以下，否则画面边缘会露。角色站在地面带上，横幅在左上，判定词在上方居中。只硬切，不叠化。

## 声音调色板

- 全部合成，由画面事件驱动：正弦 kick + 轻饱和；带通噪声军鼓与拍手；hi-hat；slap bass；失谐锯齿铜管短音 + 收滤波；方波主音 + 颤音；马林巴式拨弦；八音盒铃；三角波铺底；方波琶音；牛铃。
- **一个明亮的大调流行和声**，短和弦 loop，一小节一个和弦；每回合换一种味道（funk、quiz、electro、梦幻、重型……），不是换一首歌。
- **事件拟音全是玩具感且有音高**：pop、落地 plop + boing、盖章、打字 click、蜂鸣、叮、伺服嗡、啪叽；人群掉落时，音高不同的 pip 可以拼成旋律。
- **喊，不是句子**：一到三个词（"嘿！"、一个数字、一个判定），放在拍前 20–30ms，让辅音落在拍上。人群喊 = 几个不同声音错开几毫秒叠在一起、铺开在立体声场。
- 强度变化（按需挑）：每回合进 jingle（crash + 上行铜管 + 军鼓滚）；决赛升调；大击前一小节只剩鼓；揭示前一小节 half-time；一小节静默被一个喊打破。
- 混音：人声与拟音单独一条总线；音乐被这条总线的包络压下去；用软削波不用硬限幅；−14 LUFS，真峰 ≤ −1 dB。

## 原生手法

- **有卡的回合**：一小节卡片（回合号 + 名字 + 年份/步骤标签）踩 jingle 飞入，然后开演。适合配方步骤、创业阶段、展览章节。
- **成绩单**：打字机逐字打出，末尾盖评级章。适合季度复盘、旅行总结、最终得分。
- **呼叫-应答**：任何有来回的内容都能变成节奏型，把四分加速到八分就是剧情。适合师生问答、点单与回复、两边谈判。
- **下一关预告**：有东西孵化或解锁。适合下一个版本、下一季、下一个等级。
- **判定词**：大描边词斜着砸在回合最后一击。适合"交付完成""通过""个人最佳"。
- **混音台**：一套布景 + 一条时间轴缎带，每项在中央演几小节后缩进底部槽位，高潮时所有槽一起弹。适合年度回顾、发布清单、演出阵容。
- **数据当游戏 UI**：数字变领奖台分数、冲向目标的计数器、被锤的价签、按拍生长的柱。适合募资进度、每道菜的热量、下载量。
- **人群掉落**：一群人一拍落一个，每个带一个音高不同的 pip。适合社团每个成员、太阳系的星球、一道菜的配料。

## 变化空间

每一支由 agent 决定：回合和回合里的动词、角色阵容、布景与配色、有没有旁白、tempo、开场、结尾、长度。**网格、画法、telop 语言不变。**

- **结构**：淘汰赛对阵表（每回合两人，胜者晋级，决赛是分屏舞台）；一个不断加速的长回合（四分 → 十六分，压力上升就是剧情）；三个选手的答题秀（每题是主题里的一个事实，记分板就是论点）。
- **开场**：先给判定（空舞台上先弹出"完美！"，再倒回去看它是怎么挣来的）；一个选手独自在空地上跳，直到人群掉进来；记分板先亮出最终数字，再倒数回零。
- **结尾**：合影（所有人在跳到一半时定住、一闪、画框变成卡片上的一张宝丽来）；关卡选择地图（每个打完的回合亮成一个节点）；幕布一小节一小节落下，最后一声喊在幕布底下。

## 坑

- **有人扛了状态** → 并行渲染的冷启动帧是初始状态。改：每个姿势都从 `t` 重算，用单帧静帧和连续片段各比一次。
- **cue 清单会漂**：白闪、jingle、编排各写一张手工清单，很快就对不上。改：全部从那张节拍表派生。
- **固定长度的音频缓冲切掉尾巴** → 改：按实际时长开缓冲，留出尾音。
- **字体没加载完就量文字** → 字幕牌溢出。改：先等字体就绪再排版，然后 `preview_frames` 抽一帧看最长的行。
- **TTS 念错数字和符号** → 改：喊词里的数字写成汉字，符号写成词，`tts_narration` 之后再校对一遍。
- **把真实产品当角色**：名牌上写真实名字、画原创吉祥物、带 logo 或 UI 都不行；真人只能做通用替身。改：全部换成无品牌的玩具角色。
- **冲撞叠加过头**（同时多个 zoom 相加 > 0.06）→ 画面边缘露黑。改：一小节里的多次拍打要错开、且衰减完再下一次。
- **只堆元素不设计动词** → 变成了会动的贴纸墙。改：先写"这一回合观众要跟着数什么/跟什么"，再决定元素。
