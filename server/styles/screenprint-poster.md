# 丝印旅行海报（screenprint-poster）

> 一张海报在镜头前被印出来：每种颜色都是一层不透明的墨，各刮一刀，后印的把先印的完全盖住。
> 参照（只学语法）：1930–40 年代 WPA 国家公园丝网版画（4–6 个实色、明暗两面、阶梯天空、底部深色信息带、同心太阳）、Fifty-Nine Parks 那种"一张模板、每张换一套配色"的克制、以及丝印的物理过程（合页网框、刮刀推着墨珠走、分色刮、拖痕、针孔）。不照搬任何真实海报的构图、地名、字形与标志，片子里不点名。

## 本质 / 不是什么

- 本质：**一色一刀**——一层墨一次刮印推出来，层次就是事实的顺序，不是滤镜的层数。
- 本质：**没有渐变**。天空和雾是**阶梯色带**：一块平色 → 变细的条 → 下一个颜色，全片找不到一处平滑过渡。
- 本质：**边缘很硬**：一个形状的边就是"一种实色停下来的地方"，没有描边、没有线稿、没有糊边。
- 本质：**叠印有物证**：每层固定错开 1–3px（1080p）；挖空处留一道纸白的月牙；每层墨底下约 2 u 有一层极淡的 multiply 鬼影，墨压墨处一条更深的细边；墨有厚度——左上亮边、右下暗边，只做在填充上，刚印下的一秒有湿亮。
- 本质：**纸是颜色**：米色带纤维的纸，没印上的地方是整张画面最亮的一处（水、雪、一道光）。
- 本质：**信息按印刷顺序到位**：一层一拍，底部那块深色信息带最后才印。

不是 `risograph-print`：那个是半透明专色互相混色、半调网点、错版一直在抖、手账味。这里是**全部不透明的实色**、**没有网点**、**没有渐变**，错位固定 1–3px 全片不漂。
不是 `flat-vector`：扁平插画没有印刷的物证——没有刮刀前沿、没有墨的厚度、没有纸。
不是木刻或浮世绘（靠刻出来的线和渐层），也不是低多边形（靠 3D 面）：这里一根线都没有，体量靠色阶的明暗两面。
不是"加噪点的复古滤镜"：颗粒在这里预算很低，主角是实色和刮印本身。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 刮刀前沿拖尾 | 一条毛边前沿推着色块长出来，~30 u 拖尾上挂着刀刃、墨珠和一小截手柄 | 钩子、色块到位 |
| 阶梯色带 | 平色 → 变细的条 → 下一色，一处平滑过渡都没有 | 时间、海拔、天光 |
| 同心太阳 | 一个明色实心圆，外面一两圈越扩越细的环 | 强调、地名、开场 |
| 纸白当主体 | 水/雪/光那块完全没有墨，是画面最亮的地方 | 冬季、雪山、灯塔 |
| 底部信息带 | 最深的墨压在最下方，装名字、编号、一条细规、一行数字 | 日期、价格、时长、难度 |
| 一色一刀 | 每层一块一块被推出来，先后看得见 | 讲解、构成、清单 |
| 挖空露纸的月牙 | 两个形状交界处一道纸白细缝，像对版差了一点 | 手艺、可信度 |
| 明暗两面 | 山脊、松树、屋只有一块受光面和一块背光面，都是实色 | 地形、体量 |
| 印进天空的大字 | 名字压在浅色天光里，字距拉开；针孔和斑驳只在墨面上看得见 | 标题、地名 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；刮刀、阶梯天空、同心太阳最容易被一眼认出，也最容易被用滥，第二支片子换一组。
- 一色一刀、错位、纸是颜色是媒介的物理约束，作为材质始终都在；区别在于放大哪个。

## 这个风格最俗的版本

- 画面：一张居中竖版海报，红黄蓝三原色，一个大圆太阳压在山后面，底部写一行"EXPLORE"，镜头一路推近，所有层淡入到位。
- 声音：手风琴加曼陀林的世界音乐氛围，垫一层黑胶底噪。
- brief 的 style 一栏写明翻掉了哪几条，或为什么刻意保留。保留时把力气花在"暗度真的分级"和"最后信息带那一下"上。

## 适配

- 用途：地点/线路/景点导览、活动与节日海报、目的地系列、产品配色发布、季节与营业时间公告。时长 10–40 秒：三个条目 30–40 秒，单张活动海报 15–20 秒，系列墙 20–30 秒。
- 内容：手里有**几个事实**的题材——地名、日期、时长、距离、难度、价格、三四个选项。纯情绪片不合适，它天生是信息海报。

## 技术路线

- 一张海报 = 一个场景（`add_scene`），每层墨 = 一组形状/文字元素（`add_element`），按印刷顺序排层；形状**只填不描**。
- 挖空：本工具没有"路径挖洞"，就直接用**纸色形状压在上面**当洞——墨是全不透明的，效果一样。
- 刮印揭示：一条毛边遮罩从左往右推进，前沿挂刀刃、墨珠、一小截手柄。做不到逐点遮罩时退成"色块原点在左横向长出来"，但前沿要毛、要匀速，不许缓动。
- 错位：每层固定偏移 1–3px，写进元素坐标，全片不变，不做漂移。
- 信息带：深色矩形 + 名字 + 编号 + 一条 1px 细规 + 一行数字，最后 1–2 拍才出现。
- 验收：`preview_frames` 先看"印完的整张"（色阶、纸白、错位、信息带），再 `render_preview_clip` 看刮的平速和"一层一拍"。落地：`set_theme` / `apply_style('screenprint-poster')`；字幕 `set_subtitles`；旁白 `tts_narration`（多数片子不需要）；素材 `upload_asset`；声音 `add_audio`。

## 材质与渲染

- **纸（最底）**：米色纸，细纤维、斑驳、针孔；纸纹全片固定，不上移不缩放。
- **墨**：实色填充，边缘硬（靠不描边、不加投影）；左上亮边 / 右下暗边只在填充内侧 1–2px。
- **叠印**：上层墨直接压住下层（不透明，不做 multiply 混合）；只在交界留一条 ~2px 更深的边（墨压墨）和一道纸白月牙（挖空）。
- **刮刀与墨珠**：圆管状墨珠（上半受光、下半暗、滚动高光、黏连的丝）、平直刀刃、手柄只露一小截；分色刮时一条墨珠里并排几种色。
- **网框**：合页框 + 网纱 + 感光胶 + 胶带；抬起时它的影子是**环状**（中间空），绝不是整块矩形。
- **形状语言**：山脊带一片锯齿状的受光面；松树是一条轮廓里挂着下垂的层级；水是一整块平色加几根高光条。边全是硬的。
- **纹理预算**：纸纹一层、斑驳 multiply ≈55%、针孔 ≈75%、编码细颗粒一层——再往上就变成孔版印刷了。模板 1000×1500 u：纸边、画区、底部深色信息带，栏宽按内容定。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 纸 | `#F3EBDC` | 米色纸，全片最亮 |
| 近景（最深） | `#1E3B3F` | 山体、树，也是信息带 |
| 天光 | `#F6CD98` | 最浅的一层墨 |
| 强调 | `#FBE6B4` / `#E8553D` | 太阳、路线、关键数字，一屏一次 |

- 一张海报 ≤6 个墨，按角色分：浅天、深天/色带、远、中、近（最深，兼信息带），加**一个亮强调**；需要时可多一层受光面墨。
- 明度从远（浅）到近（深）逐级下降；**纵深靠明度，不靠模糊**。强调要罕见：太阳或光源、唯一那条路线或产品、最重要的那个数字。
- 文字墨按底下那层墨的对比度选（WCAG），不固定用某个键；夜间配色别把标题吞掉。
- 三套示例（看思路，不要照抄）：黎明 `#F6CD98 #EE9A73 #9A7FA8 #3E7079 #1E3B3F` + `#FBE6B4`；港口正午 `#E8F0F2 #7FB3C8 #D9C7A3 #2F6E8E #173247` + `#E8553D`；冬季 `#EEF1F4 #B8C9D9 #8B9BB0 #4A5D78 #1F2A3C` + `#F2B134`。

## 字体

- **展示字**：窄体大写（Big Shoulders Display、League Gothic 一类；本工具用 `Archivo Black` 压窄、或 `Inter Tight` 加大字距替代），自动缩到栏宽。
- **标签**：几何无衬线并拉开字距（Outfit 600 一类；本工具 `Inter Tight` + letter-spacing）；中文用 `Microsoft YaHei` 粗体，要文学感才换 `Noto Serif SC`。
- 名字和数字印进天空里，字距拉开；信息带最后印。直视整张的那一帧里标签 ≥18px、数字 ≥30px（1080p）；信息带特写时整条带在画面内，左右各留 ≥5%。
- 阅读时间：每段文字在它**最后一项**落位后停留 ≥ 字数 ÷ 12 + 1 秒（最少 1.5 秒）；有旁白时 ≥ max(1.8 秒, 语音 + 0.6 秒)，向上取整到拍。
- 字幕：**海报上的字就是字幕**。有旁白时把字幕做成一条纸带，一次横扫印出来，绝不漂浮。

## 运动

- 刮印是**匀速直线**——刮刀不缓入缓出。强调色比它那层的主墨晚半拍起。
- 信息带里的项按拍的三十二/十六分音符从左往右依次印出。
- **全片没有淡入淡出**；禁止叠化、弹跳缓动、文字缩放弹出。
- 抬框：网框向上掀起（纵向挤压 + 影子变大）约 0.4 秒。换色重印：一把宽刮刀斜着扫过整张纸约 0.35 秒，刀两侧的几何完全一样，只有墨变了，只出现刀刃、墨珠和一小截手柄。
- 松开的分层：按深度错开、留纸缝和厚度影，然后在一个重音上**一次卡回对位**。

## 画面怎么活

印完的纸不是死的：墨的湿亮在一秒内褪掉（唯一允许的"渐变"，而且在时间上），刮痕的毛边以 ≤1px 的幅度轻微呼吸，纸纹一动不动，印好的色块不再动。停下来时要留出可读的东西——编号、日期、一行数字，让画面停在一张完成的海报上。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 跟着刮刀平移，轻微滚转，框边入画 | 正在被印；颜色到来 | 开场钩子、分色刮的天空 |
| 锁死的俯拍整张纸 | 层叠成一张画 | 看它长出来、对比 |
| 抬框瞬间快速后拉 | 一层完成的揭示 | 段落收尾、标题 |
| 推到信息带并微俯 | 读 | 事实、日期、价格 |
| 穿过前景剪影（树、灯柱、帆） | 进入下一张海报 | 海报之间的转场 |
| 在松散的分层里穿行（多层视差） | 纵深；在印刷里走一段 | 线路、爬升、街道 |
| 沿一排成品缓慢横移，或推到网纱看见织纹 | 一套；手艺与颗粒 | 系列墙、色款、细节 |
| 对数变焦后拉到墙上/橱窗 | 海报在真实世界里 | 结尾锁定（停 ≥3 秒） |

取景：特写整张纸时纸边留在画面里；刮刀横过特写时带一点角度、手柄藏起来，别让它把画面劈成两半。换层靠刮刀，换海报靠前景剪影或桌面平移。**不用叠化，也不用硬切。**

## 声音调色板

- 只用手弹的原声乐器：扫弦吉他、滑棒、口琴、立式贝斯、箱鼓或鼓刷、班卓、提琴、手风琴、簧风琴、尤克里里。按地方选一族：民谣、冲浪、bossa、铜管乐队都成立。
- **一刀一个重音**：每层墨落在一次扫弦/一下鼓/一个和弦变化上；要加速就细分拍子，不改速度。对位卡回那一下是最响的重音。
- 拟音按材质：刮刀过网纱（带通噪声，网纹约 220–280Hz，越快越亮）、湿墨的黏声、网框落下的哒声与合页的吱声、纸的盖章声、虚线路线的滴答、纸的沙沙、木夹与金属夹、晾片夹。
- 环境声来自印刷内容里：印完的场景可以"醒过来"（海浪、街道、人群），J-cut 进、L-cut 出；桌上垫一层很低的房间底噪。
- 沉默是工具：关键事实之前音乐停一拍，只剩一个环境声，之后第一个声音是决定性的动作（一记夹子、一段长长的上滑）。混音：拟音之下音乐压几 dB，整体 −14 LUFS。

## 原生手法

- **一色一拍**：事实最后才印，正好在要读的时候。适合：开放时间、船班、品鉴笔记。
- **分色刮**：一刀里几种墨铺满画面。适合：节庆的夜空、日落的海滩酒吧、一排色款。
- **换色重印**：同一张换一套配色 = 时间过去、季节、变体。适合：夏冬两种营业时间、三款外套、市集的白与夜。
- **对位滑移 → 卡回**：松开的层在关键事实前一下卡准。适合：比赛日期、发售价格、开票时间。
- **纸当颜色**：没印的纸是画面里最亮的。适合：滑雪道、灯塔的光、屋顶的新雪。
- **路线当一层墨**：一条虚线强调色一段一段盖上去。适合：公交线、马拉松赛道、配送路径。
- **系列墙**：所有印张最后挂在一起当收尾。适合：城市的四个区、巡演日期、一个产品家族。

## 变化空间

agent 决定：主题、场景与分层、配色（在色彩逻辑内）、几张海报、相机路径、开场、结尾、乐器家族、长度。

| 用途 | 印刷顺序 | 每层停留 | 长度 |
|---|---|---|---|
| 线路/景点导览 | 地点 → 每项：场景 → 名字 → 难度 → 距离 → 时间 → 页脚 | 标题 ~3 秒；名字 ≥ 字数÷12+1 秒；数字行在最后一项后 ≥2.2–3 秒 | 30–40 秒，3 项 |
| 活动/节日海报 | 场景刮印 → 大标题 → 日期 → 场地 → 行动号召 | 标题 2.5 秒，日期+场地 3 秒，结尾 3 秒 | 15–20 秒 |
| 目的地系列 | 一张模板，每个地方一套配色：名字 → 一个事实 → 系列墙 | 每张 2.5 秒 + 墙 4 秒 | 20–30 秒 |
| 产品发布 | 围着扁平的剪影逐层印 → 名字 → 三款配色（换色重印）→ 价格/日期 | 每款 1.8 秒 | 12–18 秒 |
| 季节/营业时间 | 一张海报按季换色 → 季节 + 时间 | 每次 2 秒 | 10–15 秒 |

- 结构还可以是：一张海报四个夜晚各印一次（信息带里换阵容）；一条街的多层横移（路过一家家店铺，招牌被印出来）；一个印坏的故事（对位一直漂着，最后一刀正好落在那天日期上）。
- 开场：空网框（光穿过空网、一张感光胶网版被曝光）；先印强调色（亮色孤零零躺在纸上）；夜里挂在墙上的成品，再回到桌上。结尾：晾片架（一排夹着的印张在晃）；海报在真实场景里（贴上车站广告牌，开始下雨）；最后一刀是纸（刮刀刮干，留下一个白色剪影）。

## 坑

- **做成孔版印刷**（最致命）：半调网点、荧光、错版一直漂、颗粒堆满。这里没有网点、没有渐变、错位固定 1–3px、纹理预算很低。
- 描边当边 → 会画出一条线。只填不描；要内部线就用"填色 + 偏移填色裁进遮罩"。网框影子做成整块矩形 → 把画面弄脏，用环状影子。
- 水边用冷色阴影 → 读成水面，阴影一律用近景那层墨；墨珠画成锯齿 → 像纸边，墨珠是圆的。
- 只有视差会读成"山在动"：松层时给纸缝和厚度，卡回归零，并且出声。
- 剪影转场在中间久留 → 一帧黑屏；全遮只持续约 1 帧。很宽的长条在 16:9 里只剩一条缝 → 控制在约 4:1。
- 桌上撒一把彩色圆点 → 像彩纸屑；要有真的工作台（木纹、哑色污渍、胶带）。
- 条目太多撑不下 → 并排在同一刀里印，或把次要项留到最后那面系列墙上读。
- 本工具的坑：形状给了圆角或投影 → 整片发软，气质全丢（radius 写 0）；色块用了缓动 → 刮印变成"弹"；转场用了 fade → 直接违反这条风格（用 wipe 或纯移动）。
