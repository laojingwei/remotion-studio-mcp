# 低多边形等距（lowpoly-isometric）

> 一个由平面着色几何体搭起来的小世界，浮在多面体的海或虚空里：正交等距、单一光源、硬边、大面。
> 参照（只学语法）：Townscaper 的「放一块就是一个音」、Monument Valley 的等距几何与空镜。不照搬它们的网格、建筑、角色、界面，也不在片子里点名。

## 本质 / 不是什么

- 本质：**真的 3D 几何体**——平面着色（flatShading，每个面一个色、面与面之间是硬边）、低多边形（大面、三角面看得见）、光源单一。
- 本质：**正交相机**——没有透视汇聚，远处的房子和近处一样大；距离消解成一条屏幕空间的天空渐变，世界像一件悬在颜色里的模型。
- 本质：**光是时钟，不是纹理**——太阳一移，每个面换色；天黑之后只有自发光块还留着自己的颜色。
- 本质：**出现即表演**——每一块落下来都有一次弹跳和一声，搭建本身就是叙事。
- 不是 `isometric-infographic`（等距信息图）：那边是**画出来的 2D 矢量**等距，30° 轴线和三个明度是手工刷的；这里明度由光算出来，面还会随光转向换色。
- 不是 `soft-3d-toy`（软萌 3D）：那边圆角、哑光、有弹性；这里**所有边都是硬的**，倒角为零，形变只允许落地那一下的挤压。
- 不是体素游戏（没有方块套方块、没有像素贴图），不是移轴实拍（没有透视、没有照片细节），不是平滑着色的 3D 卡通（没有圆润法线、没有次表面）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 六边柱地形 | 尖顶六边柱一块块浮着，柱间留缝，缝里是暗的 | 地块、区域、阶段 |
| 一块一声 | 每块落定同时响一声木质或钟琴，后一段重放成旋律 | 从零到一、组装、累加 |
| 硬边的三角面 | 屋顶和树的斜面上看得见一条条棱，没有过渡 | 工艺、手工、材料 |
| 面随光换色 | 同一个面从粉变紫变蓝，太阳是唯一的变量 | 一天、季节、时段 |
| 自发光窗口 | 天黑后只有窗、灯、光柱亮着，并逐户亮起 | 上线、入夜、网络 |
| 柱顶薄盖 + 暗侧壁 | 顶面一层薄亮片，侧面是同色系更低一档 | 地表 vs 剖面、分层 |
| 海面的碎光 | 浪是一格一格的三角面，各自反一下光 | 海、航行、未知 |
| 纯缩放换尺度 | 一个物体占满画面，然后世界缩成一粒 | 个体与总量、局部与全局 |
| 低仰角长焦等距 | 天空带很宽，地平线带留在画面上三分之一 | 夜、星、辽阔 |
| 空镜里的活物 | 风车转、烟冒、鸟绕圈、船随浪起伏 | 有人住、日常、等待 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 六边柱 + 一块一声最容易一眼认出，也最容易被用滥——第二支片子换一组信号。
- 主光只允许一盏；等距角度全片不变，变的是内容、光和尺度。

## 这个风格最俗的版本

- 画面：淡蓝渐变底上一块绿地浮岛，几棵树几个小屋，镜头慢慢拉远，最后出 logo。
- 声音：马林巴 + 尤克里里 + 鸟叫。
- brief 的 style 一栏写明这支片子翻掉了哪几条，或者为什么刻意保留。保留时把力气花在「落地的节奏」和「光怎么走」上。

## 适配

- 用途：品牌形象片、产品「从零搭起来」、科普与教育、开场和段落转场。
- 内容：成长、建造、系统成形、一天或一年的循环、规模对比。
- 时长：15–60 秒最舒服。超过 90 秒要换世界、换季节或换尺度，否则同一套镜头语法会腻。
- 不适合：需要真人出演、需要密集文字阅读、需要强情绪表演的片子。

## 技术路线

- 3D 幕：`add_scene(type="scene3d")`，先 `get_guide("scene3d")` 拿当前字段；世界写在 graph 里，一个节点一件几何体。
- 只拼预设几何体：`cylinder(segments=6)` 是六边柱，`cone(segments=4)` 是棱锥屋顶，`box` 是楼和窗，`icosahedron(detail=0)` 是树冠。**不做自定义网格**——形靠预设组合，不靠建模。
- 相机：本工具只有透视相机（fov 10–120）。要等距正交的观感，就把 **fov 压到 10–14、相机拉远**（距离 ≥ 3 倍画面高度），让汇聚小到看不出；广角贴近会当场破功。仰角低（20–25°）时天空带宽，高（50°）时读起来像地图。
- 打光：`look="nature"` 起步，再用 `set_graph_lights` 换成 1 盏 `directional` 当太阳，加极低强度的 `ambient` 兜底。材质 `flatShading: true`、`roughness ≈ 0.9`、`metalness: 0`、`body: false`（body 会降饱和压暗，珊瑚屋顶会变灰）。
- 昼夜：本工具的光和天空不随帧插值，所以「一天」拆成 3–4 幕，每幕一套 `set_graph_world` + `set_graph_lights`，在拍点上硬切，不靠叠化。
- 验收：`preview_frames` 逐拍看面与面的明度差、柱顶和侧壁有没有闪线；`render_preview_clip` 看落地的弹跳。配色字体走 `set_theme` / `apply_style`。
- 其余：`tts_narration` 旁白、`set_subtitles` 字幕、`upload_asset` 素材、`add_audio` 音效与 BGM。

## 材质与渲染

- 地形：世界单位 = 一根六边柱的外接圆半径；尖顶六边柱，轴向→世界 `x = √3(q + r/2)`、`z = 1.5r`。高度就是材料：沙最低、草、丘、岩最高。
- 柱顶盖：顶面单独一层薄亮的盖片，侧面是同色系暗一档；**盖片要压进侧柱一点**，共面会闪。
- 柱间留缝：相邻柱之间留一条细缝，缝里的暗是唯一的「线」，不要描边。
- 色差抖动：每块地的明度随机抖几个百分点，否则地面像一张表格。
- 道具：箱子、棱柱屋顶、低分段圆柱与圆锥、detail 0 的二十面体、被压扁的箱子；窗和灯的发光部分**每件单独一个材质**，才能一户户亮。
- 材质：`flatShading` 全开、`roughness ≈ 0.9`、**全片零贴图**（`map` 槽位留空）；细节靠几何体和自发光，不靠纹理。
- 海：本工具没有位移着色器，做不出「每片三角各自闪光」的水。替代：一块 `plane` 当海（偏冷的 secondary、roughness 中），上面摆几十根极薄的六边柱当浪脊，高度按同一条正弦错峰上浮；近岛换一档更浅的颜色当浅滩，岛脚围一圈半透明白柱当浪花。
- 天空：`set_graph_world` 的 `gradient`，`top` 是高空色、`bottom` 取同色系更亮一档——这里的「假地平线」是允许的，本风格的天空本来就是屏幕空间渐变。雾把远处压进带子，地平线带保持在画面上三分之一。
- 后期：`set_graph_post` 的 bloom 白天压到 0.3、夜里放到 1.2 以上；vignette 轻；**grain 归零**——平涂色块加颗粒会抖。
- 光柱（探照、投影、火把）：一盏 `spot`（penumbra 低、边缘硬）把落点照亮，再叠一个 `cone(segments=4, transparent, opacity≈0.12, side:"double")` 做很淡的体积；锥体自己不许发光到发白。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 天空（昼） | `#DCE6F2` | 高空冷调，往下加亮 |
| 沙 | `#F2E4CB` | 最低的一层地形 |
| 草 | `#7FA98A` | 第二层，压一点饱和 |
| 岩 | `#9A9384` | 中性，唯一不偏色的材料 |
| 珊瑚屋顶 | `#E2705C` | 一面只用一次，成片才有节奏 |
| 夜深 | `#2A3350` | 一切被去饱和推向蓝紫 |
| 灯 | `#F2B34C` | 夜里唯一亮的东西 |

- 一个地表家族（沙、草、土）+ 一个中性岩 + 一小套墙色和屋顶色，在建筑之间重复用。低饱和、低对比、颜色的数目少。
- 面与面的明度关系由光决定：顶面最亮、迎光侧面居中、背光侧面最暗；同一色相三档，别手工刷成三块不同的颜色。
- 没有描边、没有纯黑；暗只来自阴影和缝隙。
- 可换的世界：白沙 + 草 + 珊瑚屋顶 + 淡蓝白天；雪地 + 松绿 + 红木屋 + 丁香天空；赤陶台地 + 鼠尾草 + 绿松石水潭 + 杏色黄昏。

## 字体

- 标题：几何无衬线、全大写、宽字距（`"Inter Tight"` 加宽 tracking 就够）。
- 正文与字幕：圆润的几何无衬线（`"Inter"` 兜底 `sans-serif`），中文落 `"Microsoft YaHei"`。
- 字幕：**没有框**，暖白 `#FFF6E9`，只留一层很淡的深蓝衬底当投影（bgOpacity ≤ 0.3），底部居中；时长 ≥ max(1.8 秒, 语音 + 0.6 秒)，不许压住下一行或标题。
- 标题像积木：一个字一个字从一条「水平线」底下升起、过冲、落定。文字卡中间留洞，别把世界挡死。

## 运动

- 24fps 逐帧、平滑。魅力在**到达曲线**，不在步进的机械感。
- 升起：短促的 ease-out 上升，然后一次过冲回稳；破水面那一帧加一圈水环和几粒飞沫，落定那一帧才是节奏点。
- 落下叠高（地板、屋顶、环）：快速 ease-in 下落、一次回弹、落地做保体积的挤压拉伸。
- 弹出（树、灯、小细节）：放大到 1.25 再回到 1，约 25% 过冲。
- 本工具的 `anim` 只给 linear / easeIn / easeOut / easeInOut，**没有弹簧**：过冲靠 2–3 段拼——落到 1.08、再落到 0.97、再回 1，每段 easeOut。一段关键帧做不出弹跳。
- 生长排进音乐的格子：最小格子里最多一块，快起来靠加密（二分→四分→八分），不靠提速。
- 永不动的是投影：不换 fov、不做透视摆动。

## 画面怎么活

- 世界自己在动：风车转、烟一团团冒、鸟绕圈、船跟海面共用同一条正弦上下。幅度都很小，但每一帧都有。
- 自发光在数数：夜里窗一户户亮，顺序就是「谁先上线」；亮起那一下带一点电气嗡的余音。
- 镜头可以完全不动（锁定 3/4 广角），让光和这些小循环把画面撑住——这是本风格最耐看的一种镜头。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 转台（方位角横扫） | 从每一面看这个东西 | 搭建、检视、产品组装 |
| 纯正交缩放（只改画面高度） | 不靠透视的尺度 | 细节与它的上下文、渺小、世界之中还有世界 |
| 改变仰角 | 低 20–25° 天空带宽；高 50° 读成地图 | 夜与星、横扫整个世界、做规划 |
| 锁定 3/4 广角 | 世界自己活着 | 灯一盏盏亮、延时、等待 |
| 一次落地的紧特写 | 那一下弹跳和溅起 | 关键的一块、里程碑 |
| 侧后方跟一个移动物 | 穿过画面、从不朝镜头来 | 送达、启程、一条路线 |
| 沿一排柱子横移 | 一份清单、一个序列 | 流程的步骤、时间轴 |
| 延时日光扫过、相机不动 | 光是时间机器 | 一天、一季、一段历史 |

广角与特写按拍点交替：广角让人看见形状在长，特写卖那一下弹跳。转场是拍点上的硬切、换时段、或者穿过天空的缩放；不要叠化，不要透视甩镜。

## 声音调色板

- 音乐可以由事件写出来：每一块长出的东西各带一个音，谱子按它的准确时间合成，画面写旋律。适合棱面的音色——马林巴、卡林巴、木块、钟、颤音琴、钢片琴、钢鼓；下面垫一层软 pad、一个温和的固定音型、轻沙锤或软底鼓。五声或调式，任何落点顺序都协和。**不要钢琴、不要弦乐。**
- 一个音可以当动机：世界自己拥有一个声音（一口钟、一声号），每次回来都变一点。
- 拟音跟材料走：升起的块 = 气泡上浮 + 破水 + 几粒水珠（越大越低）；地板 = 木头闷响 + 一声更轻的回弹；屋顶 = 陶片碰；木板 = 空心的板响；石头 = 沉的一记；玻璃 = 叮；任何「亮起来」= 低频一记 + 电流嗡。
- 底噪：低通布朗噪声的海浪、向下滑的 FM 鸟叫、木头吱呀；夜里换蟋蟀或风。
- 沉默：掉到一条低嗡加底噪；大拍之前把音乐总线切到绝对零，再落下去。
- 人声清楚温和、句子短；混音人声压缩、明显高于音乐，音乐让路，整体 −14 LUFS。

## 原生手法

- **搭建即作曲**：每块落定是一个音，后段按空间顺序重放成一首完成的曲子。适合：楼层是音符的天际线、团队把一个产品装起来、花开成一个和弦。
- **程序化生长**：柱子升起、楼层叠高、树弹出。适合：创业的第一年、珊瑚礁恢复、一个街区被规划出来。
- **纯缩放换尺度**：一个物体占满画面，然后世界缩成一粒（或反过来）。适合：百万人里的一个人、大陆上的一个村、网络里的一个机房。
- **转台**：绕着正在做的东西连续转。适合：机器组装、博物馆藏品、房屋改造。
- **光当时钟**：影子扫过、面重新上色。适合：店铺的一天、农场的一年、医院的一个班次。
- **黑暗里的发光块**：灯一盏盏亮、光柱像时针一样扫。适合：网络上线、小镇入夜、志愿者一个个加入。

## 变化空间

- 结构：**侵蚀**（成品一块块掉，每次掉落是一个下行的音，最后只剩必需的那一块）；**两个世界**隔着一道缝互相递块直到接上；**同一个世界的四季**，配色关键帧扛叙事。
- 开场：**施工中**（半成品，很多块已经在落）；**从正上方俯视的地图**压下来变成等距；**先给整个世界**，再推进到其中一根柱子。
- 结尾：最后一块落定的特写，不后拉；**世界被收走**（块飞起来叠进一个箱子）；**天亮**（晨光淹过世界，音乐落在第一片被照亮的面上）。

## 坑

- **做成透视** → 立刻变成 3D 卡通。改：fov 压到 10–14、相机拉远，全片不换 fov、不做摆动。
- **柱顶盖和侧柱共面** → z 冲突闪一条线。改：侧柱压低一档，让盖片压在上面。
- **相机离得太近** → 画面底部露到海面以下。改：相机距离 ≥ 3 倍画面高度。
- **一根柱子里落两块** → 旋律糊掉。改：最小格子只放一块，挤不下就加密格子而不是叠。
- **双面加色的锥当光柱** → 读成两条白线。改：靠 spot 照亮落点，锥体只做很淡的体积。
- **圆角、描边、纯黑** → 变成软萌或插画。改：所有边硬，暗只来自阴影，禁止 outline。
- **平滑着色的球当树冠** → 一眼假的 3D 素材。改：`icosahedron(detail:0)`，树冠就该有棱。
- **满屏小块** → 手机上看不清。改：少而大，一根柱子的边长至少占屏宽 8%。
