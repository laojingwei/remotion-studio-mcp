# 1920 年代默片（silent-film-1920s）

> 一卷胶片被"放映"出来：4:3 的墨线画在片门里闪、晃、划，两侧是剧院幕布，说话靠字幕卡，声音只有一台影院钢琴和放映机。
> 参照（只学语法）：Keaton《将军号》《福尔摩斯二世》的固定全景与冷面、Lloyd 的"差一点"、Méliès 的虹膜与停机再拍、《艺术家》的少字卡、1920 年代影院钢琴提示单（按情绪分段、钢琴兼做音效）。不照搬任何真实影片的桥段、卓别林造型、已出版旋律。

## 本质 / 不是什么

- 本质：**一幅版画在被放映**——墨线 + 淡灰洗 + 45° 排线画出来的画面，印在会闪会晃的银盐片基上；不是先拍后调色，是画出来的东西被"印"出来。
- 本质：**16:9 的两侧是剧院，不是一个黑窗**——4:3 的片门（1440×1080）坐在 1920×1080 正中，圆角片窗、柔和暗边，两侧丝绒幕布被银幕溢光和脚灯照亮，幕布会拉开、合上。
- 本质：**没人说话**——段落靠固定全景里的动作推进，对白与叙述交给字幕卡（intertitle）。
- 本质：**唯一的乐器就是声音设计**——立式钢琴（可换簧风琴、剧院管风琴、小提琴、小编制）弹每一个事件，放映机在放映间里响。
- 不是 `newsreel-1920s`（1920 年代新闻片）：那条是**真实档案**跑在纯黑放映窗里，有银盐分级、走片抖动、地点卡，和**一直在说话的旁白**；这条**画面是画出来的**（墨线、五档灰洗、交叉排线），两侧是**幕布不是黑边**，对白是**字幕卡不是旁白**，声音是钢琴不是铜管乐队。同一年代，两种片子：那条证明"这事发生过"，这条演"一个笑话"。
- 不是 `rubber-hose`（橡皮管）：那条的看点是四肢像管子一样连续弯曲的表演，没有片门、幕布、字幕卡这层剧院包装，也没有银盐片基的损伤；这条人物是写实比例（成人 7.5 头身、儿童约 5 头身），喜剧来自冷面与调度，不来自橡胶肢体。
- 不是黑色电影（没有以硬阴影当情绪、没有旁白），不是给现代动画罩一层棕褐滤镜，不是卓别林模仿秀。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 片门与幕布 | 1440×1080 圆角片窗居中，两侧丝绒幕被银幕溢光与脚灯照亮，会拉开合上 | 任何题材 |
| 墨线 + 五档灰洗 | 每道边的暗侧一条墨线，明暗压成约 5 档柔和灰洗，没有第二种颜色 | 人物、器物、场景 |
| 45° 排线 | 暗部 45° 排线，更暗处再交叉一层；每 2 帧重画一次，像手绘动画在呼吸 | 阴影、体量、衣褶 |
| 银盐片基的伤 | 竖划痕（白 = 乳剂被刮、黑 = 底片上的脏）、灰尘、片门里一根头发、偶发污斑 | 放映、旧拷贝 |
| 边缘焦痕 | 棕色从四边慢慢爬进画面，段落越紧张爬得越深 | 时间流逝、坏消息 |
| 字幕卡 | 黑漆卡 + Art Deco 边饰，一卡三五个词，停 2.5–3.75 秒 | 对白、转折、"与此同时……" |
| 虹膜 | 圈入圈出；半开的虹膜停住，让人瞟一眼观众 | 聚焦、开头结尾、共谋 |
| 手摇速度 | 人物与镜头按 16fps 采样（18+ 是降格），追逐时越跑越快 | 追逐、慌乱、日常 |
| 单色点睛 | 全片只留一样东西的颜色，它穿过整套印片仍吃颗粒、闪烁与暗角 | 那件"片子讲的东西" |
| 冷面表演 | 脸几乎不变，身体在演；double take 是两帧的急转 | 喜剧、尴尬、倔强 |

规则：每支挑 2–3 个，至少一个不在下面「最俗的版本」里；片门 + 墨线灰洗是最低配置，字幕卡与虹膜是标点，用两次就成模板。

## 这个风格最俗的版本

- 画面：整片棕褐滤镜、四角压暗、边缘烧焦，老式衬线体字幕抖个不停，最后"THE END"。
- 声音：循环爵士钢琴从第一帧铺到最后一帧，没有一处留白。
- 正确做法：银是**冷的银**不是棕褐，"旧"来自墨线、灰洗、损伤和手摇采样，不来自滤镜；钢琴要**会停**。brief 的 style 一栏写明翻掉了哪几条，或为什么刻意保留。

## 适配

- 用途：讲"以前"的宣传片、品牌起源、手艺与工艺、幽默的产品小传、展陈短片。
- 内容：适合有一个**可看懂的因果链**或一个**身体喜剧**的主题——追、等、差一点、搞错。需要"解释"的内容也能上，但要用字幕卡一句话一句地打。
- 时长：20–60 秒最舒服；短片里 3–5 张卡。超过 90 秒要有一次幕布开合或换段落的字幕卡。灾难、死亡题材不能用这套语法。

## 技术路线

- 建一个 1920×1080 的幕：`add_scene` 铺剧院黑，`add_element` 放 1440×1080 的圆角**片窗**（裁剪容器）居中；幕布是片窗外的独立图层（左右各一片，竖向褶皱明暗），脚灯一道暖光压在幕布下缘。**任何元素都不许画到片窗外。**
- 画风落地：`set_theme` / `apply_style` 定"墨线 + 五档灰洗 + 45° 排线"这套档位，一次定好全段共用。本工具没有 DoG + WebGL 重绘管线，"每 2 帧重画一次"用**三层叠**（线层 / 灰洗层 / 排线层）每 2 帧换一次微小抖动的种子来近似。
- 片基：闪烁、走片、划痕、灰尘用**元素层随机位移（±1.5px 横 / ±2.0px 竖）+ 固定种子颗粒层 + 1px 竖线**近似；焦痕是四边向内的一圈棕色渐变，按段落加深。
- `upload_asset` 进来的实拍也能过同一套档位（灰洗 + 线 + 排线）当"重画过的胶片"，但要粗，别让观众认出是滤镜。
- 字幕卡：`set_subtitles` 出卡，或做成独立场景；卡是画面的一部分，跟着片基一起闪。`add_audio` 放钢琴与放映机。**不用 `tts_narration`**——这条风格没有人声。
- 验收：`preview_frames` 当缩略图逐拍看明暗（值才是主角），`render_preview_clip` 看手摇速度与闪烁像"放映"还是像"卡顿"。

## 材质与渲染

- **灰阶密度**：墨 0.07、深色布 0.15–0.3、中等木头 0.45–0.6、皮肤 0.8、白亚麻 0.9–0.95；柔和的光渐变，加一条细的分界线。
- **墨线**：每道边的暗侧一条轮廓线（DoG 的味道），本工具用描边 + 轻微位移复制近似；线不许均匀，起笔重、收笔细。人物也要过同一道线，否则像贴在背景上的剪贴画。
- **灰洗**：亮度压成约 5 档柔和台阶，台阶之间不许有硬边（硬边只属于墨线）。
- **排线**：暗部 45°；更暗处再交叉一层，线距随暗度变密。每 2 帧换一次种子重画。
- **印片**：银调，sepia 0.1–0.36，印片黑 0.055、白 0.93，S 曲线，高光 halation，密度不匀，闪烁，走片（偶发一次片孔跳），断续竖划痕，四边棕色焦痕爬入，暗角，两倍频颗粒；再加灰尘、片门里一根头发、偶发污斑。
- **片门**：1440×1080 嵌在 1920×1080 里，圆角片窗 + 柔和暗边；画幅不可改，**不许做宽银幕**。
- **人物**：写实比例，2.5D 骨架（关节在 3D 里解、按 yaw 投回平面）；默片化妆（脸白、眼窝与唇深）；身份靠剪影特征（一顶帽子、一件衣服、一件工具）。
- 颗粒**只加一次**，加在成片上；字层可以吃闪烁，但不吃走片位移，否则像假复古。

| 用途 | 值 | 含义 |
|---|---|---|

| 片窗亮部 | `#EDE7D8` | 白亚麻、闪白、halation |
| 银中间调 | `#8E8779` | 灰洗中档、幕布受光面 |
| 幕布红 | `#4A1F1C` | 丝绒幕的暗红，只在片窗外 |
| 墨 | `#121110` | 墨线、排线、印片黑 |
| 单色点睛 | `#C99552` | 全片只留一样东西的颜色（可不用） |

- 全片**单色银**，值域做全部工作：深衣压浅墙、白脸压暗室，每一镜都当缩略图查一次。
- 颜色只来自印片：出问题时更冷、更脏（损伤更多、sepia 更少），温柔时更暖、更干净；tint 与损伤是**按段落调的情绪旋钮**。
- **最多一个颜色**：用在那件"片子讲的东西"上，它照样吃颗粒、闪烁、暗角。整场染色（白天室内琥珀、夜蓝、爱情玫瑰）是 sepia 之外的正解，一段只用一种。

- 边饰跟着情绪走：喊叫是一道粗横线（字跟着抖），叙述是双线 + 阶梯角 + 扇形，温柔是藤蔓与小花的细线。
- 字距、全大写、居中、上下留白，比字族更决定年代感；不要圆角卡片、不要投影、不要现代下三分之一条。

## 运动

- **手摇采样**：人物与镜头按 **16fps** 采样（降格 18fps 或更高），而闪烁、走片、颗粒、划痕**每输出帧（24fps）都在变**。这个混合才像"被放映"；单纯低帧率只会像卡。
- **速度即情绪**：追逐与慌乱降格（动更快、闪更快）；温柔段落回到 16fps、印片更干净。
- **冷面**：脸几乎不动，身体在演——发力前先蹲、保持姿势、两帧急转的 double take、手撑膝；道具也在演（倒下前先晃一下，慢慢减速到停）。
- 关键帧 + 缓动 `u^a(1−u)^b`（a、b ≈ 1.5–4），速度和加速度都不突变；**只有包袱才硬切**。
- 走片 ±1.5px 横 / ±2.0px 竖（低频噪声）；闪烁 ±4%/帧 叠 2.6Hz 慢漂；竖划痕 1–2 条各活 7–12 帧；灰尘 0–3 粒只活 1 帧；偶发一次片孔跳（4–6px 一整下）。
- 转场只用：虹膜（`circle`）、淡黑（`fade`）、直切（`none`）、幕布开合。**同一场的两镜之间不许叠化**，不许现代甩镜、不许推拉变焦。

## 画面怎么活

- **片基在跑**：走片、闪烁、每两帧一次的重描感，观众看到的是放映机而不是静态图。
- **灰洗在呼吸**：一段里明暗漂移 ±1–2%，像灯泡在热；焦点处的白不许爆，白位钉在 0.93。
- **幕布有生命**：极慢的呼吸式起伏、脚灯下一次微亮；**合上时必须有脚灯**，否则纯黑一片。
- **角落小循环**：一粒灰落定又被吹走、一根划痕从右上慢慢滑下、卡框上一道极淡反光扫过。
- **允许静**：等待（the wait）就是这个风格的笑点结构——只要片基在动，人物可以站住。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 固定超全景 | 因果整条看见；等，就是笑话 | 机械式包袱、人群、复杂流程 |
| 固定全景 | 一个镜头交代前提 | 人物日常、对峙 |
| 前景掠过的跟拍 | 追赶；惯性 | 追逐、比赛、限时送达 |
| 虹膜收 / 开 | 注意力聚到一件东西；一段心思的开头或结束 | 道具、脸、回忆 |
| 半开虹膜停住 | 角色和观众交换一个眼神 | 眨眼、秘密、共谋 |
| 缓慢有动机的推近 | 温柔；想通了 | 跪下、读信、下决心 |
| 遮罩镜头（钥匙孔、望远镜） | 主观视角；偷看 | 侦探、好奇、情愫 |
| 分屏 / 二次曝光 | 花招；梦；两地同时 | 打电话、鬼魂、白日梦 |

取景：以全景和中景为主；特写要么小、要么装在虹膜里（骨架脸的大特写会像假人）。早期镜头重，多数固定；开场与结尾由主题决定。

## 声音调色板

- **乐器即音效**（影院做法）：立式钢琴，可换簧风琴、剧院管风琴、小提琴、小编制。米老鼠式词汇可选：低音半音爬行（蹑手）、装饰音（眨眼）、前臂砸和弦（撞击）、渐强的减和弦颤音（等）、低音滚奏（暴风雨、机器）、"叮……咚"（空荡）、减和弦突强（惊吓）、琶音滚奏（开门、揭晓）、下行滑音（摔）、低音"嘣"（弹跳）、紧张的颤音（犹豫）、小二度（东西碎了）。
- **影戏习语**：左手 stride；按提示单的情绪分段（Hurry、Misterioso、Agitato、Tenderly、Maestoso）；一个主题回来时变样。**只用原创音乐。**
- **没有拟音、没有人声**。放映机就是环境声：灯箱咔哒、电机起动、爪式走片与电机的低鸣、收片盘上胶片拍打。
- **静默**：音乐停掉，只剩放映机，用来框住一个屏住呼吸的瞬间。
- 混音：钢琴击弦的瞬态先轻压缩，再标准化到 **−14 LUFS**；颗粒留在画面里，不要用声音去补"旧"。

## 原生手法

- **一镜到底的链**：A 触发 B，B 出画，观众等，B 回来撞上 C。适合供应链出错、谣言怎么传、离谱的发明。
- **差一点**：手合拢的位置正好是一帧之前那个东西在的地方。适合赶车、错过一单、守门员。
- **字幕卡翻盘**：一张卡用几个字把下一镜重新定义。适合"与此同时，在实验室里……"、把统计数字当包袱。
- **降格的混乱**：速度和损伤一起涨。适合高峰期、出餐口、崩盘。
- **虹膜上的眼神**：虹膜收到一半停住，让人瞟一眼观众。适合会眨眼的产品、什么都懂的一只猫。
- **重画的素材**：实拍过了这套印片就成了年代动画。适合公司档案、家庭录像、比赛片段。
- **回声动作**：开头一个手势，被另一个人重复，意思变了。适合师徒、交接、传统。

## 变化空间

- **类型**：喜剧、情节剧、冒险、伪新闻片，由 agent 定；人物、包袱、卡、染色方案、开场与结尾也各自定。
- **结构**：伪新闻片（一串"报道"，之间用大字标题卡）；三卷情节剧（每卷一种染色：琥珀、蓝、玫瑰；反派卡 + 营救）；魔术片（Méliès 式：一个舞台、一个魔术师，靠停机替换让东西出现与变形）。
- **开场**：追逐中途切入，片子已经在跑、已经带伤，还没有片名；先上一张只有一句话的字幕卡，再给画面；放映员视角——从放映间的光柱开始，再落到银幕。
- **结尾**：片子断了（画面烧穿，只留灯的白）；最后一张卡直接对观众说话；固定全景淡黑，钢琴按住一个和弦不放。

## 坑

- **塞太多内容**：小人物尺度下的多步链条在缩略图里就是噪声。改：一条看得懂的链 + 中间一次停顿，胜过三条热闹的。
- **木偶胳膊**：先外展再屈曲，手臂抬起时肩要抬、要往前送，抬起那一侧的肩角收窄，压在躯干上的手臂要藏掉轮廓；抬手走侧向（或把人物转过去），别横过脸。
- **姿势跳变**：所有人物都用缓动关键帧驱动，不要用 `if` 分支切换姿势。
- **道具漂浮**：道具夹在两掌之间、深度在双臂之间；滚动物体的转角 = 距离 / 半径。
- **眉毛方向不随朝向翻**：按最终尺寸裁一块检查表情。**虹膜不跟目标**：相机推过之后，虹膜要在胶片坐标里重新对准。
- **抓取对不上拍**：手必须落在那个节拍上物体真正所在的位置，差一帧就读不出来。
- **合上的幕布被暗银幕照亮成纯黑**：加脚灯。
- **颗粒一重文件就爆**：减少颗粒层数或降分辨率，别把颗粒做进每一层。
- **卡停留不够读完**：改短文字，不要改短停留——≥ max(1.8 秒, 阅读时间 + 0.6 秒)，一卡 2.5–3.75 秒。
