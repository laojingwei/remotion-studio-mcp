# 激光点云扫描（pointcloud-scan）

> 一个真实地点的激光回波在暗处浮成一片测得的云；一道扫描前缘穿过去，云在它身后就地凝成实体表面，再用头发丝一样的线去量它。
> 参照（只学语法）：测绘与考古的 LiDAR 可视化（高度上色、剥掉树冠）、带尺寸的建筑剖面图、博物馆影片的节奏（一屏只读一个数）。不照搬它们的版式、色阶、字体与音乐，不在片子里点名。

## 本质 / 不是什么

- 本质：**点云就是数据**——每一点都是真实回波落在它被测得的位置上。点会长出来、发亮、飘走，或让位给实体表面，但**永远不会被摆成一个形状**。
- 本质：**点变成面是论证**——一个前缘（扫描线、切割面）过去之后，同一片地方在同一坐标上凝成实体模型。观众看到的不是特效，是"这么稀疏的测量，够建出一个面"。
- 本质：**分类是杠杆**——地面、植被、建筑、水体是可以逐层剥开、单独提亮、重新上色的图层。
- 本质：**测量只用发丝线**——一次只给一个读数，用强调色，挂在它量的那个东西上；数字来自点本身或公开数据源。
- 本质：**暗、静、准**——近黑的地，克制的色，除了前缘和接缝之外不发光。
- 三条分界：`particle-field` 的点是审美，可以飞、可以聚成字，这里的点**是坐标**，为好看挪动它就是造假；`hologram-hud` 是科幻界面，环与百分比可以编，这里是测绘/扫描，有比例尺、回波密度、精度、数据源；`glass-material` 靠折射和厚度说话，这条靠"少得可怜的点仍然认得出地形"说话。
- 也不是蓝图（那是画出来的线）、低多边形等轴（那是造型）、卫星俯视（那是照片，这里是飞进去的三维云）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 暗处的稀疏点云 | 近黑底上一片大小不一的小圆点，越远越淡、越稀 | 测绘、勘探、遗址 |
| 扫描前缘 | 一道冷白细缝横过画面，缝前点亮、缝后凝成面 | 从图到数据、从数据到实体 |
| 按高度上色 | 深青绿 → 灰 → 近白，一个色阶，只随高度变 | 地形、树冠、体量 |
| 树冠剥离 | 一整个高度层整体抬走、淡出，露出下面 | 考古、隐蔽地形、洪道 |
| 边上走的标尺 | 画面边缘一条尺，跟着切割面报当前高度 | 精度、深度、量出来的 |
| 角落的仪器栏 | 地名、经纬、面积、数据源、点数、放大倍数 | 可信度、出处 |
| 右侧读数组 | 标签 + 数字 + 来源行，一根引线连到被测物 | 结论、规模、差距 |
| 受光的实体表面 | 暖石色、低角度掠射光、微弱等高线、山脊提亮 | 建筑、堤坝、崖壁 |
| 未测区的窗 | 测区之外仍是暗点，不黑掉 | 范围、边界、一块地 |
| 重生的鬼影 | 被剥掉的层半透明地回到结果之上 | 结尾、前后对照 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 最认得出的两样是"扫描前缘"和"角落仪器栏"，也最容易用滥——第二支片子换一组。
- 一条硬规则：**点云里不许出现被摆布的形状**。想组字、组 logo，那是 `particle-field`。

## 这个风格最俗的版本

- 画面：黑底上一大团发光点旋转，加一圈编造的科幻 HUD 环，百分比乱跳，最后一道白光扫过把点变实，屏幕上飘出"3D SCAN COMPLETE"。
- 声音：低频嗡鸣 + riser + 一声金属 impact。
- brief 的 style 一栏写明这支翻掉了哪几条，或者为什么刻意保留。保留时把力气花在"剥层的顺序"和"读数到底量的是什么"上。

## 适配

- 用途：真实地点的科技感宣传片、遗址/地形/工程勘察、容量与体积、隐蔽物发现。
- 内容：有实测数据、有"照片看不见的东西"、结论能被一个数字钉住的主题。时长 20–60 秒，超过 90 秒拆两段、各给一次凝面。
- 不适合：没有数据却要装得像测量（那是本风格最坏的用法）。

## 技术路线

- **先说实话**：本工具的 `scene3d` 不做十万级独立点的实时渲染——粒子层上限 6000 个、只有一个全局粒子层、加法发光的点，没有逐点颜色、没有逐点的前缘距离。
- 三条路，按真实度排：
  1. **点云素材当底（最像）**：外部把真实点云渲成视频或序列帧，`upload_asset` 进来当底；前缘用 `add_element` 的遮罩推进；标尺、读数、仪器栏 2D 叠在上面。
  2. **有限点 + 辉光近似（可控）**：几百到 3000 个点，按投影公式一次算好屏幕坐标，用 `add_element` 的小圆点或一块 canvas 元素画，逐帧只改大小与不透明度；`scene3d` 的粒子层只补环境辉光。点少了就靠"暗处 + 少量亮点 + 距离雾"骗过眼睛，别硬堆。
  3. **`scene3d` 场景图（有空间、更抽象）**：`add_scene(type="scene3d")` + `get_guide("scene3d")`，mesh 做实体表面、相机 `anim` 走轨道；点云只能是近似，别承诺真点云。
- 相机：`camera.anim` 关键帧写 pos / target / fov，同 key 段首尾相接，弧线用 `curve`，云里不做硬切；先 `preview_frames` 验静帧（点够不够认得出地形、读数有没有压住主体），再 `render_preview_clip` 验动（前缘速度、镜头有没有停）。
- 落地：`apply_style` / `set_theme` 套本风格，旁白 `tts_narration`，字幕 `set_subtitles`，音效与底噪 `add_audio`。

## 材质与渲染

- **点**：世界单位 0.12–0.3 米直径，屏幕下限 1 个输出像素；软边圆盘，**不透明、做深度遮挡**（只有"鬼影层"用加法混合）；色相来自高度或类别，明度来自回波强度；距离雾。位置量化到 2 厘米（垂直 1 厘米），另存每点的离地高度、类别、强度、种子——后面所有量都从它算。
- **离地高度**：每个回波减去由 class-2（地面）三角化出的地面模型——它同时驱动色阶、切割面和标尺，三者必须用同一个数。
- **实体面**：0.5–1 米的网格，法线平滑，短半径 AO 烘进去，低角度掠射光 20–35°，极淡的等高线，山脊提亮。微地形可 ×2–3 显示，但**画面上必须有一行注明**，量尺寸一律用未夸张的数据。
- **前缘**：一整片世界空间的平面，点和面共用它。前缘之前的点提亮，之后一道细缝发亮；点在同一位置**就地变面**，单点过渡约 0.2–0.3 秒（5–7 帧），整片在前缘后数十米内填满。
- **切割面**（按离地高度）：面以上的回波抬走、淡出；它与树冠相交处一圈发光；画面边缘的标尺跟着它走。
- **面上的标记**（描出的地物、剖线）：细线宽度按屏幕像素固定，不随推近变粗；读数、引线、曲线图是同一套投影出来的 2D 叠层。
- **测绘窗口**：测区之外的点云不消失，只是变暗，让观众看见"这是一块被量过的地"。
- **后期**：2 倍分辨率渲染再缩；高阈值辉光只给前缘和接缝；暗角；**不加颗粒**（点本身就是细节），码率给高一点。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 底 | `#05080A` | 近黑偏冷，不用纯黑，不做渐变天空 |
| 树冠（低→中→高） | `#1F3F35` → `#5C9A7A` → `#E2F3DC` | 一个色阶，只随高度变 |
| 地面回波 | `#C8B38C` | 土色，与植被分开 |
| 实体表面 | `#BDB5A6` | 暖中性（石、土、灰泥），受光，不与强调色抢 |
| 前缘/接缝 | `#D4FFF0` | 冷近白，它是光，不是一个颜色 |
| 强调（琥珀） | `#FFB347` | 只给"被找到、被量过"的东西：描出的地物、读数、剖线 |
| 对比图辅助色 | `#83C495` | 只在比较图里出现 |

- 点云只用**一个**色阶（高度或类别二选一），去饱和；强度只改明度不改色相。**禁止彩虹高程色带。**
- 强调色一帧只给一处；第二支冷色只在对比图里出现。

## 字体

- **读数**：细体窄字，110–130px（`Inter Tight` 300 或等宽），数字比标签大得多；**仪器**：等宽 19–22px，写地名、坐标、点数、数据源；**标签**：无衬线 24–36px（中文 `Microsoft YaHei`）。1080p 下**不小于 19px**。
- **仪器栏**固定在角落：地点、坐标、面积、数据源、点数、任何夸张倍数；只在"介质变了"（照片→点云→实体）时换内容。
- **读数组**在右三分之一，贴着它量的东西：标签、数字、来源/方法行；被测物在画面里就拉一根引线；滚动的计数器最终停在真值上。
- **字幕**：左下一条转录条（2px 细线，底板向右渐隐），一行一种语言，按真实字体量过宽度，**宁可拆行不要折行**；双语时本片语言在上。
- 停留：字幕 ≥ max(1.8 秒, 语音 + 0.6 秒)；标签 ≥ 汉字数 ÷ 4.5 + 1.5 秒（拉丁按字母数 ÷ 15 + 1.5 秒）。

## 运动

- 24fps 逐帧（on ones）；**相机不停**；关键帧在 target / 距离 / 朝向 / 俯仰上做 C1 连续，速度不许突变。正上方垂直俯视时不要用"锁定看向点"（`lookAt`）——那种角度下视角极点会甩。
- **前缘**走一条缓动曲线，主体处最慢；源规则只给空间量（在前缘后数十米内填满），秒数按前缘速度倒算，先定秒数再回算距离，典型 1.5–3 秒扫过主体。
- **点的出现**只能在前缘之后、或按高度层出现，**绝不整屏随机淡入**；**切割面**按拍进格：缓动步进 + 短停，让每一层读得出来。
- **读数**带一小下 pop 落定；描出的地物沿长度依次点亮。
- **动不得**：点与点的相对位置（不许抖、不许噪声位移）、仪器栏的位置。

## 画面怎么活

- 活的是**前缘**和**层**，不是点。点只有三种命运：被前缘点亮、被抬走淡出、让位给面。
- 每一次剥层或凝面都把上一个结果留在画面里当参照：观众始终知道"现在这一层是什么、刚才那一层去哪了"。
- 前缘经过前有一小段近静止，只留距离雾在动——那一下停顿是这条风格的重音。光只在接缝、前缘、被描出的地物上；其余地方"暗得发准"。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 正俯视锁定 + 极慢推近 | "照片上看到的就是这个" | 待检验的说法、之前、结尾回到图 |
| 摇臂下降并倾斜到斜视 | 进入数据；这地方有高度 | 从照片切到点云 |
| 低斜角贴近点云（俯仰 10–20°，90–150 米） | 体积；东西是立着的 | 树冠、建筑、立面、崖壁 |
| 缓慢环绕 | 在研究；让平面干活 | 剥层、扫描、一个停住的读数 |
| 上升后拉 | 找到的东西有多大 | 网络、总平面、走廊 |
| 横移 | 沿一个地物旅行 | 石墙、路、管线、海岸线 |
| 推向一个剖面 | 那个证明一切的细节 | 断面、净空、高差 |

取景：关键时刻主体 ≥ 画面高度的三分之一；读数在右三分之一；仪器在角落；字幕条区域什么都不放。**转场就是前缘和平面**——云里不叠化、不硬切。

## 声音调色板

- **仪器声**：FM 短 ping；点到达时细密的噼啪；绑在前缘上的噪声扫频；分拍的 tick（8 分 → 16 分 → 32 分）用来加速；每剥一层一声降调的 blip；计数器滚动时有棘轮；读数落定一声 ping。
- **重量**：定音鼓、大鼓、大锣给"凝面"和"切"，主冲击前一段反向的 swell；**合成**：低通失谐锯齿铺底，脉冲贝斯带听得见的二三次谐波。
- **干湿**：点还是点的时候用电子；面出现之后给一个有机的木质或弓弦音色（马林巴、弓弦颤音琴）。
- **底**：开场和结尾用这个地方自己的环境声（风穿过树叶、水、车流），做 J-cut / L-cut；中间铺一层很薄的气。
- **静**：主揭示前近乎无声（只有气）；揭示后的第一个声音是冲击。
- **混音**：人声比音乐高约 10dB 并做 ducking；冲击不进总线压缩；−14 LUFS，真峰 ≤ −1.2 dBTP。旁白平稳、朴素，短陈述句。
- 落地：音效与环境底噪 `add_audio`；第 1 档合成够用，需要更细的层次再往上加。

## 原生手法

- **照片变点**：一道扫描线横过航拍照片，线后那地方变成点。适合"卫星看不见"、场地踏勘、采石场的真实体积。
- **树冠剥离**：一个平面按离地高度下降，它以上的回波逐层抬走，边上一把尺跟着。适合林下考古、被埋的小路、洪道、滑坡疤。
- **点凝成面**：一道前缘把剩下的点变成实体表面，描出的地物依次点亮。适合扫描转 BIM 外壳、崖壁转风险模型、街道转车辆净空模型。
- **剖面**：一个平面穿过某个地物，轮廓发光，旁边挂一张用真实回波做的带尺寸图表。适合堤高、桥下净空、路堑。
- **窗口**：测区是未被测量的云里的一个舞台。适合地块、走廊、场地边界。
- **重生**：被剥掉的层以鬼影回到结果之上。适合结尾、林间空地的前后、街面下的埋管。

## 变化空间

每一支由 agent 决定：地点与数据、剥哪些类、前缘的方向与数量、相机路线、给哪几个读数、强调色在色阶里怎么取、开场用照片还是地图。

- **结构**：一条走廊从头飞到尾，三个读数；同一地点两次测量（侵蚀、施工）用一道前缘切换；一个物体扫完、切开、标尺寸。
- **开场**：黑帧被扫描线一行行画出来；街景照片化进它自己的回波；俯视地图抬起来立成点云。
- **结尾**：后拉露出整块测绘瓦片；被剥掉的层以鬼影回来；最后一个读数停在画面上，点慢慢退成只剩仪器栏。

## 坑

- **点数不够就散** → 地形认不出、像噪声。改：点只放在有用的地方（一条墙、一段崖），靠低斜角 + 距离雾做体积；或干脆用点云素材当底。**不许用生成的点云冒充真实测绘。**
- **远处一片密点就是一张地毯** → 没有体积。改：贴近、压低，让雾把远的吃掉。
- **彩虹高程色带** → 一秒变科普动画。改：一个色阶，去饱和，强度只改明度。
- **数据来源要交代**：USGS 3DEP、OpenTopography、荷兰 AHN、英国环境署 LiDAR、法国 IGN LiDAR HD、西班牙 PNOA、芬兰 NLS、新西兰 LINZ 这类公开源写进片尾与事实清单。许可上：公有领域、CC0、CC BY、仅署名的政府许可可用；ODbL、CC BY-SA、"no known restrictions"、非商用条款要先问用户；**商用扫描与 Google 3D 瓦片一律不用**。拍到用户自己的资产，就找用户要他们自己的扫描。
- **坐标系**：经纬投影的副本先转成局地东/北/天，垂直基准对着已知地面校一遍，否则高度全错。
- **叶期**：落叶季的 LiDAR 能到地面但树冠稀；每一层要说明是哪个季节。
- **分类是数据商给的**：class 1 混着植被、建筑和噪声；丢掉 7 和 18；切层要切到 0 米以下，否则低矮植被会留成条纹。
- **扫描条纹是真实纹理** → 别让揭示正好落在掠射角的条纹上。
- **描出来的地物是解释** → 说"描出"，描线存在数据文件里、吸附到点上，模糊的候选直接不给。
- **隐私** → 裁掉民宅和院子；测绘窗口落在公共或无人区域。
- **事实要能查**：claim / 来源 URL / 原文措辞 / 测量方法，随片交付一份清单。
- **读数压在主体上、标尺被字幕挡** → 右三分之一与角落先占位，再排点云。
