# 重绘实机录屏（redrawn-screencast）

> 看起来就是一支真实产品的屏幕录制——但它不是录制，每个窗口、菜单、diff 行、按钮都是 2D 重画的，所以相机能去任何地方、每个像素可控、文字在任何倍率下都清晰。
> 参照（只学语法）：Screen Studio 式产品录屏（自动推近光标、光标平滑、点击推镜、窗口浮在壁纸上）、Apple 式 Guided Tour（真界面、平稳旁白、一句一个功能）、吉祥物的挤压拉伸动效、产品发布短片的轻快剪辑。不照搬它们的角色、界面、音乐和素材。

## 本质 / 不是什么

- 本质：**两个分辨率在打架**——一个硬边的低分辨率像素角色，住在一个高分辨率、抗锯齿的界面世界里。这个冲突就是这张脸。
- 本质：**两个演员，永远没有一只手**——光标是用户，像素角色是软件。
- 本质：**因果必须真**——角色的每个动作都引发一次真实的界面状态变化；用户的每个动作都是光标移动、点击或按键，并且显示在按键 HUD 上。
- 本质：**重力 = 界面的上边缘**——角色只站在真实元素的顶边上（输入框、菜单、列表行、代码行、按钮、状态栏、标题的字母），位置靠每帧量元素得来，不是手摆的坐标。
- 本质：**动画的外壳下面必须是真的**——每个标签、模式名、快捷键都对得上真实产品；演示用的代码、数据、测试输出自洽，被测的应用真的在变化。
- 不是**极简界面（minimal-ui）**：那是审美风格——留白、细线、少色的"设计过的界面插画"，界面被摆在一个安静舞台上展示；这条是叙事手法——把产品的一次真实操作过程重演一遍，界面不需要好看，需要像真的。
- 不是**UI 插画 / 概念界面**：不许发明抽象界面、不许改模式名，没有"科技感的假面板"。
- 不是**真实录屏**：真实录屏没法推近到一个按钮、没法横移过一整张长页面、没法在 4× 下还保持文字清晰——这里全能，这正是要用的地方。
- 不是**像素游戏**：世界是高分辨率矢量界面，只有角色和它的道具是像素。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 角色站在元素顶边 | 硬边方块像素落在输入框、菜单、行、按钮的上边缘，走动带 8-bit 脚步和落地灰尘 | 工具演示、AI 产品 |
| 光标推近 | 相机跟着光标一起推近到正在点的那个按钮，倍率 ≥ 1 | 操作演示、设置项 |
| 菜单真的展开 | 下拉、右键、命令面板一格一格展开，条目被 hover 高亮 | 工作流、效率工具 |
| diff 逐行出现 | 绿色加行、红色删行按行序落进代码窗，行号跟着走 | 开发者工具、代码审查 |
| 按键 HUD | 右下角一块磨砂玻璃，⌘K 一个一个亮起来 | 快捷键、专业软件 |
| 窗口浮在壁纸上 | 应用窗口带软投影浮在桌面壁纸上，推拉时壁纸同步位移 | 任何桌面产品 |
| 甩镜 | 两个窗格之间甩一下，带方向性模糊 | 输入 → 输出；代码 → 预览 |
| 快放标签 | 长任务 N× 快放，角上一枚闪动的 "▶▶ 4×" | 索引、导入、构建 |
| 章节药丸 | 左上角一枚磨砂 "01–04"，只在章节缝上擦过来 | 分章结构 |
| 主题切换吃掉整片 | 一次开关的效果溢出预览、接管整支片换色，之后又换回来 | 深浅色、语言、离线 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 光标推近、按键 HUD、章节药丸这三样最容易一眼认出来，也最容易被用滥——第二支片子换一组。
- 角色可以是产品自己的吉祥物，也可以是原创像素角色；道具（铅笔、"!"、星星、爱心、灰尘）和角色共用同一套正方形像素网格。

## 这个风格最俗的版本

- 画面：深色窗口 + 一个紫色像素小人，光标点一下、界面转圈、小人跳舞，最后拉远露出 logo。
- 声音：一声通知铃 + 一个 8-bit 音效 + 一条上升的电子 pad。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么刻意保留。保留时把力气花在"因果真的成立"和一次只有像素角色才做得出的位移上。

## 适配

- 用途：产品走查、功能演示、开发者工具介绍、AI 产品的"我就是这么用它"。
- 内容：有真实可演的操作过程——填表、选菜单、跑测试、看 diff、切主题、等结果。
- 时长：45–75 秒一支，一个功能一句话。超过 90 秒拆成两支，或加重章节。

## 技术路线

- 界面全部重画（本工具：`add_element` 放窗口、面板、行、按钮、光标、角色，用 `set_theme` 统一界面质感），不拿录屏素材当主画面。
- 真实产品截图可以当素材贴进来（`upload_asset`），但必须够大、不缩放、不裁切放大——一旦被缩放，文字就糊，这条风格的立身之本就没了。
- 相机就是整个界面层的一次 transform（translate + scale）：**缩放下限 1.0，永远不拍出显示器边界**；推近不设硬上限，但让被讲的元素占画面 40%–70%，再近就失去上下文。绝不用"把界面截图放大"来做推近。
- 角色与道具用 SVG 方块网格画，位置吸附半像素（所以动起来是步进的），随相机一起缩放。
- 先静帧验收：`preview_frames` 逐个停点看；再看动：`render_preview_clip`。
- 长镜头元素多时用 `add_scene` 按章节分幕，转场只留擦除类。
- 旁白 `tts_narration`，字幕 `set_subtitles`，音效与 BGM `add_audio`。

## 材质与渲染

- **窗口**：圆角 10–14px，1px 描边（比背景亮一档），投影 `0 24px 60px rgba(0,0,0,.18)`；标题栏 40–44px 高，交通灯圆点 12px，窗口浮在有质感的壁纸上。
- **菜单 / 浮层**：圆角 8–10px，1px 描边，投影更近更深（`0 12px 32px rgba(0,0,0,.22)`）；条目高 28–32px，左右内边距 12px。
- **按钮**：圆角 6–8px，高 30–34px；hover 只提亮一档，按下位移 1px。
- **字符渲染**：界面正文 14–16px、行高 1.4–1.5；辅助信息 12–13px；代码与行号用等宽 12–13px；字重只用 400 / 500；灰度抗锯齿（不要次像素抗锯齿），除像素角色外任何元素都不要落在半像素上，否则边缘会花。
- **像素角色**：硬边、无抗锯齿、无半透明像素，调色板 6–8 色；缩放用最近邻（`image-rendering: pixelated` 一类），绝不插值。
- **景深只服务注意力**：不在被读的窗格可以虚焦，可以加暗角聚光；**正在被读的文字永远不许模糊**。
- **运动模糊只给甩镜**，而且加在"未做变换的外层容器"上——加在被 transform 的层上会把像素精灵拖成一团。慢速移动保持清晰。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 壁纸 | `#E9E7E2` | 中性浅灰，窗口浮在上面 |
| 窗口面 | `#FFFFFF` | 产品自己的界面底色（暗色主题按其真实值） |
| 墨 | `#16181D` | 界面文字 |
| 次墨 | `#7A7E87` | 次要标签、行号、占位符 |
| 产品主色 | `#3C6DF0` | 取自产品本身；强调只给当前被操作的那个元素 |
| 角色色 | `#FF5C2B` | 一个界面里没有的饱和色，任何一帧都能一眼找到它 |

- 界面的颜色由产品说了算，照它真实的亮 / 暗主题来，不要重染。
- 覆盖层（章节药丸、按键 HUD、字幕药丸）统一中性磨砂玻璃，最多一个强调色。
- 一次主题切换可以是一次剧情事件：整支片跟着换状态，再换回来。

## 字体

- 界面字体跟产品走；拿不到就用近似：无衬线 `Inter` / `Inter Tight`，中文 `Microsoft YaHei`，代码与行号用等宽（JetBrains Mono / `monospace`），编辑类界面可以用 `Georgia` 这类衬线。
- **只做信息层**：章节药丸（01–04）、按键 HUD、磨砂字幕药丸、可选的 "▶▶ 4×" 时间标签。屏幕上不再叠别的东西。
- 片名如果有，必须是"界面内的"——空状态大标题、窗口标题、一条通知，而不是一张居中大字卡。
- 字幕：药丸在底部居中，**不压住正在讲的元素、不压在角色身上**；每条 hold ≥ max(1.8 秒, 语音 + 0.6 秒)。

## 运动

- 30fps；界面按 1 帧走（on ones）；角色的位置按像素网格步进，所以它的动是有台阶的。
- **角色表演**：起跳先下蹲预备 → 离地拉长 → 收腿 → 落地压扁 + 阻尼回弹 + 灰尘；待机随音乐拍点呼吸（极小压扁）、不规则眨眼；走路靠两腿交替，换方向时翻转精灵。
- **眼睛承担表演**（平视 / 左 / 右 / 上 / 下 / 瞪大 / 弯眼 / 闭眼 / 眨）；手臂只有三档：放下 / 举起欢呼 / 挥。
- **光标**：弹簧缓动的平滑路径，点击时一次小推近（push-in），**永不瞬移**。打字 12–18 字符/秒，每 4–7 个字符插一次 80–160ms 的"人在想"的停顿，删改比输入更急。
- 界面自己按产品的方式动（它真实的菜单、浮层、diff 展开）；产品没有的花哨动作一律不加。

## 画面怎么活

- 一条链，不许断：光标动 → 角色反应 → 界面变 → 字幕跟一句。永远是这个顺序，不许两件事同时没来由地发生。
- 停着的时候也有活物：角色呼吸眨眼、光标轻漂、进度条和日志在走、一个状态点在脉冲。
- 每 1–2 拍要有一次可见的界面变化或角色位移；只有"等结果"和"让一句话落地"允许静止。

## 镜头语法

一支录屏软件的相机：屏内一镜到底，倍率 ≥ 1，只在章节转场时切。开场和结尾由主题决定。

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 推到光标或插入符 | "事情就发生在这里" | 输入提示词；选菜单项；改一个设置 |
| 静止时缓慢漂移 | 我们在听，应用还活着 | 一句旁白；等结果 |
| 窗格之间甩镜（带模糊） | 因在这，果在那 | 发消息 → 出结果；代码 → 预览 |
| 推近 + 暗角定格 | 唯一要记住的那句承诺 | 安全保证；价格；撤销 |
| 窗格之间移焦 | 注意力转移，画面不动 | 读文件；日志滚动而对话在等 |
| 后拉回整窗 | 整个流程一次看全 | 总结；并行任务；前后对比 |
| 跟着角色走完一个列表 | 软件在一项一项处理 | 扫结果；清单；迁移 |
| 分屏重构画面 | 两件事同时进行 | 并行会话；两版对比 |

取景：正在讲的东西和它的字幕不许重叠；角色不许压住要读的字。转场只用章节药丸擦除、像素擦除、主题切换的圆形揭示——**不用叠化，不用截图拼贴**。

## 声音调色板

- **音乐里也有两个分辨率**：一层 hi-fi（钢琴、立式或电贝斯、刷鼓或紧鼓、钟琴、真实采样）是世界；一条 chiptune 方波 / 脉冲是角色。两者可以交替、对答，最后合流。
- 可选项：暗色主题换成低通滤波的"夜间版"；章节缝上通鼓过门 + 镲；抽掉鼓组做紧张；角色踩在唱到的词上出音符；分屏用左右声道分开；定格下面垫一条持续 pad。
- **拟音**：键盘（"thock" + click，带人手抖动）、触控板点击、换窗"嗖"、浮层"啵"、通知铃、CI 的 tick、截图快门；角色的走、跳、落地全部是 8-bit。
- **沉默**：在那句关键承诺之前掉进一小段房间底噪，让承诺落地。
- **人声**：平稳，一句一个功能；产品名务校。音效不要落在词的起音上，否则会盖住产品名。旁白下把音乐压掉，整体 −14 LUFS。

## 原生手法

- **匹配剪辑出生**：角色从界面里已有的东西里长出来（logo 的方块字、一个图标、一个加载圈），爬出来时留下一个轮廓。
- **界面内标题**：片名作为真实界面元素出现，角色在重拍上落在它上面。
- **移动地板**：角色乘着插入符、浮层、发出的消息、进度条一起走。
- **带标签的快放**：长任务 N× 播放，闪一个标签，配移焦。
- **聚光定格**：推近 + 暗角，只留那一枚装着承诺的徽章。
- **整片换状态**：一个开关的效果溢出预览、接管整支片，之后再回来。
- **细胞分裂**：新会话或新窗口把画面切开，角色跟着一次像素爆裂分成两个。
- **光标与角色互为角色**：光标撸一下、戳一下、拖一下它，它会反应。
- **卡拉 OK 词**：角色在被念到的词之间跳。

## 变化空间

- **结构**：抓 bug（角色追一个报错穿过日志、代码、修复，单章）；一个用户的一天（一个应用里从早到晚，主题与音乐随时辰变）；比赛（两个窗口并排，旧办法 vs 新办法，角色在右边赢）。
- **开场**：半途（半篇文档，角色已经在推光标的选择）；一条通知（系统 toast 落下，角色在它里面）；空状态（空白应用、插入符在闪，角色从菜单栏掉下来）。
- **结尾**：角色睡在刚做完的那件东西上，窗口暗下去；应用关闭，角色留在 Dock 上；真的发出去（结果被发送，角色乘着它出画）。

## 坑

- **发明功能、改名的模式** → 每个按钮、模式、快捷键对着产品文档核一遍；文档里没有的，片子里就没有。
- **角色浮空、飘离元素** → 每帧重新量元素，只站在顶边上。
- **角色压字、或坐在字幕底下** → 给它留一条没有字的通道。
- **给要读的字加模糊假景深，或把倍率缩到 1 以下拍出屏幕** → 只虚不在读的窗格；缩放下限 1.0。
- **画面里出现手、手臂、手指** → 用户就是光标。
- **运动模糊加在被 transform 的层上**，把像素精灵拖错 → 只加在未变换的外层，且只给甩镜。
- **按键音、浮层音落在产品名上**把它盖住 → 拟音避开词首，终混再听一遍。
- **TTS 念错产品名** → 换音色、换拼写试，听回放核对。
- **界面被缩放过一次**（截图放大当推近） → 文字糊掉，全片白做。改：重画，或贴原始分辨率素材。
