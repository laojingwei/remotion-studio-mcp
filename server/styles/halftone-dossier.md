# 复古半调案卷（halftone-dossier）

> 整片是一张纸：明暗不是渐变，而是网点的直径；暗场也是印在这张纸上的，绝不发光。编号、骑缝、盖章、打字机字，把这支片子钉成一宗案卷。
> 参照（只学语法）：Ben-Day 网点时代的波普漫画（用网点密度当阴影）、孔版与胶印叠印的 zine（multiply 与轻微错位）、嫌疑人身高牌与档案夹（取景装置）、日本综艺的字幕条（关键词高亮）。不照搬具体画面、角色、字体文件。

## 本质 / 不是什么

- 本质：**整部片子是一张纸**——暖奶油色纸面，低频斑驳、细颗粒、暗角、一道折痕；暗场照样印在这张纸上，所以它永远是"印出来的黑"，不是"屏幕发的光"。
- 本质：**明暗 = 网点直径**。两三层不同网角的网点，按密度场（径向光晕 / 边缘挤压 / 线性斜坡）排布，与纸正片叠底，叠出"油墨压上去"的厚度。
- 本质：**官僚机器当画框**——案号、档案标签、编号证物、身高牌、名牌、橡皮图章。画框是严肃的，画框里的东西可以庄重，也可以荒唐。
- 本质：**吵但可读**：每 2–4 秒一张卡，一个大标题、一个视觉包袱或一件证物、一行字幕。
- 不是**孔版印刷**（risograph-print 的主角是"错版 + 孔版墨不匀"）：这里的物理主角是**网点**。错位只存在于标题阴影和字幕条阴影，是 8px 的死偏移，不是整片一直在抖。
- 不是波普艺术拼贴：没有漫画分格、不拿爆炸字当主角（爆炸字只做道具）、不玩美式拟声词。
- 不是瑞士动效（没有白底上的网格动字），也不是游戏节目（没有糖果布景和闯关回合）。每一帧里，网点、纸、印章至少看得见两样。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 网点即阴影 | 所有灰都长成圆点，越暗点越大，到 0.7 就并成实块 | 印刷感、复古、转折 |
| 纸与折痕 | 奶油纸有低频斑驳、暗角、一道竖折痕，纸永远不动 | 档案、回忆、旧事 |
| 案号与证物编号 | 左上角案号 + 章节标签，右上角 REC 点和日期 | 揭秘、复盘、调查 |
| 橡皮图章 | 双线圆角框 + 粗字，边缘毛糙、油墨不匀，砸下来 | 判决、通过、作废 |
| 巨号半调数字 | 一个数字大到出血，笔画里是更深的网点 | 排行、数量、倒计时 |
| 身高牌 / 证件照 | 正面、硬光、背后一条刻度墙 | 新物种、产品拆解、"嫌疑人" |
| 证据墙与红线 | 证物钉住、用线连起来，然后被一把摇乱 | 供应链、家谱、时间线 |
| 粗墨描边角色 | 约 7px 墨线、平涂、亮肚皮、高光眼 | 吉祥物、拟人、寓言 |
| 字幕条高亮 | 深墨色药丸条 + 错位阴影，关键词换成高亮墨 | 讲解、金句、关键词 |
| 网点当情绪 | 光晕散开、边缘挤满、径向炸开——都用点径做 | 破纪录、逼近、重逢 |
| 点阵擦除 | 一片圆点长大盖满画面再退去，换景在盖满的一瞬 | 转场、章节 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；信号从主题里选，不按顺序全上。
- 网点、纸、印章是**材质常驻**（每帧都在），但挑出来的那 2–3 个要放大当主角，其余压到很轻，只当底色。
- 暗场也不例外：**暗场是被印出来的**——换成深墨底 + 同一族的浅色网点，仍然与纸正片叠底，不许出现任何辉光。

## 这个风格最俗的版本

- 画面：满屏大网点做底，一张奶油纸，中间一个红色"机密"章"咚"地砸下，左上角写 FILE No.0001。
- 声音：打字机"哒哒" + lo-fi 鼓 + 黑胶底噪。
- brief 的 style 一栏写明这支翻掉了哪几条，或者为什么刻意保留（比如用户要的就是经典档案感）。保留时把力气花在"每张卡只讲一件事"和"网点密度在变"上。

## 适配

- 用途：揭秘、档案、案件式复盘、评测（把产品当"被立案对象"）、法规与政策解读、冷知识。
- 内容：**需要一个"读出来"的框架**的主题——把观点变成指控，把结论变成判决，把过程变成证物清单。
- 时长：20–90 秒。每 2–4 秒一张卡；总长随证物数量长，每件证物都要给够阅读时间。

## 技术路线

- 本工具：`add_scene` 建幕，`add_element` 建元素；画风落地用 `set_theme` / `apply_style`，先 `preview_frames` 看静帧，再 `render_preview_clip` 看动。
- **网点做不到真印刷分色**。可行做法：一张预生成网点贴图（或 CSS `repeating-radial-gradient`）当遮罩，用 mask 的 `background-size` 控制步距、`rotate` 控制网角，再按元素明度调遮罩阈值——亮的抬高阈值（点小），暗的压低（点大）。2–3 层遮罩各自加 `mix-blend-mode: multiply` 就得到叠印。
- 层序固定：纸（最底）→ 平涂色块 → 网点层 → 描边与字 → 颗粒 → 纸面脏点（最上，multiply）。素材 `upload_asset`、旁白 `tts_narration`、字幕 `set_subtitles`、音效与 BGM `add_audio`。

## 材质与渲染

- **纸层**（一次性构建，全程 multiply）：放大的随机噪点做低频斑驳、逐像素噪声偏暖、径向暗角、一条很淡的竖折痕。纸不随时间动。
- **颗粒层**（逐帧）：几百个纸色小点 + 更少的墨色小点，**每 2 帧重播种**——这是纸上的灰，不是胶片颗粒。
- **网点**：圆点排在旋转网格上，**步距 20–26px**；1080p 下这相当于约 4–5 行/英寸的粗网点（漫画尺度，**不要**用印刷厂的 85/133 lpi，那在屏幕上看不见也编不出来）。三层网角分别 **15° / 45° / 75°**，主暗层用 45° 避开水平垂直，减少摩尔纹。点径 = 密度 × 步距 × k，**k 取 0.6–0.72**（到 0.7 左右圆点并成实墨，这是"最黑"的上限）。
- **密度场**：径向（光晕、绽放、角落光）、边缘（点挤在画框四周）、线性（"从上方来光"）。
- **网点填充的字与形**：平涂 + 一层更深的网点裁进字形里；巨号数字可以出血出画。
- **煮沸线**：湍流位移约 5px、**约 10 次/秒**重播种，再用细墨噪点啃掉每个平涂的一点点边。**只给角色和手绘道具**，字、网点、HUD、字幕一律不许。
- **角色**：厚实的块面 + 约 7px 墨线描边、平涂、肚皮或脸留一块浅色；高光眼 = 墨色椭圆 + 两个高光点，会眯、会眨、会笑成弧。所有体态共用一套头部绑定。
- **印章**：双线圆角矩形 + 粗体字，过一遍粗墨噪点和位移，边缘毛、墨色花；**不透明度约 93%**，歪 **±10°**。
- **道具**：爆炸星、对话气泡、纸屑、放射线、便签、档案夹、时钟——一律平涂 + 墨线。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 纸 | `#F1E7D4` | 奶油档案纸，被网点压过之后略暗 |
| 牛皮纸袋 | `#E6D8BC` | 第二层纸（档案夹、证物袋） |
| 深墨 | `#1F3A5F` | 描边、正文、字幕条、暗场底色、淡出用的颜色（更硬的案子可换 `#201C18` 黑褐） |
| 叠印阴影墨 | `#8C5AA8` | 标题 +8/+8 的错位阴影、字幕条的偏移阴影 |
| 高亮墨 / 印章红 | `#D9455F` / `#C63A2B` | 高亮给关键词与数字；印章红只给图章和警报 |

- **一张纸 + 一种深墨 + 四五种平涂专色**。深墨扛所有描边、正文、字幕条，也是淡出时用的那个颜色。
- 只用平涂：**不渐变、不做透明度斜坡**，深浅全由点径和叠印负责。
- 夜戏 / 密谈戏：换成深墨底色 + 同族浅色网点，仍然乘在纸上。
- 角色可以自带一两个本地色（毛色、衣服），这些颜色在别处不出现。
- 示例（看思路，不要照抄）：奶油 / 藏青 / 钴蓝 / 洋红 / 黄 / 红；牛皮 / 褐黑 / 青绿 / 芥末 / 朱红；灰白 / 森林绿 / 番茄 / 天蓝 / 赭石。**最多五种油墨加纸。**

## 字体

- **标题**：极粗衬线（中文 `Noto Serif SC` 900，拉丁用黑体 slab），**100–230px**，靠左边距左对齐，带 **+8/+8px 的错位阴影**（阴影用叠印墨，multiply）。
- **展示字与数字**：胖重的展示体，`Archivo Black` 兜底；名字、大数字、时间用它。
- **感叹词**：手写感（`STKaiti` 或系统手写体），纸色填充 + 粗墨描边 + 偏移阴影。
- **数据 / HUD**：重等宽（`monospace` 700–800），案号、日期、刻度、文件名。
- **字幕与印章**：极粗无衬线（`Inter Tight` 900）。
- **卡就是字幕**：每拍一个大标题，外加一条**字幕条**——深墨圆角药丸 + 叠印墨偏移阴影、纸色字、关键词用高亮墨。字幕条在标题之后弹入，保持 **≥ max(1.8 秒, 语音 + 0.6 秒)**；有旁白时，字幕条承载那句话。
- **HUD**：左上角案号 + 章节标签，右上角状态（REC 点、日期）；暗场时颜色反转。
- 拉丁比中文长 2–3 倍：标题缩小，印章压成 1–2 个词（GUILTY / CLOSED），逐字错峰更紧（0.02 秒）。

## 运动

- 变换按 **30fps**，角色煮沸线 **约 10fps**——位置是顺的，画在呼吸。
- **一切进场都过冲**（back ease，0.3–0.45 秒）：从画面下方升上来，或从 0 弹到 1。**没有淡入。**
- **逐字弹**：每个字下落 30–100px、压扁后弹回，错峰 **0.05–0.08 秒**（小字 0.02 秒）。
- **盖章**：约 **0.09 秒**从 2.6 倍砸到 1 倍（ease-in），再一下阻尼回弹；同一帧给镜头抖动、闪白和印章声。落地压扁保体积：`scale(1/sq, sq)` 配阻尼余弦。
- **待机小动作**：呼吸、尾巴或头发摆、按剧本眨眼、闪光、REC 点或时钟冒号在闪。
- **点阵擦除转场**：一片圆点长大到盖满、再缩回去（约 **0.44 秒**），带对角线延迟，**换景发生在盖满的那一瞬**；每刀可以换一种擦除色。硬切是对比的工具，只留给重击。

## 画面怎么活

- 画面停住时，**密度场在呼吸**：光晕的点径在一个 ±0.04 的窗口里慢慢涨落，几秒一个周期——这是油墨在纸纤维上摊开，不是元素在缩放。
- 纸不动，但纸上的脏点每 2 帧换一批；折痕位置从头到尾不变。
- 角色在喘、尾巴在摆、眼睛按脚本眨；HUD 的 REC 点或冒号一直闪。
- 新卡进来时，上一张的字幕条**留在底下变暗**，观众始终知道自己读到第几件证物。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 锁定正面 + 约 0.6% 的搏动 | 这页是一张海报，在跟着拍子点头 | 标题、清单、指控 |
| 缓慢推近（1 → 1.05–1.08） | 审视、压力上升 | 人物档案、判决前的总结 |
| 二次衰减抖动（5–26px） | 撞击 | 盖章、坠落、撞墙 |
| 闪白帧（白色叠层 ≤0.95 → 0，重击封顶 0.5） | 被拍下来、真相曝光 | 证件照、判决、找到证据 |
| 横移过一块钉满东西的板 | 物与物之间的关系 | 时间线、嫌疑人、事件链 |
| 急推到网点细节，直到点巨大 | "凑近看" | 指纹、签名、某个数字 |
| 翻页 / 抽屉滑过 | 下一份、下一章 | 第二宗案、闪回 |
| 后拉露出整张桌面 | 这卷只是众多档案之一 | 规模、"每天都在发生" |

取景像排一页印刷品：标题在左上，主体在右中，字幕条在下方居中，HUD 在四角。转场只用**点阵擦除或硬切，不许叠化**。

## 声音调色板

- **合成流行印刷组**：合成 kick、snare、clap、hat；方波感的八分音符贝斯；三角波铺底；**马林巴式拨音**（基频 + 约 4 倍泛音）做旋律；拨弦和响指用于"摸进去"；音乐盒钟琴用于柔软处。
- **拟音跟着印刷和包袱走**：印章 = 下坠的轰 + 咔（重章再加一层裂响）、快门、纸张滑动与档案夹翻动、打字机或键盘、进入擦除的风声、每个字落地的"啵"、角色的 boing 与 plop、玻璃瓷器的脆响、合成的动物或怪物声（共振峰滑音）。
- **盖章前留空**：判决前把音乐清空，让章单独落下。其他选择：snare roll + 上升扫频进揭示；密谈戏剥到只剩贝斯和响指；钟琴琶音当尾签；一段持续 pad 垫在悲伤的证物下。
- **人声可选**，卡本身能讲故事。要旁白就用干燥、面无表情的汇报腔，绝不气喘。
- **混音**：撞击时 SFX 抢在音乐前面，总线软削波，−14 LUFS，真峰值 ≤ −1 dB。

## 原生手法

- **立案框**：把一个主题变成"X 一案"，列出它的罪状。适合：一种认知偏差受审、一座城市的堵车、一株停不下来的植物。
- **编号证物**：每拍背后一个巨号半调数字。适合：停电的五个原因、合同的三个条款、召回的各个阶段。
- **盖章**："经典"：判决是一次物理砸落。适合：拨款批了、政策到期、谣言核实。
- **证件照**：正面 + 身高刻度 + 名牌 + 闪光。适合：新物种、产品拆解、bug 报告里的"嫌疑人"。
- **证据墙**：证物钉住、红线相连，然后被一把摇乱。适合：供应链、家谱、劫案时间线。
- **点径 = 情绪**：点涨成光晕、挤到边缘表示紧张、径向炸开表示狂喜。适合：破纪录、截止日逼近、重逢。
- **涂黑**：黑条印在字上，一条条抬起来。适合：泄露的备忘录、惊喜计划、剧透。

## 变化空间

每支由 agent 决定：讲什么、几件证物、有没有角色、油墨在配色规则内怎么选、调子是闹剧还是庄重、开场、结尾、长度（随证物数量长）。

- **结构**：一份解密报告，一页页把涂黑抬掉直到真相露出来；一份失踪档案，从最后一次目击倒着往回查；一份保险理赔，每件证物都在拆投保人的说法。
- **开场**：证物袋（深墨底上一件东西，档案在它周围拼起来）；一个巨大的指纹网点，后拉变成一张脸；一通电话（纸面上只有一条字幕条，档案随后掉下来）。
- **结尾**：档案被塞进一个装满同样档案的抽屉；最后一页永远涂黑（答案不揭）；章砸空了——落在桌面上，然后主体走出画外。

## 坑

- **字体没加载完就排版** → 逐字位置按兜底字体算，字叠成一团。改：进场前把字族加载完（`font-display: block`），运行时字符串只用字体里有的字；先 `preview_frames` 逐字看一遍。
- **把煮沸线加在字、网点、HUD、字幕上** → 全糊。改：滤镜只给角色和手绘道具。
- **裁切 id 是全局的** → 第二个网点数字吃到第一个的遮罩。改：每个被裁的字形用唯一 id。
- **有入场时间的元素提前露出来** → 改：`t < t0` 必须显式透明度 0。
- **点阵擦除没铺满就切** → 露出硬切。改：最大半径要盖住单元格对角线（步距 × 1.42）。
- **100% 纯白闪一帧** → 像掉帧。改：封顶约 0.5。
- **网点太小** → 1080p 步距 <14px 时，编码后变摩尔纹。改：步距守 20–26px，渲染完回看一遍。
- **油墨太多** → 印刷感消失，变成彩色噪点底。改：最多五种加纸，深浅交给点径。
