# 钢笔淡彩（pen-wash-sketch）

> 一张在现场几分钟画完的速写页：先一支 0.3–0.5mm 的深褐针管笔勾线，再把透明淡彩丢上去——颜色和线永远差着 1–3px，对不上。
> 参照（只学语法）：城市速写本内页（先线后色、色不对位、角落手写日期地点、页边碎成点）、《纸人》(2012) 单色世界里一个彩色物、《红气球》(1956) 以物为主角镜头跟着它穿过城市、爵士圆舞曲（3/4 swing、walking bass、鼓刷、木管主奏）。不照搬任何角色、旋律、版式或字体。

## 本质 / 不是什么

- 本质：**两层，始终看得出是两层**。墨是墨，色是色，谁都不迁就谁。
- 本质：**线是"提示"不是"描述"**——几笔窗格代替一张网格，扇形碎段代替一整棵树的轮廓。
- 本质：**线会抖、会冲出去、会断**：约 1px 抖动、拐角多画出去 3–8px、三分之一到一半的长笔画在中途留一个小缺口、墨的覆盖率约 96%。
- 本质：**色是丢上去的，不是填进去的**——透明水彩正片叠底压在线上，跟线错开 1–3px，经常停在框里一半、或者溢出线外。
- 本质：**纸是画面的一部分**——暖奶油冷压纸，大尺度斑驳 + 细齿，齿纹乘在所有东西上（包括人）；从不涂到边，画在边缘碎成叶大小的点和白洞，给手写留出页边。
- 本质：**几分钟、在现场、记者画的**。它是报道，不是精修插画。
- 分界 vs `watercolor-wash`：那条是纯水彩、没有线，「纸本身就是橡皮」，提亮靠洗掉。这里**必须有墨线**，线在色之前，而且不许被色盖住。
- 分界 vs `one-line`：那条只有一根线、没有颜色。这里是两层：线不承担全部叙事，颜色是后到的第二件事，且故意对不上。
- 不是**水墨**（没有笔锋提按与墨阶），不是**白板讲解**（没有马克笔、没有圈重点的箭头），不是**矢量描边的插画**（线不是干净的）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 色线不对位 | 色块整体偏 1–3px，压住线又露出线 | 现场感、时间紧、手作 |
| 冲角与断笔 | 拐角多画出去几像素，长线中途一个小缺口 | 街角、建筑、边走边画 |
| 没填满的线框 | 颜色停在框内一半，另一半是纸 | 光、未完成、进行中 |
| 干边更深 | 色块边缘一圈更浓，中间平 | 水、墙、影子 |
| 留白即高光 | 最亮处一像素没画，就是纸 | 逆光、清晨、水面反光 |
| 颜色扣着不给 | 整页纯墨，只有一件东西有色 | 主角、线索、记忆点 |
| 湿边推进 | 颜色从一点或一条边参差地漫过来，前沿后有一道暗带 | 日出、开场、灯亮 |
| 页边碎成点 | 内侧一条白点带、外侧一层色点喷溅 | 手账、日记、一个地点 |
| 角落手写注记 | 日子、时间、天气、地点，写在没画的空处 | 旅行、纪实、开场 |
| 远景混霾 | 远处整块颜色往同一个灰里退约 50% | 纵深、城市、距离 |

规则：每支挑 2–3 个，至少一个不在下面「最俗的版本」里。「色线不对位」和「颜色扣着不给」最好认也最易滥，第二支换一组。抖幅一页里只有一套，别每场换一套。

## 这个风格最俗的版本

- 画面：米色水彩纸 + 一支笔在画欧式街景 + 颜色自动乖乖填满每一块 + 结尾手写 "travel diary"。
- 声音：尤克里里 + 鸟叫 + 翻页音效。
- brief 的 style 一栏写明翻掉了哪几条，或为什么刻意保留。保留时把力气花在「两层对不上」和「留白」，不是花在纸上贴纹理。

## 适配

- 用途：城市速写、在地生活记录、旅行日记、市场与食物、纪实开场、报道式的人物/地点介绍。
- 内容：现场看得见的东西，加一个「颜色什么时候来」的决定（一直在／扣着／刚刚到）。
- 时长：25–90 秒最舒服，一页纸一个地点；超过两分钟要翻页或换场地。
- 不适合：密集数字、UI 演示、需要精确读值的图表；需要严格对齐的机械结构。

## 技术路线

- 分层：`add_scene` 建幕；`add_element` 依次放纸 → 墨层 → 淡彩层 → 手写注记层。大画布（如 5120×2880）当一张纸，相机只取局部。
- 墨：带宽度的形状沿路径画出来，端点加一点毛边；全层正片叠底、约 96% 不透明。线宽只按远近给两档（远 1.3px、近 3.4px），物体内部不再变。
- 抖与断：路径顶点按固定种子做约 1px 横向扰动；拐角把路径延长 3–8px 冲出去；长笔画按 1/3–1/2 的概率在中段留 2–4px 缺口。
- 淡彩：同一形状叠 2–3 层，各层顶点轻微抖动、整层相对墨层偏移约一个线宽（1–3px），正片叠底、每层 0.4–0.65 不透明度；叠起来边自然更深。
- **真实墨水的洇开、颜料沉进纸纤维的颗粒感做不到**。近似：干边 = 同形状缩小 1–2px 再深一层；颗粒 = 整层乘一张很淡的纸纹图 + 每帧 ±2% 不透明度抖动（人和远景一起乘）。
- 色的到达：用一个圆或斜带做遮罩，遮罩边加噪声做参差湿边，前沿后 6–10px 叠一条略深的带。颜色永远「漫」出来，不淡入。
- 落地：`set_theme` / `apply_style` 定调；`upload_asset` 放纸纹与手写扫描件；`tts_narration`、`set_subtitles`、`add_audio`。
- 验收：先 `preview_frames` 看静帧——冲角、断笔、色线错位在静帧上就该看得见；再 `render_preview_clip` 看色的到达和相机滞后。

## 材质与渲染

- **纸**：暖奶油底 + 两个八度的 fbm 斑驳（各几个百分点）+ 一张细齿纹乘在所有东西上（连同人物）+ 轻暗角。永远第一层。
- **墨**：单色深褐、约 96%，正在画的那一笔末端略钝带毛边；笔画顺序按真实书写回放，从头往尾长，不是整条淡入。
- **淡彩**：2–3 层粗糙边、正片叠底、alpha 0.4–0.65，干边 30–40%，颗粒 = 色 × (0.82 + 0.36 × 噪声)。
- **树**：淡底 → 亮部块与暗部块 → 按光向打小叶点 → 边缘留洞；只在轮廓上有墨，内部不勾。
- **天与建筑**：天是几块很大很软的淡彩、低透明度往上淡出，云是留白、只在腹部带一点色；建筑用本地色，暗面混进约 45% 冷紫灰，远景整块混进约 50% 霾色。
- **人**：正交投影骨架，躯干按截面挤出，四肢是锥形管，头发与头并成一整块，**脸留白**（侧面一小道鼻子）；阴影面混紫。远处人群用「胡萝卜人」：一坨水洗 + 两条腿线 + 一个头点。
- **页边**：噪声边界 → 内侧白点带 → 外侧色点喷溅。同一个种子出同一笔。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 纸 | `#EFE3C8` | 暖奶油冷压纸；它是最亮的白 |
| 淡彩底 | `#E4D5B4` | 比纸深一档的湿痕 |
| 墨 | `#3A2A1E` | 深褐，全片唯一，永不改变 |
| 冷紫灰 / 霾 | `#8B7E96` / `#B8B4A6` | 所有暗面、所有远景各自混向的那一个 |
| 叶 | `#7FA04A` | 草坪 `#C3C96F` |
| 天/水 | `#9FBCD6` | 天空、海、雾 |
| 朱红 | `#C9573F` | 船体、遮阳棚——一个反复出现的物 |

- **墨只有一个颜色**；暗部不是加黑，是把本地色混向那一个冷紫灰；远近靠混向那一个霾。
- **纸白是最亮的值**，留白，从不涂。高光就是不画。
- **颜色可以被扣着**：一页可以纯墨，颜色当作一个事件，且来的时候有原因。
- 三组现成例子：夏日公园——草坪 `#c3c96f`、叶 `#7fa04a`、天 `#9fbcd6`、石灰岩 `#d8c6a0`；清晨港口——海 `#7fa6b8`、船体 `#c9573f`、缆绳 `#c8a86b`、天 `#bcd0dc`；冬季市集——屋顶 `#8b93a6`、灯 `#e2b04a`、棚布 `#b8483e`、雪 = 纸。
- 一页 3–5 个色相就够，两个强调色等于没有强调。

## 字体

- **所有字都是写在纸上的手写**：从左往右写出来，带笔声，跟着相机一起动。
- 角落注记：日子、时间、天气、地点，用细手写体（Reenie Beanie 一类）；标题与落款用随意的手写（Caveat 500–600），**左对齐，写在没有画的页边空处**；中文用 `STKaiti`（楷体）兜手写感，不要黑体，字一多要重新确认有没有掉字。
- **字幕不用浮层框**：手写进页边，或写成页脚一行，颜色就是墨色，底下垫一层很淡的纸色晕。
- 停留 ≥ max(1.8 秒, 语音 + 0.6 秒)。这支片子没有旁白也完全成立。

## 运动

- **画出来是主运动**：墨按笔画顺序长出来，一笔 0.4–1.6 秒，然后颜色才到。
- **人 12fps 抖**：线抖与水洗种子每 1/12 秒换一次；**纸不抖**（它是真纸），相机每一帧都平滑移动。
- **表演与看不见的力**：预备—动作—跟随，脚步落在拍上；风是一组墨的卷（从头画出来、从尾擦掉，后面跟几个点），声音是几条墨线，热是波浪线。
- **颜色从不瞬切**：从一点绽开，或沿湿边漫过来。
- 一切「出现」都按笔画顺序画，没有淡入；转场就是相机在纸上移动、翻页，或者颜色到达——**不许叠化**。

## 画面怎么活

一个街角被画出来 → 颜色从某处漫上来 → 相机顺着一条线滑到下一个东西 → 线与色又对不上一次 → 最后拉远到整页，四周碎成点，页边一行手写的日期。
生命力只在「正在画」和「颜色刚到」这两段；画完的部分跟着相机走，自己不摇。观众永远知道自己在上色前还是上色后。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 推近 | 注意；一个被观察到的细节 | 一张脸、一块招牌、一件小事 |
| 弹簧横跟（带前置目标） | 行进、追踪，相机像手持跟着 | 被带走的物体、走路的人、车 |
| 升降上摇 | 换一个高度，视野打开 | 天际线、一棵树、一个阳台 |
| 带一点侧倾的甩摇 | 突然转向 | 摔倒、一阵风、意外 |
| 短促冲击推 + 一抖 | 撞击 | 接住、相撞、关门 |
| 后拉到整页 | 尺度；这张速写本身是个物件 | 总结、一个地方的全貌 |
| 摇进页边 | 从画到字 | 注记、日期、标题 |
| 在只有线的区域慢移 | 上色之前的世界 | 安静的开场、回忆 |
| 停住，让笔去画 | 注视这个动作本身 | 正在被画的东西 |
| 翻页到新的一跨 | 另一个时间或地点 | 旅行日记、连续几天 |

取景：叙事点上主体 ≥ 画幅高度的 1/3；小关键物给一圈很淡的纸色光晕（留白），好在杂叶里读出来。
转场：相机在纸上移动、翻页、颜色到达；**不要叠化**。

## 声音调色板

- **先纸，后地方**：先是纸的房间底噪，等这个地方有了颜色才进现场声（鸟、车流、港口海鸥、市集人声）；一个地方的声音要比画面早一小节进来。
- **笔在冷压纸上**：带通噪声约 1.6–7.5kHz，加纤维质地与颗粒咔哒；**真实的一笔一声**；快速速写时几千笔叠成一片沙沙，更短更亮的笔画听起来像 hi-hat。
- **水与笔**：颜色绽开一声湿笔 "shhh"，一个洗笔缸的水声，一滴；拟音跟着物体按速写尺度走——风里的布或纸（速率与音量跟速度、声像跟屏幕 x）、踩在拍上的脚步、铃、水花。
- **音乐家族**：爵士圆舞曲（3/4 walking bass、鼓刷、钢琴、单簧管或长笛）；咖啡馆手风琴三重奏；尼龙弦吉他独奏；弦乐四重奏拨弦；人群用铜管队。页面的每一块给一件「有颜色的」乐器。
- **沉默是工具**：悬念最高处给一小节真正的静（连环境声一起），静之后的第一个声音就是下一个动作。
- **混音**：音乐在关键击点上让路，拟音高通约 90Hz，整体 −14 LUFS，LRA 中等。

## 原生手法

- **先线后色**：笔按真实顺序把东西画出来，颜色才落下；画的这个过程本身就是戏。适合：一座教堂立面、一道菜的摆盘、一个街头乐手。
- **颜色当事件**：水洗带着湿边从源头漫开，一件事把整页染上；人可以是冻住的线稿，直到颜色碰到他。适合：港口日出、游行过街、市集的灯一盏盏亮。
- **唯一彩色的东西**：一张无色的速写里只有一件有色，它就成了主角。适合：雨里的一把红伞、一辆黄出租、一只孩子的风筝。
- **把整页当画框**：后拉到整页出现，边缘化开，页边有手写注记。适合：一页旅行日记、一个街区的肖像、一个地方的一天。
- **胡萝卜人**：远处人群就是一坨水洗、两条腿线、一个头点。适合：高峰期的车站、球场、海滩。

## 变化空间

每一支由 agent 决定：地方、主体、颜色干什么（一直在／扣着／刚到）、有没有旁白、音乐家族、相机路径、开场、结尾、长度。

- **三种结构**：五页旅行日记，一天一页，页被风或手翻过去；同一个街角画四次，墨不变、水洗随时辰变；一份食谱，食材在市集现场画，最后才画那道菜。
- **三种开场**：空白页上只写了日期，第一笔是地平线；纸边一只咖啡杯的特写，后拉看见后面画着整座城；雨点落在纸上，绽成第一批水洗。
- **三种结尾**：速写本合上；最后一个人物走出纸面，走进空白的页边；暮色里颜色退回只剩墨，留一扇亮着的窗。

## 坑

- **按外框裁颜色 / 复杂轮廓外套矩形遮罩** → 色块出现笔直的边、方角缺口。改：按那条带台阶的真实轮廓、按真实形状的噪声边界裁。
- **人物走进没上色的区域就掉色** → 颜色状态在进场时采样一次（或绑在事件上），不要跟着当前位置算。
- **静态的墨压不住后来的水洗** → 后画的色盖住前面该被遮挡的墨。改：画近处形状前先擦掉它内部远处的墨；远景人群用胡萝卜人。
- **混姿态时脚被钉住** → 腿劈开。改：脚的落点朝胯下收。
- **正脸画出来是秃的** → 头发整块画上去，再把脸从这块里挖出来。
- **抖多了、或者每场换一套抖法** → 像滤镜在动。改：一页里抖幅只有一套（约 1px），冲角 3–8px，断口 2–4px。
- **颜色顺着线走、线被颜色盖住** → 变成精修插画。两层一融合，这支片子就废了。改：色层整体错开一个线宽，墨单独浮在上面。
- **整页涂到边** → 速写本的味道全没了。改：留页边，让边缘碎成白点和色点。
- **把纸纹当贴图盖在成品上** → 一眼假。改：纸只在最底层，淡彩是形状本身，颗粒靠「纸纹乘颜色」。
