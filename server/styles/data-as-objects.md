# 数据实体化（data-as-objects）

> 一个盘、一块、一枚硬币就等于一个写明数量的单位：规则在画面上只说一次，之后堆起来的高度本身就是数据。
> 参照（只学语法）：数据雕塑与实体可视化实践（一个单位一件物件，物件就是坐标轴）、影棚静物摄影（低角度暖主光、冷轮廓光、无缝背景纸）、年报编辑设计（一屏一次读数、一行来源、安静的无衬线）。不照搬它们的构图和作品，片子里不点名。

## 本质 / 不是什么

- 本质：**单位是一件物件**。一只盘、一块砖、一枚币等于一个写明的量，规则在画面上说一次（"1 盘 = 10 GW"）；每第十件换一种更重的材料，于是这摞本身就是一把尺子。
- 本质：**尺度是算出来的**。高度、件数、面积都从数据推出来；四舍五入最多一件，并写进事实表。两条序列放在同一个底座上，用的是同一个单位。
- 本质：**影棚光、真材料**。金属反射环境贴图，木头有纹理，亚克力透光；不发光、不描边、没有假界面。
- 本质：**增长就是装配**。数据靠一件件放上去变高，有重量、有声音；不是缩放、不是形变。
- 本质：**至少后拉一次**——让图表露出它是一件做出来的东西：一个表盘、一件案头摆件、一片摞成的天际线。
- 本质：**每个数字在画面上有出处**，真实公开统计或用户自己给的数字，署名在框内。
- 不是 **data-motion**（数据动态）：那条用抽象的柱、线、数字表达数量，运动编码变化；这条把数量换成实体物件，观众能数、能感到重量，说服力来自"真是这么多件"。
- 不是 **engineering-board**（工程比较墙）或 **isometric-infographic**（等距信息图）：一个是照片加马克笔的二维板面证据，一个靠图标和平涂色块讲层级；这里没有图标、没有平涂编码，只有被同一盏灯照着的实体堆和材料本色。
- 也不是 glass-material（物件是数据，不是产品）、dark-keynote（没有黑舞台和霓虹）、积木玩具（不做卡通比例、不要角色）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 第十件换材质 | 每十件里一件黄铜或更重的一件，所有序列共用 | 总量、配额、里程碑 |
| 堆边的读数 | 物件上一个点、1.4px 引线、一小块材质色、类目行、数值与单位 | 单点成绩、对比 |
| 底座上的刻线 | 木/石板面刻着刻度环、年份、类目路径，跟场景一起被照亮 | 时间、地区、目录 |
| 一摞斜着长 | 每件几毫米随机偏移和偏航、±7% 明度、发丝缝，摞起来不像柱子 | 累积、增长 |
| 一件件喂进来 | 从画外飞来、旋正、落定，计数器跟着落 | 本年新增、一个季度、一次收获 |
| 最后一次后拉 | 原来是一圈表盘 / 一片天际线 / 一件案头摆件 | 收尾、比例、总览 |
| 单件重物落下 | 一次轻微阻尼回弹，影子收紧 | 总数、目标达成 |
| 两种材料并排 | 拉丝金属对染色亚克力，缩略图尺寸也分得开 | A 对 B、交叉 |
| 角落里一行来源 | 等宽小字 20–22px，墨约 60% | 一切真实数据 |
| 裁决牌 | 左上三分之一、强调色纸牌、下面一条还在长的横线 | 结论、反超 |
| 微距擦过堆边 | 一件占满画面，只留一条锐 | 规则本身、"1 件 = 多少" |
| 相机从不停 | 连静止段也有 2–5% 的缓移 | 全片 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 第十件换材质、读数牌、最后后拉最好认，也最快被用滥——第二支片子换一组。
- 信号从主题里选：能数的量（吨、人、元、台、亩）才配这条风格；抽象比例要先找到一个能数得下去的单位。

## 这个风格最俗的版本

- 画面：浅灰无缝背景，一堆发光金币螺旋上升，每枚上都跳数字，结尾一个巨大数字加"增长 300%"。
- 声音：一路往上顶的 riser、电子 tick、每落一枚一记硬币叮。
- brief 的 style 一栏写明这支片子翻掉了哪几条，或者为什么刻意保留；保留时把力气花在**真实的换算**和**那一次后拉**上。

## 适配

- 用途与内容：年报与 ESG、能耗与产能、预算、人口、进出口、两家公司对比、达成目标；最适合数字能被拆成可数单位、而且观众本来不太相信的主题（"真有这么多吗"）。纯抽象、没有真实数字的主题不合适。
- 时长：20–60 秒最舒服。超过 90 秒拆成两段，各给一次完整的后拉。

## 技术路线

- 3D 主体：`add_scene(type="scene3d")`，用 graph 逐节点搭。**每一摞是一个 group**，件挂在它下面，加高只改这组的 y 和件数，件的朝向不会被带歪。
- 几何：box / cylinder 一族够用（盘=扁圆柱、块=薄盒、币=圆柱）。**成百上千件各自物理堆叠本工具做不到**：按网格排，每件给几毫米随机偏移与偏航，只给最上面几件加随机偏转和没对齐。
- 材质：一条序列一种（拉丝金属 / 染色亚克力 / 浅木 / 深石 / 铜），两序列要在一眼之间分开；第三种（黄铜）只给尺子件，所有序列共用。本工具材质只有一个贴图槽、没有法线贴图，木纹和拉丝画进贴图。
- 光：一盏 20–35° 的暖主光（低角度、长而软的影子）+ 一两盏冷轮廓光；ambient 抬起来，否则金属发黑；HDRI 低强度，只做反射。
- 后期：`post` 的 vignette 0.3–0.4，颗粒很轻（背景是浅色）；**不要 bloom、不要色差、不要镜头光晕**。
- 底座：一块真实纹理的板（胡桃木 / 石），刻度环、年份、类目名画成一张俯视贴图 `upload_asset` 进去，与场景共用同一盏灯。
- 景深与接触阴影：本工具没有景深开关，也没有 GTAO——把相机贴近最前面那摞、让前景吃掉画面边缘来造"只在一条锐"；贴合感靠 `ground` 的阴影 + 底座上围着物件画一圈压暗的贴图。
- 文字只活在屏幕空间：读数、裁决、来源行、字幕、标题卡。读数与引线用 `add_element` 画，锚点用 `preview_frames` 逐帧对位；**相机还在动的段落不要挂读数**。
- 流程与声音：`preview_frames` 逐拍看静帧（重点看每层只有 2–3px 的地方有没有闪）→ `render_preview_clip` 看动；色与字先 `set_theme` / `apply_style` 定死，再手调标注层。旁白 `tts_narration`、字幕 `set_subtitles`、拟音与 BGM `add_audio`、纹理素材 `upload_asset`。
- 数据来源与许可：Our World in Data（每张图"About this data"里写着原始来源，CC BY 4.0，两边都要署名）、世界银行开放数据（CC BY 4.0）、Eurostat（CC BY 4.0）、美国普查 / BLS / EIA（公有领域）、UN Data / IRENA / IEA 的免费表与各国统计局（逐条看条款）；下载 CSV 连同元数据留在项目的 `data/` 里。CC0、公有领域、CC BY 署名后可用；ODbL、CC BY-SA、"no known restrictions"、"非商业免费"都不等于 CC0——先把条款说给用户，问过再用。纹理与 HDRI 用 CC0 的。
- 数字与事实：用户自己的数字（年报、ESG、销售）要问清出自哪份文件，绝不编造、绝不四舍五入成一个更好听的故事，生成图不许顶替真实数据或真实材料；随片交一份 FACTS.md——每个上屏数字与口播断言、来源 URL、引用的原句或那一行、推导值（比例、差值、每件多少）怎么算的。

## 材质与渲染

- **件**：薄盒或圆柱。每件几毫米随机偏移与偏航、±7% 明度、发丝缝——这三样才让它读成"堆起来的"而不是"一根柱子"。
- **序列靠材料分开**，不靠上色：拉丝金属对染色亚克力、浅木对深石、铜币对纸。黄铜只给尺子件。
- **底座**：真实纹理板，刻痕按板自己的比例嵌进去（刻度环、序列路径、年份与类目标签），被同一盏灯照出凹凸。
- **PBR 与光**：亚克力给 transmission、粗糙度 ≥ 0.2、加染色衰减；金属 metalness 0.9+，环境反射收紧别糊成一片白；暖主光在 20–35°，长而软的影子，一两道冷轮廓光让远处也能把金属和亚克力从木头里分出来。
- **后期**：轻颗粒、轻暗角；无光晕、无色差、无扫描线。
- **屏幕空间只给字**：读数永远钉在它那个物件上，和相机用同一套世界→屏幕换算。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 无缝背景 | `#C4BEB4` | 暖灰米，画面里最亮的中性 |
| 胡桃木底座 | 自然木色 | 永远比物件暗 |
| 铝（金属序列） | `#C8CCD1` | 序列一 |
| 亚克力（染色） | `#9FD3D6` | 序列二，带青绿衰减 |
| 黄铜 | `#D2B07A` | 只给尺子件，每第十件 |
| 墨 | `#1C1D20` | 数值满强度，标签约 60% |
| 强调橙 | `#D4521C` | 一屏只给一个读数或一条裁决 |

规则：场景是暖中性（暖灰背景 + 天然材料底座 + 材料本色），**材料而不是颜料**来区分序列；没有彩虹序列色、没有按数值的色阶、没有深色模式。强调色一帧最多三处，且不许落在同样是橙色的物件上。

## 字体

- 数字：轻的无衬线（Inter 200–300）。主角读数 130–170px；堆上的读数 46–56px。
- 标签与裁决：片子里那种语言的黑体（Noto Sans SC 500 / Microsoft YaHei 500），24–46px。
- 单位、年份、来源行：等宽，20–24px。
- 衬线只给标题卡，别处一律不用。
- **一条读数** = 物件上一个点 + 1.4px 引线 + 一小块材质色 + 类目行 + 数值与单位，坐在约 84% 不透明的纸色牌上。一对读数额竖着摞成一列，大的在上。
- **来源行**（数据集、发布方、年份、许可，例如"数据：IRENA (2026)，经 Our World in Data 整理 · CC BY 4.0"）：20–22px、墨约 60%，放远离字幕的那个角，从第一次读数一直挂到总结，标题卡上也有一份。
- **裁决**：左上三分之一、自己一块强调色牌、下面一条正在长的横线；只在它评的那几个读数静止 ≥ 2.5 秒之后才出现。
- **字幕**：左下，2px 墨线 + 向右淡出的纸色牌；一行一句，用真字体量过（nowrap），超了拆成两条字幕而不是换行；双语时本片语言在上；停留 ≥ max(1.8 秒, 语音 + 0.6 秒)。
- 标签停留 ≥ CJK ÷ 4.5 + 1.5 秒 / 字母 ÷ 15 + 1.5 秒；计数器只显示落地后的值；屏幕上没有小于 20px 的字。

## 运动

- 24fps 逐帧；**相机永不停**，静止段也留 2–5% 的缓移。
- **堆叠**：一摞从下往上装，0.5–1.0 秒，每件从几厘米高处落下，缓出；单件重物按重力落，一次轻微阻尼回弹，影子收紧。
- **喂入**：一个周期的新增从画外一件件来，五次缓出（quintic），偏航角一边旋一边归正（是"放上去"，不是"掉下来"），每秒 8–16 件；计数器跟着落地滚，不跟时间滚。
- **读数**：淡入 + 上移 16px，同时画出引线；离场只淡出，绝不滑走。
- **永不动**：底座、已经落定的件、尺子件。禁止缩放生长、形变、界面那种弹跳缓动、文字自己淡入、翻页式转场。

## 画面怎么活

- 靠装配活：每一拍都有东西落下、放上去或被读到；静是留给读数和裁决的。
- 停住时只有三样在动：相机 2–5% 的缓移、最上面还没压实的一两件的极小沉降、计数器最后一位。
- 空底座（刻线已就位）本身就是画面的一部分：先看见尺子，再看东西一件件往上堆。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 沿堆边的微距推轨 + 移焦 | 单位是真的、可数的 | "1 件 = X"这条规则；单项纪录 |
| 沿序列的低位横移 | 时间过去；东西在长 | 十年；排名；一串站点 |
| 两个主体上的固定四分之三机位 | 对比 | 前后；A 对 B；交叉 |
| 跟着升起的顶一起摇臂上升 | 累积 | 一年新增；逼近目标 |
| 后拉到接近俯视 | 整体原来是一件东西 | 总结；比例；收尾 |
| 绕底座慢速环绕 | 装置本身是雕塑 | 标题；换气 |

取景：关键时刻主体至少占画面高度的 1/3；读数住在空背景里，绝不压在字幕条上；对比时两个主体完整在框里。**转场就是同一个景里相机的移动**，能一镜到底就一镜到底；不切到一张图、不擦除、不翻页。（预设里的 fade 只是遮住接缝，不是叙事手段。）

## 声音调色板

- **拟音就是材料本身**：金属盘清脆短促（不谐和分音 3–8kHz），亚克力"tok"更钝（1–3kHz），木头是敲击，硬币有余音。一摞落完是落地时刻的一串爆发，密度越高单件越轻。
- **尺子会唱歌**：每个第十件响一记有音高的槌音，一条序列一种音色（金属用钟琴，亚克力用玻璃琴），随计数在五声音阶上往上爬——图表变成一串琶音。
- **配乐**：槌与空气——马林巴固定音型、弓拉与敲击的颤音琴、竖琴、玻璃、一层软合成垫、带明显二、三次谐波的脉冲贝斯；转折用圆号。加速靠细分（八分→十六分），不提速度。
- **撞击与静默**：转折或最后一件落在 punch（60–120Hz）+ 底鼓 + 定音鼓 + 一记钟；全片只做两三次，是最响的时刻。每次设计好的撞击前 0.3–0.6 秒抽空（音乐与拟音 −30dB），只留一层薄薄的影棚空气声。
- **混音**：人声比音乐高约 10dB，尺子音在人声之下；−14 LUFS，真峰值 ≤ −1.2 dBTP。人声冷静、精确、短句。

## 原生手法

- **单位特写**：推进到一摞的侧面，直到一件占满画面；一件标"= 10 GW"，尺子件标"= 100 GW"。适合：吨碳排做成钢板；预算做成钞票砖；人口做成木圆片。
- **成对爬升**：两条序列一个底座、各一种材料，随相机横移一年年长起来；交叉点停住，两个读数都在，再落裁决。适合：进口对出口；可再生对化石；两家营收。
- **喂入**：一个周期的新增一件件落到上个周期的水平上，计数器跟着落。适合：今年新增的人；一个季度销量；一次丰收。
- **图表变装置**：后拉到柱子成为表盘、天际线或案头摆件，底座上的刻线变成它的排版。适合：十二个月做成一圈时钟；地区做成地图形底座；产品线做成都城。
- **最后一件**：一件更重的（黄铜圆饼、硬币、砝码）落在底座上，刻着最终数字。适合：总数；比例；达成的目标。

## 变化空间

- 每支由 agent 定：单位与它的材料、底座与形状、哪几条序列共用一个底座、相机路线、节奏、最后那件、强调色在配色逻辑里的色相。
- **三种结构**：单序列长到一个纪录；两条序列与它们的交叉；一个以地区为单位的排名，铺成地图形的底座。
- **三种开场**：一件被放下的微距；先看俯视的成品，再俯冲到第一件；空底座带着刻线在等。
- **三种结尾**：最后一件落在正中；绕整个装置慢转一圈；单独拎起一件，让你看清一个单位是多少。

## 坑

- **数字不实** → 这条风格的立身之本就是"能数"，一个编的数就把它降级成装饰。改：只用公开统计或用户自己的数字，出处写在画面上；每件等于多少、怎么除出来的写进随片的 FACTS.md，交付前逐个核对。
- **四舍五入把结论翻过来** → 两个值差不到一件，两摞一样高。改：换一个更细的单位，或在画面上写明"相差不到一件"。
- **计数按时间滚** → 数在走、件没落，就是在撒谎。改：计数器只跟落地件数走。
- **两种材料太像**（亮铝对透明亚克力）→ 读成一条序列。改：加染色或换表面处理，缩到缩略图尺寸再验一次。
- **长影子和暖反射把金属拖成棕色** → 远处糊成一片。改：加冷轮廓光，底座永远比物件暗。
- **薄件的摩尔纹与透光条**（每层只有 2–3px；低角度看亚克力）→ 改：每件随机明度与偏移、粗糙度 ≥ 0.2 并加染色衰减，把出片分辨率提上去逐帧扫一遍。
- **贴在移动物件上的读数跑出画** → 改：把读数钳在一个安全框里，或等相机停稳再落。
- **生成图顶替真实物件** → 一眼假，还破了诚信底线。改：没素材就换一种更简单的件，绝不拿生成图当数据。
- **相机停死** → 画面退化成幻灯片。改：所有"静止"都留 2–5% 的缓移。
