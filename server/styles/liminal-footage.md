# 后室录像（liminal-footage）

> 一盘 1990 年代家用摄像机录下的第一人称带子：走进一个熟悉但不对、无限重复的空房间，恐惧来自守则和录像机自己。
> 参照（只学语法）：后室网络怪谈与新怪谈的「规则恐怖」、90 年代消费级 VHS 摄像素材。片子里不出现任何既有作品名、wiki 的「层级」编号、社区实体的名字、真实机构或 logo；屏幕上所有守则、表单、广播腔，以及「那个存在」，全部原创。

## 本质 / 不是什么

- 本质：**一台摄像机在走**——4:3、手持、一镜到底。人不在画面里，人就是镜头。
- 本质：**空间是重复的**，空、熟悉、差一点。办公室、酒店楼层、学校、商场、停车层、医院走廊。荧光灯在响，没有人。
- 本质：**恐惧来自空、重复、官僚守则，以及摄像机在错误的时刻坏掉**。没有东西追人。是后颈一凉，不是跳一下。
- 本质：**媒介就是叙述者**——对焦、曝光、磁带损伤和屏上 OSD 都在推动情节。
- 不是 `crt-vhs`：那条是「任何内容再套一层显像管物理模型」（弧面、扫描线、RGB 荧光点），问的是「你在一台旧电视前看」。这条**没有扫描线、没有荧光点阵**，伪影全部来自磁带和镜头：跟踪撕裂、白平衡漂移、对焦拉风箱。
- 不是 `glitch-digital`：那条是数字编码出错（块状错位、datamosh），是几帧的事件。这条的失真是一整盘带子的底子，连续、有惯性、跟着人的动作走。
- 不是恐怖片：没有怪物特写、没有血、没有跳吓、没有配乐里的刺音。不是废墟：**干净是风格的一部分**。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 4:3 竖黑边 | 1920×1080 里居中一块 4:3，两侧是黑的；黑边不动，画面在里面抖 | 档案、年代、私录 |
| 同一间房第二次出现 | 同一条走廊、同一块告示，只换掉一个细节 | 走不出去、重复 |
| 钉在墙上的打印守则 | 发黄纸、表单编号、修订号、编号条款、管理处落款一句客气话 | 规则、官僚、制度 |
| OSD 三件套 | REC 红点、电量格、日期与时间码 | 证据、不在场、倒计时 |
| 撕裂后的同一构图 | 时钟跳了、电量掉了、一盏灯灭了，别的没变 | 时间被拿走、丢失 |
| 对焦拉风箱 | 虚 → 锁死 → 滑开 → 再锁；虚焦是把焦点往近处拉 | 那里有东西 / 没有 |
| 灯闪 0.1 秒 | 一小段纯黑，曝光约 0.45 秒才追上，暗部噪声涌起来 | 不稳、坏掉 |
| 死灯区里的剪影 | 头小、脖子长、肩窄而高、手臂长，比人多错 15–40% | 那个存在、非人 |
| 唯一一个饱和色 | 红色警报灯 / 绿色安全出口 / 琥珀警示灯，只有它会晕开 | 信号、出口、警告 |
| 低头只看见鞋尖 | 画面下半是地面，只露鞋头，从不露腿 | 服从、回避、不敢看 |
| 一秒的数字零 | 声音全被抽走，屏幕下方 `[SILENCE]` | 屏息、最强的工具 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 三类信号各占一点最好：一个空间的（重复、空）、一个媒介的（OSD、撕裂、对焦）、一个文本的（守则）。三类齐了片子就成立；只有媒介那一类，立刻退化成 `crt-vhs` 的变体。
- 质感类信号最多一个，而且必须由情节触发，不许当底纹。

## 这个风格最俗的版本

- 画面：一路芥末黄的墙纸和湿地毯，全程剧烈抖动，结尾一张脸糊到镜头上；或者干脆套一层扫描线 + 洋红色差当「复古恐怖」。
- 声音：低频轰鸣铺底 + 一声尖叫 + 心跳。
- brief 的 style 一栏写明这支翻掉了哪几条，或者为什么刻意保留（用户要的就是经典版）。保留时把力气花在「空间重复」和「守则文本」上——那才是这条风格的骨头。

## 适配

- 用途：短片、伪纪录片段落、品牌片里的「档案段」、悬疑向的产品叙事。
- 内容：夜班 / 巡检 / 房屋带看 / 闭馆后的场馆 / 裁员后的办公室 / 凌晨四点的机场。凡是「按流程走一遍」的主题都合适。
- 时长：跟着走完一段路，20–90 秒最舒服。一旦没有新东西出错，恐惧就开始变薄——超过 90 秒必须有第二次「规则变了」。

## 技术路线

- 建幕建元素：`add_scene` / `add_element` 先搭 4:3 画框（居中，两侧黑），所有内容活在这块框里；OSD 与字幕单独一层，按这个框排版。
- 空间：`scene3d` 搭室内——轴对齐隔断、柱子、吊顶与嵌入灯板；路线手工排，填充靠复制模块。3D 按约 720×540 出图再放大，低分辨率能藏住 CG 的干净感；若 `scene3d` 不能单独设输出尺寸，用简化材质 + 后期软化等效。
- 画风落地：`set_theme` / `apply_style` 定主色、信号色、字幕样式；VHS 通道（行抖动、跟踪带、色度右拖、暗角、抬黑）用后期效果层做，**暗角与畸变不作用于 OSD**。
- 验收顺序：`preview_frames` 逐拍看静帧（构图、守则字是否可读、死灯区是否真的黑），`render_preview_clip` 看手持、风箱和灯闪的节奏。
- 素材：纸质守则、告示、表格可用 `upload_asset` 传自己的扫描件；拿不到就画，**不许用生成图冒充一份真的打印件**。

## 材质与渲染

- **帧与空间**：4:3 居中、两侧补黑边到 1920×1080；网格上的轴对齐隔断，随机缺口与残墙、柱子、等距嵌入灯板的吊顶。路线穿过程序化填充的空间，保证每道门后都是更多空。
- **照明 = 几千个灯，没有阴影**：每块灯板的颜色与强度存一张浮点纹理，逐像素累加最近的灯板（发射余弦 × 朗伯 / (d² + ε)）再加一次反弹项。没有遮挡，所以这光是平的。每灯几个百分点的暖 / 冷 / 绿偏差，几百分点坏灯，几百分点在闪。环境光遮蔽把接缝压深。
- **雾跟着局部光**：雾色 ×（局部光 / 平均光）。灯死的地方雾就黑，那里的剪影读作「光里的一个洞」。背景 = 雾 × 约 0.15，走廊尽头化进黑暗，绝不是一堵亮墙。
- **克制的旧**：墙脚水线痕、天花板下一条变色带、偶尔起皮的接缝、少量发黄或缺的板、散光板里的死虫。百分比全在个位数。
- **印刷品**：办公激光打印在发黄纸上，窄体无衬线标题、表单编号与修订号、编号守则、落款「管理处」。钉上或胶带贴上。
- **VHS 摄像机通道（不是 CRT）**：小幅行抖动（≤ 0.25px 的低频晃）、一条换头噪声带、按需的跟踪撕裂、桶形畸变 + 暗角（**不作用于 OSD**）、亮度模糊 + 边缘振铃、色度向右拖尾、轻微拖光、白平衡漂移、暗部 AGC 噪声、掉磁、抬起的黑位、软削顶。噪声按磁带帧率（30fps）。**没有扫描线，没有 RGB 荧光点阵。**
- **OSD**：手工点阵字加黑描边：REC 红点、电量、时间、日期。摄像机标题发生器用同一套字，字号更大。

## 字体

- **闭路字幕（CEA-608 风格）**：等宽约 42px，白字 + 每行一块实黑底，每行 ≤ 32 字符，在 4:3 框内居中、压在 OSD 之上。**不受磁带噪声影响**（电视机自己解码）——本工具里 `set_subtitles` 天生叠在成片之上，正好。中文按每行 ≤ 16 字换算；保持 ≥ max(1.8 秒, 语音 + 0.6 秒)。
- **说话人标记**：`[PA]` 给广播，斜体给操作员，SDH 描述放方括号里（`[LIGHTS FLICKER]`、`[TAPE NOISE]`、`[SILENCE]`）。
- **告示上的守则不配字幕**：它们就是画面。1080p 下要可读，且不被遮挡 ≥ 3–4 秒。拍特写时**把相机放低到镜头与纸面平行**；对着竖纸俯拍会把字剪切成假斜体。
- **标题**是摄像机标题发生器压在第一个镜头上的字（点阵字，更大号）。

## 运动

- **一条连续的手持长镜**。只在磁带断开处切：开机卷带、跟踪撕裂、REC 关。
- 手持 = 走路步态（头部起伏几厘米、左右摆、小幅滚转）+ 呼吸（约 0.27Hz）+ 几个频率的颤抖噪声，幅度跟着一条**恐惧**曲线走。屏息那一刻，**全部冻结**。低头只看见鞋尖和地面，永远不看见腿。
- 自动对焦 = 对焦距离带过冲地动：虚 → 锁 → 滑开 → 再锁。变焦收窄视场并开大光圈。
- 灯闪是约 0.1 秒的短黑；自动曝光迟约 0.45 秒才追上，增益噪声跟着泵。东西自己慢慢动（一扇门用 > 1 秒、缓动），**从不突跳**。
- 时间线按 24fps 或 30fps 都行，但噪声必须按帧固定种子、按磁带帧率落帧，不许每帧重掷。

## 画面怎么活

- 空间一直在「给更多」：每转一个角、每开一扇门，后面还是同样的空。重复本身就是动作。
- 每一拍加一次「不对」：一条守则被改了一个字、同一块告示换了位置、时间码跳了、灯少了一块。
- 恐惧曲线同时驱动三样东西：手抖的幅度、呼吸的频率、对焦开始漂的早晚。曲线平的时候画面几乎不动，只在呼吸。
- 背景永远不许亮。远景没有剪影的时候，也要让人盯着那里看很久。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 沿走廊走的第一人称 | 例行、无尽 | 建立空间；时间流逝 |
| 从细节缓慢摇开 | 尺度；空间还在继续 | 第一次看；揭示 |
| 低头看自己的脚 | 服从、回避 | 遵守一条规则；不敢看 |
| 蹲下，停在印刷文字上 | 阅读；官僚 | 一条守则；一处矛盾 |
| 变焦 + 对焦搜到远处 | 看见 / 看不见 | 一个存在；一个疑心 |
| 撕裂之后同样的构图，只有 OSD 变了 | 时间被拿走 | 跳跃；丢失 |
| 转过一个角，站住不动 | 一道门槛 | 出口；一个选择 |
| 无声地缓慢推近 | 被什么拉着 | 一扇门；一块牌 |
| 一边拍一边后退 | 退却、怕 | 离开房间；规则被破 |
| 把摄像机放在台面上，静止自录 | 遗弃 | 人不见了；漫长的等待 |
| 朝一个声音猛甩，然后什么都没有 | 期待落空 | 有响动，没有来源 |

取景：字要可读、不被遮挡；任何存在都要小、要远、要待在死灯区里。**转场只有磁带事件**，没有叠化、没有擦除。

## 声音调色板

- **没有配乐**。只有磁带本来会录到的声音。音乐只存在于世界之内（等待音乐、隔墙的收音机、劣质的 PA 小调），被滤波、带混响，还可能被磁带抖动拖慢。
- **荧光底噪**：120Hz（或 100Hz）+ 谐波，一条带通嗡嗡成分，一点镇流器啸叫，坏灯管爆音；和画面用同一条灯曲线门控；小房间里更近。
- **PA 人声**：平静、企业腔，通过天花喇叭（带通约 300–3500Hz、锥盆共振、饱和、房间混响），干到仍然听得清。广播前一段原创短提示音；时间跳跃之后，提示音和人声可以走音变平。
- **操作员**：几句短、轻的话，近讲低频与呼吸；呼吸速率跟着恐惧；一次屏息、一次长呼气。
- **拟音按材质**：地毯脚步（低闷响 + 湿的挤压）或硬地吱嘎、衣料摩擦、摄像机咔哒与马达、变焦伺服、对焦咔嗒、灯闪时的镇流器叮、黏滑的合页、头顶的拖拽、售货机、管道。
- **静音**：数字零，一秒以上（连尾音一起），字幕打 `[SILENCE]`，是最强的工具。最多一次轻惊吓：声音回来时所有东西同时重新起音。
- **低频底噪三个选项**：一段低棕噪带 + 慢慢升起的拍频正弦；房间底噪自己移调；或者什么都没有。**混音**：底噪与画内音乐比人声低约 8dB；整体 −14 LUFS；**不加颗粒**——噪声在画面里，不在声音里。本工具用 `add_audio` 分层，PA 与操作员用 `tts_narration` 念完再过带通与混响。

## 原生手法

- **对焦 / 曝光搜捕**：东西只在焦点对上的那几帧里存在。适合：酒店楼层上走失的宠物、空球场里的一个人影、走廊尽头的形状。
- **磁带跟踪损伤**：一次撕裂就是宇宙做的一次剪辑；之后构图一样，但钟跳了、电量掉了、一盏灯灭了。适合：夜班日志、商场里丢失的一个周末、两盘带子之间变老的房子。
- **OSD 即情节**：REC、电量、日期、时间码是证据。适合：不在场证明、倒计时、一次有日期的巡检。
- **守则当画面里的文字**：告示和广播先是正常的，慢慢变味、互相矛盾，最后开始对着观众说话。适合：泳池安全须知、学校消防演练、闭馆后的美术馆。
- **空与重复**：同一块告示出现在另一个地方；同一个房间少了一个细节；一条走廊通向雾。适合：搬家前的看房、凌晨四点的机场、裁员后的办公室。
- **几乎是人形的东西**：远处一个剪影，比例错 15–40%（小头、长脖、窄高的肩、长臂），用有机曲线画在一块广告牌上，慢慢移动。适合：不是假人的假人、夜班保安、慢半拍的倒影。
- **屏息冻结**：所有手持噪声瞬间归零，只剩荧光底噪。适合：听到了什么的那一刻。

## 变化空间

你决定：地点与它的材质、拍摄的程序或理由、守则、路线、那个存在（或者没有）、信号色、开场、结尾、长度。

- **结构**：两盘带子（同一条路一年后重拍，第二盘找到变化）；一次房产带看（每个房间都被兴高采烈地介绍，房子却在不断加房间）；一条清单逐条念出、边念边在画面里打勾，直到出现一条不在清单上的。
- **开场**：话说到一半（带子启动时人已经在讲，卷带还在滚）；一段测试卡加日期板，然后才拿起摄像机；镜头盖没摘，只有声音，直到盖子拿掉。
- **结尾**：电量耗尽（图标闪，画面停在最后那格）；摄像机被放下，继续录一个空房间；带子绕回第一个镜头，只是这一次画面里有操作员的鞋。

## 坑

- **全亮的场景读起来像医院走廊** → 隔断留缺口，远处压黑。
- **光会穿墙**（没有遮挡）→ 一个死区需要它周围约 ±5 米内每一盏灯都死，而且它背后的空间也要暗。
- **走廊尽头露出一个亮矩形**、**均匀的雾把剪影抬成灰** → 背景 = 雾 × 约 0.15，而且雾必须跟着局部光走。
- **行抖动把字扭斜、俯拍把字变斜体、字幕被磁带噪声啃掉** → 抖动 ≤ 0.25px；把相机放低到与纸面平行；字幕永远在 VHS 层之上单独解算。
- **用基础几何体拼的人像玩具、腿像管子** → 用有机曲线画剪影；只露鞋尖。
- **纯红在低自发光下（亮度低）永远不泛光** → 把它推得远高于阈值。
- **用滤波前的峰值去归一化滤波后的信号会顶爆总线** → 归一化处理后的信号。
