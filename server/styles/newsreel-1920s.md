# 1920 年代新闻片（newsreel-1920s）

> 真实档案投在放映窗里：银盐单色调、走片抖动、地点卡与字幕条承接叙述，一支铜管乐队把所有切点咬在拍上。
> 参照（只学语法）：Fox Movietone News、Universal Newspaper Newsreel（1927–1930 年代）的片头仪式、旁白腔、"一地一事"、末条之后那一记收尾；Pathé News 的条目标题卡；好莱坞"旋转报纸"蒙太奇；1920 年代热舞乐队（Charleston 节奏、班卓、大号）。不照搬任何真实新闻片的名称、台标、地球图案、字体和号角旋律。

## 本质 / 不是什么

- 本质：**一种剪辑风格**——好看在"真实素材如何被编排、切分、加字、被声音抬起来"，不在画法。**档案在放映窗里**：1.37:1、满高、圆角、窗外纯黑，窗内所有东西共用一套银盐分级、同一次走片抖动、同一层划痕灰尘。
- 本质：**新闻物件负责解释**——报纸、杂志页、书、电报、地图、唱片，它们是被"拍"的（转、砸、摇、翻、划线），不是排成幻灯片；而且**永远有个声音在讲**，音乐是乐队，乐队还参与剪辑（切点落拍、急停让一句话落地）。
- 不是**橡皮管动画 / 默片喜剧**（`rubber-hose`）：那种是画出来的、在丝绒幕布之间放映、用对白卡代替人声、有钢琴师没有拟音。这里除包装外全是真的，素材和拷贝是真的，永远有人说话，声音是铜管、班卓和唱片，字卡是新闻卡片（地点 · 日期）不是台词卡，也没有幕布和剧场。
- 不是**年代媒介混搭**（`mixed-media-era`）：那条把多个年代的媒介拼在一支片里、靠"换媒介"推进；这里**全片只有一种媒介——胶片**，变的是素材的编排。
- 不是**复古电视 / VHS**（`crt-vhs`）：那条是 80 年代磁带信号叠在内容之上；这里是光学声轨、放映机片门和 1920 年代乐队，没有扫描线、色差、OSD。也不是带"复古滤镜"的纪录片：没有访谈头、没有缓慢的 Ken Burns 漂移、没有现代下三分之一条。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 放映窗 | 1480×1080 的圆角窗（1.37:1），窗外纯黑，画面只活在窗里 | 任何档案题材 |
| 银盐单色 | 暖银灰、黑位 14、白位 238，没有第二个颜色 | 年代、纪实 |
| 走片抖动与划痕 | 画面 ±1.6px 横 / ±2.2px 竖地游移，1–3 条竖划痕各活 9 帧 | 放映、旧拷贝 |
| 地点卡 | 左上角暗底奶油细框，"PLACE · DATE"压在中文一行上 | 换地点、换年份 |
| 旋转报纸 | 边转边长大砸满画面，砸下时一顿 | 头条、公告、发布会 |
| 新闻片自己的转场 | 虹膜收圈、带 6px 亮边的斜划、百叶、钟面划、翻页 | 段落之间 |
| 蜡笔圈证物 | 定格 + 一顿，手绘圈套住那个细节，再加箭头 | 证据、"看这里" |
| 乐队急停 | 一刀切死，只剩放映机，一句短话 | 每条故事的最后一击 |
| 地图铺开 | 虚线航迹按拍画出去，到达处星点脉冲，角上滚年份 | 风潮、迁徙、扩张 |
| 78 转唱片 | 角落一张唱片转起来，落针噪声先到，压住乐队 | 让"真的那个年代"说话 |
| 底部字幕条 | 180px 暗条横贯窗底，上缘透明，下缘 93–96% 的 `#0a0908` | 所有镜头 |

规则：每支挑 2–3 个，至少一个不在下面「最俗的版本」里；信号从主题里选，不按顺序全上。放映窗 + 银盐 + 地点卡是最低配置；转场各用一次当标点，用两次就成模板。

## 这个风格最俗的版本

- 画面：全片棕褐滤镜（sepia）、四角压暗、边缘烧焦，一张报纸旋转入场，老式衬线体字幕抖动，最后"THE END"。
- 声音：一段循环爵士钢琴 + 打字机声，从头铺到尾，没有一处留白。
- 正确做法：银是**冷的暖银**不是棕褐，"旧"来自分级、走片和划痕，不来自滤镜；brief 的 style 一栏写明翻掉了哪几条，或为什么刻意保留。保留时把力气花在**地点卡的节奏**和**乐队急停**上。

## 适配

- 用途：讲"以前"的宣传片、品牌周年、城市与机构史、产品考古、展览导览。
- 内容：必须有真实档案可用——老照片、旧报纸、老影像、老地图、老唱片。**没有真档案就不要选这条**，它是编排风格，编不出素材。
- 时长：25–75 秒最舒服；一条故事 6–12 秒，全片 3–6 条。超过 90 秒要有一次条目标题卡换段落。语气轻快逗趣；灾难与死亡题材不能用这套语法。

## 技术路线

- 建一个 1920×1080 的幕：`add_scene` 铺纯黑底，`add_element` 放 1480×1080、圆角 26px 的**窗**（裁剪容器）。所有画面元素只许进窗，**任何元素都不许画到窗外**。
- 素材 `upload_asset` 进来作为窗内图层；`apply_style` / `set_theme` 定基础银盐档位（灰度 + 对比拉伸 + 微 S）。本工具没有逐帧 LUT 管线，档位一次定好整段共用，逐帧自动色阶会让画面一泵一泵地呼吸。
- 窗内两层分离：**画面层**（影像、印刷品、地图、卡片）吃全部胶片质感；**字层**（地点卡、标签、字幕、唱片小窗）保持锐利稳定；蜡笔标记属于画面层，跟着抖。
- 胶片抖动、划痕、灰尘本工具做不精准：用元素层的**随机位移（±1.6px 横 / ±2.2px 竖，低频噪声）+ 一条固定种子的颗粒层**近似；划痕画成 1px 竖线，每 9 帧换位、同时 0–3 条；灰尘 0–4 个、只活 1 帧。
- 分级参数（写进风格设定，全片共用）：灰度 → 百分位拉伸（0.6% → 黑、99.6% → 白；印刷品用 0.2–0.3% / 99.0–99.7%，黑位抬到 26–30，像新闻纸）→ 轻 S 曲线 `x + 0.18·(x−0.5)·(1−|2x−1|)` → 输出 14–238。**一段影像只用一组档位**（跨全段取样定档），绝不逐帧。
- 投影感：暖银叠色（正片叠底 `#efe7d6`、滤色 `#17140f`）、暗角 0.42H 收到 0.95H、闪烁 ±3.5%/帧 叠 3Hz 漂移、走片 ±1.6px 横 / ±2.2px 竖。
- 老素材放大上限约 **2.5×**；NTSC 转换（720×480）当 4:3，裁到 1.37 再放到 1480×1080（≈2.31×）。播放按 24fps 定帧取整，保证渲染可复现。印刷品按扫描原分辨率用，**裁到需要的那个折面**。只允许代码画**包装**：片头（放射光、两道探照灯、线框地球）、条目标题卡、地图、片尾卡。**永远不要生成"档案画面"**。
- 验收：`preview_frames` 当缩略图逐拍看明暗与构图，`render_preview_clip` 看动与切点。素材来路：先问用户有没有自己的档案；否则用公有领域源（美国 1931 年前出版物、NARA 联邦作品、Commons 的 PD/CC0、1926 年前美国录音自 2026 年起进入公有领域、Natural Earth 地图轮廓）。"No known restrictions" 不够用；不要搬运版、上色版、"AI 修复"版。用前读完片目说明——说明里可能写着镜头里到底在发生什么。

## 材质与渲染

- **窗**：1480 × 1080 嵌在 1920 × 1080 里（1.37:1），圆角 26px，窗外纯黑。画幅不可改，不改宽银幕。
- **画面层**：暖银单色。暗角 0.42H → 0.95H；闪烁每帧 ±3.5% 叠 3Hz 慢漂；走片 ±1.6px / ±2.2px（值噪声，不是白噪声）；竖划痕 0–3 条、各活 9 帧；灰尘 0–4 粒、只活 1 帧。**颗粒只加一次**，加在成片上（约 24fps / 强度 7 的量级），不在页面里再画一遍。
- **印刷品**：扫描原分辨率、裁折面、黑位轻抬 26–30；纸上的油墨比影像更"实"。
- **字层**：不抖、不闪、不吃暗角，永远比画面干净一档；蜡笔是略偏暖的白，笔迹粗细微变，跟着画面抖。
- **包装银**：Art Deco 渐变字 `#fff → #d9d4ca | #9e978a → #efebe2`，中间一道**硬**的金属断口，外加 0.12em 黑描边。
- **边缘**：窗内硬切到黑、不羽化；虹膜/圈入留下的透明角要垫黑，否则叠色后发灰。

- 地点卡（段落标题，不要每条故事都上满屏卡）：窗内左上（窗 x + 48，y 56），暗底 + 内缩 2px 奶油细框，英文 "PLACE · DATE" 压一行中文；**0.22 秒从左往右抽出**，离场前 **0.15 秒淡出**；读完起停留 ≥ 中文÷4.5 + 拉丁÷15 + 1.5 秒，所以两行都要短。分屏里的标签每格一个、顶部居中、同一套暗盒、**相隔一拍**入场。
- 条目标题卡：全片最多一次（用来翻到新故事）。黑底，双线 Art Deco 框在 **0.35 秒**画出、四角四分之一扇形，Limelight 行 + 中文行，缓慢推近，**≥ 2.5 秒**。
- 字幕条：横贯窗底的 180px 暗条，上缘透明、下缘约 93–96% 的 `#0a0908`，**每个镜头都开**；一段字幕开始前 **0.25 秒**淡入，1 秒以内的空隙不消失，免得闪。字幕中文一行压英文一行，**每种语言一行、永不换行**；每条 `max(1.8 秒, 语音 + 0.6 秒)`，提前 50ms 结束。画面上已有的印刷字**不重打成字幕**，用蜡笔划线指过去。

## 运动

- **乐队就是时钟**：热舞速度 **190–220 BPM**；每个切、落板、砸下、标签入场都咬在拍上，多数切在小节线；插入镜头落在第 3 拍或 Charleston 重音（第 1 拍和"2 的 and"）。放 78 转唱片时切在**唱片自己的拍**上（先量出来），不跟网格。
- 一条故事 = 一个地点 + 一种材料 + 一句旁白。故事越来越短（2–3 小节 → 1 小节 → 按拍），最后一次长按。
- 镜头长度：影像 1–2.5 秒；印刷品与文件 2.5–4 秒（要读得完）；对比在裁决前**完整在框 ≥ 2.5 秒**；**任何静态画面不超过约 1 秒**而没有东西在动（推、摇、铅笔、计数器闪）。
- 缓动：推近用 `u^a(1−u)^b` 一类，速度不突变；旋转报纸按 `u^2.3` 长大、转角按 `(1−u)^1.25` 衰减、共 2.5 圈。砸下的垂直顿是阻尼正弦 **16px**、砸下时 **3%** 回弹；片头头 **0.2 秒**探照灯带一次闪打亮。
- 转场只用新闻片自己的：虹膜收/开、斜向硬划（带 **6px** 亮边）、竖轴翻、百叶（**12 片**转）、12 点钟起转的钟面划、旋转报纸、翻页、面板推挤、定格。**每条只用一次**。故事之间不许叠化，不许现代甩镜，不许推拉模糊。L 切：旁白可压过切点 **0.3–0.5 秒**；新的音乐状态可比画面早一拍进入（J 切）。

## 画面怎么活

窗里永远有东西在动，即使"静止"：
- **走片**：整个画面在 ±1.6px / ±2.2px 内游移，慢、不规律，像片门在磨。
- **闪烁与划痕**：亮度每帧 ±3.5%（叠 3Hz 漂移）；1–3 条竖划痕每 9 帧换位；0–4 粒灰尘一闪即灭。
- **蜡笔的呼吸**：已在纸上的圈和线有极小的粗细抖动；正在画的那一笔尖端略亮。**角落的小循环**：地图角的年份滚一格、唱片转过 1/8 圈、地点卡细框上一道极淡的反光扫过。幅度都必须小——**动的是胶片本身，不是内容**；内容一晃，就变成特效片。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 旋转砸下 | 报纸"到来"，新闻感 | 头条、电报、海报 |
| 缓慢推近 + 落拍打特写 | 从整页到那个细节 | 头条 → 版内那张照片 |
| 横摇过宽幅印刷品 | 人群、游行、天际线 | 全景、合影 |
| 抬起露出后方 | 主角背后那个地标 | 建筑、纪念碑 |
| 地图推进 | 从国家到一个城市，直接进下一条 | 旅行、扩张、风潮 |
| 网格发牌 | 多张相关静图一拍一张落下 | 步骤、收藏、"全都在做" |
| 翻页书 | 一串静图按拍播放就变成运动 | 舞步、装配阶段、前后对比 |
| 定格 + 一顿 | 把档案停在"说明问题"那一帧 | 包袱、证据 |
| 分屏 / 四格 | 两三个地方同时在场 | 对比、阵营 |

影像**不加超过约 6% 的假运镜**（它本来就有自己的镜头）；静图则必须有目的的动。

## 声音调色板

- **旁白**：明亮、有劲的男声，两种音色混合（约 0.6 : 0.4）得到大西洋中游口音；语速 ≈ 1.15–1.2；每句 6–12 个词，多用感叹与反问。做 1930 年光学声轨处理：高通 260Hz、低通 3.7kHz、1.5–2.3kHz 提 +4dB（喇叭箱的"存在感"）、tanh 驱动 2.0、压缩 4:1、**wow 0.22% @ 0.55Hz + flutter 0.07% @ 6.3Hz**、两处短墙面反射（31ms、67ms）。干净音上查一遍语音，成片再查一遍。
- **乐队与对立音乐**：大号踩 1、3；班卓每小节四下（重音在 2、4）；长号吹 Charleston 音型（第 1 拍和"2 的 and"）；军鼓打背拍；酒吧钢琴右手；小号先弱音后开声，单簧管低六度跟；木鱼做 pickup。片头是铜管 + 定音鼓的号角；包袱处**一刀切死 + 一记重音**；收尾用"哒—哒！"两下。故事有两面时给对面一支自己的乐队（民谣提琴、拨弦扬琴、立式钢琴、大号），在分屏里你一小节我一小节地换、再换半小节，声像分左/右。
- **档案唱片**：公有领域的 78 转可以拿下整条声轨当"真的那个年代"——落针（咔哒 + 表面噪声）、带通 110–6500Hz、只在针压着时有噼啪与转动隆隆、变速 ≤ 2% 去贴片子的速度；结束在它自己的最后一个和弦，然后抬针。
- **拟音与底噪**：碳弧灯啪、旋转报纸的上扬呼啸 + 抖动、闷响 + 纸拍、地图线下的电报嗒嗒、每张静图一次快门、翻页书每页一声纸弹、百叶片颤、翻页、蜡笔吱、软铅划；放映机（24Hz 爪式咔哒 + 电机嗡 + 光学嘶声）从第一帧铺到最后帧。
- **混音**：乐队与唱片在人声下让 4–5dB（人声高出音乐约 12dB）；乐队带限 95–7500Hz + 低频搁架 + 轻饱和；两处留白（转折前的急停、收尾一击前只剩放映机）；整体 −14 LUFS。

## 原生手法

- **片头仪式**：头 0.2 秒探照灯带闪打亮 → 地球长大并转 → 名字带过冲落定 → 虹膜收在地球上。适合任何"新闻形状"的开场，收尾复现一次就成了落版。
- **旋转报纸**：2.5 圈、三份 18ms 的残影当动态模糊、砸下时 16px 垂直顿 + 3% 回弹，下一拍立刻推近并打特写。
- **地图铺开**：虚线航迹按拍从出发城市画出去，到达处星点脉冲，标签放在屏幕空间，角落一个年份里程表；结束时推进下一条的城市。
- **发牌 → 翻页书**：静图一拍一张落下（每张一声快门），然后镜头扎进第一格，整串按拍变成定格动画。
- **证据处理**：砸下书或信、翻页、推到那一段，用软铅在字上划线（位置跟着扫描件的字走）；或者定格、顿一下、手绘圈套住细节再加箭头。
- **分屏对决 → 推走**：两格滑入、各带标签、各带自己的音乐在对位；赢的那格把输的挤出画。
- **落针 → 急停 → 一句**：乐队一刀切死，角落唱片转起来，78 转在档案下面唱，定格时收在它自己的和弦上；或者干脆一记重音、只剩放映机、旁白说一句短的。任何一条故事的最后一个字都该这么落。

## 变化空间

- **年代**：晚期默片（不说话，全靠字卡）↔ 早期有声（本风格）↔ 1940 年代战时新闻片（更低的嗓音、带箭头的地图、进行曲）。
- **语气**：滑稽收尾（本风格默认）↔ 严肃报道（不抖机灵但仍然快）——灾难与死亡题材换掉这套轻快语法。
- **材料与音乐**：全影像；或影像稀缺时以印刷品为主（地图、书页、翻页书承担运动）。配乐可用 Charleston 乐队、进行曲队、摇摆大乐队，或让一张 78 转唱片扛整段。
- **包装与结构**：自己发明片头名字和徽记，语法（探照灯、地球、号角、地点卡）保留、形状全换。结构可走三条消息递进、一条消息越查越深、或同一地点跨十年。

## 坑

- **不读片目说明**：一段野餐片里可能既有老式舞也有 Charleston；只用和你的说法对得上的镜头。
- **档案头尾没切干净**：拷贝开头结尾常有场记板、"End of Recording"和白闪，要切进里面；水印与档案馆台标要抹掉。
- **报纸页上有无关甚至冒犯的旧闻**：裁到你需要的折面。
- **逐帧自动色阶**：画面会一泵一泵地呼吸；一段影像只用一组档位（跨全段取样）。
- **虹膜留下透明角**：叠色后会发灰；先在窗框后面垫纯黑。
- **字卡淡出早于读完 / 旁白跑赢字幕**：缩短文字，不要缩短停留（中文÷4.5 + 拉丁÷15 + 1.5 秒起算）；每行 6–12 个英文词，中文 ≤ 23 字。
- **TTS 念错人名**（Bessie 念成"Bestie"）：改写措辞，直到语音检查通过。
- **老素材本来就软**：放大不超过 2.5×，宁可取景宽一点也不要硬裁。
- **颗粒加两遍 / 字层跟着抖**：颗粒只属于成片那一道；字幕、地点卡一旦抖就成了假复古，抖只属于画面层。
