# 爆炸图拆解（exploded-teardown）

> 一个真实的产品被当作影棚静物拍下来，在一次环绕里逐层拆开、标上真实的数字，再合拢回一个整体。
> 参照（只学语法）：硬件发布会的爆炸图影片（层的错拍、环绕的时机）、维修指南的拆机（打开的顺序、关键零件的那记微距）、工程制图（引线、尺寸线）。不照搬它们的产品、构图、字体和音乐，也不在片子里点名。

## 本质 / 不是什么

- 本质：**物体是真的、准的**——几何、位置、数量来自产品自己的图纸与物料表。文件能给的东西，一律不靠眼估。
- 本质：**它是被拆开给你看的**——各层沿**一个轴**浮起，间隙均匀、读得清，每一层仍保持它在产品里的朝向。
- 本质：**它是被拍摄的，不是被画的**——物理材质、一盏影棚主光、一道冷轮廓光、HDRI 反射、隐形地面上的一层软接触阴影。
- 本质：**数字长在物体上**——从零件上一个点拉出的细引线，带刻度的尺寸线，画在场景自己的透视里，绝不在旁边摆一张表。
- 本质：**相机一直在走**——一次或几次连续运动，外面环绕，里面微距，中间没有翻页。
- 不是**玻璃材质渲染**（一个物体、材质本身当主角、不拆）；不是**蓝图**（网格上的线稿、没有光）；不是 keynote（幻灯片、大标题、舞台）；不是装配手册（步骤号、箭头、一双手）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 沿一个轴浮起的层 | 均匀间隙、朝向不变、整摞像被撑开的书 | 内部结构、模块划分 |
| 引线落在零件上 | 起点是一个点，末端是那颗芯片/那个密封圈 | 传感器、主控、关键件 |
| 透视里的尺寸线 | 带刻度、跟着面的角度、文字永不倒过来 | 厚度、间距、口径、尺寸 |
| 双层编号标签 | 强调色两位序号 + 名字 + 一行规格 | 规格、参数、清单 |
| 板是"印"出来的 | 铜箔、走线、过孔、焊盘、丝印，双面都画 | 电路、算力、控制 |
| 影棚光 + 石墨背景 | 暖主光在上前方，背后一道冷轮廓光把边从地面分出来 | 一切产品 |
| 相机钻进层间 | 从两层之间穿过去看背面 | 隐藏面、内部通道 |
| 零件做一次真实动作 | 按键走完行程、铰链开合、卡扣弹开，只做一次 | 手感、机构、机关 |
| 拆开时里面的灯亮起 | 状态灯、背光屏、指示环在被拆开的状态下点亮 | 通电、激活、状态 |
| 合拢后现场量外形 | 关成一体，尺寸线才落到真实轮廓上 | 结论、规格背书 |
| 重复件的波浪升起 | 按键、电芯、螺钉按到某个角的距离依次跳起 | 数量、阵列、可扩展 |
| 静默之后的那一声 | 两处只剩房间底噪，然后一记拆开的闷响 | 转折、进入内部 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 尺寸线、橙色引线、编号标签这三样最好认，也最快被用滥——第二支片子换一组信号。
- 拿不到文件时，只按**公开尺寸**建模（数据表、规格页），并在画面或旁白里说明「这是模型」，**一个说不出来源的数字都不许标**。绝不用生成图冒充真实零件。

## 这个风格最俗的版本

- 画面：一个手机/相机模型从中间"炸"开成一排零件，每件旁边一个白字英文标签、橙色引线，最后转回原位；背景全黑，一记低频 riser 顶上来。
- 声音：低频 riser + 一记 whoosh + 电子 tick 打点。
- brief 的 style 一栏写明这支片子翻掉了哪几条，或者为什么刻意保留；保留时把力气花在**真实的零件关系**和**那一次环绕**上。

## 适配

- 用途：产品内部结构片、硬件发布、维修与拆解科普、原理讲解（比如"AI 由哪几部分组成"）。
- 内容：有真实零件、真实数字、需要"看见里面"的主题。抽象概念要先被做成有零件的东西，否则拆不出东西来。
- 时长：20–60 秒最舒服。一个环绕 + 两个停留点是最稳的结构；超过 90 秒就拆成两段，各给一次完整的拆开与合拢。

## 技术路线

- 3D 主体：`add_scene type="scene3d"`，用 graph 逐节点搭。**每一层是一个 group 枢轴**，零件挂在它下面，拆开只动枢轴，不动零件本身——这样朝向永远不会歪。
- 几何体只有组合件：box / cylinder / cone / sphere / torus / plane / capsule / ring / dashRing / icosahedron 一族。**CAD 文件在本工具里读不进来**：按公开的真实毫米尺寸在 scene3d 里建模，或先在外部转成 mesh/贴图再 `upload_asset` 当参考与板面。
- 相机：`camera` 的 position / target / fov + 关键帧（posX/Y/Z、rotY…），或 `orbit.degPerSec` 做匀速环绕。关键帧单调插值，**不过冲**。
- 灯光：`lights` 里 ambient 抬到 1.2–2.0（否则金属发黑）+ 一盏暖 directional 主光 + 一盏跟着相机走的冷补光当轮廓。
- 后期：`post` 的 bloom 只喂发光件（threshold 抬到最亮漫反射面之上）、tonemap aces、vignette 0.3–0.4。
- 背景：`world` 用 gradient，上 `#34363A` 下 `#0D0E10`，haze 压很低；`worldPreset` 可选 `warehouse`，但纯净无缝更符合这个风格。
- 地面：`ground.mode "shadow"`，只接阴影（0.55–0.7），别铺一块看得见的板。
- 景深：本工具不给景深开关。用**把相机贴到零件上**、让前景层吃掉半张画面来造"在里面"。
- 标注：引线、尺寸线、编号标签画在 2D 覆盖层（`add_element`），用 `preview_frames` 逐帧对锚点；**相机还在动的段落不要挂标注**，等停稳再落。
- 验收顺序：`preview_frames` 逐拍看静帧 → `render_preview_clip` 看动。色与字先 `set_theme` / `apply_style` 定死，再手调标注层。
- 素材：`upload_asset` 传真实板面/纹理。材质只有一个贴图槽，**没有法线贴图**，凸起靠贴图上的明暗画。
## 材质与渲染

- 材质：塑料 roughness 0.55–0.7（软高光）；机加工金属 metalness 0.9+ 且 envMapIntensity 抬到 1.4–2.0，高光要收紧；橡胶哑光；灯罩/亚克力用 physical（transmission、ior）而不是靠透明度硬凑。
- **板是照着布线画的**：板面贴图按 14–20 px/mm 画，铜箔、走线、过孔、焊盘、钻孔、丝印，正反各一张；走线在阻焊下是更亮的浅浮雕（无法线贴图，就画在贴图里）。元件按封装尺寸和焊盘位置立起来。
- 光：暖主光从上前方来；背后一道冷的矩形轮廓光，**跟着相机走**，让边缘始终与地面分开；一盏柔顶光；低强度 HDRI 只做反射；只有相机钻进去的地方才补一盏。
- 背景：石墨色无缝渐变（上 `#34363A` 下 `#0D0E10`），地面只以一层软阴影存在。黑塑料贴黑底会糊成一块——抬到深灰，交给轮廓光去分边。出片给足分辨率（1080p 起，要贴脸看零件就 4K），不要靠缩略图放大。
- 世界坐标里的效果（引线、尺寸、发光）按 3D 点定位；只有字幕和标题卡活在屏幕空间。
- 项目里留一份 FACTS.md：每条数字写清来源（URL、原文引用，或从图纸量出来的方法），随片交付。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 地面/背景 | `#34363A` → `#0D0E10` | 石墨无缝，永远最暗 |
| 产品 | 它自带的颜色 | 画面里最亮、最饱和的那一块 |
| 墨 | `#F1EFE9` | 名字、主句（满强度） |
| 规格 | `#9A958C` | 参数行（约 60%） |
| 强调 | `#FF6B3D` | 只给被量出来的东西：尺寸线、标签序号、产品上与之呼应的那一个细节 |
| 冷灰 | `#8E939B` | 轮廓光、结构线、次级信息 |

值是有顺序的：**地面最暗 < 产品居中到亮 < 标签最亮**。又亮又花的面不许直接压字，先垫一块暗底。强调色一帧不超过三处。

## 字体

- 名字：干净无衬线、中等字重，28–32px（中文思源黑体 500 / `Microsoft YaHei` 500）；拉丁用 `Inter Tight` / `Inter`。
- 规格与数字：等宽 15–22px（`JetBrains Mono`，没有就 monospace 兜底），位数对齐——数字要读起来像"量出来的"。
- 标签结构固定三段：**强调色两位序号 + 名字 + 一行规格**。单位永远写出来（mm、MB、计数写 ×n）。
- 一个标签最多带一条旁白没说的信息。多一条，观众就不看物体了。
- 尺寸文字放在一块小暗底板上，跟着线的角度走，**永不倒过来**。
- 字幕：底部居中的一条，软阴影、无框；双语时本片语言在上。阅读时间：每条字幕 ≥ max(1.8 秒, 语音 + 0.6 秒)；标签完整入画 ≥ CJK÷4.5 + 其他÷15 + 1.5 秒。

## 运动

- 24fps 逐帧，一切平滑、确定、可复现。
- **拆开**：慢起、中段快、长停（ease-in-out 三次方）；层从最上面开始走，彼此**错拍 0.15–0.2 秒**；重复件（按键、螺钉）按"到一个角的距离"排序，波浪式散开。
- **合拢**：从下往上，更快（每层约 1 秒）；最后一层落地要有真实的机械回应——按键走完行程再回位；**不是橡胶就不许弹**。
- 保持在拆开状态时：层可以浮动 1–2 毫米、相位错开；**微距段完全静止**。
- 标注：锚点先出现 → 引线生长 → 文字滑入 10px；零件再动之前，标注先淡出。
- 永不移动：地面、灯组与相机的关系、标签那一栏的 x 位置。相机的关键帧单调（monotone cubic），不许过冲——一个"停住的微距"必须真的停住。

## 画面怎么活

- 这个风格不靠"动"活，靠**揭示的顺序**活：每一拍多露一层，每一层都带来一个新的空间关系（谁压在谁上面、谁给谁让位）。
- 保持段的活，只放在缝里：层间 1–2mm 的错相浮动；发光件的呼吸；还没画完的引线。
- 微距段必须完全静止——静是这种风格的语法，不是失误。
- 背景允许极慢的渐变漂移（幅度 ≤ 2%），只为不让画面"死"。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 拆层的同时环绕 | 整体，以及它的装配顺序 | 揭示、结构总览 |
| 掠过的微距推轨 | 触摸感、材质、工艺 | 开场、质感 |
| 钻进层与层之间 | 你在里面 | 隐藏的元件、它怎么工作 |
| 对一个静止零件慢推 | 重要的就是这一个 | 芯片、传感器、密封圈 |
| 穿过叠层上升 | 从一个子系统到下一个 | 段落之间的过渡 |
| 快速后拉 | 回归、收束 | 结尾、前后对比 |
| 高位三刻钟漂移 | 尺度与精度 | 尺寸、间距、厚度 |

取景：关键那一刻主体至少占画面高度的 1/3。标签住在空的那一侧——**用视口偏移挪投影，不要挪物体**。字幕占底部 12%。
转场就是相机从物体里穿过去；**不切黑、不滑页、不分屏**。

## 声音调色板

- 乐器：调音木槌（马林巴、颤音琴、钟琴、玻璃）、圆润的贝斯、短促的合成底鼓、小小的干打击。物体外部精确干爽，内部持续空灵。
- 拟音就是材质本身：键帽与外壳的中空塑料咔哒、开关的 click 加一记低频 thock、板子的干敲、小机加工件的不谐和余音、外壳的闷响、层浮起与相机俯冲的气声 whoosh、尺寸线画出的细笔沙沙、每个标签一记极小的 tick。
- 每一次分离、每一次落地都有声音，**声像按零件在画面里的位置摆**。
- 静默：至少两处近乎无声（只留房间底噪），放在大拆解或回身之前；之后的第一声是那一带最重要的撞击。
- 混音：人声清楚地在最上（说话时音乐压到约 −10dB），音乐总线 ducking，次低频收干净（20–60Hz 远低于全频段），整体 −14 LUFS。人声本身：平静、贴近、不赶；短句；数字念成词，写成数字。

## 原生手法

- **波浪式升起**：重复件从一个角开始依次跳起。适合电池电芯、太阳能瓦、模块化柜格。
- **钻进缝隙**：相机进到两层之间看隐藏面。适合主板背面、无人机机臂内侧、传感器模组底面。
- **落在零件上的引线**：微距标签的线端正好收在元件上。适合鞋里的压力传感器、防水壳的密封圈、电机驱动。
- **画在实物上的尺寸**：合拢后，真实轮廓才被加上透视尺寸线。适合笔记本上盖厚度、路由器占地、阀门内径。
- **一次真实动作**：一个零件把它的真实机械动作做一次（按压、开合、卡扣）。适合快门、表扣、折叠铰链。
- **里面的灯亮起**：拆开状态下，内部发光件点亮。适合状态灯、背光屏、指示环。

## 变化空间

- 每支由 agent 决定：哪个产品哪个版本、拆哪几层与什么顺序、里面几个停留点、哪几个零件值得停、相机路线、从整体开还是从细节开、产品自身配色与强调色、人声。
- **三种结构**：一个环绕带两个停留点；沿一条信号/流向穿过各层的"它怎么工作"；两个版本并排拆开，各自先停住，再指出差别。
- **三种开场**：微距里一个零件做它的真实动作；合着的产品在无声里缓缓转；一个零件单独浮着，其余产品在它周围组装起来。
- **三种结尾**：合拢后在外形上画尺寸；合拢成一个俯视，慢慢变成一张技术图；最后一次拆开、冻住，每个零件都标好，像一张可打印的图。

## 坑

- **编造的尺寸** → 观众一查就崩。改：从公开图纸量并注明"实测"，量不出来就不标。
- **版本混用** → 孔位对不上、叠高不齐。改：跨文件核对孔位与叠层高度，把版本锁死。
- **拼板（panelised）的板** → 布局文件里是带断点的拼板，不是单片。改：用同版本的外壳或中框取外形，或从内部点做泛洪填充。
- **零长度边** → 重复的外轮廓点给出零法线，辉光后炸成黑方块。改：清理轮廓、修零法线、逐帧扫一遍有没有一帧黑块。
- **相机样条过冲** → 关键帧间距不匀时会冲过微距停留点。改：逐段单调插值，一个停留点一组键。
- **标签太短** → 微距停留本来只有约 3 秒。改：一个标签一条事实，相机停稳之前就让它开始画。
- **扫光过亮** → 面光把塑料洗成纯白。改：扫光功率只用主光的一小部分，辉光阈值抬到最亮漫反射面之上。
- **零件上的品牌标** → 芯片顶面、接插件外壳带商标。改：用无字的封装顶面；不是用户自己的产品就去掉带 logo 的封装。
- **死黑** → 黑塑料贴黑背景直接消失。改：抬到深灰，交给轮廓光分边。
- **标注不跟相机** → 相机一动，引线就脱靶。改：标注只落在停稳的段落，或在停稳帧逐帧对位。
- **生成图当零件** → 一眼假，且违背这套风格的立身之本。改：没素材就少拆一层，不要拿图糊。
