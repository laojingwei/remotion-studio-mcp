# 电视新闻包装（news-package-system）

> 一家电视台的整套上屏零件：品牌板、强调色标签、纸条、墨卡、等宽日期行、印章，从头用到尾；观众先认出这套零件，再读字。
> 参照（只学语法）：晚间联播的标题菜单、财经频道的行情图、欧洲新闻频道的解释地图、科技版的规格卡。不抄任何一家电视台的台标、片头、字体、配色、音乐，片子里也不点名。

## 本质 / 不是什么

- 本质：**系统先于文字**。所有图形由同几个零件搭成；观众读字之前先认出这套零件，认出之后才听内容。
- 本质：**串联单的秩序**：片头 → 今日几条 → 一条一条 → 回到串联单打勾 → 收播。
- 本质：**一屏一件事**。全屏图形只说一个数、一次突破、两个股价、一个地点、两封信、一句原话、一个裁决。
- 本质：**纸条不下班**。下三分之一从第一条新闻到回顾一直在，只换字不换位置；上面那块画面留给图形。
- 本质：**干净版面**。没有跑马灯、没有烧死字幕；画面只有图形、纸条、台标、角标、来源行。
- 不是 **caption-news（字幕新闻）**：那条是编辑风格——静音可读、巨大字幕承叙述、没有串联单和纸条。这条是图形包装系统：字小而有秩序，图形领叙述。两条可叠用（纸条在下、字幕另挂），但不是同一条。
- 不是 **dark-keynote（暗色发布会）**：那条是暗场幻灯片，居中标题 + 项目符号 + 翻页；这条是日间/演播室包装，平图形压在墨底上，没有页眉、没有页。也不是**数据故事片**：图表只是新闻里的插页，不是全片，更不是仪表盘。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 板变台标 | 平行四边形 520×180 砸进画面，结尾飞到右上角一直留着 | 周更、栏目化内容 |
| 纸条不下班 | 底部 x96 y904 的 1250×104 纸带，只换字不换位置 | 多条目、连续叙述 |
| 标签即分类 | 纸条左端 48 高的强调色标签，中英各一行，换条时白闪 | 分类、板块 |
| 等宽日期行 | eyebrow 一行 mono 13px 全大写：`SOURCE · 2026.08.03` | 周更、跨天事件 |
| 翻牌价格板 | 220×130 瓦片，上下半分别裁切，旧值新值同框 | 涨跌、前后、报价 |
| 破线的一刻 | 折线走到金色虚线阈值，最后一步用强调色穿过并抖一下 | 阈值、纪录、警戒 |
| 印章 | 强调色实底或墨底双强调边，−6° 到 −10°，一次一枚 | 裁决、认证、结论 |
| 引语卡 | 墨底 + 光束，巨大引号先落，句子一行行顶上来，金线托名 | 声明、表态、原话 |

规则：每支挑 2–3 个，至少一个不在下面「最俗的版本」里。零件必须复用——同一块板既是片头、台标、主播台前脸又是片尾；只用一次的不算系统。

## 这个风格最俗的版本

- 画面：蓝底旋转地球 + 红白标题条 + 跑马灯 + 结尾发光 logo；图形各做各的，谁也不像谁。声音：通用新闻紧张鼓点 + 一堆 whoosh。
- brief 的 style 一栏写明翻掉了哪几条，或为什么刻意保留。保留时把力气花在**零件复用**和**包装层与画面同步**上——这是它和普通信息图的分界。

## 适配

- 用途与内容：周更/日更资讯、行业快讯、财经与政策解读、发布会后的规格拆解、多条综述；最好有 3–5 条并列事实、每条都能落到一个数、一个地点或一句原话。
- 时长：60–150 秒；16:9 按 1920×1080 设计。条目少于 2 条就别上串联单，直接做单条包装。

## 技术路线

- 一个 scene 一件事：`add_scene` 分镜，`add_element` 放板、标签、纸条、墨卡、文字、图表；纸条与台标单独一层，跨 scene 保持同一位置。
- 翻牌、滚数、折线步进用文本/形状元素逐帧替换，靠 `preview_frames` 抽临界帧核对不抖、不闪。擦除转场本工具用 `wipe`，两侧各画一版包装层（旧侧旧字、新侧新字），带子底下进来的画面同时开始入场。
- 调色、双色调、颗粒在素材阶段做好再 `upload_asset`；本工具不做实时调色节点，颗粒用一层 7% 的图叠上去。画风落 `set_theme`/`apply_style`；旁白 `tts_narration`；字幕 `set_subtitles`（单独交，不烧进画面）；音效/BGM `add_audio`。
- 验收：先 `preview_frames` 看静帧（纸条与图形打架、来源行压到纸带），再 `render_preview_clip` 看动（切点是否踩拍、擦除首帧是否已有内容）。

## 材质与渲染

版式固定（1920×1080）：

| 区 | 位置 | 内容 |
|---|---|---|
| 内容区 | x 96–1824，y 56–840 | 全屏图形；纸条在时 y 840 以下不放重要内容 |
| 纸条 | 标签 x96 y856 高 48；纸带 x96 y904，1250×104，另加 120px 墨色端块 | 标签：强调色底 + 墨字 + 中英分类；标题中文 50px + 英文 27px |
| 来源行 | 右对齐 x1836，y950 / y978 | `SOURCE: …` mono 13px + 中文 16px，75% 不透明；英文 ≤36 字符，超了被端块压住 |
| 台标 / 角标 | 台标在右上、板心 (1739, 86)，为片头板的 0.327；角标在左上 x96 y56，330×64 | 台标 = 板 + `AI NEWS`；角标：生成插画写 `ILLUSTRATION / 示意 · AI 生成画面`，示意图写 `SCHEMATIC / 示意图`，0.2s 翻入翻出 |

零件规格：

| 零件 | 规格 |
|---|---|
| 片头 | 0–1.5s：两道强调色斜线（0.04、0.10s）→ 板过冲砸入 + 冲击环 + 抖（0.16–0.42s）→ 字逐个落下 → 字标与日期行自中线张开 → 一道反光 → 板飞右上变台标，同时竖带擦入首镜；0.4s 内要有一击。板是平行四边形 520×180，强调色渐变，左侧墨条与金条，名字窄体 800 |
| 串联单 | 左：日期块（大数字、月、周）；右：三行各 1024×140，行号块用强调色；踩拍竖直翻入（back 缓动）+ 反光；结尾原样回来逐行打勾 |
| 纸条 | 见上表；换字 0.32s（新字自下上、旧字向上出），分类变时标签白闪；`人物 PROFILE` 版给发言人 |
| 翻牌板 | 瓦片 220×130，上下半分别裁切；旧值与新值同板，×2 / +x% 标在右侧 |
| 阈值图 / 柱 | 自峰值起一条线，金虚线是阈值；线头每步走一个交易日；最后一步用强调色穿越 + 抖 + 环，读数板随后滑入，轴只标数据支持的。柱自零线向下长（亏损），数值滚，共用阈值处一条参照线 + 一枚徽章 |
| 解释地图 / 文件 | 同一投影，一个长镜；成员按离城市远近依次亮，城市与机构标签带引线，一枚章；镜头先推后横移让位。文件 380×490 纸、墨色页眉，自城市点沿弧线飞出（0.5s，scale 0.08→1，旋转收住），念到关键词时勾选框逐个打勾 |
| 引语卡 | 墨底 + 光束，巨大引号先落，句子间隔 0.18s 一行行顶上来，再中文大意、金细线、姓名、场合、日期；引号内用原话原语言，不改写；念到关键词时下划线扫过 |
| 规格卡 | eyebrow（来源 · 日期）、名字自遮罩顶出、分类章、同一把尺上的比例条（整体 vs 部分，数值滚）、百分比徽章、语境 chip；右侧第二组用括号接到总数 |
| 印章 | 强调色实底或墨底双强调边，−6° 到 −10°；0.16s 自 1.9× 落下 + 扩散椭圆；每条最多一枚 |

- 去掉字幕与跑马灯后要重排：内容整体下移 60–110px，别在纸条上方留死带。墨卡是 `#1B1E23` 卡面、顶上一条 8px 强调色边。图形与包装层**不加颗粒**，颗粒只属于实拍画面层。
- 实拍一条调色：去色 → 0.5 / 99.6 百分位定黑白点 → γ1.05 → 35% S 曲线 → 黑 8 白 232 → 双色调 `#0E1013`→`#ECE7D8`；再叠左暗墨渐变、50–55% 暗角、7% 颗粒（六张循环）。放大 ≤1.5×，档案 ≤2.5×（先去块），原台标裁掉。

| 用途 | 值 | 含义 |
|---|---|---|
| 墨 | `#121417` | 底、面板、纸条端块 |
| 墨 2 / 墨 3 | `#1B1E23` / `#22262C` | 卡片、地图上的陆地 |
| 强调（柠檬） | `#F2CF1D`（浅 `#F8DE4A`，深 `#D8B30C`） | 板、标签、擦除带、柱、印章、破线那一笔 |
| 金 | `#D4B064` | 阈值、日期行、来源行、光束、徽章 |
| 纸 | `#F4F1E8` | 纸条、文件、图表线 |
| 突发 | `#FE6B3D` | 只给 BREAKING 与 LIVE；周更综述两样都没有，所以永不出现 |

换品牌时保持结构：一个强调色 + 金类次色 + 纸 + 墨 + 一个保留的警报色。强调色上用墨字；纸上英文副行用暗橄榄 `#6E5A1E`，金在纸上太弱。圆角 0–2px，没有投影、没有玻璃。

## 字体

- 中文无衬线 900（标题、纸条）/ 700（标签）；拉丁窄体 800（数字、台标）/ 600（副行、引语）/ 600 斜体（片尾英文标题）。源文件是 Noto Sans SC 与 Barlow Condensed，本工具用 `"Inter Tight"` + `"Microsoft YaHei"` 近似，不承诺原字形。
- 等宽只给日期、来源、轴标签，全大写，字距 1–4px。层级：纸条标题 50 / 英文 27 / 来源 13 / 中文来源 16 / 角标 18 / 轴标签 13。标签中英各一行，永不折行。无手写体。

## 运动

- **120 BPM 网格**，第 0 拍在片头结束（1.5s）。每个切、每个擦除落在拍或半拍上。
- 镜头长度：片头 1.5s；串联单 4–5s；每条 3–7s；解释地图长镜 6–12s 当全片换气口；对比要停到每一项完整在屏 ≥2.5s。
- 镜头内每 0.5–1s 一个包装动作（翻牌、计数、盖章、打勾、换字、地图点亮、折线步进）。任何一帧不许静超过 1s；每个切点后 0.5s 内要有强动作。
- 转场只有三种：竖带擦除（强调 84px + 墨 5px + 金 14px 边，0.3s）；条内硬切 + 定音鼓；进片尾的斜切。没有叠化、3D 翻转、翻页、穿场。运动一律硬起硬收：砸入用短过冲，其余用长滑行；不做 UI 弹跳，不做文字自己淡入。

## 画面怎么活

- 一条之内顺序固定：**是什么（名字或数字）→ 多大（折线、柱、价格板）→ 谁受影响 / 谁说的（柱、文件、引语）→ 裁决印章**。
- 包装层跟着画面走：擦除下两侧各画自己的纸条字、标签、来源行、角标（旧侧旧状态，新侧新状态），带子把标题刷过去；硬切时同帧换。纸条字不跨两侧翻转、不与带子重叠。
- 每条都要有日期：在串联单行、eyebrow、读数板或文件上。周更综述的条目发生在不同天，日期是防混的关键。地图长镜是全片唯一允许慢的地方：成员按远近依次点亮，镜头推完横移让位。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 板砸入 → 飞右上变台标 | 片头和栏目是同一个物件 | 开场、系列片 |
| 翻牌同框旧值/新值 | 变化一眼读完 | 涨跌、报价、前后 |
| 折线一步步走向虚线阈值 | 逼近一条不能越的线 | 警戒线、纪录、指标 |
| 文件自城市点飞向收件方 | 谁发给谁 | 政策、函件、跨地 |
| 引号先落、句子顶上来 | 这是原话，不是转述 | 声明、表态、判决 |
| 同一把尺上的长条 | 部分与整体是真的 | 规格、占比、份额 |
| 印章落下 + 画面一顿 | 裁决 | 结论、评级、是否通过 |
| 竖带擦除刷过标题 | 换条，不是换页 | 条与条之间 |

取景：平视、正视、无透视；图形占满内容区，四周留 96px。转场就是擦除或切，不做镜头炫技。

## 声音调色板

- **主播声**：一个人，一屏一句，切点后 0.1s 起；高通 90Hz、3:1 压缩在素材侧做好。本工具用 `tts_narration`；合成前先问用户有没有自己的录音、想要的声线与片头音乐，有就用。人声把音乐压约 −7dB，并在 1.2–5kHz 让出一条。
- **新闻主题**：120 BPM 小调——小提琴断弓根—五—八度八分音符、拨弦贝斯踩拍、圆号铺底、低通十六分锯齿脉冲、底鼓 1、3，军鼓 2、4。串联单与第一条给满；行情段小提琴降八度 + 颤音 + 四踩（心跳），政策段只留拨弦与圆号。
- **标志音与拟音**：片头全奏；串联单行落下时钟琴；硬切与换条定音鼓；最大突破前留一拍静音，然后全片最重的一击；印章后一段持续低鸣；最后一条转大调；片尾全奏。擦除 whoosh、翻牌咔哒、印章闷响 + 脆响、交易厅细响、地图每亮一国一声 click、城市一声声呐 ping、文件纸声与打字机 tick、打勾 click + 钟琴。
- **房间与母版**：科技板下机房低鸣、地图下极轻空气声，都很低。母版 −14 LUFS，真峰 −1.2 dB；音效与 BGM 用 `add_audio` 落轨。

## 原生手法

1. **片头变成台标**：板砸进来，再飞到角落留整场；开场与栏目是一个物件。
2. **标签即分类**：新一条开始时标签换类（模型 MODELS、市场 MARKETS、监管 POLICY）并白闪，条与条之间不需要单独的过场卡。
3. **串联单，然后打勾**：同一份清单开场合上，结尾每行落勾。
4. **规格卡**：把一次发布压成比例——整体与部分同一把尺，右边用括号接上"跑在什么上"。
5. **不下班的纸条**：从第一条到回顾只有一组纸条，字翻，条不走。
6. **翻牌前后对照**：旧值与新值同板，每片瓦自己翻。
7. **破线**：折线一周期一步走向金虚线，最后一步前停一拍，穿越给最重的一击。
8. **日期在 eyebrow**：每张图的眉线都是 mono 大写的来源 + 日期。
9. **城市寄信**：地图长镜里文件自发出城市飞向收件方；一个 world→screen 函数让标签与文件在推拉中不脱位。
10. **引语卡 + 裁决章**：官方原话上屏，配姓名、场合、日期；念到关键词时下划线扫过；一枚章。

## 变化空间

每支决定：频道名、板与强调色、几条（一条长片 / 三四条均分 / 五条综述）、每条要哪些全屏图形、长镜放哪、主播声音。

- **三种结构**：串联单 → 条目 → 打勾综述；一条主打 + 连线双框 + "今日还有"小格；条目倒计时（选举夜、赛果）。
- **三种开场 / 结尾**：片头 → 串联单；冷开场先给最大图形，再进片头；片头直接进第一条，串联单只当回顾。收尾是打勾 → 片尾卡、"下周预告"卡，或最后一枚印章冻成片尾卡。

## 坑

- **包装层被落下 / 残留版式**：纸条、来源行、角标只画一次压在最上层，擦除后画面换了、纸条晚 0.3–0.5s 才追上；或去掉字幕、跑马灯却不把内容下移，纸条上方留一条死带。改：每幅画面各画一版，放进擦除的裁切里，并按新版面重排。
- **遮罩里的字露头**：推入标题被遮罩裁着，行程没走完就先露上边缘。改：从完全在下方开始，progress 0 时不画。
- **用词比来源硬 / 只有报道说过的事**："要求提供信息"不是"调查"，也不是"处罚"；只有来源写了才写"未罚款、未立案""首次"——并核对机构自己的页面，它可能与报道相反（"首次要求"也许几个月前就发过）。官方来源没点名公司时，图上写"据…报道 / reported by …"，旁白也要说。
- **阈值靠参照 / 示意图冒充数据**："熊市"是从**哪一个**高点算 −20%？轴上写明参照，换一个峰值结论就可能不成立；数据不支持的轴不要标。收盘价上滚动计数会闪出从未存在的值，收盘用遮罩顶入。
- **印章盖住关键词**：印章声会盖住"罚款"这类词；去掉铜管，把脆响低频滤掉。
- **来源行压到纸条下 / 金落在纸上**：来源行右对齐 mono 13px、≤36 字符；纸上英文副行用墨或暗橄榄，金色对比不够。
- **串联单行文字太短**：它们是条目预览，开场会被判定过短——回顾与纸条里会再出现一次；接受，或干脆不进文本清单。
- **合成语音念错名**：TTS 文本按读音写（改拼写、数字写成词、缩写去掉点），纸条与字幕保留正确拼写；逐条听回放再改。
