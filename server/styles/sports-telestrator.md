# 体育战术板（sports-telestrator）

> 电视足球解说席那块板：先把动作完整放一遍，倒回去，冻住，在真实画面上画圈画箭头——再放下去，换机位，数帧，最后把草皮压平成一块战术板。
> 参照（只学语法）：转播里的触屏讲解段落（解说员手里的 telestrator 板）、给真实比赛素材做标注的拆解频道。不照搬任何转播方或频道的 logo、字体、配色、台标与包装，片子里也不点名。

## 本质 / 不是什么

- 本质：**先看它动，再把它拆开**。每一段动作都先完整跑过一遍，冻帧永远跟在运动后面，解释从不抢在前面。
- 本质：**一次冻帧只出一个发现**（球没被解围 / 没人顶出来 / 他在禁区外起脚），一个标签，最多两组线；同几秒素材反复用，每过一遍只深一层。
- 本质：**画在真画面上**。圈套在脚下，箭头顺着球的真实路线，禁区线描在真的禁区线上；直到片子主动把草皮压平成板之前，没有东西悬在抽象图里。
- 本质：**数是从素材里数出来的**。时间来自帧数（跑源帧的秒表），距离来自草皮标线（一份透视变换）；素材量不出的东西（球速、冲刺距离）不写。
- 本质：**演播室的劲**。亮马克笔线、每次冻帧一个白闪加一记顿挫，画面冻住音乐也冻住。
- 不是**视觉调查**（那是克制、多机位同步的证据片，时间轴才是主角）：这是有包装、有情绪的解说节目。
- 不是**集锦混剪**：没有配乐进球蒙太奇，每一段都被分析过。
- 不是数据故事片或信息图：图表不是片子；俯视战术板只出现一次，作为总结，并且是压平真实画面走到的。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 冻帧 + 圈线 | 画面停住，脚下套一个透视椭圆，一条箭头顺着球的来路 | 任何"看这一步"的瞬间 |
| 角标三态 | 右上 x1452–1880 / y38–110：黄块上节目名 + 模式行 LIVE（红点）/ ANALYSIS（黄）/ REPLAY（青） | 全片包装，从第 1 帧就在 |
| 比分条翻数字 | 右下 x1392–1880 / y926–996：主 n–n 客 + 分钟；球过线那一帧客队数字 0.5 秒滚动 + 一次黄闪 | 有得分的叙事 |
| 源时间码 | 左上 x40–370 / y38–90：`❚❚ 04.20s F106`，慢放显示 ▶ ½，倒带显示 ◀◀ | 一切分析镜头 |
| 帧数秒表 | 从接球那一帧起数"源帧 ÷ fps"，射门那一下停住转黄 | 时机、越位、反应速度 |
| 双机位冻帧 | 两个 960×1080 窗口（1:1 原分辨率切片），中间 6px 黄分隔，各自左上角 A MAIN CAMERA / B HIGH REVERSE，两个角度在同一拍同时冻住 | 夹角、遮挡、同时发生 |
| 空白区域红块 | `#FF3B30` 填充 0.34–0.38 + 虚线边，标"这块没人" | 防守漏洞、空当 |
| 倒带 | 0.6 秒反向 + ±13px 水平抖动 + 四条白色磁迹 + 大 ◀◀ 与 REWIND | 一段动作的回头 |
| 压平成战术板 | 三角网格从画面位置飞到板位，画面淡出，露出 `#0C1411` + 60px 网格的板 | 收束、全场总结 |
| 黄色斜带转场 | 一条带暗边的黄色斜带 0.34 秒扫过整个画面 | 段落之间（唯一允许的转场） |
| 证据卡 | 板上左列文字、右侧图；黄色大数字 + 一个红圈圈住关键那个 | 数据、判决 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 三态角标和比分条是这套包装的骨架，能一眼认出，但也最容易变成"贴了个电视台的皮"——第二个片子里换掉一个。
- 信号必须落在真实素材上：没有素材就退回"冻结一张图 + 画线"，**不许用生成的比赛画面冒充转播素材**。

## 这个风格最俗的版本

- 画面：一段比赛素材，暂停，画个红圈，说"看这里"，再放下去，结尾来一句"这就是足球"。
- 声音：一段激昂的管弦铺底从头压到尾，冻帧时音乐不停。
- brief 的 style 一栏写明这支片子翻掉了哪几条，或者为什么刻意保留。保留时把力气花在"数出来的时间"和"压平成板"这两件别人不做的上。

## 适配

- 用途：单点拆解、赛后复盘、战术解析、技能教学（把"看动作"换成"看操作"同样成立）。
- 内容：有一台能拍到整个动作的宽机位、并且同一段可以反复回看的主题；观众需要在同一秒里看清两三个人的位置关系。
- 时长：按"一段动作"组织，一段动作内必须走完 看→倒→冻→画→再放 的闭环；整片 2–4 段动作，超过四段就把两段并成一次双机位冻帧。

## 技术路线

真实素材是主轨，其余全是叠在它上面的层。`add_scene` 一幕一幕排，`add_element` 放视频/图片/形状/文字，`add_freeform_element` + `set_transform` 逐帧推坐标来画线、套圈、拖拖尾（本工具不给逐帧绘制回调，用关键帧密一点替代）。压平成板是一组二维变换，不需要 `scene3d`，除非要真透视。素材先 `upload_asset`。静帧验收 `preview_frames` 逐拍看，再看动 `render_preview_clip`；整套色与字体用 `apply_style` / `set_theme` 一次落地。

## 材质与渲染

- **素材（最底）**：全片同一档调色——轻降噪 → 补到 1920×1080（现代素材最多放大 1.5×）→ 轻锐化 → 饱和度 0.90 / 对比 1.04 / gamma 0.97、暗部略偏冷；成片上再压一层颗粒 2。任何一帧都不许把素材放大超过原分辨率。
- **马克笔线（叠在素材上，跟着画面一起动）**：三层——暗描边（宽 w+6、黑 0.55）+ 彩色核心（外发光 18）+ 白色细高光（w×0.28）；沿线长画出，箭头在最后 10% 弹进来，顶点有极小抖动，像手画的。虚线 = 意图或未来路线（一次传中、一次跑位），实线 = 已经发生的。
- **圈**：透视椭圆，`ry = 0.36r`，顺时针画出；外圈虚线以 60px/s 旋转；球员移动时脚下加一道竖直光柱。
- **聚光**：焦点椭圆以外压到 0.42（奇偶孔），0.3 秒淡入。
- **标签卡**：黑卡 `rgba(8,12,14,0.9)`（盖 logo 处用不透明的 `#080C0E`）+ 左侧彩色竖条（条的颜色取自它命名的那个东西）+ 中文一行 + 小号加宽英文一行。
- **板面**（证据卡、射门图）：`#0C1411` 墨绿黑 + 很淡的 60px 网格；左列文字，右侧图；没有页眉，没有居中的标题加项目符号。

## 配色

| 用途 | 值 |
|---|---|
| 我们跟的队/人、球、主标记线 | `#FFD400` 荧光黄 |
| 对手（圈、封堵箭头、连线） | `#3FD8FF` 青 |
| 空间（没人管的那块） | `#FF3B30` 红，填充 0.34–0.38 + 虚线边 |
| 描过的草皮线、中性标记、印章 | `#F4F1E8` 粉笔白 |
| 板面 | `#0C1411` 墨绿黑 |
| 标签/角标底 | `rgba(8,12,14,0.9)`；盖 logo 处不透明 `#080C0E` |

一色一身份，全片不变：标签左竖条用它命名的那个东西的颜色。色相可以按节目换，**这三个角色不能换**。

## 字体

- 标签：重型无衬线 900，40px（人名 30px）；英文行窄体 600，21px，字距 2px，用角色色。等价于 Noto Sans SC 900 + Barlow Condensed 600（本工具用 `Archivo Black` / `Inter Tight` 顶中文重体，窄体交给 `Inter` 压字距）。
- 包装上的数字（比分、分钟、秒表、大数）：窄体 800 斜体，视觉上再压 −3% 字距。
- 时间码 / 帧号：等宽 500，24px。
- 板上：标题 60–64px，行文 34–42px、每行下带一行灰注，数字 64–150px 用黄；文字从左往右裁切揭示。
- **全片不许手写体**：印刷字配暗卡才是同一套包装，手写会读成学生笔记本。
- 字幕：中文 38px 在上、英文窄体 32px 在下，黑条 0.64 + 4px 黄边；一行一种语言，绝不折行——宁可把句子改短。

## 运动

- **冻帧入场**：0.1 秒白闪（0.55）+ 顿挫 1.035 → 1.0（0.35 秒，ease-out）+ 去饱和 42% + 偏冷 + 加重暗角；之后缓慢 1.2% 蠕变。**叠加层必须用画面同一个变换**，否则画好的圈会从人身上滑走。
- **冻帧长度** 1.8–2.4 秒；超过 ~2.5 秒里面必须再有第二个动作。一段动作 2–4 次冻帧；超过四次，用一次回放切开。
- **冻帧里的顺序**：圈（是谁）→ 区域或连线（发生了什么）→ 标签（那一句结论），彼此间隔 0.3–0.6 秒。
- **慢放**：源帧 0.6–0.85×，相邻帧交叉混合，不许一顿一顿。
- **倒带**：0.6 秒反向（ease-in-out）+ ±13px 抖动 + 四条白磁迹。
- **拖尾**：只在屏幕空间留最近 ~0.6 秒（球 0.24 秒）——镜头在摇，长拖尾会落在错的地方。
- **印章**（如一次判罚）：带边框的卡片从 1.7× 砸到 1×，过冲，略旋转，配一小下闪光；全片只用一次。
- **转场**：段与段之间只用那条 0.34 秒的黄色斜带；段内硬切。没有叠化，没有翻页。

## 画面怎么活

冻帧本身就是静止的，活全在"还在被画出来"这件事上，只放小幅度：
- 外圈虚线以 60px/s 自转——圈是活的，里面的人是冻住的，这个对比就是这套语言的呼吸。
- 焦点椭圆以外压暗，光圈边缘极慢地收一点（0.3 秒淡入，之后不再动）。
- 画面本身缓慢 1.2% 蠕变，像镜头还在轻微推。
- 边角的时间码每帧跳一个数、比分条的分钟数偶尔进一位——这些数字在动，主体不动。
- 标签卡出现后停住不晃；需要人读的东西（比分、板的行、证据卡）一律 ≥ 2.5 秒。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 1× 放完再倒回 | 先把动作交给你，再收回来看 | 每一段动作的开头 |
| 推近到冻帧 | 注意力钉在一个点上 | 决定性一传、射门前一秒 |
| 跟着球的拖尾走 | 球实际走的路线 | 长传、折射、二次进攻 |
| 双窗口各自推进到同一拍 | 两个角度原本是同一件事 | 越位、手球、夹击 |
| 绕着圈的外侧走 | 这个人为什么站在这里 | 盯人、站位、封堵角度 |
| 单帧停 ≥2.5 秒 + 证据卡 | 让人自己核对数字 | 数据、判罚 |
| 从俯视板回到素材 | 结论落回真实画面 | 结尾、复盘 |
| 后拉到整块板 | 一次看全 | 收束、总结 |

取景：大部分时间是满幅素材，包装只住在四角。标签放在空草地或看台上，**绝不压住它正在解释的那个动作**。第一帧就要有可读的主体，0.5 秒内出现第一个强动作。

## 声音调色板

- **层**：英文/中文旁白（每次冻帧一句，约 2.5–3 秒，`tts_narration`）→ 现场声（1× 时解说 + 人声满档；冻帧下只留低通的人浪底噪并循环；进球那一帧给一次爆发）→ 配乐 → 拟音。旁白把其他所有层压到 0.55。
- **配乐**：采样乐队编制（鼓组、电贝斯、断奏小号与长号、定音鼓、圆号、大提琴、钟琴），约 120 BPM。每一段播放的开头重新起拍，所以不需要全片一条小节网格（`set_beat_grid` 只用作参考）。
- **冻帧时鼓停**：一记铜管重音 + 定音鼓 + 低闷击 + 快门声，之后只剩闭合踩镲——音乐跟着画面一起冻住。进球：大铜管和弦 + 钹 + 钟琴，卡在比分条翻数字那一帧。
- **拟音**：马克笔的吱声（2–5kHz 带通噪声带抖动，每画一条线一次）、圈的"啵"、标签落地的"嗒"、每次斜带转场一声 whoosh、倒带时的磁带电机嗡鸣、秒表每 0.2 秒一响、印章一记闷响、压平成板时一段长 whoosh 加定音鼓滚奏。
- 整体 −14 LUFS，响度对齐后混限一次。

## 原生手法

1. **冻帧再画**：一帧源画面 + 白闪 + 顿挫 + 去饱和 + 聚光，叠加层按进度画出来。适合"就看这一下"。
2. **跟踪圈**：手打脚下点，每 3–6 帧一个关键帧（源像素坐标），中间线性插值；验收时把每个跟踪点画成洋红点铺一遍看有没有跑偏。适合任何"人"的问题。
3. **帧数秒表**：从接球帧起，数源帧 ÷ fps；射门那一下停住并转黄。适合时机与越位。
4. **比分在进球帧翻**：一个进球一条记录，数字滚动 + 黄闪，状态必须和那一刻吻合。适合有得分的叙事。
5. **包装盖水印**：角标和比分条按 logo、URL 的坐标定位，从第 1 帧就在，绝不做淡入。适合所有用别人素材的片子。
6. **双机位冻帧**：两个窗口各有自己的片段与帧区间，在同一拍到达各自的冻结帧，叠加层用各自窗口的源坐标画。适合夹角。
7. **压平成射门图**：每一脚球，在它自己那一帧里标 6–8 个已知草皮点（禁区角、六码区角、罚球弧与禁区线的交点，按标准场地尺寸），用最小二乘拟合一份地面单应（残差 ≤6px 可接受）；把射门帧当成 1.5m 网格的三角网，每个顶点从画面位置飞到板位，每个三角形做仿射映射；画面淡出、粉笔板接上，其他几脚球用各自帧的矩阵换算后落到同一块板上。**先把源画面里的转播方 URL 涂掉**，因为压平会把它拖到屏幕中间。适合"全场就这几个位置"。
8. **证据卡**：把数出来的数字在板页上再说一遍——左标签、右黄色大数、关键那个用红圈圈住。适合结论。
9. **解说转写**：原话 + 时间码 + 译文，1× 时放在小框里；听不清的字写成省略号，绝不去猜。适合现场原声。

## 变化空间

每支由 agent 决定：项目（足球、篮球的挡拆把掩护画成横杠、网球回合画落点、F1 超车画走线——只要有一台能拍到整个动作的宽机位都成立）、拆哪几个瞬间、节目的虚构名字与颜色（三个角色不动）、几次冻帧。

- **三种结构**：按时间线累进到最后一次深拆（次要瞬间只给轻处理，决定性那个给完整的倒带 + 三次冻帧）；一个瞬间从三个角度拆；"哪里错了"的防守拆解，收在空间图上。
- **三种开场**：节目片头 sting 进一张战绩卡；第一个进球帧先在 1 秒内冻住，再倒回去；秒表在 1× 的画面上开始跑。
- **三种结尾**：俯视板把几个瞬间合起来；证据卡上一个数字被圈住；主角那一脚慢放，叠上分钟和名字。

## 坑

- **跟踪点错**是最常见的翻车：从缩放过的联系表上读坐标会偏 20–50px。改：在全分辨率裁切上用像素尺读，再把所有跟踪点铺出来逐个核。
- **叠加层不在顿挫变换里** → 冻帧期间圈会从人身上滑走。改：叠加层与画面共用同一个变换。
- **球会消失**：远射只有几个像素还带运动模糊，颜色跟踪会丢。改：丢球的帧用插值补，数字上写"≈"。
- **写出素材量不出的数**（球速、跑动距离）→ 直接删。改：距离只能来自对可见标线拟合的单应，而且每一脚球用它自己那一帧（镜头在两脚之间会推拉）。
- **包装晚一帧** → 露出别人的 logo。改：角标从不淡入，第 1 帧就在。
- **分屏窗口滑进来** → 露出窗口外的东西（logo、URL）。改：按源坐标把每个窗口裁到它那一片，而不是只裁到屏幕的一半。
- **比分状态和当下不符** → 第 67 分钟进球前是 3–2，不是 3–3。改：每个进球记一条状态，逐帧核。
- **旁白念错人名** → 用音写（"Zayits"、"Saduk"）喂给 TTS，字幕保留正确拼写，并把识别结果记下来当交付物。
- **冻帧标签和字幕互相打架** → 标签只活 ~1 秒，说的是同一句话。改：标签写短结论，字幕说完整句；任何必须读的东西给 ≥2.5 秒。
- **冻帧冻在可识别的观众身上** → 不道德也没必要。改：只冻球员、裁判、工作人员，观众只可作背景掠过。
