# 延时摄影交响（timelapse-symphony）

> 一个地方被当成一首极简乐曲来剪：延时把车流、人群、云压成光的河，每一刀都落在拍或拍的细分上，只有一样东西被放到几乎停住，最后硬切到黑。
> 参照（只学语法）：城市交响曲传统与「Qatsi」系列（Reggio / Fricke，配乐走 Philip Glass 的路子）的剪辑语法。不取任何影片的素材、旋律、字幕字体和片中人名。

## 本质 / 不是什么

- 本质：**配乐是剧本**——谱先写好，弧线是「最小重复 → 加速 → 高潮 → 骤停 → 再加速 → 硬停 → 安静的尾」。画面照着谱排，每一刀落在拍或它的细分上。不是「先剪好再配一首曲子」。
- 本质：**风格活在时间怎么被弯、刀落在哪里**，不在画出来的样子。素材全是真的：延时、大范围移动、航拍、升格、档案胶片、照片。
- 本质：**机器快、人慢**。车、列车、云、光被加速到变成线；唯一被放慢的是脆的东西（肥皂泡、蒸汽、旗、鸟群）；人只以人群、轨迹、长曝鬼影的身份出现。
- 本质：**字极少，每一个都挣来**：一个片名、几个说明这地方体量的官方数字、一个档案年份、结尾一句真实的公版文字。
- 不是 `cinematic-title`（那条是片头，字与光是主角）、不是 `tilt-shift-miniature`（那条靠移轴把城市做成模型，这条不缩小任何东西，它换的是时间）、也不是旅行 vlog / 无人机炫技混剪 / 带解说的科普片 / 明信片幻灯片：没有角标人名、没有页眉、没有居中标题卡、没有 logo 音效。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 光的河 | 长曝车灯连成一条不抖的线，越夜越连续 | 车流、港口、机场 |
| 同一机位的「时钟」 | 一台机器不动拍满 ≥12 小时，日出日落同框 | 一天、一年、开合 |
| 网格分屏 | 1×2 → 2×2 → 3×3 → 4×4，缝 6px 黑 | 全城同时发生的事 |
| 对位分屏 | 左档案、右今天，同一种地方或形状 | 城市变迁、一百年 |
| 数字卡 | 84px 大字 + 2px 钠橙线 + 一行中文一行英文 | 人口、吞吐、班次 |
| 24 小时日环 | 右下一条细环，一根钠橙指针，3 小时弧 | 日与夜的结构 |
| 昼/夜闪切 | 同机位正午与夜景每 2 帧互换 | 时间被抽走 |
| 倒放闪回 | 最后两小节里前面镜头倒序回来，先 4 帧后 2 帧 | 硬停前的回收 |
| 一个被刹车的慢动作 | 整片唯一放慢的东西，薄、脆、会散 | 泡、蒸汽、旗、鸟 |
| 人群变轨迹 | 底板压暗降饱和，人变成一条条慢慢淡的细线 | 流量、通勤、潮汐 |
| 35mm 拷贝质感 | 1.85:1 遮幅、暖高光、抬黑、渗光、结块颗粒、±0.5px 片门抖 | 通吃 |
| 读页光 | 扫描页上一条高斯光带移过引文行 | 历史文献、结尾引文 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。三类各占一点最稳：一个**时间**的（光的河 / 时钟 / 昼夜闪），一个**结构**的（网格 / 对位 / 闪回），一个**字**的（数字卡 / 年份 / 引文）；只堆时间类，立刻退化成城市延时机位素材集。
- 光的河、网格、数字卡最容易一眼认出也最容易被用滥——下一个片子里换一组。

## 这个风格最俗的版本

- 画面：黄昏车流延时 → 天际线航拍 → 网格塞四段街景 → 大数字弹出来 → 白色居中片名 → 黑场；全程无人机运镜，最后一个拉镜堆鼓。
- 声音：现成版权曲 + 一个「咚」的冲击音效落在镜头上。
- brief 的 style 一栏写明这支翻掉了哪几条，或者为什么刻意保留。保留时把力气花在**切点与谱的对齐**和**那一次刹车**上——这两样才是这条风格。

## 适配

- 用途与内容：城市 / 港口 / 机场 / 市场 / 校园 / 工厂的形象片、年度回顾、时间主题纪录片的开场、展会循环片。要有一个能被「量」的地方（人口、班次、吞吐量），和一个能被看见的时间跨度（一天、一夜、一年）；没有时间跨度就只能拍成空镜合集。
- 时长 30–90 秒。至少一次刹车、一次硬停。超过 90 秒是**加一段**（多一个乐句），不是把镜头拉长。

## 技术路线

- 先定帧率（30fps 为准），再定 BPM。**音乐先定**：`add_audio` 先把 BGM 铺上，把长度与 BPM 钉死（96–132 BPM；30fps 下挑一拍是整数帧的速度：120→15 帧、100→18 帧、112.5→16 帧）。
- 算一张表：一小节 = 240 ÷ BPM 秒；一拍 = 60 ÷ BPM 秒；十六分 = 一拍 ÷ 4。120 BPM 下：一小节 2.0 秒 / 60 帧，一拍 15 帧，三连音 5 帧，十六分 3.75 帧。
- **每幕帧数 = 细分格数 × 每拍帧数**，帧数 ÷ 帧率 = 秒数——绝不手打秒数。这张表同时供 `add_scene` 的幕长、`add_element` 的入场帧、`add_audio` 的重音与音效时间码使用，只此一张。**每段素材要覆盖多长**：输出秒数 × 速度 = 需要的源秒数；源片不够长就降速或换机位，不许循环播放凑时长。
- 建幕：一个乐句一幕，幕长直接取小节数；素材 `upload_asset` 按轨分组（时钟 / 地面 / 航拍 / 升格 / 档案 / 照片 / 页面）。画风 `set_theme`（或 `apply_style('timelapse-symphony')`）落地，再手调拷贝层（遮幅、渗光、颗粒、片门抖）。
- 静帧验收 `preview_frames` 逐拍看（构图、字是否可读、亮天空上的字还在不在）；动效验收 `render_preview_clip` 看连续两小节，确认刀踩在拍上、速度曲线没有拐点。
- 字幕 `set_subtitles`：本片没有旁白，字幕承担屏上文字（中英各一行）供静音与无障碍播放。`tts_narration` 只在客户硬要一句话时用，且放最开头或最结尾，绝不压在切点上。

## 材质与渲染

- 全部实拍 2D。来源可混：三脚架延时、单机长延时（≥12 小时，日出日落同框）、大范围移动延时、无人机航拍（正俯拍是金子）、高帧率升格、1931 年前的档案胶片、照片（同机位一对是金子）、一页扫描的古籍。
- 统一成一种 **35mm 放映拷贝**：1.85:1 遮幅（1920×1080 上下各 21px 黑边）、暖高光、抬起的黑位、高光渗光、结块的中调颗粒、±0.5px 片门抖动、柔和暗角。档案胶片保持黑白、过同一个 LUT，才像同一份拷贝印出来的。
- 不用生成图；不用修复、上色或变速过的档案；不用别人搬运的档案镜像。放大上限：档案 ≤2.5×（降噪 → lanczos → 轻锐化 → 回颗粒），现代素材 ≤1.5×。

## 配色

| 用途 | 值 |
|---|---|
| 文字（暖白） | `#EDE8DF` |
| 次级行（英文、标签、出处） | `#B0AAA0` |
| 钠橙——唯一强调色（数字下的线、出处行、人群轨迹、日环指针） | `#D9772F` |
| 遮幅与黑 | `#000000` |

调色顺序：每镜先做部分灰世界白平衡（只取亮度 0.12–0.88 的像素，强度 0–0.6；**夜景强度 0**，保住钠灯与蓝），再全片一个 LUT：S 曲线（sigmoid 斜率 6.2、拐点 0.47，与线性 55/45 混合）→ 黑 7/255、白 250/255 → R×1.025、B×0.965（高光偏暖、暗部偏冷）→ 饱和 0.86。渗光：>170/255 的像素，1/8 尺寸模糊 6px，按 (1, .82, .62) 加回，白天 0.09、夜里 0.15–0.2。颗粒：半分辨率高斯噪声放大后模糊 0.6px，权重 `0.35 + 1.3·L·(1−L)`，强度 9/255。色只有钠橙一种，它出现的地方就是重点。

## 字体

- 拉丁：Michroma 大写、字距 0.06–0.32em。本工具没有 Michroma——用 `Inter` 大写 400 加 0.06–0.32em 字距顶（**别用 Archivo Black，太重**）。中文思源黑体 300–350 字重、0.08–0.14em 字距 → 本工具用 `Microsoft YaHei` 常规 + 字距拉开；片尾署名 17px。
- 一行一种语言，永不折行；每块字完整停留 ≥ 中文字数÷4.5 + 其他字符÷15 + 1.5 秒。字可以跨切点留着，但下面那些镜头必须还属于它数的东西。**永远左对齐**，左边距 168–196px，永不居中、永不加底板；可读性靠块后一块极软的椭圆压暗（α ≤ 0.6），不是面板。
- **数字卡**：数字 84px（三个数字叠放时 44px）；下面长出一条 2px 钠橙线；一行中文 28px + 一行英文 14–16px 说明它数什么、出处年份。普查型数字按十六分逐位锁死（锁一位一记钟琴）；流量型数字 0.6 秒 ease-out 数上去。约数带 `≈` 和「约」。**档案年份**只写年份，22px，压在档案画面左下角。
- **结尾引文**：读页镜头里整句被照亮；卡片版取短句压在最后一个运动镜头上——中文 60px、英文原文大写 20px、出处行 14px 钠橙，0.25 秒内淡入，停到刚过读完时间。
- 一行一种语言，永不折行；每块字完整停留 ≥ 中文字数÷4.5 + 其他字符÷15 + 1.5 秒。字可以跨切点留着，但下面那些镜头必须还属于它数的东西。

## 运动

- **速度是主乐器**：全片 0.3×–75×。凡 >1× 一律**帧混合**（360° 快门）——每个输出帧平均它覆盖的源帧，上限 N 帧。车灯变连续线，人群变雾，云变水。
- 速度曲线在关键速度之间用 smoothstep，且必须有含义：走廊从实时加速出去（1×→6×）；延时冲进狂热（1×→7×）；快镜在音乐停下的那一小节刹进慢动作（**0.55 秒内 2.2×→0.3×**）。后期加的运动要省：缓推（全镜 1.00→1.05–1.10）；开场静帧的下落推（0.35 秒 1.0→1.3，ease-out，之后加速到切点前 ×2）。不抖、不甩、不做超过放大上限的数字变焦。
- 转场：只有硬切，加一次硬切到黑；只有读页与片尾卡允许从黑淡入。帧数按累计取整，不要每格单独四舍五入——120 BPM 下十六分是 3.75 帧，逐格取整一分钟会漂掉一整拍。

## 画面怎么活

- 骨架是一条时间轴在走：同一机位长延时当「时钟」回来三到四次（夜→晨、正午云、一秒入夜、昼夜闪），观众不用字幕也知道几点。
- 密度跟着谱走：镜头不许切得比当前细分更快；**最慢的画面放在琶音停下的那一处**（一个 3–4 秒的长和弦，只给一两个镜头）。
- 三个安静的小循环：日环指针在走（刹车时冻住变暗，倒放闪回时倒转）；网格单元按十六分重新切；数字卡的钠橙线在长。

## 镜头语法

切点表（谱决定切点；120 BPM / 30fps：一拍 15 帧、三连音 5 帧、十六分 3.75 帧）

| 谱面织体 | 切多长 | 帧数 | 用在哪 |
|---|---|---|---|
| 开场重击 + 八分琶音 | 2 小节 → 1 小节 | 120 → 60 | 开场静帧、第一支单机延时 |
| 八分 | 2 拍 → 1 拍 | 30 → 15 | 清晨、形状对切 |
| 三连音对八分（3:2） | 1 拍 → ½ 拍 | 15 → 7/8 交替 | 上午、街道混剪 |
| 十六分、全奏 | 每 1–2 帧亮一格；格子按十六分重切 | 1–4 | 网格 |
| 琶音停、一个长和弦 | 3–4 秒，一两个镜头 | 90–120 | 刹车：被放慢的东西、档案分屏 |
| 十六分 + 三连音 + 圆号 | ½ 拍 → 4 帧 → 2 帧 | 7 → 4 → 2 | 黄昏入夜、倒放闪回 |
| 全奏干切、只剩混响 | 在小节线上硬切到黑 | — | 硬停 |

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 单机长延时回来一次 | 时间过去了多久 | 一天、季节、开合 |
| 光的河（夜 40×/混合 30） | 城市在呼吸 | 车流、桥、航道 |
| 大范围移动走一条街 | 空间被拉直 | 街区、市场、站台 |
| 正俯拍夜航拍 | 城市变成电路板 | 规模、夜班 |
| 缓推 + 形状对切（钟→钟、拱→拱） | 同一个形在时间里重复 | 地标、几何 |
| 刹进慢动作（2.2×→0.3×） | 时间被捏住 | 一滴、一缕、一群 |
| 对位分屏（缝从中心 8 帧长到 6px） | 同一个地方的一百年 | 变迁、对照 |
| 倒放闪回（4 帧、2 帧） | 刚才那些一下倒回去 | 硬停之前 |
| 硬切到黑 | 全曲终止 | 结尾 |

取景：偏中心、贴得近，暗部留给人读字。第一帧要有一个可读的主体，第一小节内必须出现第一次加速。字不压在亮天空上：数字卡放在画面暗的一半，或加那块软压暗。

## 声音调色板

- **只有音乐**。没有旁白、没有现场声（素材自带的声音是别人的音乐）、没有音效。旁白会把「看」变成「听」，并和配乐抢结构——这就是这条风格没有旁白的原因。
- 编制：管风琴（全奏与弱奏音栓、脚键盘）、木管断奏（长笛、单簧管）、弦乐（大提琴与提琴跳弓、持续音、低音提琴）、最后两小节一对圆号、段落强拍上大军鼓、冲进重音前的吊镲渐强、钟琴**只**用于数字锁定。
- 写法：一小节一个和弦上的琶音，加法叠层（八分 → 三连音叠在八分上 → 十六分）；**断口**是所有琶音同时停进一个持续和弦（maj7 或 9），**回归**是全管风琴一记，**硬停**是每件乐器 15ms 内干切、混响尾巴继续响，**尾奏**是一个不解决的软和弦，片尾卡下面开场的动机用四分音符回来。混响：本体 size .7 / mix .28，尾奏 size .78 / mix .36；总音量 −14 LUFS / −1.2 dBTP，声音里不再加颗粒——颗粒已经在画面里。`add_audio` 分层放 BGM，重音与钟琴按同一张拍表落点；一次性音效先问「谱里有没有这个乐器」，没有就不加。

## 原生手法

- **光之河**：按速度曲线积分出源时间，每个输出帧平均窗口内的源帧（有混合上限）。夜 40×/混合 30、云 37.5×/24、一秒入夜 75×/30。车流变光就是静止或极缓漂移的正俯拍 5× 全帧混合。
- **刹车进慢动作**：2.2×→0.3×；软主体用运动补偿，细线（电缆、栏杆、字）改用最近两帧交叉淡——运动补偿会把线撕开。
- **人群变轨迹**：同机位整段取逐像素中值当背景；与背景差 >22/255 的团块（半尺寸下面积 8–900px）算人；相邻帧质心相距 <70px 的连一条 2px 线；线每帧 ×0.9 淡出；轨迹出现时底板压暗降饱和（0.15→0.55 秒）。只对固定机位有效，漂移的航拍会把每栋楼都标成运动。
- **网格**：1×2 → 2×2 → 3×3 → 4×4，半小节或一小节升一级，新格在 0.3 秒内以散乱顺序点亮（不回黑），缝 6px 黑；最后一拍里格子按十六分重切。
- **对位分屏**：左档案 4:3 居中 960px｜右今天居中 960px，缝从中心 8 帧长到 6px。
- **昼夜闪**：同机位正午与夜景各 15 帧，每 2 帧互换。**会动的照片**：同机位一对照片每 2 帧互换。
- **数字锁**：每十六分锁一位、其余位滚动；钟琴每锁一位一记。
- **日环**：右下角一条 24 小时细环，钠橙指针 + 3 小时弧；跟着片中的一天走，刹车时冻住变暗，倒放闪回时倒转。它是图形，不是时钟读数。
- **读页光**：扫描页，16:9 取景窗从 1.06 推到 1.56 页宽，侧光（左上亮），纸色 (1, .93, .80)，一条高斯光带（σ 95–140px）压在引文行上并长到 +38%。
- **硬停**：画面在小节线上切黑，音乐同一帧 15ms 干切，只剩混响。

## 变化空间

- 地点：任何城市、港口、机场、市场、校园、工厂，或者一条河拍一年（时钟变成季节）。
- 长度 30–90 秒；至少一次刹车，永远一次硬停。
- 谱：管风琴 / 木管 / 弦乐是默认；合唱、钢琴重奏或模拟合成器琶音也行，只要写法还是加法、断口还是一个突然的持续和弦。
- 速度 96–132 BPM；30fps 下优先选一拍为整帧的速度（120:15、100:18、112.5:16）。
- 网格级数与对位的一对随素材变（档案对今天、日对夜、两座城）；数字卡最多 2–4 个；非日周期结构可以去掉日环。
- 固定不动的：只用实拍、帧混合出来的光、切点落拍、一次刹车、字极少、一句引文、硬停、拷贝调色。
## 坑

- **素材里藏着水印和板头** → 角标从中心放大到出画（1.5× 以内）、片头致谢卡、片尾音乐署名、压在第一个镜头上的标题字。选入点前先抽一秒钟的缩略图带逐个看。
- **素材内部有隐藏的切点** → 大范围移动的成片里藏着 2–3 帧的跳切和甩镜转场，跨着它做帧混合会出鬼影。过一遍场景切换检测，每条素材的取用窗口关在同一镜之内。
- **混太多变成灰糊 / 灰世界把夜景洗白** → 正午的云 40% 快门（60 帧里取 24）比 100% 好看；夜景的白平衡强度取 0，否则钠灯变白。
- **跟踪要固定机位** → 漂移的航拍会把每栋楼标成运动；航拍改用帧混合，不用轨迹。
- **运动补偿的慢动作会撕细线** → 电缆、栏杆、字改用交叉淡。
- **字压在亮天空上会消失** → 放到画面暗的一半，或加软压暗；**永远不要加底板**。
- **慢下来的脸不是免费主体** → 别把可辨认的普通人做成被放慢的特写主角。放慢一个东西；人只作为人群、轨迹、鬼影出现。公众人物与新闻事件里的人另论。
- **数字会漂** → 官方页面会更新：引页面和年份，把说法、URL、原文存下来，出片前再核一次；一个干净的数字好过一个区间。
- **CC BY 署名很长** → 每个都要作者、全名、许可，放在片尾卡上当小字排（16px、行距 29px、许可与改动并一行）；片尾卡控制在 4–5 秒，10 秒的黑底字卡会把人送走。最后一个运动镜头在卡下面继续走，压暗。
- **不要停在死黑上** → 硬停之后是尾奏：一页纸（约 1 秒）→ 引文压在最后一个城市运动镜头上（约 4 秒，刚够读完）→ 同一镜头上的片尾卡。
- **素材平台会限流（429）** → 串行取用、失败退避；4K 长文件只取需要的那一段或 1080p 转码版，别整条拖下来。
- **片比谱长或短半拍** → 收尾再对一次总帧数 ÷ 每小节帧数，尾巴必须落在小节线上；差几帧就改尾奏引文的停时，不改切点。
