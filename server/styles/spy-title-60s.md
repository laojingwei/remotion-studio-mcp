# 60s 间谍片头（spy-title-60s）

> 四种不透明油墨印在纸上，每个形状都是手剪的边，人物抽象到侧面剪影，在演职员表搭成的布景里追一样东西，铜管一响就切。
> 参照（只学语法）：Saul Bass 为《西北偏北》《桃色血案》《迷魂记》做的片头（平涂实墨、抽象到剪影、字即结构）；Kuntzel + Deygas 2002 年为《猫鼠游戏》做的致敬（剪纸追逐穿过图形布景、横向跟拍）。不做枪管开场，不做踮脚走路的卡通豹，不复制任何真实片头的 logo、字形、角色与镜头。

## 本质 / 不是什么

- 本质：**四种实墨印在纸上**，没有渐变；一个场景一个主底色，随地点换。
- 本质：**每条边都是剪的**。形状带切口、层与层之间留切缝、纸片彼此投一点小影子，像真的剪纸动画。
- 本质：**抽象到剪影**。人物一律侧面，只靠轮廓、姿态和卡点演戏，没有脸。
- 本质：**字就是布景**。演职员表是建筑、道具、车辆；片名和字幕是主角，不是画面上的装饰层。
- 本质：**音乐剪画面**。铜管的每一下都是一个剪辑点；片头本身是一个故事：一个目标、几个地点、一次揭示。
- 不是 `art-deco`（装饰艺术）：那里靠金线、对称与几何装饰组织构图；这里没有金、没有镜像对称，靠的是**实墨色块 + 剪影动作 + 爵士卡点**，画面是歪的、俏皮的。
- 不是 `cinematic-title`（电影片头）：那条路是实拍质感、光效、慢推与衬线字从黑暗里浮现；这里**不许有摄影机拍出来的光**，一切是平涂纸片，快、硬、有拍子。
- 不是 `constructivist-montage`（构成主义）：那条是红黑双色 + 斜轴 + 档案重剪，用素材拼出一个论点；这里是四色、手剪、人物在演戏，讲的是追逐，不是论证。
- 也不是 `paper-cut`（纸艺分层）：那里的看点是层深与灯箱柔光；这里是平贴的实墨、硬边、几乎无纵深，前后靠切缝和小投影区分。
- 不是扁平矢量动效（边是剪的，纸是实物）、不是半调网点印刷、不是瑞士网格（这里是斜的、跳的）、不是带道具和枪管的间谍恶搞。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 手剪硬边 | 每条边每隔约 9–10px 重采样、沿法线做低频位移，偶尔一个 1–2px 缺口 | 任何形状；一眼看出不是矢量 |
| 纸片切缝与小投影 | 相邻两块之间留约 2.4px 底色缝，纸片投一点偏几像素、模糊 5、透明度 0.3 的影 | 分层、装配、叠印 |
| 侧面剪影人物 | 约 7 头身、戴帽穿大衣，全身合成一个轮廓，只有肩肘胯膝几道细缝 | 追逐、偷窃、盯梢、快递 |
| 一个字色当速度指示 | 领带或围巾向后飘，是人物身上唯一的彩色 | 奔跑、急停、风向 |
| 字即布景 | 一整行演职员表当柱廊、车厢或门锁，人在字里走 | 发布会、节目单、名单 |
| 追的东西最亮 | 一个物件衬在黑墨底上（墨色描边），是全画面最亮的东西 | 钥匙、样片、样品、奖杯 |
| 硬切卡铜管 | 每一下刺音换一个地点，没有叠化 | 蒙太奇、揭示、转折 |
| 图形对切 | 同形同位的圆：轮子→硬币→瞳孔→月亮，圆心与大小分毫不差 | 加速、押韵、时间流逝 |
| 斜切网格 | 一条约 30° 的切线把画面切成条，条子交替沿斜向滑走 | 碎裂、阴谋、多人同框 |
| 停顿静帧 | 一记刺音上整幅冻住（连背景滚动也停），静默两拍再走 | 险过、揭示、愣住 |
| 片名由碎片拼成 | 全片的碎片最后落成一个片名；或故意缺一块 | 落版、悬念、标题 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；硬切卡点与侧面剪影最容易被认出，也最容易被用滥，下一支换一组。
- 信号从故事里选：先定"追什么、谁追、几个地点"，再决定用哪几个。

## 这个风格最俗的版本

- 画面：黑底、圆形枪管、一个拿枪的剪影、螺旋条纹转场，最后片名从枪口里推出来。
- 声音：一段人人都会哼的半音下行，加一记廉价的合成铜管。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么刻意保留。保留时把力气花在"手剪的边"和"卡点上的硬停"上，别花在模仿某个真实片头。

## 适配

- 用途：片头、悬念短片、发布倒计时、活动开场、作品集章节、产品"预告"。
- 内容：有一个明确目标、几个地点、一次揭示的题目；名单、流程、关卡、追一个结果的过程。
- 不适合：需要大量长句解释的教学片，或需要真实人脸、真实场景质感的主题。
- 时长：30–60 秒最舒服；超过 90 秒要分段，每段给一次"停住—揭示"。

## 技术路线

- 建幕建元素用 `add_element` / `add_scene`：每层纸片一个元素，底、布景、剪影、字、字幕条分别成层，顺序就是纸的叠放顺序。
- 剪影和手剪边用矢量路径（SVG path）：**边只在元素自己的坐标系里剪一次，全段复用**，不要每帧重算，否则移动时边缘会爬。
- 静帧验收用 `preview_frames` 逐拍看（看边、缝、影、剪影比例），动起来用 `render_preview_clip` 看卡点与硬停。
- 颜色与风格落地用 `set_theme` / `apply_style`，把四色写死，别在中途引入第五个颜色。
- 旁白用 `tts_narration`，字幕用 `set_subtitles`（纸带样式见「字体」），素材用 `upload_asset`，音效与 BGM 用 `add_audio`。
- 本工具不承诺运动模糊：用硬停、切点速度匹配和 12fps 步进来换。

## 材质与渲染

- **剪边**：每个多边形每隔约 9–10px 重采样，沿法线用低频噪声位移，幅度约 1.2–2.2px（大形状大一点），偶尔给一个 1–2px 的缺口。**剪一次、缓存住**，让移动中的剪影保持同一条边，就像真的剪纸动画。
- **叠纸**：两块独立纸片之间留约 2.4px 的底色切缝；每片投一小片纸影（偏移几像素、模糊约 5、透明度约 0.3）。整人也要有这道缝当轮廓，黑人在黑字前面才分得开。
- **纸纹**：整幅叠一层纸纹（乘算：斑驳 + 细纤维），深墨上撒一点稀疏的"墨渣"，再加几条很淡的刮刀痕；成片颗粒约 6。
- **剪影**：高挑的成年人，约 7 头身；身份靠帽子、大衣的剪裁、鞋，再给一个**唯一的彩色点缀**（领带或围巾），跑起来向后飘，兼作速度指示。人物内部合成一个轮廓，只在肩、肘、胯、膝留细缝；手是尖楔形；没有脸，特写时只开一道眼缝。
- **追的东西**：垫一块黑墨底（墨色描边），放在任何底色上都读得出，是全画面最亮的东西。
- **字**：演职员表用窄体展示字（如 League Gothic），转成轮廓后**逐字重剪**（边噪声、旋转 ±0.8°、基线抖动 ±1.5px）；片名用自制的几何切口字（直切 + 弧段、粗细不匀、基线错落），绝不用真实片头的字形。

## 配色

三组示例，看逻辑不要照抄：**黑 `#1b1714` / 奶油 `#efe4c9` / 红 `#d23a22` / 芥末 `#e2a52a`**；**墨 `#161a22` / 骨白 `#ece6d6` / 青 `#1f8a8a` / 橙 `#f07a28`**；**墨黑 / 粉 `#f3d6cc` / 钴蓝 `#2a46b8` / 柠檬 `#f0d23a`**。

- 四色：墨黑、纸奶油、一个烫色、一个暖副色；需要纵深感时只加它们的"暗纸"变体。
- 每个场景一个主底色，随地点换；人和字用另外几色。
- 烫色只给主角身上那一处点缀和危险；副色专门标"追的那个东西"。
- 背景道具用主底色的暗版本，**不许用黑**，否则会被读成字。

## 字体

- **演职员表**：窄体展示字，一行一个地点，某个时刻必须整行可读；只写虚构职务，绝不写真人姓名。
- **片名**：几何切口的自制字形，直切配弧、字重不匀、基线错落；不用任何真实片名的字形。
- **字幕**：一条窄纸带（两端剪口、略微倾斜）放左下，前面一颗小图形当项目符，几何无衬线（如 League Spartan 600、约 44px）。深底用浅纸带，浅底用深纸带；从左滑入约 0.18 秒。
- **阅读时间**：每条 ≥ max(1.8 秒, 语音 + 0.6 秒)；每条演职员表停留的时间要够和字幕一起读完。
- 片名、表、字幕三者字号拉得开，不要挤在同一档。

## 运动

- **木偶二拍一动（12fps）**：人物、手、落字、车辆的姿态与位置都锁在 12fps；**相机、字幕条滑动、网格生长走 24fps**（相机步进会抖）。
- 跑：约 8 张循环，一拍一步，身体强前倾，彩色点缀向后飞；走：一拍一步，大衣摆起来。
- 演职员表沿网格线滑入，**在拍子上一下停死**（很短的缓出）；字落地时带一下纸的"啪"。
- **停时**：刺音上一整幅冻住（含背景滚动），静默两拍，再继续。
- **碎裂**：一条切线把场景切成平行窄条，窄条交替沿斜向滑开。
- 禁止：叠化、文字缩放弹出、橡皮筋回弹、匀速平移。

## 画面怎么活

每 1–2 拍必须有一件事发生：一个剪影跨过、一行字落定、一片纸被推走、一个图形对上。
故事按"一个目标、几个地点、一次揭示"推进：追的东西始终在画面里（或被暗示在画面外），换地点就是换底色，观众永远知道在追什么、追到哪了。
只有停时那两拍允许完全静止；静止之后第一个声音必须是刺音或纸的声音。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 先给整行字的宽景，再推进 | 先读、后动 | 任何用字搭起来的地点 |
| 横向跟拍，一个方向不换 | 追逐、动量 | 追人、赶时间、送货 |
| 铜管一记硬切 | 打击、换地点 | 蒙太奇、揭示、抖包袱 |
| 图形对切（同形同位） | 押韵、加速 | 轮子→硬币→瞳孔→月亮 |
| 平底上一个锁定形状 | 神秘、一个图标 | 冷开场、线索、logo |
| 剪影对着一个巨大的圆 | 主角时刻 | 抓住、得手、对峙 |
| 斜切成网格 | 碎裂、很多人同时在场 | 分屏、阴谋、团队 |
| 沿一列字向下摇 | 下降、清点 | 建筑、名单、倒计时 |
| 推进一个字母直到它填满画面 | 字母变成一个地点 | 门、隧道、窗 |

取景：强斜线（约 30°）、大块平底、人小字大。对切时圆心的位置和大小必须完全一致。**不许叠化。**

## 声音调色板

- **1960 年代间谍大乐队**：成叠的短促小号与长号（八度叠置）配一记镲 = 刺音；弹簧混响的冲浪吉他低音弦；行走的低音提琴；刷子或鼓棒；邦戈与沙锤；颤音琴、长笛、风琴短音、羽管键琴。小调、半音线条、附点节奏。动机必须原创：不要那段人人皆知的半音下行，也不要它那个小—大九和弦收尾。
- **刺音 = 剪辑点**：短促铜管提前约 8ms 放，让采样峰值正好落在那一帧上。
- 手法（可选）：追逐加速时把切点间隔一段段缩短；停时的彻底静默；片名给一个大和弦再接一个短收尾音；安静场景只用一件独奏乐器。
- **拟音跟着材料**：纸（剪的"嚓"、滑动、落字的纸啪、翻纸、撕）、金属（钥匙、链条、锁、咔哒）、磁带（咔哒、嘶声）。环境只做暗示：掠过的喷气机（带声像）、按拍子走的火车轮、渐慢的轮盘嗒嗒、风、电话铃、楼梯脚步。
- **静默**：真零，混响尾巴也一起断，只允许留一记磁带咔哒或底噪。
- **混音**：音乐在人声下让约 7dB；峰多的混音先给几 dB 进限制器，再到 −14 LUFS。
- **人声**：一段过磁带链的任务简报（带通约 220–5200Hz、轻度饱和、缓慢抖晃、人声底下嘶声渐起），只说几句很短的话。

## 原生手法

- **字即布景**：一个地点就是一行字，那行字是它的建筑（字母当柱子、单词当车厢、一个字母当锁）。适合：会议日程当城市、菜单当餐馆、队名当球场。
- **演职员表就是节奏**：表落在拍上，刺音就是切。适合：功能清单、节目单、提名名单。
- **图形对切**：形状押韵，张力越大间隔越短。适合：硬币→行星→钟、齿轮→车轮→太阳。
- **斜切网格**：一条斜切线增殖成网格，碎片最后沿它飞回来拼成一个东西。适合：解谜、组队、logo 拼合。
- **剪影木偶**：侧面剪出来的角色，演技只有轮廓和时机。适合：偷窃、限时送达、侦探。
- **停时抖包袱**：刺音上冻住、静默、再继续。适合：险过、回头再看一眼、价格揭示。
- **追的东西就是片名**：所有人抢的那个东西，是最后被拼出来的东西。适合：产品发布、书名、生日名字。

## 变化空间

你决定追什么、谁在追、地点（都以字的形式出现）、四色、开场和结尾。

- 结构：**不追，倒计时**（十行演职员表、十个地点，每个地点用一个数字当布景）；**反向偷窃**（东西被一站站送回去）；**两个特工一个画面**（斜切两半，各一个底色，最后合上）。
- 开场：**满幅片名先碎掉**，散成整段（揭示挪到开头）；**一间剪纸房间里电话响**；**主角已经在一列字里往下掉**。
- 结尾：**片名永远拼不齐**，缺一块，主角带着它走掉；**缓慢拉远**，原来每个地点都在同一张巨大的演职员表上；**最后一记刺音上停时冻住不放**。

## 坑

- 每块内部都描边留缝 → 看起来像人体模型图。改：人物内部合成一个轮廓，只切关节细缝，只给整个人描外轮廓。
- 人物被字完全挡住 → 读成"那里没人"。改：让帽子、鼻子、彩色点缀露出来。
- 飘带太硬 → 像吐舌头。改：多段带子，正弦波在带子上跑。
- 一行演职员表只在画面上露一半 → 难受。改：总有一次完整宽景把它整行给足。
- 黑底上的黑道具 → 被读成字。改：用主底色的暗版本。
- 物件和它脚下的底色同色 → 消失。改：垫黑墨底。
- 圆道具丢进词里 → 盖住旁边的字母。改：把词在它周围排开留一个洞。
- 对切时圆心移动了 → 对不上。改：圆心与大小逐帧对齐，切点上完全一致。
- 平涂实墨 + 颗粒在低压缩率下文件巨大 → 同画质下把压缩率调高，看不出差别。
