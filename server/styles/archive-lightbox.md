# 档案灯箱（archive-lightbox）

> 真实档案物件按真实比例摊在一张冷白的发光台面上，破损、折痕、铅笔字都留着；放大镜落下来，物件只在镜片里面改变状态。
> 参照（只学语法）：往静照里推的档案纪录片、逐条标注真实影像的视觉调查、拍玻璃边缘与透射光的微距产品片。不照搬它们的构图、字体、镜头与音乐，片子里不点名。

## 本质 / 不是什么

- 本质：**物件是真的**——公有领域或已授权的扫描件，真实比例，真实损伤（缺角、乳剂边、折痕、铅笔字）。里面没有一个像素是画出来或生成的。
- 本质：**光从下面来**——台面近白偏冷（≈0.97 白），胶片与玻璃透光，纸在边缘发暖，不透明的东西比台面暗。台面可以关掉（环境 ≈0.04）再闪一下亮起来。
- 本质：**放大镜是相机的门**——每一次进入物件都经过一只落在它上面的放大镜；物件改变状态只发生在镜片里面。
- 本质：**编目即事实**——每件物件带着它真实的编号、日期、题名；屏幕上的数字来自档案记录，不来自估算。
- 本质：**只有一种信号色**，只给标记、读数、锚点、裁决；其余全是档案自己的银灰与纸色。
- 与 `newsreel-1920s` 的区别：那条有片子、有放映窗、有走片抖动与银盐颗粒；**这条没有片子、没有放映、没有颗粒**——物件静止摊在发光台面上，靠"手"去拿起、翻转、放下来看。
- 不是 `editorial-collage`：拼贴靠层次堆叠出视觉趣味；这里每件物件都承担证据，**摊开的顺序就是论证顺序**。
- 不是 数据故事片（没有图表，数字住在物件上）、不是 keynote（没有页头条、没有居中要点的幻灯片）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 冷白灯箱 | 近白台面 `#F7F9FB`，中心亮、边缘软衰减，铝框，台外收暗 | 档案、溯源、产品考古 |
| 真比例的物件 | 扫描件按原尺寸摊着，缺角、折痕、铅笔线都在 | 老照片、电报、剪报、手稿 |
| 放大镜 | 黑环 + 斜面高光 + 亚克力裙边，落下时投一道柔影 | "再近一点看" |
| 镜下改变状态 | 负片变正片、一行字亮起来、照片长出深度 | 证据、关键帧、签名 |
| 编号与日期 | 等宽小字贴在物件旁，一个锚点、一条垂直引线 | 编目、时间、出处 |
| 读数坐暗板 | 74–120px 等宽数字，上一行小标签、下一行出处 | 数字、规格、读数 |
| 一处信号橙 | 全片只有一种颜色，且只落在标记与读数上 | 裁决、标出、命中 |
| 纸的暖边 | 纸在背光下发暖，不透明的部分比台面暗 | 信件、票据、手稿 |
| 从镜内升起 | 一次呼吸式的退开，不是切镜 | 段落、转折 |
| 后拉成索引 | 整张台面 + 每件物件的标签飞成一张清单 | 收尾、时间轴 |

规则：每支挑 2–3 个，至少一个不在下面「最俗的版本」里。灯箱 + 真比例 + 放大镜是最低配置；编号与读数一旦上了暗板，就要真的读得完。信号从主题里选，不按顺序全上。

## 这个风格最俗的版本

- 画面：全片棕褐滤镜、四角压暗、一张老照片慢慢推近（Ken Burns），加一层做旧的划痕纸纹，标题用打字机体逐字敲出来。
- 声音：一段循环钢琴 + 翻页声，从头铺到尾，一次留白都没有。
- 正确做法：**旧在物件里，不在分级里**——不加棕褐、不加网点、不盖纸龄层、不要"老电影"抖动。真东西自己会旧。brief 的 style 一栏写明翻掉了哪几条，保留时把力气花在"镜下改变状态"和"读数落在旁白上"。

## 适配

- 用途：史料溯源、品牌考古、机构周年、展览导览、产品与规格的对照核验。
- 内容：必须有真物件——扫描件、老照片、纸片、胶片条、手稿。**没有可授权的真档案就不要选这条**，它编不出素材。
- 时长：20–70 秒最舒服；一次"落镜 → 读 → 升起"约 4–8 秒，全片 4–8 次。超过 90 秒要有一次后拉成索引。

## 技术路线

- 1920×1080 建幕：`add_scene` 铺灯箱底（径向渐变发光面 + 很轻的扩散噪点 + 铝框 + 台面外的暗桌），`add_element` 逐件放扫描件，中心/旋转/缩放手填，尺寸按真实比例换算。
- 相机是一个二维中心点 + 缩放 + 侧倾；**所有物件和所有标记共用同一套"世界→屏幕"换算**，否则镜内的和镜外的永远对不上。
- 放大镜：镜内就是同一张图放大 ≈2.5×，用圆形蒙版裁出来，边缘加一点枕形（k≈0.16）和按 RGB 分开的一点点色边。本工具做不出真的折射，亚克力裙边用一层半透明白 + 一道内发光近似。
- 负片转正片不走渲染管线：叠一张正片图，用放射状蒙版逐帧扩散，边缘给一道细暖边，扩散只发生在镜内。
- 标记与非印在物件上的字单独一层：发丝线 1.5–3px、圆环、裁切角、下划线、引线；镜下的标记要被圆形蒙版裁掉——真实世界里它们不会浮在镜片上。
- 先 `preview_frames` 逐拍看静帧的明暗关系与构图，再 `render_preview_clip` 看落镜、推进、升起的手感；画风落地用 `apply_style` / `set_theme`，旁白 `tts_narration`，字幕 `set_subtitles`，素材 `upload_asset`，音效与配乐 `add_audio`。
- 素材来路：CC0、公有领域、CC BY（署名）可用；"no known restrictions" 与 CC BY-SA 不算 CC0，要当面问用户。另存一份事实清单（每条：说法、来源 URL、原文措辞、数字怎么算出来的）随片交付。

## 材质与渲染

- **灯箱**：发光面 ≈0.97 白、略冷，中心亮、边缘软衰减，一层极轻的扩散噪点，铝框在暗桌上有一道极淡的边光；关掉时环境 ≈0.04，开起来先闪一下再稳住。
- **物件**：扫描件按真实比例贴成一个四边形（中心、旋转、缩放），不补光、不加暗、不改色——档案自己的灰就是画面的灰。
- **玻璃负片**：透射 `T = 0.035 + 0.9·(1−pos)^1.25`，带一点暖银；乳剂遮罩来自扫描件本身（贴边的白边 = 没有玻璃），所以缺角处直接透出台面。灰尘与划痕只在台面坐标系里生成，不跟物件走。
- **纸**：背光，颜色 = 纸色 × 光；被照亮的那行墨更黑、纸更亮；没被照到的字可以压暗，把一行推出来。真实纸张的透光与纤维做不到，用**背光渐变 + 极轻的纸纹贴图**近似。
- **投影规则**：台面上的物件**不投影**（光从底下穿过）；画面里唯一的投影属于放大镜——落下与抬起时缩放 1.35× 并投一道柔影。镜圈是黑环 + 斜面高光 + 透明亚克力裙边，裙边脚下有一圈光。
- **照片空间**：推进去之后镜片不再是镜片——照片获得地面近远度（地平线为 0，往下的每一行线性加），直立的人/机器抠成层、背后补一块填色；推车与横移带出视差，主体层可以轻轻漂移。**留在地面上的东西会斜，推车点要放在它们中间。**
- **采样**：镜内放大倍率越高越容易糊——一张图被拉伸到超过原始分辨率就会软，所以放大上限由扫描尺寸决定，不靠后期锐化救。
- **后期**：轻暗角 + 很细的运动颗粒（照片空间里重一点）。没有胶片划伤、没有棕褐、没有网点。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 灯箱 | `#F7F9FB` | 冷白，光从这来 |
| 墨 | `#15171A` | 编号、日期、读数、字 |
| 信号橙 | `#FF5A1F` | 标记、读数、锚点、裁决 |
| 说明板 | `rgba(14,15,17,0.74)` | 读数与出处的暗底 |
| 银灰 | `#9AA3AB` | 档案自己的灰：框、次级字、辅助线 |
| 纸（示意） | `#E7DCC6` – `#F2E9D8` | 背光下的暖，只在纸的边缘明显 |

- 中性底 + 档案自己的色调，**不把档案调成一个色系**。
- 信号色永远只做标记：不做图片背后的填充，不做装饰；一帧里最多一处橙。
- 字按底选对比——浅底用墨，暗板上用纸白；绝不在颜色上叠颜色。镜内的正片可以轻推黑点与白点，让弱扫描读得出来；负片保持玻璃给它的样子。

## 字体

| 角色 | 字体 | 字号 |
|---|---|---|
| 编号、日期、读数 | 等宽（本工具用 `monospace` 回退，中文 `Microsoft YaHei`） | 17–34px；读数 74–120px |
| 片内语言的标签 | `Inter` / `Microsoft YaHei` | 21–36px |
| 只有标题和照片上那一个名字 | `Georgia` / `Noto Serif SC` | 60–76px |

- 标签**挂在物件上**：一个锚点圆 + 一个环，一条垂直引线，然后是字。读数坐进暗板：上面一行小标签，下面一行出处（编目号或原文措辞）。
- 字幕：底部居中的一条字幕带，压在暗板上，上缘一道 **3px** 信号色；双语时片内语言在上，一行一种语言。停留 ≥ `max(1.8 秒, 语音 + 0.6 秒)`。
- 能引原文就引原文：裁出真正的那一行、或把记录里的措辞加引号放进画面，比转述有力。

## 运动

- 24fps 逐帧（on ones）；每一个相机参数都走单调平滑曲线过关键帧——**不过冲、不跳步**。
- 相机在台面上滑过去，慢下来让放大镜落下，然后推进去。速度活在滑移与推进里，静止只用来读。
- 拿起与放下都是 **0.4 秒的快出（ease-out）**，抬起的路和落下的路同形；**角度是 90°，垂直落、垂直起**——镜片一倾斜，镜内的映射就错位，这是几何约束不是偏好。翻面（负片变正片）最长 1.2 秒，期间画面不旋转、不做 3D 翻页。
- 线与下划线 **0.3–0.6 秒**画上；文字从引线那一侧擦进来；数字数上去，和旁白一起落地。
- 永远不动的东西：照片空间之外档案自己的内容，以及台面本身。

## 画面怎么活

台面一直是活的，但那不是"动效"：光在物件的透射里极轻地呼吸（±0.5% 亮度）；放大镜落下的那一刻镜内亮一点点；已经画上的线有细到几乎看不见的粗细变化；角落的编号每拍换一个数。**动的必须是光和手，不是版式**——版式一晃就成了特效片。

节奏上，一个"落镜 → 读 → 升起"就是一句话：落镜前有半拍安静，读的时候相机停住，升起时旁白已经进下一句。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 台面滑移（平移 + 侧倾） | 巡视；走向下一件证据 | 时间轴、产品谱系、相册 |
| 放大镜落下 + 推进镜内 | 选定一件；"再近一点" | 主张、关键照片、签名 |
| 镜内沿一行字跟踪 | 在读 | 信件、账簿那一行、说明、规格 |
| 照片空间：推车 + 视差 | 在场 | 事件本身、创立那一刻、那个地方 |
| 从镜内升起 | 退开，证据已经记下 | 段落转换、小结 |
| 后拉到整张台面 | 规模；一次看全 | 索引、时间轴、收尾 |

取景：阅读时刻主体占画面高至少 **1/3**；读数与标签不进入底部 **140px**（留给字幕）。转场只由放大镜（落、推、升、抬）和滑移完成——**物件之间不切、不黑场、不翻页**。

## 声音调色板

- **环境**：灯箱镇流器的嗡（100Hz 及其谐波）、起辉器的咔哒、房间底噪。进入照片空间时嗡声让位给那个地方的气。
- **拟音**：放大镜碰玻璃（一声脆响带高频余韵）、滑移与亮线时的纸张扫过、刻度与计数器的嗒、裁决的笔划声、标签落地时轻点。
- **音乐**：克制而小——毛毡钢琴、少量弦乐、玻璃或弓弦金属给"看见"的那几拍。靠细分与音区堆叠，不靠鼓。揭示或裁决前留真空，空白之后的第一个声音必须是放大镜、那个地方、或裁决。
- **人声**：平静的旁白，短句，只说物件说了什么。音乐压低约 **10dB**、说话时闪避；整体 **−14 LUFS**。

## 原生手法

- **镜下负片转正片**：一道显影前沿从镜心扩散，带一道细暖边，只在镜内把玻璃负片变成它的正片。适合：创始人肖像干版、灯片上的工厂、一张 X 光片变成里面的产品。
- **那一行亮起来**：镜内的纸上，一行字亮起来、其余暗下去，下划线在它下面画出来，一个字或一个数被提出来变成一张读数卡。适合：账簿里的一笔、专利里的那句话、订单上的第一个数。
- **走进照片**：镜圈长过画框，镜内视野变宽，照片获得分层深度，主体轻轻漂移。适合：第一家店的门脸、发布日的人群、考察队的营地。
- **在照片上量**：一把尺按透视铺在地面上，刻度朝地平线变密，计数器落在记录里那个数上；是示意就标成示意。适合：赛程、桥跨、楼高。
- **两份记录并排**：两张说明卡，各带一截来源，静静停着，等两边都读完，再划掉其中一份。适合：印错的日期、两个版本的创立故事、规格与交付。
- **台面变成索引**：后拉到整张台面，每件物件的标签飞进一张清单，带着编号和它的读数。适合：公司年表、藏品目录、产品谱系。

## 变化空间

由 agent 决定：放哪些物件、它们的顺序、讲什么故事、用哪几个原生手法、相机怎么走、照片空间里是什么、信号色用哪一种。

- **三种结构**：一家公司的创立讲成按日期摊开的五件物件，每次落镜揭开一个人；一张照片用三次落镜看完（地方、人、背面的日期）；同一栋楼的图纸与照片成对看前后。
- **三种开场**：黑暗里台面亮起来；放大镜已经压在一张干版上，升起时才看见整张台面；一只信封上手写的日期占满画面。
- **三种结尾**：台面上所有东西的索引；最后一张照片停在深度里，只留一行字；台面关掉，剩一件物件还亮着。

## 坑

- **放大一张弱扫描** → 镜内发虚。改：镜内每个扫描像素不超过约 1.5 个屏幕像素；按扫描尺寸挑物件，别用后期锐化救。
- **放大镜扫过空台面** → 一大段什么都看不见。改：物件摆紧一点，让镜片直接落在物件上（**掉进去，不要滑进去**），相机在物件上滑、不在缝里滑。
- **照片空间剪切** → 一张近远度图会把人和机器撕开。改：直立的东西抠成层、背后补色，2.5D 的位移小到看不出补的那块。
- **标签跟着台面滑走** → 还没读完就出画。改：相机停住，或者把说明固定在屏幕上。
- **复古味渗透** → 一加棕褐、网点、纸龄层，档案就变成道具。改：旧在物件里，不在分级里；不加胶片划伤，不加"老片"抖动。
- **编号是编的** → 整个论证塌掉。改：编号必须来自记录；查不到就写"未编目"，别造一个好看的号。
- **信号色用第二遍** → 系统散掉。改：一帧里只允许一处橙；橙落在纸上或木头上就挪开。
