# 木刻版画（woodcut-print）

> 每个镜头是一块印版：黑是没动过的木头，白是刀刻掉的地方，光靠刻痕的宽窄疏密"雕"出来，四周留一圈纸边。
> 参照（只学语法）：Masereel《激情之旅》与 Lynd Ward《上帝之人》的无字木刻小说（一页一块独立的版）、Kollwitz 木刻里情绪长在刀口方向上、Doré 的排线用间距与方向造光。不照搬他们的版面、人物、边框与标题。

## 本质 / 不是什么

- 本质：**一块版，只有黑**。亮部是许多宽刀几乎并成白，暗部是一整片没碰过的木头；中间调只靠几刀疏密撑住。
- 本质：**画是刻出来的**。没有淡入：刻痕沿形体一笔一笔长出来，先粗刀开形，再细刀收光。
- 本质：**版是反的**。字在版上读反，揭纸才读正——这个反转本身就是这个风格的转场。
- 本质：**纸边一直在**。图像被纸边包住，下边最宽、放说明文字；图像边缘是毛糙的墨线，不是干净矩形。
- 不是 `ukiyo-e`（套色凸版：主版线 + 若干平涂色版，日本名所绘），也不是 `copperplate-engraving`（凹版：白底上极细平行排线，纸币质感）。更不是林诺板海报（不许大块平涂彩色），不是黑白照片压一个阈值（刻痕必须跟着形体走）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 纸边与版边 | 四周一圈纸边，下边最宽；图像边界是吃墨不匀的毛边 | 出版、手作、章节 |
| 白是刻出来的 | 亮处是宽刀几乎并成一片白，暗处是完整的黑木 | 光、火、夜里的窗 |
| 刻痕随形体走 | 圆物被弧线包住，坡顺落势，火与光呈放射，布顺褶 | 人物、机械、地形 |
| 宽窄即明暗 | 亮=宽刀近乎并白，中调=细刀，暗=不刻；远细密、近粗疏 | 尺度、空气、纵深 |
| 白皮黑五官 | 脸刻成白，五官留黑；黑白相接处有一道刀缝 | 肖像、群像、劳动 |
| 帘纹纸 | 一组平行链线 + 极疏的垂直帘线，墨浮在纸面不咬进去 | 手作、档案、年代 |
| 只有一块色版 | 全片只有一种颜色，且只落在刻掉的白里，像从缝里透出的光 | 火、熔金、信号灯、血 |
| 错版两帧 / 镜像的版 | 硬切时整幅图错开几像素又归位；版上的字是反的，揭纸才读正 | 断点、结果公布、名字 |
| 木纹与墨厚 | 墨厚有 ±6% 起伏，木头条纹透上来，几处没吃上墨的白点 | 材料、工艺、年代 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 纸边、白刀缝最容易被一眼认出，也最容易被用滥——第二支片子换一组信号。
- 那块唯一的颜色**全片只给一件事**；第二次出现就废了。

## 这个风格最俗的版本

- 画面：一张黑白高对比照片压阈值，加一圈滤镜式边框，角落盖一个手刻感小图章，标题用做旧字体。
- 声音：低沉大鼓 + 一声金属撞击，全程如此。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么刻意保留。保留时把力气花在"刻痕跟着形体"和"纸边与揭纸"上，别花在滤镜上。

## 适配

- 用途：讲劳动与代价的短片、纪录片章节头、社论式宣传、传记里的一个转折、工艺与材料。内容要粗犷、有力量、经得起"一刀一刀做出来"。
- 不适合：密集 UI 教程、需要照片级光泽的产品展示、需要连续自由旋转的三维镜头。
- 时长：20–70 秒最舒服。无字刻小说的段落可以停在版上读 2 秒以上，超过 90 秒要拆成两段。

## 技术路线

- **一块版，两个画布**：一个 mask（黑=未刻，白=刻掉），一个可选的色版。所有刀路都是独立路径：用 `add_element` 放 SVG path / 形状，每刀一段，不要用重复 pattern 贴排线——图案会露馅成机器线。
- **刀路从形体来**：先在元素上定形体的法线 / 等照度方向，再沿它布弧线或放射线；每个刀路单独 `add_element`，端点做不规则收尾，近似崩口。
- **小高度场做特写**：手、器物、机器零件先搭胶囊 / 块 / 皱的简单高度场，取它的等照度线当刀路。
- **印刷层**：最上面叠一张帘纹 + 木纹 + 墨厚不匀的合成层；色版用同一张 mask 的白色部分做限制。
- 静帧先验收：`preview_frames` 逐拍看，**看 1:1 裁切**（细排线在缩略图里会假白）；再 `render_preview_clip` 看动。画风统一用 `set_theme` / `apply_style`；素材 `upload_asset` 进来后重新刻一遍，不要把照片直接贴进去。

## 材质与渲染

- **刀的种类**（1080p、1× 相机下的像素宽度）：

| 刀 | 宽度 | 用途 |
|---|---|---|
| 尖刀 `k` | 1.2–2 | 轮廓；把黑形从黑底里分开的那道白缝 |
| V 口 `v` | 2–8 | 排线、头发、胡须、细部亮 |
| U 口 `u` | 10–22 | 射线、天空扫笔、第一遍开形 |
| 点凿 `stab` | 半径 3–8 | 雪、火星、土粒、木屑 |

- **排线（Doré 语法，用木刻执行）**：线**方向随形体**（圆物用弧线绕住，坡顺落势，火与光放射，布顺褶）；**宽度随调子**（亮=宽刀几乎并白，中=细刀，暗=不刻）。**远细密、近粗疏**。每一刀都是独立的一刀（30–160 px，入刀钝、收刀渐细、边口有缺），绝不连成一条机器线。
- **人**：黑剪影 + 一道白刀晕 + 只在受光边打掠射排线（光在 z≈0.2 处掠过来，平的地方留全黑）。**皮肤刻白、五官留黑**——无字刻小说的规矩。
- **印**：mask 之上叠边缘的刀崩、±6% 的墨厚不匀、木纹条纹、没吃上墨的白点、一块有固定微错的色版。版模式（拍版本身）：上墨的木头有光、刻槽里是浅木色。本工具不许出现干净矩形满幅、均匀的灰、网点半调、柔和投影。

## 配色

两个值撑住全部：近黑的墨、暖的帘纹纸白。木头的本色只出现在"拍那块版"的镜头里。

| 用途 | 值 | 含义 |
|---|---|---|
| 纸 | `#E8DDC3` | 帘纹纸，暖、略旧，但别有尿黄滤镜感 |
| 纸边 | `#F1E8D2` | 版外那圈更亮的边，说明文字坐在这里 |
| 墨 | `#16130F` | 不是纯黑，带一点木头暖 |
| 副墨 | `#3A342B` | 只在极少数需要"第二层黑"的地方 |
| 那一块色 | `#B0471C` | 烧红的铜橙，只给热 |
| 冷色版 | `#2E4A63` | 普鲁士蓝，水或夜 |

- 色版只印在**刻掉的白**上，从刀缝里透出来；压在墨上几乎看不见，所以要在白区上规划。它可以在高潮时铺开、之后收缩成一个高光点，永远不是装饰。备选色版：牛血红 `#6E2B2B`（伤口、封蜡）——按主题选一块，别混用。

## 字体

- **说明文字是活字**，排在纸边里、图像下方，像木刻小说里的版下说明。永远不压画面。
- 拉丁用老式活字（IM Fell English 一类），40–44 px；中文用 `Noto Serif SC` 或 `STKaiti` 近似手刻的顿挫。字也要过同一层印刷质感。
- 墨在 0.1 秒内"顶上来"，不许滑入，0.15 秒内褪掉；停留 ≥ max(1.8 秒, 语音 + 0.6 秒)。
- **标题是刻出来的，不是打出来的**：从黑里挖出来（反白），如果镜头先给版，就镜像。
- 字幕走 `set_subtitles`，放在纸边位置，样式接近活字而不是屏幕弹幕；结尾文字是一次新的印张。

## 运动

- **人物 12 fps（on twos）**，镜头、粒子、火与光 24 fps（on ones）。排线活在各个体块的局部空间里，所以刀缝跟着肢体走、不会"沸腾"；只有火与液体每 2 帧重刻一次，那是刻意的沸腾。
- 每个关键动作都有预备 / 发力 / 跟随：往回几帧 → 2 帧的击打 → 定住 + 一小下余震。
- **刻痕揭示**：每笔有自己的起始时刻和速度（0.08–0.35 秒）。揭示键：`light`（先亮处、由粗到细）、`radial`（从一个点出发：射线、灌注）、`down`，或用任意函数。
- **揭纸转场**（全片唯一的转场语法）：滚筒上墨（一道湿亮扫过）→ 纸落下 → 马连打圈、图像洇上来 → 纸贴滚筒朝镜头揭起，先沉后快，背面是镜像的透印。
- **硬切 = 新印张**：两帧位移几像素，再复位。**纸边永远不动**。
- 本工具里用逐帧关键帧落到偶数帧模拟 on twos；镜头用缓动叠加，速度与加速度都不许突变。

## 画面怎么活

一个镜头是一个自足的版面：先给形，再给光，最后给那一块色。变化只发生在刀口上——同一形体可以越刻越深（版被重新刻），情绪靠刀的方向转，而不是靠表情。
在无字段落里，允许一个镜头只说一件事、说完就切；两个版面之间可以静默。观众读的是"上一版和这一版差在哪"。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 跟着刀尖走 | 制作；线就是故事 | 第一刀、地图上的路线、签名 |
| 刻痕扩散时持续后拉 | 一条线长成一个世界；尺度 | 从一条街到一座城、族谱、消息传开 |
| 固定版 | 无字小说的一页；阅读时间 | 一个决定、一幅肖像、事后 |
| 对准雕塑特写的慢微推 | 耐心、手感、劳动 | 手上的活、一件工具、一封读着的信 |
| 急推并停住 | 惊吓；那个戳破的细节 | 一道裂缝、一个错数、转过来的脸 |
| 画中画（门、窗、拱） | 距离、排斥、等待 | 门外的人群、病房、边境 |
| 卡拍硬切，每一刀一个新印张 | 累积，一组版画 | 供品、日子过去、一串名字 |
| 从细节升到全景 | 后果 | 洪水到村口、光到脸上 |
| 借揭纸在两块版之间摇 | 一个状态印在另一个上 | 前后、守住的承诺、两代人 |

取景：黑块压在刻白上，或白压在未刻的黑上，**不许灰对灰**；文字只在纸边。
转场只有两种：硬切（新印张）或揭纸。**不做叠化。**

## 声音调色板

- **乐器**：低弦（低音提琴、大提琴，跳弓与拨奏）、木与皮（木鼓、木鱼、框鼓）、大鼓、定音鼓、一面大锣、合成的敲击金属（模态：3–5 个非谐分音 + 锤击瞬态）；一把锯琴或绞弦琴的持续低音给一点民间色。
- **手法**：故事里那件东西的音色，先扣着不给，等它出现；用节拍转调代替速度跳变；在长衰减里做调式偏移；固定版下面只留一条持续音。
- **拟音跟着材料走**（都可合成）：刀入木（瞬态 + 带通滤波的纤维撕裂，随刀速变）、木屑、滚筒的黏、纸的空气声、马连的沙、湿揭纸；金属按尺寸（大=低，小=高而纯）；有共鸣的物件用模态模型 + 回声给距离。
- **沉默是工具**：近乎无声只留一点环境，或在最响之前留真正的数字静音；静音之后的第一个声音是被挑过的。J/L cut 把声音带过版与揭纸。
- **混音**：音乐在人声下让 ~8 dB，关键拟音也让一点；**拟音同样要在人声下让**。硬瞬态相位甩开中间。整体 −14 LUFS。用 `add_audio` 铺 BGM 与拟音，`tts_narration` 出旁白。
- **人声**：话少、低、平，像把说明念出来；其余交给版。

## 原生手法

- **光是刻出来的**：从一个点炸开一组放射刀路。适合：电网合闸、一个洞见、灯塔修好。
- **刻 = 时间**：把耐心的工作放在画面上，一刀一刀。适合：一年训练、一栋楼起来、学徒出师。
- **镜像的版 → 真的印张**：揭纸时那个反字读正了。适合：投票结果、洗清的名字、被纠正的误会。
- **点凿当质感**：白点可以冻在半空，也可以被墨一点点填回去直到黑干净。适合：城市上空的星一颗颗灭、雨停、地图上的疫区退去。
- **那块唯一的色版铺开又收回**。适合：献血、丰收上的日出、停电里唯一亮着的窗。
- **把雕塑或一帧画面滤成随形体的刻痕**。适合：由照片刻出的真人肖像、一个零件、一张档案图重刻。
- **无字小说的排法**：自足的版面、极少或没有台词，段落之间允许静默。适合：迁徙、罢工、七块版里的一生。

## 变化空间

每一支由 agent 决定：故事、人物（或没有人物）、几块版、开场、结尾、相机路径、节奏，以及那块颜色给谁。

- **三种结构**：一本时祷书（七块固定版，一小时一块，版内不动）；同一块版重刻（一镜比一镜刻得深，形象随木头改变）；两块版轮流印（两个地方交替出印张，最后一张纸上两版都在）。
- **三种开场**：墙上已经挂好的成品印张（然后退回版里看它被刻）；一张白纸（一块上了墨的版压上去，第一幅图整块到位）；木纹（头几刀顺着木纹走，它慢慢变成水或田）。
- **三种结尾**：版被洗净（墨冲掉，剩下浅色的刻木）；一摞印张（同一块版印很多张，越叠越高）；一个没刻到的角（停在刀从没到过的黑木上）。

## 坑

- **白刻痕落在白区上 → 看不见**。改：点凿后面必须有黑块垫着。
- **每个面都排线 → 像毛或下雨**。改：掠射光，只在受光边打 3–6 刀。
- **黑脸配白刻痕，小尺寸读不出**。改：皮肤刻白、五官留黑，白区外围留一道黑保线。
- **手绘特写道具像连指手套和面团**。改：先搭小高度场（胶囊、块、板、皱），再按等照度线取刀路；本工具做不到真实的崩口，就用路径端点的不规则收尾 + 极轻的墨厚不均近似。
- **短刻痕带一点色调摆动 → 变成锯齿人字纹**。改：长刻痕（长度 ≈ 14–50 倍间距）、一条宽高光带、一道细轮廓光、更强的白刀晕。
- **蒸汽或烟压在主体上方 → 读成火焰**。改：画在主体后面，只让几缕漏出来。
- **跨镜头复用同一批刻痕** → 帧与帧之间会突然不一致。改：每幕的刀路现建，不要复制上一幕的刻痕组。
- **细排线 + 墨噪 + 纸纹把画面糊成灰**。改：正式渲染用更高码率，按 1:1 裁切检查；平坦区要么全黑要么全白，中间调只留给排线。
- **干净矩形满幅、墨色均匀** → 一眼假。改：图像永远被纸边包住，四边都吃墨不匀，暗部留几处没吃上墨的白点。
- **把唯一的颜色用在装饰上** → 全片唯一的强调点被花掉。改：色版只在刻白上、只给那一个东西。
