# 图鉴卡（pictogram-catalogue）

> 一部图鉴片：N 个平级条目一张卡一张卡地快闪过去，每张卡只做三件事——一个象形符号做一个动作、一个巨大标题、一行第二语言加一个等宽编号 `07 / N`。
> 参照（只学语法）：1972 慕尼黑奥运会的几何象形运动员、大型综合运动会的「赛会形象」系统（一套模数图案 + 一组颜色用到底）、瑞士体育转播的图形层（等宽元信息、刻度进度条）。只学语法：不抄任何真实赛会的象形、会徽、口号、图案和颜色命名，片子里也不点名它们。

## 本质 / 不是什么

- 本质：**并列清单**，不是解释一个东西的内部结构。N 个条目彼此平级，先后由编号决定；推进感来自「卡数在走」，不来自「论证在深」。
- 本质：**一张卡 = 一个象形符号 + 一个动作 + 巨大标题 + 第二语言行 + 编号**。删掉任意一项，这张卡就不成立。
- 本质：**符号在做动作**。投、切、拉、转、倒——一个动词在一小节里读完；符号没有脸、不做表情、不表演情绪。
- 本质：**网格图案是底噪**。圆盘与半圆盘骑在方格上，整行被横切错位；它证明「这是一套系统」，不承担叙事。
- 本质：**章 = 一种色相**。一个族类占一个色相，每章开头一张满版图案卡，观众永远知道自己在第几章。
- 本质：**一切卡在拍上**。每个镜头起于拍点，每个关键动作（松开、触地、落地）落在整数拍。
- 不是**等距信息图**：没有深度、没有 3D、不拆解内部结构。
- 不是**数据动态**：数字只是标签和编号，绝不当图表画。
- 不是**瑞士编辑**：那条靠版式与字重说话、符号只是配件；这条符号和图案的分量和字一样重。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 整行错位的方格图案 | 半画面大的圆盘骑在格子上，某几行被横切、错开一格 | 开场、章节页、转场 |
| 格里的小纹样 | 四分之一圆、鱼鳞波、点三角鳞、同心弧、太阳轮、棋盘、月牙，按 90° 倍数旋转 | 族群、品类、地区 |
| 圆头杆人形 | 平涂、无脸、圆盘当脑袋，远侧肢体向背景混约 40% | 动作、工种、姿势 |
| 太阳盘舞台 | 人形站在一块相邻色相的大圆盘上，一道极淡的光扫过 | 单品展示、单人动作 |
| 巨大标题 | 900 字重，1080p 下 150–330px，紧字距，自动适配宽度 | 条目标题 |
| 第二语言行 | 紧贴标题下方的重字重行，比标题小一档 | 双语、学名、外文名 |
| 等宽编号 `07 / N` | 角落，等宽字体、宽字距；旁边是 N 格刻度进度条 | 任何清单 |
| 满版图案章卡 | 整屏只有图案，没有字，或只有一个章节词 | 章节切换 |
| 图案退成低对比 | 正文卡上图案压到几乎看不见，只留质感 | 正文卡 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 「人形 + 巨字 + 编号」是保底三件套；真正让它不像 PPT 的是**图案**和**动作**，至少选一个。
- 编号固定为 `07 / N`，两位数补零，N 是整支片子的条目总数，不按章重置。

## 这个风格最俗的版本

- 画面：白底、彩色圆点图标、默认字体的大字、右下角一个 `1 / 8`，图标逐个淡入，结尾「感谢观看」。
- 声音：一首通用励志电子乐，配「叮」。
- brief 的 style 一栏写明翻掉了哪几条，或为什么刻意保留。保留时把力气花在图案、动词和拍点上。

## 适配

- 用途：图鉴式盘点、全量清单、产品线 / 菜单 / 工序 / 物种 / 站点的快速过片；「全套都在这儿」的品牌片。
- 内容：条目平级、数量明确、每条一句话能说清且能被一个动作表达。
- 时长：8–20 个条目最舒服，约 30–60 秒。超过 20 条要开章并启用快放档，否则观众记不住编号。
- 不适合：需要论证因果、需要看内部结构、条目之间强弱悬殊的主题。

## 技术路线

- 一卡一幕：`add_scene` 建幕，`add_element` 放图案层、符号层、文字层、编号层；图案与符号各成一组，方便整组位移。
- 网格：全片一个方格，格高约画面高 1/6；所有尺寸取格的整数倍，错位量取 1/4 格或 1 格。
- 图案先当素材做一张：铺满并左右各多出一格，靠横向位移做错行；章节卡与正文卡共用同一张，只改不透明度与对比。
- 画风落地：`set_theme` / `apply_style` 定色板与字体，别逐元素改色。
- 先看静帧 `preview_frames` 逐拍验字号、编号位置、图案对比；再 `render_preview_clip` 验卡点。
- 符号自己新画就 `upload_asset` 上传 SVG，保持同一线宽、圆头端点。
- 旁白可选：`tts_narration`；字幕 `set_subtitles`；鼓组、拟音、BGM 走 `add_audio`。
- 本工具不做运动模糊：转场靠切点两侧的速度与方向接得上，不做子帧平均。

## 材质与渲染

- 平面填充，边缘干净；不做描边、不做投影、不做渐变，唯一允许的渐变是一道极淡的光扫过太阳盘。
- 颗粒很轻且全片一致，不做动态噪点。
- **图案模型**：底填中暗调；在格点上随机放格半径的圆盘，颜色在同色相五阶里随机；一部分格放「圆盘套圆盘」；再让约一半格子各挂一个小纹样，按 90° 倍数旋转。图案要比屏幕宽，任何一行都能错开一格。
- **人形模型**：以身高为单位、原点在胯；先远侧肢体（向背景混 40%），再躯干、近侧肢体、头。第二个人形压在后面，混 60%。
- 符号的「环境」（水线、网、坡道）留在符号自己的范围里，到文字栏之前用渐变遮罩收到 0。
- 线宽全片一个值、圆头端点；圆盘头直径约为线宽的 2.5 倍，不变。

## 配色

| 用途 | 值 | 说明 |
|---|---|---|
| 底（奶油） | `#F2EBDD` | 浅色相上的字与符号用墨 |
| 墨 | `#171512` | 通吃所有色相 |
| 主色相基阶 | `#D8452F` | 第一族；配深字、圆盘用更浅一阶 |
| 副色相基阶 | `#1C6E68` | 第二族；深色相配奶油字 |
| 强调（暖） | `#E3A02B` | 只给编号或那一格 |
| 暗中性 | `#1E1C19` | 暗底章；圆盘必须用浅一阶，否则会消失 |

- 五色相 + 一个暗中性，每个色相**五阶**（最深 → 最浅，中间那阶是基色）。一章一个色相；多彩章按卡轮换。浅色相配深字深符号、圆盘用更浅一阶；深色相配奶油。无描边、无高光，只有那道光扫。
- 三套示例：暖节庆（红 / 紫 / 林绿 / 金 / 赭）、海岸（藏青 / 青绿 / 珊瑚 / 沙 / 天蓝）、厨房（番茄 / 罗勒 / 藏红 / 茄紫 / 面粉奶油）。自己给色相起名，不借赛会的名字。
- 类型压在图案上时图案走**低对比**；章节卡上**全对比**。

## 字体

- 标题：900 字重紧字距无衬线，1080p 下 150–330px，自动适配宽度；`Inter Tight` 或 `Archivo Black`。
- 第二语言：紧贴标题下方的重字重行，比标题小一档；中文用 `Noto Serif SC` 或 `Microsoft YaHei` 的重字重。
- 元信息：等宽，约 22px，宽字距，放四角当转播 HUD；标签做成等宽小胶囊。
- 编号：等宽 `07 / N`，两位数补零，字号与元信息同级或大一档，固定在右下或左上。
- 文字从遮罩里向上滑出：标题先，第二语言约 0.08 秒后，标签最后；元信息逐字出现、不带光标。短卡按比例压缩全部时序。
- 字幕：章节色相实色条上的一条等宽行，贴底，绝不压标题；≥ max(1.8 秒, 语音 + 0.6 秒)；必须被读的卡（规格、数字）≥ 1.6 秒。

## 运动

- 一个速度定全片；第二速度靠**切分拍**，不靠变速。
- 节奏阶梯：常规卡一小节；同族子项变半长做连发。
- 缓动：入场指数缓出，甩镜与擦除指数进出；回弹缓动全片至多一次。
- 人形入场：横向条带从两侧交替滑入，合上才对位。
- 背景呼吸：图案行交替方向缓慢漂移；章节卡上按拍跳 1/4 格。
- 转场只许网格类：滑行行、下落列、推、从格角开出的四分之一圆、从上一个符号收的虹膜、瓦片翻转。轮流用，每次只占切点前后几帧。
- 切点两侧的速度方向必须接得上；静止的帧就真静止，不给持续微动。

## 画面怎么活

- 生命在「符号那一个动作」和「行的错位」上，不在相机上。
- 每卡只有一个动词；动词一小节内读完，读完就停，停在最有形状的那一帧。
- 图案一直在慢慢动，但正文卡上压到低对比，只在章节卡上全对比。
- 编号与进度条每卡前进一格，这是观众感到「在推进」的主要来源，别让它停。
- 换卡时先让图案走，再让字进来；字没落定就切走，一定读不完。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 固定平帧 | 清晰；卡就是一张海报 | 任何条目；需要被读的规格 |
| 横移，每拍甩一屏 | 同一族的连续性、动量 | 一串站点；产线；路线 |
| 沿一行缓慢漂移 | 从容、浏览 | 画廊；菜单；慢章 |
| 按格行纵向滚动 | 排名、深度、下降 | 前十；楼层；海深 |
| 推进一个纹样格直到它变成下一帧 | 放大看局部 | 菜里的一味；地图里的一座城 |
| 后拉成整墙瓦片 | 一次看全 | 总结；「全部」；对比 |
| 瓦片塌缩成一点 | 多合一 | 合并；共同目标；计数归零 |
| 沿网格线分屏 | 两件并排 | 对抗；前后；两版 |

取景：文字与符号永不重叠（一栏字、一个舞台）；横躺的动作（游泳、匍匐）把舞台往外推、文字栏收窄。HUD 始终在角上。禁止叠化、3D 相机运动、手持抖动、景深。

## 声音调色板

- 字与音乐可以独立撑起全片；人声可选、平稳，每章至多一句。
- **打击是脊椎**：按主题选一套鼓（框鼓、太鼓、行进小鼓、钢鼓、身体打击、电子鼓组），再叠边击、拍手、沙锤、镲片。
- 色彩乐器：Karplus-Strong 拨弦（鲁特 / 筝 / 竖琴类，可带推音）、槌类（马林巴、钟琴）、失谐锯齿和弦、合成贝斯、铺底、上升音、持续低音。
- 每族一个专属拟音（溅、啵、铛、裂、呼、滋）：换章就换材质。
- 卡点：把每卡的入场时刻写进音频事件，逐个对到 ±15 毫秒。
- 沉默也是手段：大击之前半拍抽掉鼓与贝斯；数数时整小节只留一个滴答。
- 混音：胶水压缩 + 限幅，−14 LUFS，≤ −1 dBTP。

## 原生手法

- **一卡一条目**，数量就是钩子（「全部 N 个」）。
- **章 = 色**：族类变成色相，观众随时知道自己在哪。
- **一条目一动词**：一小节内可读的一个身体动作，或一个道具动作（齿轮转、杯子倒）。
- **快放档**：同族子项用双倍速连发。
- **沿轨长镜**：站点一屏一站，每个切点甩一下。
- **数字上冲**：大数字在一小节里滚到值，砸下。
- **图标墙**：所有符号回到网格、统一成一个颜色。

## 变化空间

- 结构：倒计时（N 递减、沿格行下滚、越到后面越快）；符号里的一天（一个人形、一小时一卡、色相从黎明走到夜）；装配（每卡给角落那台符号机器加一个零件）。
- 开场：单个纹样格占满画面再裂成网格；动作已在进行（字砸下来时符号已经在跑）；空白网格先按拍画出细线再上色。
- 结尾：最后一卡停住、图案行逐条停下；最后一个符号走出画面、HUD 一格格里退掉；倒装配（网格拆成行滑走，只剩奶油底）。

## 坑

- **符号的环境漫进文字栏** → 把符号层单独成组，到文字栏前用渐变遮罩淡出到 0。
- **浅色相上用奶油字** → 对比不够。改：浅色相配深字深符号，圆盘用更浅一阶。
- **太阳盘在暗中性上消失** → 圆盘改用浅一阶。
- **图案素材太多、逐卡生成吃内存** → 全片只做有限几张（每章一张 + 一张正文版）复用，别按卡现做。
- **横躺的动作压到标题** → 舞台外推、文字栏收窄。
- **像某个真实赛会** → 自己的色相名、自己的纹样组合、自己的口号，从网格里长出来。
