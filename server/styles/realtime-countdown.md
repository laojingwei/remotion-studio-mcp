# 实时倒计时分屏（realtime-countdown）

> 一整段时间一秒不剪地放：屏幕时间＝事件时间，大号时钟每整秒跳一次带着画面走，格子越近零点越多，零点合成一张。
> 参照（只学语法）：剧集《24》的实时时钟与分屏、纪录片《Apollo 11》(2019) 的多机位档案板与任务时间码。不照搬它们的字体、颜色、声音、图形和镜头，片子里也不点名。

## 本质 / 不是什么

- 本质：**真实时间**。一段连续的事件，不剪、不重排、不加速，慢动作素材按真实速度还原；任何一帧，时钟读数和画面都能互相核对。
- 本质：**时钟是主角**。每整秒跳一次（有声音、有数字下落），它说明谁在掌控，并在零点换状态。
- 本质：**格子显示同一秒**。每个视频格都跟时钟同步，或者明说它没同步（见「同步徽标」）。
- 本质：**版面就是剪辑**。切点＝版面变化；每次版面变化都落在现场声里真实的一句呼叫或镜头里可见的事件上，绝不落在音乐上。
- 本质：**格数就是紧张曲线**：1 → 2 → 3–4 → 6–9（时钟自己变成中间格、字幕占一格）→ 零点合成**一张** → 零点后再散开几格收尾。最短的版面离零点最近。
- 不是 `data-motion`：那是抽象数据图形在讲数，这里主体是拍到的素材，数字只是骨架。
- 不是 `isometric-infographic`：那是画出来的等距小世界，这里是同一段时间的真实素材在实时编排。
- 不是蒙太奇（时间会跳）、不是监控墙（版面从不变化）、不是倒叙（真实时间不能回头）、不是幻灯片（格子里塞满文字、居中标题带翻页）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 主时钟 | T− 读数占一角，每整秒数字下落一次，十段进度条跟着走 | 发射、开庭、开票、开赛 |
| 秒数可对帧 | 画面里发生的事与读数一一对应，观众能倒查 | 任何有「零点」的事件 |
| 格子渐多 | 1 格变 2 格、4 格、9 格，逼近零点 | 紧张累积 |
| 零点合一 | 所有格子同时缩到各自拼图位，化成一张全屏 | 判决、进球、点火 |
| 机位牌 | 每格左上角深色牌：方点＋编号＋中英文名 | 多机位事件 |
| 同步徽标 | 每格右上角「● 实时同步 / ○ 同一时段·未逐帧同步 / 慢动作还原 1×」 | 素材不齐的纪实 |
| 控制条 | 时钟头上几段：谁在掌控，交接时一段填橙闪一下 | 权限、责任移交 |
| 实时字幕 | 逐词浮出的英文行＋方块光标，中文整句落定 | 现场解说、庭审 |
| 计划 vs 听见 | 官方节点按计划时间打勾，现场真说出来时旁边多一个红的「听见 −32.1」 | 时间表 vs 实况 |
| 橙色事件旗 | 黑字橙条从格底滑入，写「ENGINE START · T−6.36」 | 关键动作 |
| 统一调色 | 暗部偏冷、高光微暖，机房和发射台像同一部片 | 多来源素材拼一屏 |
| 零点反色 | 零点前四分之一秒音乐消失，只剩现场声和滴答；零点时钟块橙底黑字 | 结局那一刻 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；表里前两条（主时钟、秒数可对帧）不是可选项，它们是这种风格的定义，其余是选配。
- 信号从事件里选：有档案文件就上「按行的文件」，有呼号交接就上「控制条」；凑不齐就不上，别把格子塞满。

## 这个风格最俗的版本

- 画面：深蓝渐变底、发光蓝色数字从 10 数到 1、背景随机切镜、零点一团白色粒子爆炸加「GO！」、结尾居中 logo 翻页。
- 声音：越来越急的电子滴答＋一段通用的「史诗」弦乐上行。
- brief 的 style 一栏写明这支片子翻掉了哪几条，或者为什么刻意保留。保留时把力气花在「秒数真的对得上」和「零点那一下怎么合」。

## 适配

- 用途：纪实短片、事件复盘、发布倒计时、赛事/开票/庭审的现场型宣传片；不适合纯抽象品牌片、无真实素材可用的题材。内容上**必须有一个可测的零点**和至少两段可同步的画面，没有零点就只能借「同一时段」的壳并诚实标注。
- 时长：30–90 秒最稳（30fps 下每格每 1–2 秒要有新东西）；超过 2 分钟要给两次零点。

## 技术路线

- 本工具：`upload_asset` 收素材，每个机位**先各自转成同一时长、同一帧率**的素材再并排（本工具不做多路 4K 实时同步解码，这条路不承诺）；再做一张同步表——全片一条映射 `M = t − T0`，每个机位一个源偏移 `s = M + c`，一次量好写进表，时间一律由帧号算（`frame / fps`），不靠关键帧叠。
- 版面：`add_scene` 建幕（`split` / `image` / `hero` / `timeline`），`add_element` 放格子矩形、机位牌、时钟块、字幕盒、清单。格子位置变化靠元素动，不靠换幕。
- 画风：`set_theme` / `apply_style` 落调色、字体、转场；字幕 `set_subtitles`；旁白 `tts_narration`；音效与 BGM `add_audio`。
- 验收顺序：`preview_frames` 逐整秒抽静帧，对一遍「读数＝画面」；`render_preview_clip` 看动（尤其重排版和零点合成 0.42 秒那一段）。

## 材质与渲染

- **三种素材同时在场**：同一刻的多机位视频（2–8 路）、文件（事实表、诉状、赛程：当纸拍，绝不重打成幻灯片）、照片（当天的人）。我们自己的字负责解释；素材里印着的字只是画面。
- **我们自己画的数据**：清单、条形、流程/飞行剖面、到下一个节点的二级倒计时。每个数都要有出处。
- **格子**：近黑 `#06080A` 上的硬矩形，外边距 24px，格间距 8–9px，1px 描边 `rgba(222,232,238,.16)`，视频格叠一层轻径向暗角（压到 36% 黑）。不要圆角、不要投影、不要 3D。
- **机位牌**：每格左上，深色板 84%，一个方点（橙＝已同步视频，灰＝未同步/静帧），编号（`CAM 4`、`DOC`、`LIST`），中文名，小号英文名。
- **素材里烧死的字**（台标、机号、计时器、遥测读数）：按镜头划可用区裁掉，或先用于对时再抹掉（本工具：遮罩/模糊一层）。绝不当作我们自己的字出现在画面上。
- **全片一套调色**：对比 1.07、饱和 0.90、gamma 0.97、亮度 −0.01；暗部略冷、高光略暖，让机房和发射台看起来是同一部片；母版加 1 档胶片颗粒。**分辨率**：现代素材最多放大到源像素的 1.5 倍，要推近就在该段用更高分辨率重新出，而不是把 1080p 帧拉大；文件类做到屏幕 1 像素≥源 1 像素。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 地面 | `#06080A` | 格外的黑；面板 `#0B0E11` |
| 主文字 | `#F2F5F7` | 读数、名字、结论 |
| 次文字 | `#7C878D` | 单位、小字、未发生的节点 |
| 橙 | `#FF5B1F` | T− 号、已同步的点、打完的勾、事件旗、控制条当前段 |
| 红 | `#FF3B30` | 说话灯、「听见」标记 |
| 全屏压板 | `rgba(6,8,10,.80)` | 全屏素材上压时钟与字幕 |
| 零点后时钟块 | 底 `#FF5B1F` / 字 `#0A0B0C` | 反色，倒计时改成已过时间 |

橙＝此刻/已同步/已完成，灰＝待定/未同步；除此之外不上色，颜色属于素材本身。

## 字体

- **时钟数字**：窄体无衬线，**每个数字占固定宽度的槽**（本工具：等宽数字特性 `tnum` 或 monospace，逐位摆槽），读数最大 132px；T−/T+ 号 0.85×；十分位 0.41× 且用灰；下面一条十段亚秒条。数字必须逐位定位，否则整块会抖。
- **中文**：结实无衬线（Noto Sans SC 500/700，子集化）；**英文**：干净的 grotesque（Inter / Inter Tight）；**标签、编号、小字英文**：等宽。
- **实时字幕就是字幕本身**：固定盒（右下，或占网格的一格）——说话灯＋说话人类型（解说/现场环/旁白；我们自己的旁白用橙标出，绝不与现场声混淆）；英文按说话时刻逐词出现（每词 0.08 秒淡入＋方块光标），中文在提示点整句落定。**一行一种语言，绝不折行**，长句拆成两条；每条 ≥ max(1.8 秒, 语音＋0.6 秒)。只转写真的说了的话。
- **其他文字的阅读时间**：CJK ÷ 4.5 ＋ 其他 ÷ 15 ＋ 1.5 秒，从「写完那一刻」起算；两个条形/两个数的对比必须整屏停 ≥ 2.5 秒。

## 运动

- 30fps。时钟：每整秒新数字在 0.12 秒内下落 14px（ease-out）；亚秒条每 0.1 秒空掉一段（零点后反向填）。
- 重排版：0.34 秒 `easeInOutCubic`。留下的格子矩形插值；新格子从左边线张开；退出的格子往左收；新格落定时闪一下 3px 橙边约 0.2 秒。网格按呼叫一个个填满时，每开一格 0.30 秒。
- 换源（同一矩形换一路画面）：从左擦入。硬切只用在两个全屏素材之间。
- 照片在其停留期间推近 ≤ 6%；名字每 0.16 秒弹一个。文件窗口按行下移 0.45 秒，高亮从左扫到右 0.35 秒。
- 绝不做：靠缓慢推近假装运动、翻页转场、居中弹出文字、速度斜坡。

## 画面怎么活

- 活着的东西全在「此刻」：时钟每整秒一落、亚秒条在走、说话灯在闪、字幕逐词浮出、清单一个勾往下走。
- 每 1–2 秒必须多一个元素（一格、一个勾、一面旗、一次推近），否则一个十秒的静态大远景就读成平了——**用新元素，不用假运镜**。
- 全屏段落靠底部的压板与渐变（0 → 75% 黑）承载时钟与字幕，画面里其他东西不动。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 分屏格子（格数上升） | 同一刻有很多人在看 | 多机位事件、联合行动 |
| 格子缩到拼图位、合成全屏 | 所有目光收成一件事 | 判决、进球、点火 |
| 时钟块反色 | 时间从「还有」翻成「已经」 | 开票、开门、哨响 |
| 控制条跳段 | 权力/责任交接 | 发射、庭审、比赛 |
| 按呼叫点名的硬推近 | 那句话指向这个细节 | 解说点了名字的部件 |
| 文件窗口按行下移 | 逐条核对 | 时间表、成绩单、条款 |
| 照片轻推 6% ＋ 名字逐个弹 | 这些人在场 | 人物、名单 |
| 全屏＋底部压板 | 退一步看整体 | 关键动作、全景 |
| 二级倒计时沿剖面走 | 下一件事还有多久 | 分离、下一次计票 |

取景：第一帧就要有时钟和一个可读主体；0.5 秒内出现第一次版面变化；零点前后用最短的版面；合成全屏那一镜不许中途再动版面。

## 声音调色板

层次从上到下：
1. **现场声**：事件自己的声音（解说、无线电、人群），高通 90Hz、压缩，**永远在最上层，绝不被压**。
2. **旁白**（克制，只填在现场声的空隙里，绝不同时压着说）：干净、贴耳，性别或口音与现场人声不同；每一句都过一遍实际语音校对。
3. **时钟**：每整秒一声滴答（两个音高交替，1.5–1.9kHz，左右各偏 15%），最后十秒更响；零点后换成一声柔和的单音。
4. **界面拟音**：重排版 whoosh＋金属扣合、开格咔、清单 tock、事件旗 whoosh、全屏切换的闷响。
5. **配乐**：60 BPM，一拍＝一秒＝一次滴答；低频合成持续音，滤波器随零点打开；每拍一记底鼓、反拍 hat、每数一个数一记 tom、进零点前定音鼓滚奏；**零点前四分之一秒全部消失**，只剩现场声和时钟；零点落一记低铜管大三和弦＋底鼓＋镲＋管钟；零点后换织体（拨弦固定音型、更轻的滴答）。只用低铜管、定音鼓、tom、管钟、钟琴，不要钢琴加弦乐的铺底。
- 混音：音乐比现场声低 8–10dB，说话时再压；点火（或事件本身的高潮声）是全片最响的一点；整体 −14 LUFS，混音前先在归一化后限到约 −4 dBFS，别让广播热峰爆表。
- **换音乐**（用别人的曲子也一样）：绝不为音乐挪时钟或切点；挑或拉一首让重拍正好落在零点、段落变化落在 T−10，并保留零点前那四分之一秒的静。

## 原生手法

- **多合一**：零点时每格移到自己那块拼图位（3×3 就是九块 640×360），同时交叉淡到同一张全屏，机位牌和描边在前半段消失，一层暖白光（`rgba(255,248,236,.7)`，衰减 τ≈0.11 秒）冲到最亮，时钟与字幕从格子里滑回底部。0.42 秒。适合：判决念出、终场哨的那一球。
- **时钟反色**：零点钟块由「暗底橙 T−」翻成「橙底黑 T+」，标题从「倒计时」变「已过」。适合：开票、开门。
- **控制条**：时钟头里分段表示谁在掌控（地面→载具→指控；控方→陪审→法官）；交接那句一响，该段填橙并闪一下。故事的所有转折住在这里。
- **按数填格**：空格先显示虚线 standby 框，每说出一个数字开一路机位。适合：「三、二、一」。
- **同步徽标**：每格右上——`● 实时同步 LIVE SYNC`（已同步）/`○ 同一时段·未逐帧同步 SAME WINDOW`（斜纹灰，同几分钟但没有可用时钟）/`慢动作还原 1× REAL-TIME`（慢动作已还原）。诚实是这种画风的一部分。
- **计划 vs 听见清单**：官方节点带计划时间，时钟走过就打勾；现场真说出来时，旁边出现红色「听见 −32.1」和一小段波形。适合：庭审日程 vs 实际发言、列车时刻 vs 站台广播。
- **二级倒计时**：零点后一块小钟数到下一个官方节点（`−1:47 到助推分离，预计 T+2:09`），沿一条按时间（不按距离）画的示意剖面走。
- **事件旗**：橙条黑字在那句呼叫时滑入相关格底（`RS-25 ×4 启动 ENGINE START · T−6.36`），至少停够阅读时间。
- **按行看文件**：纸面特写只露两三行，纸下一条高亮条＋一层注释带翻译这一行；窗口只在行与行之间移动（接缝落在空白处）。
- **点名推近**：解说说出某处时硬推近那一块，用同一素材更高分辨率的版本。

## 变化空间

每支由 agent 决定：事件、真实时间的起止、机位数量、放哪些文件与数据、控制条分段、旁白有无、收尾版面。

- **时钟**：T−/T+；比赛计时；新闻日的墙钟 HH:MM:SS；到截止时间后改成「超时」往上数。
- **三种结构**：格子渐多到合一（本型）；零点后一格向外裂开（多地出结果）；两条倒计时并排同时归零（两队、两城）。
- **三种开场**：一个全景加第一句呼叫；黑底上只有时钟，第一格随后打开；一份日程文件，第一条开始打勾。
- **三种结尾**：反色时钟压在一张全屏上；格子重新填满「后果」，最后一格换成标题；二级倒计时走到它自己的零。

## 坑

- **素材无法同步**（剪过的「精华」片、没有时钟也没有可对齐的事件）→ 绝不硬凑：标「同一时段·未逐帧同步」，把它排除在倒计时的关键秒之外，或者只用在不会和时间打架的地方，并在事实表里写明。先去找带烧录计时、有点火闪光/哨声、或有同一路声音的源。
- **零点靠猜**（信元数据）→ 用两个独立标记互相验证：一个可见事件（点火闪光、台标倒计时翻转）＋一句话的时间点（零点上的那个词），并且在实际用的那份文件上重测。
- **源本身的时基不对**：切换过的信号源声音可能比画面慢约 1 秒，逐机位按**画面**对同步；慢动作素材要用两个已知间隔的事件测出倍率（如发动机启动到助推点火 6.36 秒）再整体还原成 1×。
- **素材里烧死的字**（台标、机号、计时器、遥测）→ 按镜头划可用区或抹掉；源里每次切换机位可用区都会变，逐段核。
- **十秒不动的大远景**→ 读成平。每 1–2 秒加一个新元素（一格、一个勾、一面旗、一次推近），不要假运镜。
- **字幕剧透**→ 一整句中文会提前泄露「数到几」。把倒数拆成独立提示，一句一个数。
- **时钟抖动**→ 用了比例字宽。必须固定字槽逐位画。
- **热峰爆表**→ 广播声和点火那一下最容易过真峰；先归一化到 −14 LUFS 再限到约 −4 dBFS。
- **零点没有「安静」**→ 少了零点前那四分之一秒的静音，合一就只是又一个转场。
