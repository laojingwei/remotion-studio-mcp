# 视觉调查（visual-investigation）

> 一张冷调调查台：画面、照片、证词、报告行、声音从同一件真事里来，摊在同一个钟上互相对质，时间轴长在画面里。
> 参照（只学语法）：报纸的视觉调查片、法证建筑式重建、电视台核查组的核验段。不照搬、不点名、不用它们的台标与包装。

## 本质 / 不是什么

- 本质：**来源汇合**。每一节的落点是两条以上互相独立的证据（一帧画面、一张照片、一句证词、一行报告、一个声音）指向同一个位置或同一秒；**切点就是同步点**。
- 本质：**一个钟，读在画面里**。时间是版式的一部分：每张电报卡自带时间戳、数据图上一根带时钟的播放头、关键几秒上方一个 `T+xx.x` 秒表、冻住的一帧标"32 秒"。钟的尺度随故事走（小时 → 分 → 秒 → 天），**只在段落切点换**。
- 本质：**一版一个发现**。标题是版式的一部分，永远不是页眉。
- 本质：**不确定是画出来的，不是嘴上道歉**：`≈`、*推断*、*示意*、虚线框；已知与未知分两栏；某路来源还没开始就**先不在画面里**，让它晚点点亮，而不是留个空槽。
- 本质：**克制**。真灾难、真人：不给灾难慢放，不用音乐叫人该有什么感觉；火只在证据框里；伤亡是数得清的点与数字。
- 不是 **data-motion**（那是图表自己长大、讲一个量）：这里图表只是证据之一，主角是几路来源在时间上对上。
- 不是 **engineering-board**（那是把候选拿去撞限制、比出结论）：这里不比方案，只核对同一件事的多个版本。
- 不是 **sports-telestrator**（那是先放完再冻帧拆一个动作、有演播室包装和情绪）：这里没有台标、没有解说腔，只有证物和刻度。
- 不是卫星简报（无轨道影像、不从太空推近）、不是看片台（无纸压玻璃、放大镜、手：文档是平的证据框）、不是网点档案（无油墨肌理、印章、拼贴）、不是新闻简报包（无角标、滚动条、主播）、不是发布会（无居中标题页、无翻页）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 同一个钟，换形状 | 卡片时间戳 + 图表播放头（分）→ `T+` 秒表（秒）→ 日期（天），切点处换形不换位置 | 从一周缩到一分钟的事 |
| 三栏同步栅格 | 报告 / 照片 / 视频并排在一个大秒表下，谁开始谁白闪切入，栅格从左往右填满，同步点横一条红虚线 | 两台行车记录仪 + 一份警方日志 |
| 硬同步点 | 所有来源都认得的那一瞬（撞击、闪光、公共钟、枪声峰值）对齐；晚开始的来源就晚出现 | 谁的手机先开始拍 |
| 冻帧 + 圈 + 引线 | 白闪冻住，2.5px 红圈顺时针画满 0.5 秒，到 60% 引线带粗体标签出现，旁边开 ×2 放大镜 | 监控里的车牌、焊缝的裂纹 |
| 电报按时间落位 | 排好的电文卡带摩斯与打字声落在各自时间戳，红色虚线引线牵到图表轴上的针脚 | 聊天记录、空管通话、邮件 |
| 地图 → 平面图 | 实测地图推进到现场，切到带方位、距离环、机位点与推断视锥的平面图，地图缩成定位小图 | 每个证人站在哪 |
| 证据 → 模型连线 | 每路来源里的圈都拉一条红虚线到同一张示意图的同一区域，✓ 徽章间隔 0.12 秒落下 | 火从哪个房间起 |
| 已知 / 未解 | 两栏，勾选框对虚线框，每一项整块停 ≥ 2.5 秒 | 任何调查的结论 |
| 点阵数人 | 一人一点，死者一个个变成红色空心环，旁边一个大数字 | 乘客、工人、任何事件的受害者 |
| 声称 vs. 记录 | 先放当年的说法（原声），再落核查卡，把错字划掉 | 新闻稿对上报的数字 |
| 证据地图 | 平面图 + 断轴迷你时间线 + 示意图 + 所有来源缩略图，红线全部汇聚 | 调查的收尾 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；永久的底部时间轴带是**可选项，而且通常是错的**：它吃掉画面下沿、加一层小标签，故事一离开钟就空在那里。
- 来源必须是真素材（用户自己的、可授权的档案）；**不许生成一张图去顶替历史影像**。

## 这个风格最俗的版本

- 画面：黑底、满屏红色圆圈和箭头乱指、底部一根常驻时间轴、右上角一个假台标、结尾一句"真相仍在调查中"。
- 声音：一记低沉 boom 反复砸，加一段悬疑弦乐不停推。
- brief 的 style 一栏写明这支翻掉了哪几条，或为什么刻意保留。保留时，把力气花在"两路以上来源对上同一秒"和"钟换形状"这两件别人不做的上。

## 适配

- 用途：事故复盘、调查报道、争议事件的科普、任何需要观众自己核对结论的片子。
- 内容：有多个版本的说法、有可对齐的时间、有可看的原始材料。
- 时长：60–180 秒最舒服。每节只放一个发现，30 秒内必须完成一次"对上"。

## 技术路线

一幕一个发现，用 `add_scene` 建；每一路证据是一个硬边面板，用 `add_element` 放图片/形状/文字，按原比例不拉伸；圈、引线、栅格用形状与线元素画在素材之上，与素材同帧同坐标，不脱离。
先 `preview_frames` 逐拍看静帧（一帧是否只有一个发现、字是否读得完），再 `render_preview_clip` 看动（切点是否落在同步点、秒表是否匀速）。
画风用 `set_theme` / `apply_style` 落地灰度 + 单一红；旁白 `tts_narration`；字幕 `set_subtitles`；素材 `upload_asset`；原声、拟音与底噪 `add_audio`。本工具没有滤镜链：去隔行、去边框、放大、灰度、颗粒必须在导入前做好，或由统一覆盖层完成**一次**；不承诺真 3D 视差、不承诺逐帧运动模糊。

## 材质与渲染

- **至少三类来源**：活动影像（新闻片、监控、手机视频、发射机位）、文档（证词、备忘、电报/电传、报告页）、照片。有声音（现场解说、电台、录音）、数据（气象、遥测、计数）、地图就都加进来。
- **文档**：扫描页按条或按页原样呈现，绝不重画；只高亮决定性的那一行（红、`multiply`、α ≈ 0.6、从左往右擦出）。只以转录形式存在的文字（报告、无线电报）由排版重新排出，并标明是转录。
- **档案画面**（1950 年前胶片，放大 ≤ 约 2.5×）：去隔行 → 切边 → 去块 → lanczos 放大 → 轻微锐化 → 灰度。现代素材 ≤ 1.5×。**绝不用上色版或"修复版"**。
- **一套调色**：影像与照片 `grayscale(1) contrast(1.22) brightness(0.94)`；纸 `grayscale(1) contrast(1.05) brightness(0.86)`（白页压成浅灰）；地图灰度反相 `brightness(.62)`，读成深色线描。
- **一套颗粒**：六张 256² 高斯瓦片逐帧旋转，`overlay`，影像/照片 α 0.22，纸 0.10。颗粒**只在素材上**，不在字和线上。
- **画出来的证据**（平面图、侧视示意、图表、点阵）是面板底色上的细线，没实测过就标 *示意*。去掉台标、水印和原片自带的片头卡。

## 配色

| 用途 | 值 |
|---|---|
| 底 | `#0B0C0E` |
| 面板 | `#141619` |
| 细线与框 | `#2E3238` |
| 文字 | `#ECEAE4` |
| 次级文字 | `#8B9097` |
| 刻度、*不确定* | `#4A4F57` |
| **唯一的强调：这里 / 此刻 / 对上了** | `#FF4A2E` |
| 纸卡（排出的电报） | `#E4E0D4`，墨 `#1D1D1B` |

来源全是灰的；红是唯一的颜色，而且只用来**指**：圈、图表播放头、同步线、高亮、✓ 徽章（红框里一个画的勾，不带字）、大家汇聚的那个区、*未解*那一栏、把错误说法划掉的那一道。

## 字体

- 中文标题与发现：Noto Sans SC 700（30–124px）；标签、时间码、刻度：等宽（IBM Plex Mono 400/600，本工具用 monospace 兜底）。引语：原文用衬线斜体（Source Serif 4 Italic / Georgia Italic），中文译文在其下一行用 Noto Serif SC 500、次级色（只在字幕没说的时候才加）。
- **每帧少字**：只留这一拍要的东西——主读数或标题、被高亮的原文、每件证据一个短来源标签。不要眉标、不要每个中文标签下面配英文、不要档案号、日期、"估计/示意/不按比例"的脚注（除非这一拍说的就是这个），也不要字幕正在说的同一句话。
- **来源标签**：6×12 的色块 + 等宽`类型 · 来源`，≤ 约 12 字（`照片 · Pasquarella`、`FBI 电传 · 1937-05-08`），紧贴在自己的框上方。完整出处放尾卡，不放面板上。
- **下三分之一**：一条红杠 + 地名（36px 粗体）+ 一行等宽（地点代号）。
- **字幕**（双语片）：画面底部（中文基线 y ≈ 984，英文 y ≈ 1022）：中文 34px 粗体压英文 23px，居中，10px 黑投影；**每种语言一行**，按 1500px 宽量；长句拆成两条。原声也要字幕，标 `【原声】` / `[1937 新闻片]`。
- **阅读时间**：关键文字整块静止 ≥ 中文 ÷ 4.5 + 其他 ÷ 15 + 1.5 秒；判决帧与对比帧停 ≥ 2.5 秒且每项完整在框内。计数器（时码读数、秒表）与刻度标签不受此限。

## 运动

- 30fps。元素**切进来**（≤ 0.1 秒不透明度），配 3–4 帧白闪，像从证物柜里抽出来；什么都不飞、不弹、不缩放冒出。
- 只有**画出来的**才有过程：圈 0.5 秒顺时针画满（ease-out cubic），引线与连线 0.4–0.8 秒，平面图一笔一笔描，高亮擦出，电文用打字机逐字。
- 框内允许慢推（地图 ≤ 1.9×，照片 ≤ 1.06×）；"相机"本身不动，版式靠切点换。
- 事件钟（图表播放头、秒表）在关键帧间缓动，计时段内匀速（每跳一格 = 真实一秒）。
- 尺度变化（分 → 秒 → 天）只发生在段落切点，靠读数**换形**承担（时钟 → `T+` 秒表 → 日期），不靠一根缩放的带子。每 1 秒内必须有东西变；静止只留给判决。

## 画面怎么活

一场"对质"：先摆出这一节要核的那一秒 → 来源一个个切进来（晚的就是晚的）→ 在同步点冻住、横一条红虚线 → 圈出各自看到的同一处 → 拉线汇聚到示意图的同一区（✓ 依次落下）→ 落一个发现，停 ≥ 2.5 秒读得完 → 钟换形状，进下一节。
版式永远是硬的：1920×1080，边距 60px，内容占满 y 60–900，字幕在其下（y ≈ 950–1030）；**没有任何一根带给时间轴预留**。没有字幕的一节，内容垂直居中。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 硬切换版（0.5 秒栅格上） | 又一件事、又一路来源 | 全片基本语法 |
| 冻帧 + 圈 + 引线 + 放大镜 | 这里，就是这一处 | 车牌、裂纹、手势 |
| 三栏同步栅格从左往右填满 | 谁先开始、谁晚到 | 多机位同刻 |
| 图表播放头横推 | 时间在走、事件有先后 | 停电前的负荷、风切变 |
| 地图推进再切平面图 | 从"在哪"到"谁站在哪、看向哪" | 现场空间关系 |
| 两栏判决（已知 / 未解），整块停住 | 让你自己核对 | 任何结论 |
| 红线全部汇聚到证据地图 | 收束、一次看全 | 结尾海报帧 |
| 倒带（画面反向 + 扫描线） | 回到开头重来一遍 | 冷开场之后 |
| 慢推（照片 ≤ 1.06×） | 靠近看，但不表演 | 一张静态证人照 |

避免居中版式、页眉、翻页感的转场；转场是硬切、白闪与倒带，**没有叠化**。

## 声音调色板

1. **底**：低音 D 由低音提琴与大提琴持续；一层滤过的房间底噪，比人声低约 30dB。
2. **钟**：以分为尺度的段落每 0.5 秒一记摆钟；关键的等待段更响；计时段每个**事件**秒一记（每 5 下重音）——听得见的秒表。
3. **和声**：慢段落下一层弱拨弦固定音型（八分音符，Dm – B♭ – Gm – A）；紧张处小二度颤音簇；判决栏用慢持续和弦；证据地图用带颤音琴的 D 小调 add9 解决。
4. **拟音**：纸（文档）、快门（照片）、摩斯"滴"与按键（电报）、电传声、倒带扫频、铅笔划（画平面图）、撞击那一记深沉的闷响——然后近乎无声。
5. **原声**（档案解说、电台、录音）：带通 180Hz–5.5kHz，稀疏噼啪，以波形 + 红色播放线 + 逐词点亮呈现；音乐在原声下压 −12dB。原声与配乐轮换，绝不同时大。
6. **人声**：平稳、不煽（沙哑或清亮的男中音均可），音乐下压约 −9dB；整体 −14 LUFS，真峰值 ≤ −1.2 dB。

## 原生手法

- **冻帧、圈、放大**：白闪冻住画面 → 2.5px 红圈顺时针画满 → 到 60% 引线与粗体标签出现 → 旁边开 ×2 放大镜，从同一份源像素裁出（绝不超过 1 源像素对 1 屏幕像素）。适合：监控里的车牌、焊缝的裂纹。
- **硬同步点**：挑一个所有来源都认得的一瞬（撞击、闪光、公共钟、枪声峰值），把各路对齐；晚开始的来源就让它晚出现；这个差如果重要，用旁白或字幕说出来。适合：哪台手机先开始拍、发射机位何时跟丢。
- **三栏同步栅格**：文档 / 照片 / 视频并排在同一个大秒表下，谁开始谁白闪切入，栅格随钟从左往右填满；在同步点冻住，横一条红虚线穿过三幅画面。适合：两台行车记录仪 + 一份警方日志。
- **读数换尺度**：时间读数在每次段落切点换形——卡片时间戳与图表播放头（分）、`T+` 秒表（秒）、日期（天）——故事在收窄或放宽。可选：只有全片始终在一个钟上的片子，才用底部按来源分轨的时间带，不带标签，钟一停就撤。适合：从一周缩到一分钟的一次崩盘。
- **倒带冷开场**：先从决定性的冻帧开始，把其它来源砸进栅格，扫一条同步线，再倒带（画面反向、扫描线）回到开头。适合：任何重建。
- **电报按钟落位**：排好的无线电报/消息带摩斯与按键声落在各自时间戳，红色虚线引线把每张卡牵到数据图轴上的针脚。适合：聊天记录、空管通话、邮件。
- **带播放头的数据图**：横跨画面下半的一张图（风、速度、温度），时间轴 + 事件带（风暴、停电）各用一个词标注，加消息针脚，红色播放头携带时钟。适合：停电前的电网负荷。
- **地图 → 平面图**：实测地图推进到现场，切到带主体位置、方位、距离环、机位点与推断视锥的平面图；地图留作定位小图。适合：每个证人站在哪。
- **证据 → 模型连线**：每一路里画的圈都拉一条红虚线到同一张示意图的同一区域；✓ 徽章间隔 0.12 秒落下，配轻轻的木槌音。适合：火从哪个房间起。
- **当年 vs. 记录**：把当年的说法当原声放，再落核查卡，把声称里错的词划掉。适合：新闻稿对上报的数字。
- **已知 / 未解**：两栏，勾选框对虚线框，每项整块停 ≥ 2.5 秒，整块板只挂一个来源标签。适合：任何听证的结论。
- **点阵数人**：一人一点；死者一个个变成红色空心环；旁边一个大数字。适合：乘客、工人、任何事件的受害者。
- **证据地图**：平面图 + 断轴迷你时间线 + 示意图 + 每路来源缩略图，所有线汇聚——海报帧。适合：任何调查的结尾。

## 变化空间

每支由 agent 决定：事件、来源、同步点、钟要经过哪些尺度、版式、开场与结尾。

- **三种结构**：决定性一帧冷开场 → 倒带重建；一个问题（"从哪开始的？"）一路来源一路来源地回答；严格时钟（T−10 分 → T+1 小时），发现在发生的时刻落下。
- **三种同步点**：撞击或闪光那一帧；在几段录音里都听得到的声音峰值；一个公共钟或报时信号。
- **三种结尾**：证据地图；已知/未解板留在画面上；回到开场那一帧，此刻已被标注满。
- **其它题材**：交通事故（行车记录仪、监控、警方报告）、抗议现场（手机视频、照片、陈述）、体育里的争议判罚（多机位、规则手册）、发射失败（跟踪相机、遥测、事故报告）。

## 坑

- **把推断当事实**：机位、照片时间、时间偏移，必须在画面上和稿子里都标 `≈ / 推断 / 位置不明`。**把早期报道当事实**同样致命：头一晚的备忘与当年的新闻片常与最终报告不一致；只能当影像用、当待核的说法用，**绝不能当数字的来源**。
- **假造多机位事件**：只有一份可授权影片时，不许借用来源不明的片段；改用 影片 + 照片 + 文档 + 声音 交叉核对，结构一样成立。
- **"连续"镜头里的接缝**：曝光跳变或 splice 会毁掉计时；时长取官方记录的数值，并把对齐误差说出来。**时区与钟**：旧报告可能用标准时，而当地实行夏令时；选定一个，在画面上一处说明（第一次读数就写 `18:25:00 EST`）。
- **一次塞太多**：一版一个发现；一块板最多五路来源；字幕绝不逐字重复标题。**画面字太多**：只留这一拍要的（主读数或标题、被高亮的原文、每路一个短标签）；眉标、双语并列、档案号、脚注、字幕已经说过的译文，都会把画面变成噪音。
- **为缺失素材留空框**：灰底"无素材""等待照片"的面板看起来就是渲染坏了。填真材料、换版式，或让那路来源到它开始的时候再出现。
- **底部预留一条带**（时间轴带、说明轨）：没内容时就是一条空带。内容做到 y ≈ 900，字幕区（y ≈ 950–1030）不放任何东西。
- **把灾难当奇观**：不给火与撞击慢放，不整屏火焰，不给死亡配声效。
