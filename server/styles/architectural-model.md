# 白模投影（architectural-model）

> 暗房里一座纯白的实体模型站在台座上，一台投影机把数据当光刷上去：一层一层来，只亮朝向它的面，稍微溢一点到台座上。模型永远不变，变的是落在它上面的光。
> 参照（只学语法）：城市展馆里投在规划模型上的投影（暗房、柔和投距、颜色只落在白面上）、模型微距摄影（屋顶高度的浅景深）、编辑型数据图表（每层一个数字、一条标签、一处出处）。不照搬它们的版式、字体、配色与音乐，也不在片子里点名。

## 本质 / 不是什么

- 本质：**模型是真实地点的真实几何**——建筑轮廓与高度来自公开数据，按**注明比例（1:1000、1:2000）**挤出。模型上没有一处是编的、"代表性的"，也绝不用生成图顶替这个地点。
- 本质：**模型是白的，数据是光**。颜色从不画进材质：它被投上去，所以只让朝向投影机的面变亮，背过去的面暗掉，到投射边缘就停，往外溢一点点到台座上。
- 本质：**层一层一层到**，每层有自己的光的动作（一片漫开、一栋栋点亮、一个标高往上爬、太阳走表），且每层回答上一层提出的问题。
- 本质：**它是一间真实的房间**——家用灯、一台会亮会灭的投影机、一个台座、周围的黑暗。灯灭是数据的开头，灯亮是结尾；屏幕上每个数字都由桌上这批建筑算出来。

**和库里的近邻怎么分**：`exploded-teardown` 拆的是产品零件，靠拆解讲结构；这条一个零件都不拆，讲的是**建筑体量与城市街区**的尺度与规划。`soft-3d-toy` 是玩具质感的圆润 3D、有塑料高光；这条是纸/石膏/白卡的**素白模型**，只有哑光没有高光。`tilt-shift-miniature` 靠移轴把真实场景做成微缩；这条的场景本来就是造出来的实物模型，靠**投影与贴上去的标记**说话。

不是等距信息图（没有沙盘图标）；不是低多边形小岛（没有编出来的地形）；不是科幻全息 HUD（没有线框，光落在实体上）；不是卫星简报（没有影像）；也不是激光扫描或点云片（没有扫描线，光是投出来的，不是量出来的）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 素白模型 + 暗房 | 只亮一块，周围全黑，台座接住一点点光 | 城市规划、地块、建筑 |
| 一栋栋点亮 | 建筑带一记短闪依次亮起，其余仍是白的 | 增长、分期、逐年落成 |
| 投影的溢出 | 光到投射边缘就停，稍微漫到台座上，墙的背面暗下去 | 一切（这是光的签名） |
| 空洞 | 只点亮满足条件的那一批，用缺席画出形状 | 战损、洪泛区、一家公司持有的地、保护区 |
| 标高上爬 | 一层软光在每面墙上同时往上爬，矮的先到、高的后到 | 高度、限高、楼层、水位 |
| 太阳走表 | 真实日期时间里影子扫过，投影随后描一条影子去量 | 日照、遮阴、屋顶光伏 |
| 贴上来的标记 | 从屋顶或地面一点拉一根发丝线，到暗底上的小标签 | 单体、地块、一栋被点名的楼 |
| 读数栏 | 左三分之一：序号 + 层名、一个数字、一行出处、一条图例 | 层层递进的数据 |
| 比例与身份行 | 左上角安静一行：地点、1:1000、数据来源 | 可信度 |
| 灯灭 / 灯亮 | 继电器一响全黑；结尾白模重新被家用灯照回白色 | 开场与收尾 |
| 一栋单独被挑出 | 全场暗着，只有一栋亮着，带一个标记 | 文保建筑、待售地块、医院 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 「一栋栋点亮」「空洞」「太阳走表」最好认，也最容易被用滥——第二支片子换一组信号。
- 信号必须由**手上这份数据真的有**的属性驱动；没有建造年份就换高度、占地面积、分区、边界或日照，**绝不编一层年份**。

## 这个风格最俗的版本

- 画面：深蓝底上一座会发光的城市模型，一束蓝光横扫全城，"未来城市"四个字压在画面中间，粒子往上飘。
- 声音：科技感 pad + riser + 一记 whoosh。
- brief 的 style 一栏写明这支片子翻掉了哪几条，或者为什么刻意保留。保留时把力气花在**真实几何**和**唯一的那一处光**上。

## 适配

- 用途：城市规划、地块开发、交通/防洪/日照这类要"看见体量"的主题；建筑与地产；数据新闻的空间版。
- 内容：有一个真实地点、有可公开的轮廓与高度、有一个能用光照回答的问题。
- 时长 20–60 秒最舒服；超过 90 秒拆成两段，各给一次灯灭与灯亮。拿不到数据就换主题，或明说"这是示意体量"；不许把示意图说成实测。

## 技术路线

- 3D 主体：`add_scene type="scene3d"`，先 `get_guide("scene3d")` 看节点写法，再逐节点搭：底板 → 台座 → 城市网格 → 家用灯（第 0 盏）→ 太阳（第 1 盏）。几何只有组合体（box / plane / cylinder 一族），**外部模型文件读不进来**：轮廓与高度按公开数据在 scene3d 里挤成体量，或先在外部烘成贴图/剪影再 `upload_asset` 当参考。
- **挤出规则**：每栋按轮廓（含洞）从地面标高挤出到屋面标高，**1 单位 = 1 模型米**；1:1000 时 1 米 = 1 毫米，1:2000 时减半，比例必须写在画面上。屋面高取高度字段（如 3DBAG 的 70 分位高），地面高取场平字段；只有层数没有高度时按**每层 3.0 米**折算，并在画面注明"按层数折算"。
- 数据门槛：优先找本地已有的开放 3D 或"轮廓带高度"数据（3DBAG 荷兰 CC BY 4.0、PLATEAU 日本 CC BY 4.0 兼容、各城市开放数据门户的轮廓+高度/层数/分区/规划）。CC0、公有领域、CC BY 可用（CREDITS 与画面都要署名）；OpenStreetMap 与 Overture（ODbL）、CC BY-SA、"no known restrictions" 不是 CC0——**先把条款讲给用户听，问过再用**。用户自己的项目就找用户要（规划图、城市模型、实测高度）。
- 相机：`camera` 的 position / target / fov + 关键帧，或 `orbit.degPerSec` 慢速环绕；关键帧单调，不停死、不过冲。灯光：一盏柔和主光 + **中性**影棚环境（不要暖 HDRI）+ 近景 AO，太阳是真实 directional light 带阴影贴图，按纬度与真实日期时间算方位/高度角。
- 投影层：白模材质上加一个"投影项"——`色 × (0.42 + 0.58 · max(N·指向投影机, 0)) × 投射遮罩`，再乘反照率，水面上减弱。**不是贴在网格上的贴图**。每栋的属性（年份、高度、排序、标记位）挂在顶点数据里，逐帧由这一项决定投影给它什么颜色。
- 后期：`post` 里 bloom 只喂投影高光之上、vignette 轻压。景深本工具不给开关，用**把相机贴到屋顶高度、让前景吃掉画面下缘**造浅景深。GTAO 只在近景开。
- 2D 层只有读数、标记、量线、字幕：`add_element` 按 world→screen 定位，逐帧对锚点。
- 验收：`preview_frames` 逐拍看静帧（重点看墙面法线和投影落点）→ `render_preview_clip` 看动。色与字先 `set_theme` / `apply_style` 定死；旁白 `tts_narration`、字幕 `set_subtitles`、音效与 BGM `add_audio`、底图与纹理 `upload_asset`。
- 项目里留一份来源清单（说法、URL、原文引述，或量法），随片交付；屏幕上每个数字都由同一份数据算出来。

## 材质与渲染

- **模型**：哑光白 ≈ `#F3F3F1`，roughness ≈ 0.9，边缘干净；水是底板上一块更深的缎面嵌块；桥是低矮的白板；一块薄底板坐在深色缎面台座上。反照率就是数据本身，不靠贴图加脏。
- **光模型**：家用光 = 一盏柔主光 + 中性影棚环境 + 近景 AO；投影 = 只在受光面上加的那一项（见「技术路线」），靠反照率缩放，水面上减弱。
- **太阳**：真实方向光带阴影贴图。投影可以**描**出太阳的影子（填色 + 描边）并去量它，但绝不许伪造一个影子。
- **后期**：物理景深（近景更明显）、bloom 只在投影高光之上、vignette、轻颗粒。
- 只有 2D 层用屏幕空间：读数、标记、量线、字幕走相机 world→screen，永远钉在模型上；发光、量线这类世界里的东西按 3D 点定位。白模发米黄 = 用了暖色 HDRI，换中性影棚环境。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 暗房 | `#08090B` | 周围的黑，永远最暗 |
| 台座 | `#17181B` | 深色缎面，比暗房亮一档 |
| 白模 | `#F3F3F1` | 素白纸/石膏，反照率 ≈ 0.9 |
| 投影黑位 | `#10161C` | 投影机落在底板上的冷近黑 |
| 例外色（旧 / 例外） | `#E9A13B` | 单一分类强调色：那时候就有的、某一方持有的 |
| 时间坡 | `#2E4E7C` → `#58C4DE` → `#F3F3F1` | 蓝→青→白，连续时间数据 |
| 高度坡 | `#5B3B7A` → `#B4537E` → `#F0B49A` | 紫→品红→桃，连续高度数据 |
| 日影蓝 | `#2B3E5C` | 太阳照不到的地方，被投上去的深蓝 |

- 每层只用**一个色系**：分类用单一强调色，连续数据用顺序色阶。一个颜色**只能带着同一个含义回来**（"之前"那色后来再出现，指的还是同一批建筑）。
- 太阳来的时候把数据色收走：太阳是暖的，它的影子是投上去的深蓝。家用光下不许给模型上色；同屏最多两套层的色板。

## 字体

- **数字**：轻体无衬线 `Inter Tight` 200，120–140px——它是画面上最大的东西。
- **标签与仪表**：本片语言的无衬线（中文 `Noto Sans SC` 300/500，20–36px；兜底 `Microsoft YaHei`）；年份、坐标、编号用等宽（`IBM Plex Mono`，18–22px），位数对齐，读起来像量出来的。
- **读数在左三分之一**，每层一条：序号 + 层名、一个数字、一条标签、一行出处、一条图例条。
- **标记**：从屋顶或地面一点拉一根发丝线到暗底上的标签（标题 26px + 一行副标 20px）。锚在**建筑最高处**，不在轮廓质心。
- **身份行**：左上角安静的一行——地点、比例、数据来源。
- **字幕**：底部居中，软暗渐变上，无框；双语时本片语言在上，每种语言一行，宁可拆成两条也不折行。1080p 下不小于 18px。
- 阅读时间：字幕 ≥ max(1.8 秒, 语音 + 0.6 秒)；标签 ≥ 字数÷4.5 + 1.5 秒（中文）、字母÷15 + 1.5 秒（拉丁）。

## 运动

- 24fps 逐帧；相机连续、缓慢、跟着层换速度，**永不停死**。
- **光是演员**：每层靠一次软边的光的动作到场——从投影轴铺开的一片、一栋栋带短闪点亮、标高在每面墙上一起上爬、太阳的钟在走。**没有硬边光带横扫桌面**。
- 家用灯灭得快（继电器，0.25 秒）、回来得慢（1 秒）；投影机点亮时先闪一下。
- 数字在光走的时候滚，光落定时落定；量线从 A 长到 B，带刻度。
- 永不动：模型、台座、标记在模型上的锚点。缓动一律单调、可复现；不许弹簧，不许文字自己缩放弹出。

## 画面怎么活

- 活在"一次只多一层"：上一层的光还留着，新一层压上去，上一层提出的问题被下一层回答。
- 保持段的活只放在边角：投影边缘极慢的一点呼吸、读数里数字的尾数、还没画完的量线。
- 模型本身一动不动——静是这种风格的语法，不是失误；每 1–2 拍要有一个"层到达"的动作，只有灯灭之后到灯亮之前允许全黑静止。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 屋顶高度的微距滑行，浅景深 | 模型是一个真实的物件 | 开场；一个重要的细节 |
| 升起来再往后拉 | 整个图案只有从上面才看得见 | 揭示一个空洞、一簇、一条边界 |
| 缓慢环绕 + 上升 | 城市作为整体，层在累积 | 时间上的生长；模型上的对比 |
| 摇臂下压到贴地低角，背景全黑 | 高度、天际线 | 高楼、限高、单独一座塔 |
| 沿一条线侧向平移 | 模型上一段被量出来的距离 | 影子、走廊、路线、视线 |
| 家用灯回来时后拉 | 数据结束，物体留下 | 结尾；话题之间的重置 |

取景：关键那一刻主体占画面高度的三分之一；读数在左三分之一、字幕在底部居中，**标记永不压在读数上**。转场是**一条镜头里的光的变化**（灯灭、一层替掉另一层、投影机变暗），不是切、叠化、滑页或擦除。

## 声音调色板

- **房间**：房间底噪、投影机风扇（嗡 + 滤过的风）在灯亮起时升上来、家用灯的继电器、灯泡点亮（一记 zap + 闷响）、光铺开的气流（滑动的带通噪声）。
- **光变成声音**：东西亮起来用木槌与玻璃，持住的光用弓拉颤音琴，标高一路上爬用上行的木槌线 + 气声 riser，每栋被点亮的建筑一记玻璃音。
- **重量**：定音鼓、大鼓、锣、低铜管给重事实；暖低铜管给转折。
- **底座**：低音提琴与大提琴只作和弦的地板；**不要通用的钢琴加弦乐旋律**。
- **静默**：投影机变暗，只剩一层薄风扇声，等在转折之前；最重那一击之前先抽空一下。沉默后的第一个声音就是转折本身。
- **混音**：人声比音乐高约 10dB；两处设计过的撞击是全场最响；−14 LUFS，真峰值 ≤ −1.2 dB。人声：平静、短陈述句、数字平着念。

## 原生手法

- **灯灭，灯亮**：家用灯、一记继电器、全黑、灯点亮，第一层到达。*适合*：场地的前后、规划公布前的街区、"现在再看近一点"。
- **空洞**：只点亮回答某个问题的那一批（某年之前建成的、某一方持有的、某个区内的），让缺席画出形状。*适合*：战损的城市中心、没有住宅的洪泛区、一家公司持有的地、保护区。
- **层按时间到**：建筑在它建成的那个十年亮起，每层比上一层更快，一个年份计数器在滚。*适合*：新城的生长、校园分期、港口扩建、开发商的年度组合。
- **标高上爬**：一层软光同时在每面墙上往上爬，矮楼先到顶、最高的最后，读数跟着往上走。*适合*：建筑高度、海平面或淹没深度、楼层数、被试探的限高。
- **太阳走表**：真实日期的真实太阳扫过影子，投影随后描住其中一条影子去量。*适合*：新塔对公园的遮阴、冬天的院子、光伏最好的屋顶、街道的日照时长。
- **单独挑出**：一栋或一组独自亮着，其余暗着，带一个标记。*适合*：文保建筑、待售地块、疏散计划里的医院。
- **灯亮**：数据停下，白模回到白色。结尾，或两个话题之间的重置。

## 变化空间

每一支由 agent 决定：地点与比例、哪几层按什么顺序、它们的颜色、开场、相机路线、结尾、节奏。

- **三种结构**：一个问题被一层层回答；规划 vs 今天（规划中的楼用第二种颜色亮起）；一栋楼的故事由它的邻居讲出来。
- **三种开场**：在白屋顶上做一次微距滑行；全黑里单独挑出一栋；隔着房间拍台座，家用灯在落下。
- **三种结尾**：灯亮，白模回来；最后一层独自留着；相机一直升到模型变成暗房里桌上一件东西。

## 坑

- **墙面法线反了 / 共用墙** → 看到内侧面，墙像空心的；相邻体量在共面上闪烁。改：由轮廓环方向推出朝外法线，低于较矮邻居的那段重叠直接不画，逐帧扫一遍内翻。
- **暖色 HDRI / 广角掠射开 GTAO** → 白模被照成米黄；广角出台阶状暗带。改：只用中性影棚环境，AO 只留近景。
- **低太阳只照亮立面，不照屋顶** → 屋顶全黑，像没做。改：从受光的一侧拍，或正侧向拍。
- **窄影子淹没在别的影子里** → 观众找不到。改：只描那条要紧的（填色 + 描边），并把它量出来。
- **细扫描线被读成激光扫描** → 媒介被认错。改：每个投影面都给宽软边，或者一栋一栋单独点亮。
- **标签浮着** → 锚点落在轮廓质心，线看着像悬空。改：锚在建筑最高处。
- **数字来自混着来的来源**（官方高度 vs 量的屋面） → 说不清；**编造年份层** → 数据里根本没有。改：画面上写明"屋面""实测"；换成高度、层数、占地、分区、边界或日照，宁少一层。
