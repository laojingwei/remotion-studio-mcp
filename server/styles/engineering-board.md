# 工程方案比较墙（engineering-board）

> 一面被拍下来的搪瓷板：实物照片钉上去，马克笔三种颜色各有一个含义，相机沿着线走，最后才拉开看整面墙。
> 参照（只学语法）：图纸墙上的讲解片、制图规范（平面图在上、立面图在下、尺寸线、剖面线）。不照搬具体构图，不在片子里点名这些参照。

## 本质 / 不是什么

- 本质：**一面真实的板在房间里**——搪瓷面、窗光衰减、一道缓慢滑过的反光、擦过又留下的笔迹、边框和笔槽。
- 本质：**板上的东西是真的**——实物照片剪下来贴上去，离板面几毫米，被同一扇窗照出影子，随相机推拉有视差。它们是被检验的证据，不是渲染出来的插画。
- 本质：**墨有语义**——石墨色写名字和规则，蓝色只给水与测量（尺寸线、投影线、量出来的数），红色只给裁决（否决、结论里那个词），灰色只用于制图辅助线。
- 本质：**一整面墙，没有翻页**——相机沿着线、投影和引线走，不切页。
- 本质：**整面墙只在最后出现一次**，前面每一帧都是它的局部裁切，最后拉开成一整张海报。

不是**白板讲解**（那是手绘线稿画在平面页面上）：这里的板是被拍摄的实物，主体是照片。
不是**数据故事片**：对比是真实单位下的尺寸线，画在实物旁边。
不是 keynote：没有页眉、没有居中项目符号、没有翻页。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 搪瓷板 + 窗光 | 板面有反光衰减、擦痕、边框，格子里的旧笔迹淡淡的 | 工程、评审、复盘 |
| 剪下来的实物照片 | 干净边缘、统一调色、离板面几毫米的影子 | 产品、设备、场地、路线 |
| 三种颜色的墨各管一件事 | 石墨写名字、蓝量尺寸、红只落裁决 | 评测、方案比选 |
| 尺寸线带真实单位 | 一条线量一段长度，端点有箭头 | 距离、续航、容量、预算 |
| 磁贴当可数的东西 | 一个一个"咔"地吸上，被规则刷掉时弹飞 | 票数、名额、配额 |
| 擦掉留鬼影 | 被否决的方案擦淡但还看得见 | 上一年 vs 今年 |
| 印章落裁决 | 一下砸下去，画面一顿 | 通过 / 不通过 |
| 引线指向结论 | 从那个决定性的数字拉一条箭头到结论 | 瓶颈、短板 |
| 贴纸/卡片/便签的次级层 | 比主线淡，只在最后拉开时才有用 | 资料、出处、备注 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 尺寸线、磁贴、印章这三样最容易一眼认出来，但也最容易被用滥——第二个片子里换一组信号。
- 照片必须是真照片（用户给的、可授权的图库）；拿不到就画成马克笔草图，**不许用生成图冒充实物**。

## 这个风格最俗的版本

- 画面：一面白板，上面贴满便签，一根马克笔在写"方案 A / 方案 B"，最后镜头拉远看见"结论：选 B"。
- 声音：鸟叫 + 轻快的木吉他。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么刻意保留。保留时把力气花在"量出来的对比"和"最后那一下拉开"上。

## 适配

- 用途：方案比选、评审复盘、工程讲解、预算/续航/容量这类要"量给你看"的宣传片。
- 内容：需要观众自己核对结论的主题——给一个限制，把候选一个个拿去撞。
- 时长：20–60 秒最舒服。超过 90 秒要拆成两段，各给一次整墙揭示。

## 技术路线

分层图片 + 相机（本工具：`add_element` 放图片/形状/文字，用 freeform 画布做层叠与位移；需要真正的 3D 视差时用 `scene3d` 的相机 + 平面）。
运动模糊本工具不承诺，靠**缓动曲线 + 切点速度匹配**替代（见「运动」）。
先做静帧验收：`preview_frames` 逐拍看，再 `render_preview_clip` 看动。

## 材质与渲染

- **板（最底）**：搪瓷面，淡淡的擦痕与指印，窗光衰减，一道斜向反光缓慢滑过；边框在暖灰墙上投影。
- **墨（正片叠底）**：约 90% 实色、中心略亮、圆头笔尖，正在写的那一笔尖端有一点点湿亮。字是逐字出现的，每个字有轻微倾斜和基线抖动。
- **照片层**：全分辨率剪下（干净边缘），统一调色（降饱和、略偏暖、黑位抬起）；细结构（线缆、栏杆、桅杆）量好位置后用单色干净线重画。影子 = 沿同一条光的方向的模糊剪影，物体越高越虚。**任何一帧都不许把照片放大到超过原分辨率**。
- **次级层**（相机在结尾之前不去的地方）：钉着的打印件、来源卡、便签上的算式、一张小草图。
- **道具**：磁贴、钢尺、打印卡、印章压痕，笔槽离镜头最近。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 板面 | `#EDE6D6` | 搪瓷奶油白，被窗光照出衰减 |
| 墙 | `#8C8577` | 板外的中性暖灰 |
| 石墨 | `#2E2B27` | 名字、规则、事实 |
| 蓝 | `#2C6E9B` | 水与测量：尺寸、投影线、量出来的数 |
| 红 | `#C0392B` | 裁决：否决、结论词、唯一要看见的那一笔 |
| 制图灰 | `#8C8577` | 只用于辅助线、剖面线 |

红很少：一帧最多两三个红标记，且不能落在红色的物体上。彩色属于照片，道具保持中性；一颗红磁贴就是一次裁决。

## 字体

- **手写标注**：马克笔手写体（中文用本机行楷/楷体，`STKaiti` / `KaiTi`；拉丁用单字重马克笔体）。正文 100–160 板面像素，裁决 230–400。
- **印刷标签**（吊牌、卡片、印章）：结实无衬线；署名行用等宽。
- **字幕**：底部居中的磨砂亚克力条 + 一个蓝色马克笔记号；一行一种语言，超宽就拆成两条；关键内容保持在条上方（底部 15% 留给字幕）。
- **阅读时间**：字幕 ≥ max(1.8 秒, 语音 + 0.6 秒)；板上的字按 CJK ÷ 4.5 + 其他 ÷ 15 + 1.5 秒估；最后整墙里要给人读的字，屏幕上 ≥ 20px。

## 运动

- 24fps 逐帧，不做步进。
- **相机**：叠加的缓动移动，速度按 `u^a(1−u)^b`（a、b ≈ 1.5–4），速度和加速度都不许突变；b > a 会有惯性。底下垫一点手持呼吸（≤ 3px），只有撞击才抖。
- **重量**：照片从镜头这一侧放下→落板→一小下回弹→影子收紧；磁贴"咔"地吸上；吊牌摆动；取下的磁贴朝镜头弹开；被打的东西一顿再弹回。
- 动的时候可以虚，读字的时候必须实。每 1–2 拍要有东西落下、画上或摆动；只有沉默和"等判决"允许静止。
- 墨按手的书写速度画出来；尺寸线落下时箭头一顿。
- **禁止**：叠化、文字缩放弹出、UI 那种弹跳缓动、文字自己淡入。

## 画面怎么活

板是一直在变的：一个量被画出来 → 拿它去撞限制 → 撞过或撞不过 → 落一次裁决 → 相机移向下一个。
每揭示一个新项，都把上一个结果留在画面里当参照（阶梯构图）；观众永远知道自己在比什么、比到哪一步了。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 跟着一条线走（跟着笔或尺寸线） | 在测量；"能走多远" | 长度对比、路线、时间轴 |
| 沿投影线上抬 | 同一个量换一个视图看 | 平面 → 立面；总量 → 分解 |
| 缓慢推近 + 轻微荷兰角 | 紧张，问题逼近 | 碰撞、截止日、超支 |
| 后拉并侧移 | 退一步，说一条规则 | 约束、论证转折 |
| 顺线甩一下、过冲、回稳 | 结果超出预期 | 破纪录、离群值 |
| 沿引线上升 | 从证据到裁决 | 结论、建议 |
| 阶梯式构图（新项带着上一个结果入画） | 逐项对比 | 排名、测试、选项 |
| 判决帧：整项 + 限制线 + 裁决，停 ≥ 2.5 秒 | 让观众自己核对 | 卡阈值、卡预算 |
| 长距离后拉到整墙 | 规模；一次看全 | 论证收尾、总结 |

取景：偏中心、裁切、贴得近。第一帧要有一个可读的主体，0.5 秒内要有第一个强动作。每撞一次限制给一个判决帧（项越大给越宽）；裁决在相机停稳之后落。揭示之前，露出的板面不超过总宽度的 60%，不露两侧边缘，不露揭示区。**转场就是移动**，不切、不叠、不缩放贴合。

## 声音调色板

- **房间**：空调底噪 + 窗外远处车流，比人声低约 20dB——听得见，但不是噪声；沉默段只留这个。
- **拟音**：笔尖按笔画长度变的沙沙声、笔尖轻点、磁贴吸附（一排磁贴音高不同）、拔开的"啵"、照片落板（板闷响 + 纸啪）、钢尺的余音、橡皮的毡声、印章的闷响。
- **主体的声音先到**（J-cut）；沉默之后的第一个声音必须是撞击或主体的声音。
- **音乐**：小编制节奏组，走路到轻快——贝斯 + 轻鼓组 + 木质打击，裁决用低铜管短音（或木槌）；不要钢琴加弦乐的铺底。落板、印章、箭头都卡在拍上。人声平稳、像在评审会上汇报，比音乐高 8–10dB；整体 −14 LUFS。

## 原生手法

- **整墙揭示**：先把墙当一张海报设计（层级、阅读路径、填满画面），再把每个镜头当成它的局部裁切来规划；留一块区域只给最后揭示用。
- **主体穿过答案**：真实的东西从选定方案里穿过去，声音先到。
- **跟着尺寸线**：把一个量画成真实长度（同一比例尺），相机跟着端点走。
- **投影线**：虚线把一个边从一个视图带到另一个视图，让两张图共用比例尺。
- **磁贴当可数物**：单位按节奏一个个吸上，被规则刷掉时弹飞。
- **擦成鬼影**：被否决的想法擦淡但仍然看得见。
- **盖章**：裁决带着闷响落下来，画面一顿。
- **实物答案**：把一个真道具放下当结论。
- **引线到结论**：从决定性的数字拉一条箭头到结论。

## 变化空间

每一支由 agent 决定：结构、哪些东西被拍成照片、平面还是立面、墙的阅读路径、开场、结尾、相机路径、节奏。

- **三种结构**：一个量不断长大直到撞破限制；前后对比（被擦掉的旧方案留在新方案底下当鬼影）；沿墙往下逐项盖章的清单。
- **三种开场**：先给一张已完成的图盖了章，再倒回去看为什么；一个大数字先写出来，再画那条量它的线；一张照片落在空角落。
- **三种结尾**：整墙揭示、答案被圈住；回到开场那个标记，现在它被改正了；最后一枚吊牌从问号翻成答案，然后后拉。

## 坑

- **字在路过时一闪而过** → 读不完。改：字放在相机停下来的地方；每一项都带着上一个结果入画。
- **只有特写** → 观众从没看过整物和限制线放在一起。改：细节 → 判决帧 → 停 → 裁决 → 移走。
- **照片彼此不像一套** → 改：同一个调色、同一条光、同一类视角。
- **细部件被抠丢或出现锯齿** → 改：对着干净背景抠，量好位置用干净线重画。
- **照片被放大** → 特写发虚。改：全分辨率素材、够大的原图、逐帧检查。
- **照片里有别人的字**（招牌、名字、logo） → 改：抹掉、裁掉，或换一张。
- **整墙露得太早** → 结尾被提前花掉；**最后的墙太稀或太小** → 白拉开。改：量每一帧的露出比例，按海报的层级定尺寸，次级层安静，不要空中间。
