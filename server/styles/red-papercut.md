# 红色窗花剪纸（red-papercut）

> 画面上每一样东西，都是剪刀从同一张红纸上剪下来的一片纸，平摊在另一张纸上；体积、表情和叙事只能来自剪掉了什么。
> 参照（只学语法）：陕西、蔚县窗花的锯齿、月牙、云勾、旋涡剪法与折叠加倍的团花、阴剪阳剪交替；1958–59 年上海美影剪纸片的"分片铆钉 + 侧面表演"语法。不照搬任何厂牌角色、署名艺人的作品或现成纹样谱——图案全部用路径长出来，片子里也不点这些名字。

## 本质 / 不是什么

- 本质：**一张纸，平摊**。没层、没影、没透视，所有信息写在同一张纸上。
- 本质：**孔即画**。亮的是纸，暗的是洞——眼睛是上下两弯月牙留一道桥，中间再挖一个瞳孔的孔；衣上的花是剪掉的，不是画上去的。
- 本质：**厚度只靠剪口**。每片轮廓是一条带低频抖动的折线（手剪的），左上 1px 亮边、右下 1px 暗边，就是剪断面。厚度只有这一圈，别的不给。
- 本质：**对称读秩序**。团花按 45° 一瓣镜像 8 次（D4），折 2/4/6 次得 2/4/6 倍对称；折缝留下的淡折痕要留着，那是真折过的证据。
- 本质：**人物是铆钉偶**：头、躯干、上下肢钉在颈、肩、肘、髋、膝、下颌、尾上，按 12fps 换姿势；镜头、光、天气、火苗、飞纸片走 24fps。
- 不是 **`paper-cut` 纸艺分层**：那是 4–8 层彩色卡纸前后错落、层间有柔和投影，像纸雕灯箱或立体书。这条反过来——**一层都不许有**；只要出现层间阴影或视差，就退回那条了。
- 不是 **`shadow-puppet` 透光皮影**：那边有幕布、背光、染色皮革和操纵杆，纸是透光的。这里纸**正面受光、不透光**；背光是一次性的特殊事件，留给最需要它的那一下。
- 不是扁平矢量插画（没有描边、没有渐变），也不是纯剪影（每个形状的内部都被剪过）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 一整张纸 | 前后景同一材质、同一平光，没有任何一层压着另一层 | 说明"这是纸"这件事 |
| 负形五官 | 眼＝两弯月牙留桥＋一个瞳孔的孔，嘴是剪掉的一道弧 | 人物、情绪、面孔 |
| 双轮廓 | 轮廓内几单位处拉一道细缝，手臂压在衣襟上也分得开 | 叠压、动作 |
| 八折团花 | 一瓣镜像成整圆，淡折痕留在花瓣之间 | 秩序、循环、团队 |
| 阴阳环 | 一圈剪掉一条带只留红线，下一圈反过来 | 节奏、繁简对比 |
| 锯齿边 | 一排小三角啄着轮廓，不是平滑曲线 | 毛皮、草、瓦、穗 |
| 月牙／云勾／旋涡 | 鳞、绗缝、关节、云头，都是有数的那几种剪口 | 纹理、天气、连接 |
| 12fps 铆钉动作 | 姿势一格一格跳，关节是一个圆点 | 叙事、打斗、赶路 |
| 背光透红 | 一张纸挡在灯前，所有孔同时亮 | 顿悟、家、夜、希望 |
| 投在墙上的花 | 孔的形状压扁落在墙面或地面，跟着纸一起动 | 影响、扩散、传承 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；「一整张纸」和「负形五官」是底，不算挑中。
- 从主题里选，不按顺序全上；全上就是一份纹样素材包。
- 团花、锯齿、鞭炮这三样最容易被一眼认成"年味模板"——第二支片子里换一组。

## 这个风格最俗的版本

- 画面：大红底上贴一朵金色团花，中间"新春快乐"四个烫金字，片尾 logo 定格，底色不变。
- 声音：锣鼓不停 + 唢呐 + 鞭炮，一个动作配一声锣。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么刻意保留。保留时把力气花在**负形**（让人从孔里读出脸）和**12fps 的停顿**上，不花在花纹密度上。

## 适配

- 用途：节日问候、品牌短片、工艺与非遗讲解、Logo 演绎、故事向短片。
- 内容：手工、传承、家、团圆、一年、一段关系的分合。
- 时长：20–60 秒最舒服。超 90 秒拆成两段，各给一次完整的团花或整面背光。

## 技术路线

- 2D 就够，不要开三维。每个元素一条封闭 path，孔用子路径 + evenodd 挖穿（本工具：`add_element` 放形状/文字/图片，用 freeform 画布排版；蒙版只用来做"剪出来"的那一下，绝不用它做层）。
- 静帧先验：`preview_frames` 逐拍看每一处镂空是否还连得住；`render_preview_clip` 看 12fps 的跳格是否成立。
- 落风格参数走 `set_theme` / `apply_style`；纹样用参数化路径生成（一瓣函数 + 镜像），不要一张张手摆。
- 一场只组织成"一张纸"：所有元素同一平面、同一平光、z 值相同、无阴影。
- 字幕 `set_subtitles`，旁白 `tts_narration`，音效与 BGM `add_audio`，素材 `upload_asset`。
- 做不到的：真实纸纤维的撕口、毛边厚度渐变。用极细的不规则描边加极窄的亮/暗边近似剪口，别在画面上假装有真纸。

## 材质与渲染

- **纸面**：中性灰的斑驳（纤维、色点）用 soft-light 压进每一片，再按该片的 alpha 裁回去——孔必须还是孔。
- **剪口**：轮廓折线带低频抖动；左上 1px 亮边、右下 1px 暗边。建筑与机械用直段 + 抖动，不许圆滑。
- **厚度**：**不投影**。厚度只由那一圈亮/暗边承担；源文件原本给每片投一圈紧而软的影，这条在本风格里关掉——有影就变回分层。
- **双轮廓**：人物每片沿轮廓内几单位拉一道细缝，红压红时才分得开（胳膊压在褂子上）。
- **不许有浮岛**：剪一个闭合圆环，圆心那块真纸会掉下来。五官一律"留桥"剪——上下眼睑各一弯月牙，中间留桥，再挖瞳孔的孔。
- **脸不形变**：表情是换片（笑、惊、惧、咬牙、睡），不是把嘴拉长。
- **纹样词表只有这些**：锯齿轮、月牙、云勾、旋涡、团花、梅花、铜钱、尖头细缝。全部参数化，不描谱。
- **光**：白天纸什么样就什么样。夜里 `画面 × 光图` + 暖光池，把要发光的那片做 emissive（光 × 纸的透射比，孔给全亮），两级 bloom，可加极淡光束——压到团花中心仍读得清。
- **投影花**：把某片的孔蒙版压扁铺到地面或墙上，`lighter` 叠；打在人物身上时用它的 alpha 当蒙版，再垫一块暖光斑，让剪出来的五官仍读作孔。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 红纸 | `#D2201F` | 主角材料，在 `#C8102E`–`#D7261E` 之间取 |
| 近处纸 | 红纸亮一档 | 离镜头近的一片 |
| 远处纸 | 红纸暗一档 | 远片、对手、重物 |
| 米纸地 | `#EFE3CE` | 白天的地，暖稻纸 |
| 靛夜纸 | `#1E2A4A` | 夜里全背景同一个深染纸族，远层浅、近层深 |
| 金箔 | `#C79A3B` | 只用一次：日头、标题、一枚铜钱 |

- 深度与角色靠**纸色差一档**，不靠调明暗；一旦开始打光塑造体积，就不是剪纸了。
- 地与主角必须不同纸族。全是红，剪影就贴不住了。
- 玉绿纸、黑纸也成立（不喜庆的主题），但地永远比主角淡一个族。

## 字体

- **标题**：剪出来的字，阳剪，字腔是真空洞；逐字 12fps 弹出，配锯齿边条和一枚代码剪的印章。
- **字幕**：一条横批，红比画面里的红更暗，米色字才压得住；锯齿边、燕尾收口；结实衬线约 44px，位置偏低，带一层纸的厚度影；按"贴对联"两格 12fps 落下来。
- **阅读**：≥ max(1.8 秒, 语音 + 0.7 秒)；两条不许重叠。
- 小字署名可以是印在纸上的墨字，别做烫金。

## 运动

- **人物 12fps**：`floor(t·12)/12` 取姿势；镜头、光、天气、火苗、飞片 24fps 走 ones。
- **铆钉**：颈、肩、肘、髋、膝、下颌、尾。硬姿势、极小缓动、1 帧过冲（pop = 一步内 1.15×）。重量靠尺寸和镜头抖，不靠变形。
- 侧面时近侧手臂抬起会挡脸：手留在脸前方，或用道具挡住。
- **折**：翻盖切成约 16 条，每条按 cosθ 压扁、沿折线放大 `1 + 0.28·高度`（假透视），立起时变暗，过 90° 露背面的浅色，影子长出来，折完留一道折痕。一折约半秒，每折卡一个音。
- **剪**：沿剪刀路径排一圈圆的蒙版把图案"揭"开；越过外轮廓后废料掉下；刀刃按拍的细分开合；碎屑飘出去落地。
- **展**：几次展开相隔零点几秒，每片 ease-out 从折到平（"啪"），然后强调物上弹一下尺度加一下暖闪。

## 画面怎么活

- 静止时也有三样在动：外轮廓极轻的呼吸翘动（≤2px）；背光孔亮度缓慢起伏（幅度不碍读字）；一缕碎屑还在空中飘。
- 人物的"活"在格与格之间的停顿：抬到一半停一格再落。不做连续眨眼，眼睛是整片换。
- 团花可以极慢地转（一圈 8–15 秒），像被风带着。整张纸别抖——纸是钉在墙上或糊在窗上的。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 极近，跟着剪尖 | 在做；专注手艺 | 开场、一次精准的动作、落款 |
| 平视正面，锁死 | 剪影当徽章 | 标题、宣言、全家福 |
| 沿纸层慢横移（视差） | 一个世界铺开 | 村庄、路线、时间轴 |
| 低机位广角，一个形状从地里立起 | 体量、威胁 | 风暴、对手、截止日压过来 |
| 桌面俯拍 | 手艺本身是情节 | 折、剪、拼、分拣 |
| 推向一片亮的，再拉回一片多的 | 一次行动扩散 | 影响、网络亮起来 |
| 翻页／揭纸 | 换时间或地点 | 昼夜、前后、章节 |
| 拉回到房间里的一个物件 | 这片子是谁做的 | 记忆、礼物、传承 |
| 绕团花中心转 | 秩序、重复 | 循环、团队 |

取景：一切与屏幕平行，深度只来自视差和纸色差，绝不用透视。转场是纸的动作（折、翻页、揭、一张纸飞走、一刀划过画面）；**不许叠化**。

## 声音调色板

- **拟音跟材料走**：剪刀＝金属剪切扫频（2.5–9kHz）＋短余音＋一下纤维崩裂；折＝呼＋折痕轻叩；展＝脆响；重脚步＝**纸板**闷响，不是肉声；揭纸；贴＝掌拍；划火柴、吹气；鞭炮＝20–60ms 的密点击＋低频炮。
- **乐器**：明亮的民乐小合奏——琵琶（长音轮指）、古筝（扫弦、刮奏、摇指）、二胡（滑音）、笛、笙或扬琴、木鱼、大小锣、框鼓，五声调式。不要钢琴加弦乐，也不要皮影那套戏曲锣鼓。
- **用法**：一剪＝一拍细分；筝的爬音，出现一样东西给一个音；框鼓当心跳给重量；大锣只留一次；屏息处全静。
- **人声**：暖的说书人，字少。垫乐在语音下压约 9dB，拟音压约 3dB；撞击不落在语音窗里；生僻的民俗名字走 `tts_narration` 的读音替换。
- 混到 −14 LUFS，**不加颗粒**（纸纤维就是质感）。

## 原生手法

- **折—剪—展**：一折 2/4/8 次，一剪变很多；展开放强拍。适合：一个老师很多学生、一个设计量产、一粒种一片田。
- **孔就是光**：背光的一片每孔都亮，花纹投到世界上。适合：一个念头从人身上透出来、灯塔、故事里的家窗。
- **对称复制**：镜像的一片剥下来繁殖（团花→窗花→烟花）。适合：连锁、细胞分裂、一首歌传遍人群。
- **碎屑有后事**：剪落的碎屑后来回来当雪、当彩纸、当星。适合：回收、剩下的时间、小失败攒成大事。
- **全是一张平纸**：东西共用同一套剪口，山脊立起来是兽，浪一翻是路。适合：风景变地图、工厂其实是一台机器、拉远看见那个被做出来的东西。
- **镜像一对**：一张对折纸剪出两个人。适合：双胞胎、搭档、同一个人的前后。

## 变化空间

- **结构**：一年十二剪（生肖或日历轮，一格一月，会转）；流水线（一件产品由剪片一片片拼起，每片一个花纹）；一封信（折起来的信息一格一格展开，每格一场）。
- **开场**：先给一个剪完的团花，然后一片掉出来自己走了；空纸，出现第一道折痕；一群剪好的人已经在跳，视差全开。
- **结尾**：折回去（世界折成一个小方块递给别人）；碎屑落定（所有废料飘成一个新花纹）；只剩背光（灯全灭，只有一片后面亮着，把最后一格画投在墙上）。

## 坑

- **红压红糊成一坨** → 换纸族、拉开远近纸色差、叠压处加双轮廓。
- **用光图压暗一层，把压在上面的东西也压暗了** → 染那一层本身（multiply 后把 alpha 还回去）。
- **平摊的 cos 压扁翻盖读成"滑动的卡片"** → 切 16 条、加假透视、立起时变暗、过 90° 露背面浅色。
- **剪开的那一刻从孔里看见没剪的整叠纸** → 叠厚只放进"未剪"的蒙版里，剪开的部分单独给错位的副本。
- **剪刀朝反了** → 刀刃轴跟着行进方向，铆钉略在切点后面。
- **镜头之间留空帧** → 出镜和入镜的纸动作要重叠，别切黑。
- **全片连镜头都 12fps** → 抖成廉价定格。人物步进，镜头/光/火走 24fps。
- **字幕压在花纹最密处** → 挪到纸的空白边，或给横批一条纯色纸。
