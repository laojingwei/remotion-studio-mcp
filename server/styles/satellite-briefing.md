# 卫星地图简报（satellite-briefing）

> 一张真的卫星影像，压成分析员的灰，上面只画细白线：锁定框、轮廓、一条量距离的线、一个读数。
> 参照（只学语法）：给卫星图做标注的开源调查片（细线压在影像上、一屏一个结论、测量即叙事）、一次连续变尺度的《Powers of Ten》（换尺度必须带读数）、NASA Earth Observatory 的《World of Change》（一个地方，让时间跑）。不照搬它们的版式、字体、图标和音乐，不在片子里点名。

## 本质 / 不是什么

- 本质：**地面是照片**——真实、授权干净、带经纬度的卫星或航拍影像，拍的就是那个地方。地面上没有任何东西是画的、风格化的或生成的。
- 本质：**两层两个真相**——影像层是卫星看到的，细线层是分析员量出来的。标记很细、白色、稀疏，钉在真实坐标上。
- 本质：**调色跟着故事走**——入轨用真彩，分析层用灰，只有故事转折处把颜色还回来。
- 本质：**比例尺就是相机**——一次从轨道到地面的连续缩放，由嵌套的影像图版拼出来，高度读数和比例尺都由同一台相机换算。
- 本质：**一屏一个发现**，只用一个强调色。
- 不是**数据故事片**（那是纸上的图表）、不是**科幻 HUD**（没有发光线框、没有虚构的机身装饰）、不是**蓝图**、不是**等距信息图**（真的正射或斜视，不做沙盘）、不是 keynote（没有翻页、页眉条、章节编号）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 正射锁定帧 + 缓慢蠕动 | 机位停住，画面仍在 2–5% 地挪 | 证据、同一地点的时间流 |
| 细白线压在影像上 | 1.2–2.6px 的发丝线、带暗色描边 | 范围、边界、主张 |
| 一条带刻度的测距线 | A 到 B 长出一根带 ticks 的线，端点读数往上跳 | 距离、退了多少、隔多远 |
| 高度读数 + 比例尺 | 角落的等宽数字跟着缩放变，比例尺同步换段 | 缩放、定位、规模感 |
| 时间扫描前缘 | 一道柔和的扫描带从北往南推过，日期换掉 | 冰川退、城市长、火烧迹 |
| 灰色里一块真彩 | 只有主体保留真实颜色 | 复绿、回水、复耕 |
| 印刷地图被撕开 | 扫描条把"纸上的地图"撕掉，下面是地面 | 地图还说它是海，其实已是沙漠 |
| 轮廓留在框里 | 每个日期扫过都留下自己的边线，丢掉的那条带闪一下 | 逐年变化、对比 |
| 引线标签 + 出处 | 标签拉一根线钉到地面，读数下写"Landsat，实测" | 地名、口径、来源 |
| 轨道弧线带边缘 | 地球边缘在画面里，大气一圈极薄 | 开场、收尾、把一处放回星球 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 锁定帧、测距线、时间扫描这三样最容易被一眼认出，也最容易被用滥——第二支片子换一组。
- 影像必须是真影像（公有领域或可署名使用）；拿不到就换地方或换日期，**不许用生成图或示意图冒充实拍证据**。

## 这个风格最俗的版本

- 画面：一张 Google Earth 截图，红色大箭头猛推过去，一串发光圆圈炸开，角落写着"Zoom 15x"。
- 声音：科技感 riser + 一记 boom + 电子滴答，从头铺到尾。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么刻意保留。保留时把力气花在"量出来的那一个数"和"颜色回来的那一下"上。

## 适配

- 用途：讲地点、讲范围、讲一块地这些年的变化；调查、环境、城市、灾害复盘、纪录片段落。
- 内容：结论要能被观众自己核对的主题——先把地方摆出来，再量给你看。
- 时长：30–90 秒最舒服。超过 2 分钟要有第二次尺度变化，否则观众会忘了自己在哪。

## 技术路线

- 本工具不做实时地图瓦片渲染。**底图先离线导出成一张大图素材**，用 `upload_asset` 上传；按世界 → 区域 → 细节做三级，重叠边缘羽化，细节层在相机下降时化入。
- 相机：`add_element` 放图片，叠加相机变换——正射用二维缩放 + 位移，斜视/入轨用 `scene3d` 的相机 + 平面贴图。距离在对数空间插值，所以每一段的速度感一致。
- 标记层单独一层，和底图共用同一套世界→屏幕换算，推拉时才钉在地上不飘。
- 高度读数、比例尺、影像署名、字幕条固定在屏幕坐标，不进相机。
- `preview_frames` 逐拍看静帧（读数和线宽最容易在这一步露馅），`render_preview_clip` 看整段缩放。

## 材质与渲染

- **图版**：带经纬度框的地理栅格，按分辨率嵌套（世界 → 区域 → 细节），边缘羽化，细的图版在相机下潜时溶解进来。
- **地球**：入轨时才有——一层极薄的大气边、边缘明暗过渡；只在这一档出现。
- **时间**：同一天的图版共用一套网格。换图靠柔和的扫描前缘（一道卫星过境，**绝不画成发丝线**）：从北往南是正向，从南往北是倒放。增长可以从旧边缘往外长，按距离场排序。
- **分析员的调色**（颜色到灰只有一个滑块）：提亮度和局部对比/清晰度，加一个肩部让盐田、雪、云压在白以下；色相从蓝黑到冷银，最亮到约 65% 灰，饱和度只留五分之一。**白色留给标记**。
- **标记**：1.2–2.6px 发丝线，带暗色描边（亮地上才读得出）；历史与主张用虚线；括号、刻度、引线。线是"画出来"的，轮廓在扫描之前先印上去。
- **仪表**（高度、比例尺、影像署名）和转录条只存在于屏幕空间，其他一切都钉在地面上。
- **主张层**：一张印刷地图，平涂、制图式，永远不用于任何被测量的东西；任何缩放下纸纹都只有几个像素宽，半调网点、海岸线与等深线、经纬网、衬线地名。
- **后期**：轻微的颗粒（叠在底图素材上或渲染后处理里加，本工具不写 ffmpeg 命令）、暗角；运动模糊只给甩镜。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 地面最暗 | `#070B0E` | 灰阶的底，约 3% |
| 地面最亮 | `#A1A7A9` | 约 65% 灰，云雪不冲到白 |
| 标记 | `#F2F5F6` | 白只属于"量过的东西" |
| 读数 | `#FFBE55` | 唯一的暖强调，一屏只出现一次 |
| 主张层的蓝 | `#2E70CE` | 平涂的地图色，只给"被检验的说法" |
| 真彩 | 影像本身 | 证据：入轨时，以及故事转折处 |

规则：中性地面（灰度 3–65%）；一个暖强调只给那个读数，绝不当装饰；第二个色相只标**主张**（一张地图、一个规划、一句承诺），平涂、制图式，绝不用于实测；真彩是证据，只在入轨和转折处回来；**影像上不许压伪彩 ramp**。

## 字体

- **角色**：读数用轻的窄体无衬线（96–130px，如 Barlow Condensed，本工具用 `Inter Tight` 收紧字距替代）；仪表和日期用等宽（20–34px，如 IBM Plex Mono）；片中语言的标签用无衬线（24–42px）；衬线只给主张层和标题。
- **标签贴地**：用引线钉到地面。读数放在右三分之一、紧挨着它量的东西，标签在上，出处在下（"Landsat，实测"）。
- **字幕是转录条**：左下角，一条 2px 白线 + 一块向右淡出的深色板，左对齐，每行一句一行排完（按真字体量宽，超长就拆成两条字幕）。双语时片中语言在上。
- **1080p 下任何字不小于 20px**，影像署名也算。
- **时间**：字幕 ≥ max(1.8 秒, 语音 + 0.6 秒)；滚动的计数器要停在自己的终值上；标签停留 ≥ 字数 ÷ 4.5 + 1.5 秒（中文）。

## 运动

- **相机不停**：距离在对数空间插值，分段缓动；"停"也要留 2–5% 的蠕动或慢旋。**一帧不动不许超过一秒**。
- **标记靠"被做出来"到达**：线长出来、轮廓在扫描后印上、计数器滚到终值并轻轻一顿、锁定框带一点过冲地咔上。
- 时间变化是扫描，**不是叠化**；扫描的间隔就是速度，相机跟着它走（间隔变短就加速，最后一步刹住）。
- **不许动**：注释底下的地面、仪表的位置。
- 转场：扫描线替换、关掉一层地图、穿过图版缩放、甩镜、锁定框张开成标题卡。**无关地点之间不许叠化，一次缩放中途不许硬切**。

## 画面怎么活

- 相机在做一件可读的事：找（甩镜、搜索的锁定框）→ 量（测距线加读数）→ 核对（时间扫描、轮廓对比）→ 退（爬回轨道）。
- 每一屏只有一个结论，落在那一个读数或那一条线上；其余全部退成灰。
- 转折靠"颜色回来"或"地图被撕开"，不靠音乐推上去。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 斜视入轨，边缘入画 | 尺度、上下文、距离 | 开场、收尾、标题卡 |
| 下潜（对数缩放 + 转到正射） | 亲自去看一眼 | 揭示、核对一个说法 |
| 锁定正射 + 缓慢蠕动 | 证据、对比 | 一个地方的时间流、一次测量 |
| 推近一个点 | 单挑出来 | 一个镇、一道坝、一块田 |
| 沿一条线跟拍 | 走完一段距离 | 测量、一条河、一条路、一条边界 |
| 带模糊的甩镜 | 同高度换一个对象 | 反例、"与此同时" |
| 爬回轨道 | 后果、视野 | 结尾、总结 |

关键帧里主体要占到画面高度的三分之一；读数在右，字幕在左下，仪表在四个角。取景偏中心、贴得近；第一帧就要有一个可读的主体。

## 声音调色板

- **遥测**：FM ping（一次锁定 ping 值得反复用）、网格上的干 ticks（越分越密就加速）、噪声扫描（倒放上行、正放下行）、伺服器的细鸣、测距线拉出时的棘轮。
- **重量**：定音鼓、大鼓、大锣、弓擦镲片、时间倒放时反过来用的 tam-tam。测量落在一个有音高的击打上。
- **合成**：能听见二三次谐波的脉冲贝斯，低通下的失谐锯齿 pad，下潜时的 riser。
- **底噪**：轨道嗡鸣、无线电嘶声、数据流；那个地方自己的环境声（风、水、远处一声号），少量用，常做成 J-cut / L-cut。
- **一种可选的性格**：整套保持"干"（电子、皮、金属），只留一个"湿"的音色（玻璃、水、弓擦金属）标记转折。
- **静默**：音乐和拟音停，只留一条细底噪，冲击可以衰减进来；静默之后的第一个声音就是转折。最重的冲击前抽一下（0.2–0.45 秒，音乐与拟音降约 25dB），它才落得住。
- **混音**：人声比音乐高约 10dB；两三个设计过的冲击是全片最响的时刻（出总线压缩器、带中频身体，例如低铜管短音）；20–60Hz 比全频低约 15dB（约 40Hz 高通，冲击重量放在 60–120Hz）；整体 −14 LUFS，真峰值 ≤ −1.2dB。人声：冷静的分析员，短陈述句。

## 原生手法

- **地图对着照片**：相机落进"主张"的那张印刷地图，一道扫描条把它撕开，下面是地面；地名活得比纸久。适合：地图上还是湖、实际已经没了；被清掉的特许林地；从没建成的规划城。
- **锁定帧里的时间环**：带日期的图版一张张扫进来，每张留下自己的轮廓，两条环之间丢掉的那条带闪一下。适合：冰川退缩、城市蔓延、一季一季的火烧迹。
- **测距线**：标出终点，从 A 到 B 长出一根带刻度的线，追着线头跑、读数一路往上数，落在那个数上，再后拉看全长。适合：岸线退了多少、村子到它的井、营地到边界。
- **下潜与爬升**：从轨道到地面的一次缩放，或反过来。适合：定位任何东西、尺度揭示、把一个地方还给星球的结尾。
- **颜色在转折处回来**：灰里只有主体拿回真彩。适合：一块灌溉的田、一座重新蓄水的库、一片复绿的林。
- **锁定框变成画框**：括号张开，框住一张标题卡或最后一个读数。

## 变化空间

- 每一支由 agent 决定：地点、有没有主张层、哪几个日期、结构、相机路径、强调色的色相、颜色从哪儿回来。
- **结构**：一个地方的锁定延时，收在一次推近；一条河从源头跟到河口，每一站一个读数；两个地方同一比例尺对比，用甩镜切换。
- **开场**：一个地面细节慢慢爬升露出它的尺度；黑场被一道扫描线画出来；带搜索锁定框的斜视入轨。
- **结尾**：爬回轨道；最后一个测量落下后停在静默里；主张层被重画成和地面对上的样子。

## 坑

- **授权**：不可用——Google Earth/Maps、Bing、Esri World Imagery、Mapbox Satellite、Planet、Maxar、新闻图、AI 生成影像。EOX Sentinel-2 cloudless 仅 2016 那版是 CC BY 4.0（2018 起是 NC）。原始 Copernicus Sentinel 要写"Contains modified Copernicus Sentinel data [年份]"，先看用户的规则。公有领域或可署名免费：USGS Landsat（1972 年起，全球）、USGS NAIP（美国，约 1m）、NASA Blue Marble、MODIS、VIIRS。把可读的署名烧进画面，并在 CREDITS 里逐条列出每个素材。
- **给新地点找影像**：按经纬度框 + 日期去搜（Planetary Computer STAC 的 Landsat C2、Sentinel-2 L2A 免账号，或 USGS EarthExplorer；MODIS/VIIRS 与 Blue Marble 走 NASA GIBS；轮廓用 Natural Earth），每次请求都记下来。OSM（ODbL）、CC BY-SA、"no known restrictions" 都不等于 CC0：写清条款，先问用户。地点是用户的就向他要素材或 GIS 图层。**任何缺口都不许用生成影像填上再当证据。**
- **接缝**：不同日期成像的图块拼起来会打架。一条航带一个日期，每一景在地物稳定处做增益匹配，重叠处羽化，空洞只用同年份补齐。
- **老传感器**：Landsat MSS（到 1992）没有蓝光与短波红外，还有丢行：用最近邻重采样，近零行当 nodata 用同年景补，扫描角条纹只在地物上清。每一年都要在全对比度下看一遍。
- **羽流与霾**：会以亮斜带横穿水面——换同年的另一景，不要把它涂掉。
- **边缘**：对着 nodata 重采样会让图幅边缘变暗（掩膜向内蚀一点）；图版边界上的等高线碎段直接丢掉。真实的直边（堤、圩田）会被看成接缝：框出去或标注它。
- **近景灰糊**：只给那个高度提局部对比，把测量走廊之外压暗。
- **水与云**：有短波红外的用 MNDWI，只算你要量的那个流域；灰阶里云会读成地物，所以用旱季。
- **事实**：在项目目录里留一份 FACTS.md（主张、来源 URL、原文措辞，或带景号与日期的测量方法），随片交付。**在你展示的那个日期上测量。**
- **偷懒的替代**：拿一张地图截图当底图放大 → 一推就糊。改：导出够分辨率的大图，逐帧检查边缘；本工具不做瓦片流式加载，别指望"推到哪渲染到哪"。
