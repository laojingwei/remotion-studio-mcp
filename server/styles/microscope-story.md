# 显微镜故事（microscope-story）

> 标本本身就是一张真实的显微照片：标注、比例尺、推近都是后加的，图上不画、不修、不生成。
> 参照（只学语法）：《Powers of Ten》式的一次连续尺度变化、读数跟着镜头走；高端显微镜发布片的暗台面与克制标记；数字病理阅片器的仪器语言（比例尺、视野、倍率）。不照搬它们的构图、界面、字体、配乐，片子里不点名。

## 本质 / 不是什么

- 本质：**标本是照片**——真实的显微图或全片扫描（WSI），CC0 / 公有领域 / CC BY。标本上不画、不修、不生成。
- 本质：**尺度就是相机**——一次对数空间的连续推近（需要时再爬回来），穿过同一份标本的嵌套层级；比例尺按 1-2-5 序列缩短并跳，视野读数在滚，倍率在跳级。
- 本质：**对焦有语法**——开场从虚到实的一次 rack-in；每次换倍率一次短呼吸（模糊 + 一点视野变化）；镜头落位时一条焦平面扫过画面。
- 本质：**读数是量出来的**——每个数字都由文件算出（像素尺寸 × 像素数），屏幕上说明它是怎么测的。只描述测到了什么，不下诊断。项目里留一份出处表（说法、来源、引用的原话或测量方法），随片交付。
- 本质：**一屏只放一个读数**，只用那一个强调色。
- 本质：**标记在屏幕空间，但钉在标本上**——同一个 world→screen 函数，推拉时标记跟着结构走，不飘。

不是 `exploded-teardown`：那个把物体拆成零件、按装配关系摊开；这里什么都不拆，标本是一整张连续的图，变的是尺度不是结构。
不是 `blueprint`：工程图是从零画的矢量线；这里每一根线只用来指和量一张已经存在的照片。
不是 `data-motion`：图表是被造出来的图形；这里唯一的"图"就是照片，数字只是它的属性。
不是 `hologram-hud`：没有发光线框、没有准星、没有科幻界面；标记是 1.5–2.5px 的发丝线。
不是 `dark-keynote`：没有舞台光、没有英雄产品镜头；暗只是台面。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 带染色的真实显微照片 | 组织或材料在暖白玻璃上，染色保持本色（三色红蓝、H&E 粉紫） | 医学、生物、材料 |
| 在跳的比例尺 | 按 1-2-5 序列缩短，每换一级跳一下，数值跟着换 | 一切"从多大看到多小" |
| 角落里的仪器组 | 比例尺加数值、视野、倍率；倍率旁一个小转塔图标每换一级转 1/4 圈 | 需要可信度的科普 |
| 发丝线标注 | 1.5–2.5px，深或浅的描边光晕；圈是分两段画出的弧，四个方位有小刻度 | 结构、尺寸、位置 |
| 扫描前数像素 | 一条带通滤波的扫描从左到右，被计数的像素点亮，读数滚到落点 | 占比、孔隙、覆盖率 |
| 磨砂玻璃面板 | 面板底是这一帧自己的模糊副本，白字在玻璃上和染色上都读得清 | 读数、字幕、出处 |
| 焦平面扫过 | 落位时一条斜的清晰前沿扫过一张被柔化的帧 | 同一帧里的深度 |
| 两个圈，一个裁决 | 同一倍率下 truck 到另一处，再把两处框进一帧 | 处理 vs 未处理、边缘 vs 中心 |
| 台面上的整张玻片 | 先给肉眼能拿起来的那片玻璃，再给细胞 | 开场、尺度锚点 |
| 倍率只说一次 | 换级时新倍率以大字号出现一次，随即收进角落面板 | 段落转折 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 比例尺、圈、磨砂面板最容易认，也最容易被用滥；第二支片子换一组。
- 信号必须是真的：照片是真照片，比例尺是真比例尺，读数是真算出来的。

## 这个风格最俗的版本

- 画面：黑底一张荧光细胞图，一圈发光的准星锁住细胞核，旁边飘一个科幻感的 "10,000×"，配上持续上升的 whoosh。
- 声音：深空 pad + riser + 心跳。
- brief 的 style 一栏写明这支片子翻掉了哪几条，或者为什么刻意保留。保留时把力气花在"比例尺真的在变"和"读数真的对得上画面"上。

## 适配

- 用途：医学/生物的感知科普（眼睛、神经、细胞）、材料与失效分析、科研机构解释片、显微镜/扫描仪/试剂的可信度片、质检与检测。
- 内容：要"把测到的东西给你看"的主题——有一个能一层层放大的实物，有一个能数出来的量。
- 时长：45–120 秒最舒服；只有一次下潜或一次爬回时 30 秒也成立。超过两分钟要拆成"下潜 → 对照 → 爬回"三段，每段收一次比例尺。

## 技术路线

- 层板：`upload_asset` 传各级倍率的切片，`add_element` 当图片元素一张张叠进同一个场景（freeform 更好排版与层叠）；相机就是一个 world→screen 的相似变换，用 `set_transform` 按帧驱动缩放/旋转/位移。
- **做不到真正无限放大**：准备多级倍率的素材，按级切。每帧只用"降采样不超过 1.45×"的最细一级，在 2.2×–1.45× 之间把下一级混进来；素材到头就停（超过约 1.6× 一定是糊的），别硬撑。
- 对焦呼吸：整帧的模糊用 `add_effect` 的 `blur` 通道按帧给值。焦平面扫做不到"局部斜前沿"：要么准备同一取景的一张实焦、一张虚焦，把虚的那张按斜向裁切推进；要么退成一次整帧呼吸，不要硬做前沿。
- 磨砂面板 = 画面模糊副本 + 一层 rgba + 白字，三层元素叠出来。
- 先 `preview_frames` 看静帧（比例尺对不对、标注有没有钉在结构上、有没有超采样），再 `render_preview_clip` 看动（推近有没有顿、换级有没有呼吸）。
- 画风落地：`set_theme` / `apply_style('microscope-story')`；旁白 `tts_narration`；字幕 `set_subtitle` / `set_subtitle_style`；音效与配乐 `add_audio_track`。

## 材质与渲染

- **层板（plates）**：同一份标本的金字塔各级，放在同一个世界坐标系里（以 level-0 像素为单位）。粗级整张、扫描边缘 alpha 羽化；细级是落点周围的裁切。各级本来就已配准，所以级与级之间不该有缝、也不该看见上采样。
- **肉眼层**：扫描仪自带的整张玻片照片，用扫描的视野元数据配准，再和组织质心核对。把玻璃从托盘里抠出来、去掉线阵拖影、厂商印的 logo 用周围磨砂玻璃填掉。视野低于约 30mm 这张就该上采样了：让盖玻片变成干净的玻璃，灰尘离开焦平面。
- **一套调色配所有板**：玻璃归一到暖白，染色加一点密度和彩度，别的都不加。不做假色，不做胶片模拟。
- **台面**：石墨色，一池缓慢移动的光；玻片下面一层软影。
- **对焦**：带余量渲染再上屏幕空间模糊（边缘不会发暗）；焦平面扫就是一张柔化帧上一条斜的清晰前沿。只加很轻的照明暗角。
- **标记**：发丝线 1.5–2.5px，深或浅的描边光晕；圈用两段弧画出、带四个方位小刻度；尺寸线端点有端刺；引线只有一个折点。被计数的像素用掩膜在扫描前沿后面揭示，之后留成一条淡痕。
- **磨砂面板**：深色半透明玻璃盖在画面模糊副本上，白字；白字在玻璃和染色上都成立，全片不让字换色。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 玻璃 | `#F4F1EC` | 暖纸白，所有板归一到这里 |
| 台面 | `#0B0D0F`→`#2A3036` | 石墨，一池光 |
| 墨 | `#181B1F` | 玻璃上的字与细线 |
| 面板 | `rgba(12,14,17,0.74)` | 磨砂玻璃 |
| 薄荷（染色上） | `#78F0CD` | 唯一强调：读数、被数亮的像素 |
| 薄荷（玻璃上） | `#007A63` | 同一支强调色在亮底上的那档 |

染色是证据，保持本色（三色红蓝、H&E 粉紫）。强调色必须冷、且离染色色相远：红蓝染色配薄荷，绿紫染色配琥珀。一屏只有一个强调读数。

## 字体

- **读数与比例尺**：轻的窄体无衬线 40–72px（Barlow Condensed 一类；本工具用 `Inter Tight` 压窄字距替代）。
- **仪器与像素计数**：等宽 20px（`monospace`），数字等宽对齐。
- **标签**：与片中语言一致的 sans 20–34px（中文 `Microsoft YaHei`）。
- **标题**：整片只用衬线（`Noto Serif SC` / `Georgia`）。
- 1080p 下任何字不低于 20px。CJK 标签停留 ≥ 字数 ÷ 4.5 + 1.5 秒；滚动的读数按落点值报一次。
- 字幕：底部一条磨砂横条；双语时一行一种、片中语言在上，绝不折行；用真字体量过宽度，太长就拆两条。

## 运动

- 24fps 逐帧。相机是相似变换（缩放、旋转、位移），关键帧之间按对数螺线插值（关于两帧的不动点做 M^u）——每一次推近都是朝一个点的真下潜，旋转是它的一部分。
- 缓入缓出；hold 时继续微推 2–5%；**任何一帧静止不超过一秒**。
- 倍率只在板真正换级的地方变，每次配一次对焦呼吸、一声转塔咔哒、和一次"新倍率"大字（只说一次）。
- 标记是"做出来"的：尺寸线从中心长出去，圈按弧画，扫描前沿一边走读数一边滚，读数落点带一点小回弹。
- 永不移动：标记底下的标本、仪器的位置。
- 禁止：叠化、随便淡入、文字缩放弹出、UI 那种弹跳缓动。

## 画面怎么活

镜头一直在往里走或往外退，画面里始终有一条比例尺在变，观众每一秒都知道自己站在哪个尺度上。每落一次位就发生一次测量——画线、圈、扫描数像素——读数落在它的旁边，不在屏幕中央。换级是段落的呼吸：不是转场，是同一份标本被看得更清楚。安静的时刻也不是停，是 creep。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 下潜（对数缩放 + 旋转） | 自己去看一眼 | 开场；从玻片到细胞 |
| 锁死的帧、缓慢微推 | 证据，一次测量 | 读数；对照 |
| 同一倍率下 truck | 同一个东西的另一处 | 反例；"旁边 meanwhile" |
| 拉回到两个标记同框 | 比较 | 裁决 |
| 焦平面扫 | 到达；深度 | 落位；一帧里的揭示 |
| 爬回（反向下潜，比例尺倒跳） | 后果，尺度 | 结尾；回到眼睛的尺度 |

取景：关键帧里被测结构占画面高度 1/3 以上；仪器在角落，字幕底部居中，读数在它的标记旁边。转场就是尺度变化、truck 和对焦——**绝不在两份标本之间切或叠化**。

## 声音调色板

- **仪器拟音**：物镜转塔（一声咔哒、定位珠、一圈小金属余音）、对焦伺服、每画一条线的笔尖划玻璃声、一条带通滤波的扫描从左到右配逐渐加快的计数 tick、焦平面一声柔和的滤波扫频。
- **音乐**：硬槌颤音琴走八分与十六分，马林巴的 tick，弓拉颤音琴和玻璃水杯做 pad 与动机，每个读数落点一声钟琴，带二三次谐波的脉冲贝斯，落点下面定音鼓和低音鼓。和声保持开阔明亮，曲子由用户定调。
- **底噪**：安静的实验室（风扇、一点交流声）。
- **沉默**：裁决之前、爬回之前留空；之后第一个声音必须是读数或转塔，不是音乐。
- **混音**：人声比音乐高约 10dB，音乐在人声下压；整体 −14 LUFS。旁白冷静、精确；数字交给 TTS 时拼成词，屏幕上仍是数字。

## 原生手法

- **下潜**：从手里的玻片一个镜头到细胞，每一次真的换级转塔才咔哒一声。适合：活检到细胞、镀层到晶粒、头发/皮肤切片到分层。
- **数颜色**：画一个圈，让扫描前沿横穿，点亮每个被计数的像素，把占比滚到落点，底下给原始计数。适合：组织里的胶原、陶瓷的气孔、涂层的覆盖、样品里的色素。
- **两个圈一个裁决**：量一处，同倍率 truck 到另一处，再把两处框进一帧，说出差在哪。适合：处理 vs 未处理、边缘 vs 中心、之前 vs 之后。
- **焦平面扫 + 圈**：落位，扫过焦平面，圈住一个结构并给出它的尺寸。适合：细胞核、颗粒、纤维直径。
- **爬回**：拉回眼睛的尺度，比例尺倒着跳；标题写在玻璃上。

## 变化空间

agent 决定：标本、染色或成像方式、数什么、相机路径、强调色、结尾。

- 结构：一次下潜落到一个测量；同一倍率下两处或两份标本的对照；从细胞开始、爬出去揭示它属于什么。
- 开场：台面上移动光里的玻片；已经对焦的细胞，爬出去才看见全貌；一片虚焦 rack 进焦点。
- 结尾：标题写在玻璃上；最后一个读数留在沉默里；玻片被抬出画面。

## 坑

- **许可**：网上大部分显微图是 CC BY-NC 或全版权。可用：CC0 全片扫描、政府公有领域显微图（NIH、CDC PHIL、NASA、USGS）、CC BY 图集；每个文件都要进出处表。不可用：未谈妥的 CC BY-SA、NC 图、期刊插图、AI 图。
- **找素材**：按器官/染色/材料 + "whole slide" 去公开测试集、影像数据中心、细胞影像图库、博物馆与维基共享（按许可筛选）找；优先元数据里带像素尺寸的文件。CC BY-SA、ODbL、"no known restrictions" 都不等于 CC0——把条款说给用户，问过再用。做产品/实验室/品牌时先问用户要他们自己的扫描件。**永远不许拿生成图代替真实标本。**
- **不同样品之间不许互相放大**：两份"同一个东西"的显微图就是两份标本。只用一份金字塔；非要接素材，就在一次对焦呼吸上切，并说明。
- **像素尺寸**：从文件里读（XMP `ScanRes`、TIFF 分辨率、OME `PhysicalSizeX`）；玻片照片的分辨率标签要在和扫描比对过之后才能信。
- **上采样**：超过约 1.6× 就成糊。下潜在扫描的真实分辨率处结束。
- **拼缝**：有些扫描仪的分块是重叠的，会露出接缝；查接缝信息，或用取景把它框出去。
- **玻片上的字与 logo**：条形码和编号是标本的一部分，保留；厂商标识不是，填掉或裁掉。
- **说法**：染色的颜色只等于染色协议说的那件事，不多不少；测出来的占比只属于画出来的区域和写明的阈值，永远不是临床评分。
- **本工具特有的坑**：图片元素被二次压缩或缩放 → 糊；用 `preview_frames` 在倍率最高那一帧看清楚。字幕条压住读数 → 读数放上半区。标记没钉在 world→screen 上 → 推近时漂移。为了"好看"给照片补画结构 → 这条片子作废。
