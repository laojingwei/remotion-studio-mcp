# 微游戏快闪（microgame-flash）

> 一句话本质：一个微游戏 = 喊出来的一句指令词 + 2.5–4 秒 + 一个动作 + 一个结果（成功，或者好笑的失败）；每个微游戏换一种视觉媒介，统一的只有结构和切点。
> 一句话参照（只学语法）：五秒训练营式的微游戏合集（指令→动作→判定）、各媒介自己的工艺（蜡笔的压力、孔版的套版、终端的字形、蓝图的线宽）。不照搬它们的名字、角色、UI、关卡和音乐。

## 本质 / 不是什么

- 本质：**一个微游戏 = 一句喊出来的指令词 + 2.5–4 秒 + 一个动作 + 一个结果**（成功，或者好笑的失败）。
- 本质：**每个微游戏换一种视觉媒介**——蜡笔、水墨、终端、孔版、像素、蓝图、瑞士排版、黏土、剪纸、木刻……换媒介那一下的冲击既是笑点也是节拍。
- 本质：**一个固定主场把片子箍住**：一个有主持人的舞台、一个命数计数器、一个关号牌；微游戏之间回到这里。
- 本质：**它一直在加速**：每过几关，tempo、关卡时长、主场停留、指令词停留、角色帧率一起上台阶。
- 本质：**主角跨媒介活下来**：每种媒介重画一遍，但保留两三个剪影记号。
- 不是 **`game-show-flat`**：那是**一套固定的综艺包装**——全片同一套平涂厚描边、条纹/放射布景、回合制、呼叫-应答。这条正相反：**每一段的画风都换**，只有结构不变。不是综艺包装，是媒介轮换的段落结构。
- 不是风格样品卷，也不是蒙太奇：每一关都有赌注、命数把它们串成一条线，且规则必须在一秒之内被看懂。
- 也不是 `crayon-storybook` / `ink-wash` / `terminal-ascii` / `risograph-print` 这类单一媒介风格——那些是"全片一种做法"，这里是"每段一种做法"。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 指令词砸屏 | 一个动词斜着砸进来，白字厚墨描边 + 彩色投影 + 身后一个爆炸形 | 任何动作类主题 |
| 换段就换画风 | 上一段还是蜡笔，下一段已经是琥珀色终端，再下一段是蓝图 | 步骤、技能、一天、流程 |
| 画中画舞台 | 游戏只占画宽约 40%，在电视/街机柜/手机/窗里演 | 主持人视角、闯关 |
| 命数板 + 关号牌 | 3 → 2 → 1（最后一颗在闪），关号随关卡往上跳，跳的那一下带一声 | 机会、预算、体力、闯关 |
| 结果印章 | ✓ 或 ✗ 砸在缩回去的画面上，配一声闷响 | 胜负、及格、验收 |
| 扳机道具 | 按钮/拉杆/铃，被按下的极近景就是开场 | 综艺、教学、演示 |
| 一个颜色跟着人走 | 水墨里一颗朱砂点、终端里一个反白字、瑞士排版里一个信号红圆 | 跨段的连续性 |
| 计时器压拍 | 引信一拍一个结，火花正好走过每个结 | 倒计时、deadline |
| 失败的物理 | 动作过冲、拍扁、撞头、弹飞、滚出画 | 搞笑、翻车复盘 |
| 即时回放 | 定格、半速、推近、上下黑边、用这个媒介的字写说明 | 必须看懂的那一下 |
| 一轮比一轮快 | 同样的动作后段做得更短、更快、帧率更足 | 加速、收尾 |

规则：
- 每支挑 2–3 个，至少一个不在「最俗的版本」里；**"换段换画风"是必须项**，少了它就是别的风格了。
- 指令词和结果印章最好认、也最容易用滥；第二支片子换一组信号。
- 媒介清单至少要跨三类（手绘 / 印刷 / 屏幕 / 技术图纸），不能四种都是"手绘风"。

## 这个风格最俗的版本

- 画面：紫外舞台 + 主持人喊"跳！"，切蜡笔小人跳一下，✓ 出现；再切像素小人跳一下，✓ 出现……十关都是"小人做一下 + ✓"，画风换了、动作没换，第三关观众就走了。
- 声音：一段通用 8-bit loop 从头放到尾，每关一个"叮"。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么刻意保留。保留时把力气花在"每一关的动词都不一样"和"失败真的好笑"上。

## 适配

- 用途：快节奏、一连串小场景的主题——五秒训练营、技能速览、一天的流程、闯关式教学、能力罗列、新品功能串烧；不适合要沉静、要留白、要一条线讲完的题材。
- 内容：能切成 6–14 个"一个动词就能说清"的小任务，每个 2.5–4 秒，各有一个明确结果。
- 时长：30–75 秒最舒服（8–16 关）。超过 90 秒要分组，中间回主场歇一拍，否则高频切点会把人打累。**加速一旦停下就结束**，别拖。

## 技术路线

- 本工具：一个微游戏 = 一个 `add_scene`；指令词、角色、道具用 `add_element` 放进去；回主场也是独立一幕。
- **每一段各自落地画风**：进这一幕先 `set_theme`（或 `apply_style`），用这一媒介的配色与字体；**切到下一段就必须再设一次**，不要指望上一段的主题还留着。这条是整支片子最容易做错的地方——全片只设一次主题，就退化成 `game-show-flat`。
- 节拍表先做：BPM、关卡时长、指令词停留同一张表；切点帧、印章落点、`add_audio` 的音效时间码全从它派生，不另开手工清单。静帧验收 `preview_frames` 每关抽三张——指令词定帧、动作定帧、结果帧；动效 `render_preview_clip` 看连续两三关，确认"换媒介那一下不闪、不空帧、不残留上一段的图形"。
- 字体落地：指令词用 `Archivo Black` + `Microsoft YaHei` 粗体，厚描边靠"墨色底层 + 白色上层"两层文字叠出来；幕内文字可以换字族（终端 `VT323`、水墨 `STKaiti`、瑞士排版 `Inter Tight`、古典 `Georgia`），但字族切换只发生在幕与幕之间。
- 旁白 `tts_narration`；字幕 `set_subtitles`；素材 `upload_asset`；音效与 BGM `add_audio`。

## 材质与渲染

- **主场**：平涂卡通，近黑粗描边（约 7px），纯平填充，**一道硬边阴影**（同形状填暗色、按形状裁切、往左上偏移再填一次）。固定家具：一个"画中画"窗口（电视、街机柜、手机、窗）、命数板、关号牌、一个扳机道具。
- **每种媒介是一次简化重画**，只要一条"通道技巧"就能一眼读出来：
  - 手绘类存**压力或湿度**：蜡笔的透明度 = 压过纸纹的力度；水墨分湿墨与干墨两条通道。
  - 印刷类存**版密度**：孔版一版一通道、叠印相加、网点、套版偏移。
  - 屏幕类是**低分辨率缓冲放大**：像素是索引色缓冲 + 自动描边 + 抖动；终端是手工排的字形画 + 磷光。
  - 技术图纸类是**线系统**：蓝图看线宽与尺寸线；瑞士排版是严格网格、一个字族、一个信号色。
- **主角翻译**：每种媒介从头重画，但同样的记号必须活下来（一个帽子形状、一个彩色点、胸口一个数字）。动手前先列一张"主角在各种媒介里的对照表"。
- **混媒介画面**：带透明的媒介压在底上，纸质媒介走正片叠底，屏幕媒介压平并裁进一个面板里；图层顺序一旦定下就不许变。

## 配色

| 用途 | 值 | 含义 |
|---|---|---|
| 主场底 | `#2A0F5C` | 深紫，放射光在它后面转 |
| 主场强调 1 | `#FF2E88` | 洋红，指令词投影、横幅 |
| 主场强调 2 | `#FFC928` | 金，关号牌、大字 |
| 主场强调 3 | `#1FD1D1` | 青，命数板、角标 |
| 成功 | `#3FBF6F` | 固定色，只给 ✓ 印章与命数板 |
| 失败 | `#E03A3A` | 固定色，只给 ✗ 印章与命数板 |

- 主场有一份饱和派对色盘：深底 + 旋转放射 + 两三个响亮强调色，外加**固定的成功色与失败色，只出现在印章和命数板上**。
- 每种媒介自带色盘，从它的传统里来：蜡笔的蜡色、单墨加朱砂、琥珀磷光、三张孔版色、受限像素盘、蓝底白线、黑白红。**绝不用主场的颜色去染一种媒介。**
- 一个强调色跟着主角跨媒介走（水墨里一颗朱砂点、终端里一个反白字、瑞士排版里一个信号红圆）——换段之后眼睛靠它找到人。另两套主场备选：青绿底 + 珊瑚 + 柠檬；黑舞台 + 亮橘 + 电蓝。

## 字体

- **指令词就是字幕**：重磅展示字族，白色 + 厚墨描边 + 一层彩色投影 + 身后一个爆炸形，整体斜几度。约 3 帧砸进来（过冲 → 回稳），停住，然后**在第一个动作之前缩成角标**，结果永远不会被它压住。只出现一次的横幅直接飞出去、不缩角标，这样角标不会堆。
- **其他行**：主场配色的圆角卡 + 主场描边 + 硬阴影，一个圆头友好的字（约 50px），一个小喇叭图标；放在计时器上方。保持 ≥ max(1.8 秒, 语音 + 0.6 秒)，绝不压在大横幅底下。
- 一关之内任何文字（回放说明、标签）用**那个媒介自己的字体**；指令词只出现在字幕轨里，**绝不烧两遍**。

## 运动

- **帧率也是阶梯的一环，五样东西一起加速**：早期角色一拍二或 8fps，后段更快、高潮一拍一；tempo、关卡时长、主场停留、指令词停留、角色帧率同时上台阶。镜头运动、转场、计时器火花永远一拍一。
- 计时器可见且压拍：一根引信一拍一个结，火花正好走过每个结；回放时它冻住。
- **通过画中画的统一转场**：推进屏幕开始一关（约 0.25 秒），把这一关缩回屏幕里结束（约 0.33 秒）并盖 ✓/✗ 印章。不叠化，不空帧。
- 失败是演出来的：动作过冲、拍扁、撞头、滚出画——由媒介自己的物理制造笑点。本工具不承诺运动模糊，连续运动用缓动曲线 + 切点速度匹配。
- 必须让人看懂的那次失败给**即时回放**：定格、半速、推近、上下黑边、用这个媒介的字写一行说明。
- 主持人每拍有一个小动作；把它一下停死，是最强的情绪工具。

## 画面怎么活

- 主场每拍都在动：放射缓慢转、命数板的数字在跳、关号牌在等、主持人踩着拍轻微起伏，幅度小，不抢指令词。
- 一关之内，动作从指令词落地那一刻起算，一路跑到结果，中间没有"准备"——2.5–4 秒里塞不下停顿。
- 换媒介那一下是画面最响的一下：切换前后都不许留空白帧，靠推进/缩回把两段缝起来。
- 只有三处可以静：最大那一击之前的沉默、印章落下前的一顿、回放的定格。

## 镜头语法

| 动作 | 表达什么 | 适合 |
|---|---|---|
| 从一关内部开始，指令词已经在砸 | 规则自己会解释自己 | 把观众直接扔进去 |
| 从游戏画面里拉出来 | 尺度：这只是舞台上的一个屏幕 | 第一次回主场 |
| 锁死的正面主场 | 那个常量，只有记分板在变 | 舞台段落、主持人反应 |
| 老虎机条（舞台裂成一条条旋转的旧画面，一拍停一条） | 加速、小结 | 提速、换轮 |
| 极近景插到扳机道具上 | "开始"被感觉到 | 在重拍上开一关 |
| 灯收成一束顶光，画框不动 | 赌注、最后一次机会 | 最后一条命、抉择 |
| 瓷砖翻面（旧关末帧翻成新画面的一块） | 过去成为现在的材料 | Boss、决赛、回顾 |
| 推到一个细节，停住 | 观众比主角先发现 | 线索、一段静默 |
| 一拍之内甩回全景 | 释放 | 解法开花、救回来 |
| 分屏，两种媒介并排 | 对比、对决 | 两个玩家、前后、两种做法 |

取景：游戏画面占画宽的固定比例（约 40%）；混媒介画面里只留**一条主视线**（A 引到 B 引到 C），信息面板推到角落。

## 声音调色板

- **音乐先行**：先有 tempo 网格和一张 cue 表，每一下画面重音都落在表上列出的点。
- **一条不变的律动 + 每种媒介一件色彩乐器**：律动（带 ghost note 的鼓组、slap 或合成贝斯、铜管短音、键盘）从头到尾在；每种媒介加自己的音色——蜡笔玩具钢琴、水墨尺八或古琴、终端方波哔声、印刷颤音琴、像素脉冲琶音、图纸打字机、瑞士排版响木、黏土卡林巴、木刻筝。
- **拟音跟着媒介走**：蜡笔的吱、湿的啪叽、电传机的嗒嗒、纸的脆响、降位深的噪声、棘轮与印章、空心的"咚"。主场：弹簧扳机的咔、丢命时玻璃裂、卡片翻、卷轴转、稀疏的掌声。
- 加速的做法（按需挑）：每次提速前一段上行铜管；每轮升一个调；不改 tempo 而是把音符时值减半；最后一条命时律动抽成心跳。
- **真正的留白**：最大的那一击前至少一次沉默（可以留一个心跳或一个定音）。最响的一下紧跟在最长的沉默之后。
- 人声：主持人喊每一句指令词，比铜管那一击**晚一丝**，否则被盖住；主角话极少（反应比台词好用）。人声之下音乐让约 11dB、拟音让约 6dB。整体 −14 LUFS。

## 原生手法

- **每关换媒介**：每件事用最适合它的媒介画（烤面包——面粉用蜡笔、烤箱刻度用蓝图、壳用木刻；护士的一天；一场劫案的几个角色）。
- **指令词**：一个动词同时是剧本、字幕和重拍（收银台的"扫！"、瑜伽课的"呼吸！"、签约的"签！"）。
- **命数当 UI**：计数器不靠旁白就有情绪，3→2→1（最后一颗在闪）自己就能造张力。
- **提速**：五样东西一起上台阶。
- **失败变成解法**：前面某次失败的材料，在最后一关成了答案。
- **Boss 混规则**：最后一关由前面几种媒介的碎片拼成。
- **即时回放**：用慢动作把笑点讲清楚。

## 变化空间

每一支由 agent 决定：任务是什么、每一关用哪种媒介、主场和它的画中画、主持人与主角、关数、失败落在哪、决赛是什么、开场与结尾。**指令→动作→结果的单元、换媒介、加速，这三样不变。**

- 三种结构：两个玩家轮流（命数板变成拔河）；一天按小时（一关一小时，早上和傍晚各一次提速，决赛是午夜）；接力（每一关的结果是递到下一关手里的那个东西，链条就是故事）。
- 三种开场：主场还没醒（灯暗着，主持人在第一拍醒来）；从一个 game over 画面倒带回来；只有命数板，计数器在往下跳，我们还不知道它在数什么。
- 三种结尾：排行榜（主角用每种媒介的字体逐字母打自己的名字）；片尾字幕做成再一关（"抓住这些名字！"）；主场收进画中画里，屏幕关掉。

## 坑

- **全片只设一次主题** → 每关画风一样，风格退化成综艺包装。改：每一幕进来各自 `set_theme`/`apply_style`，切段就换。
- **用亮度坡做的 ASCII 人是一团糊** → 改：手工排的结构化字形，强调处用一个反白字。
- **水墨形状读起来像烟** → 改：先设计剪影（一个短的圆斑阶段，然后是有接缝和亮边的清晰结构）。
- **高 tempo 下的失败没人看清** → 改：让动作过冲、撞到什么东西，或者给它一次即时回放。
- **带透明的媒介从缝里露出背景** → 改：必须实的地方铺满压力的实底。
- **跨段复用元素/图形** → 上一段的图形残留到这一段。改：一个微游戏一个独立场景，画布与元素组不跨段借。
- **指令词角标越堆越多 / 100% 白闪被读成空帧** → 改：只出现一次的横幅直接飞出去、不缩角标；白闪封顶约 60%。
- **`tts_narration` 念单字指令会拖出元音尾巴**（"跑" → "跑啊"）→ 改：让它念一个两词短语，再按字幕时间截在第一个词之后，每段都试听确认（密集混音里这种 0.2 秒的词很容易被误读）。
- **只换画风不换动作** → 十关都是"小人做一下 + ✓"，第三关观众就走了。改：每一关写一个不同的动词和一个不同的结果。
