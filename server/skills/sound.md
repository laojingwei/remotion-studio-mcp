# 声音设计指南

声音是视频的另一半：同样的画面，音画关系对不对，观感能差一个档次。
（方法论源自 garden-skills/motion-showreel 的 sound.md，按本工程音频能力改写——
本工程没有内置作曲引擎，BGM/音效来自**素材库或用户提供的音频文件**，口播走 TTS。）

## 1. 先选档

| 档 | 适用 | 本工程怎么做 |
|---|---|---|
| 无声 | 循环动图、要进别的片子的素材、汇报静音场合 | 什么都不加；确认没有残留音频轨 |
| 只配音 | 讲解/教学/口播片（最常见） | `tts_narration(segments, applyToScenes=true)` 一站式：合成、对齐幕长、写字幕 |
| 配音 + BGM | 情绪需要托底的片子 | BGM 走 `add_audio_track`（全局轨，不占场景）；人声优先避让（§5） |
| 配音 + BGM + 音效 | 卡点、作品集、产品片 | 音效素材落具体场景（场景内音频元素），落帧规则见 §4 |

BGM/音效来源在 brief 问诊第 7 步确认（`music` 字段）：素材库挑选 / 用户提供 / 关闭。
**用户没提供且素材库没有合适的，如实告知并问，不要拿不搭的曲子硬凑。**

## 2. 先定声音方向

BGM 不选也会落进默认：每支片同一首电子垫乐。选曲前先回答：

- **角色**：音乐是推动（卡点片）、托底（口播片，音量压低）、还是几乎不出现（拟音/安静片）？
- **情绪与段落**：全片情绪曲线是什么（§3），BGM 哪一段对应高潮？
- **对标**：想想这类片子里好听案例用什么曲风；写进 brief 对标一栏（学结构不搬曲子）。
- **别连用**：上一支片子用过哪首，这支换掉，除非用户要系列统一。

## 3. 结构与戏剧曲线

BGM 段落和幕结构对位（幕结构本身见 `get_guide("craft")` §2）：

| 曲线 | 形状 | 适合 |
|---|---|---|
| 吸气→爆发 | 铺垫 → 渐强 → 停半拍 → 撞击 | 作品集、宣传、logo 片 |
| 累加 | 一层层叠，从不停 | 生长/从零到一主题 |
| 抽空 | 满编 → 突然只剩一件 | 反差、产品亮相（比 drop 克制） |
| 波浪 | 起伏几次无单一高潮 | 氛围、品牌情绪、循环 |
| 单线条 | 一件乐器从头到尾 | 极简、高端、诗意 |

落法：选 BGM 时**挑包含你要的那条曲线的段落**（如截取一个完整乐句 4/8 小节，最好含一个 drop）；
高潮幕对齐曲子的重拍/爆发点。曲子有能量突降段正好放在「吸气」幕后面。

## 4. 时间规则

- 音效落在**动作那一帧**：元素进场帧、数字落定帧、转场起点。场景内音频元素的时间窗按场景帧换算（fps 30）。
- **重拍前留半拍静音**：drop 前让 BGM 音量短暂压低（或选曲自带停顿），静音后的第一个声音要最响。
- **J-cut**：下一幕的声音提前 2–4 帧进来，切点更顺（把音频元素 start 提前即可）。
- 循环片：BGM 首尾音量一致，尾巴别带长混响突然断掉。
- 场景内音频只裁时间窗、窗口内从文件第 0 秒播：需要曲子中段时先裁文件或用 `startFrom` 语义确认落点。

### 4.1 卡点：怎么拿到拍点

**先测再放，别凭感觉估帧号。** 有 BGM 文件就用 `analyze_audio`：

```
analyze_audio(src="/assets/bgm.mp3")        # 返回 BPM、置信度、拍点帧号（前 16 个）
analyze_audio(src="...", save=true)         # 同时把网格写进工程，后续 get_project 能看到
```

读返回值时只看两样：**BPM** 和**置信度**。

| 置信度 | 含义 | 该怎么做 |
|---|---|---|
| ≥ 2.5 | 有清晰鼓点，结果可信 | 直接用拍点帧号放转场/特效 |
| < 2.5 | 纯人声/氛围/古典，测不出拍 | **别用**。问用户「这首歌多少 BPM」，然后 `set_beat_grid(bpm=128)` |

用户直接告诉你 BPM 时不用测，直接：

```
set_beat_grid(bpm=128, offsetSec=0.25)      # offsetSec = 第一拍在第几秒（可负）
```

之后按这个 BPM 算帧号手动对位：`interval = 60 / bpm * fps`（128 BPM @30fps = 14.06 帧）。

**卡点手法**（按性价比排序）：
1. **转场起点对齐拍点**：把 `set_transition` 所在幕的接缝挪到拍点附近（±2 帧内听不出）
2. **闪白/频闪压在重拍**：`add_effect(kind="flash", from=拍点帧, durationInFrames=4)`
3. **画面切点对齐拍**：在拍点处 `add_scene` 或 `move_scene`
4. **drop 前留白**：重拍前 2–4 帧把 BGM 音量压到 0，落地瞬间恢复

不要每拍都卡——**一拍一卡会变成 PPT 翻页**。挑 4–8 个关键拍（一般是每 2 或 4 拍）足够。

## 5. 混音（人声优先）

### 5.0 音量刻度：1 = 原音，可以调到 5

**这是所有音量参数统一的口径**（`set_audio.volume` / `audioTracks[].volume` / `update_element.audioVolume`）：

| 值 | 含义 | 什么时候用 |
|---|---|---|
| 0 | 静音 | 临时关掉、做停顿 |
| 0.2–0.4 | 压到 20–40% | BGM 垫在人声下（常规做法） |
| 1 | **原音**（不是最大值） | 素材本身音量合适时 |
| 2 / 3 / 5 | 放大 2× / 3× / 5×（+6 / +9.5 / +14 dB） | 素材录得太小声、找不到更好的源时 |

放大的硬约束：**输入是线性的，源文件峰值已接近满刻度时放大就会削波**。
`set_audio` / 音轨工具会读文件峰值算一次，会爆音就在回执里警告并给出「不削波的最大音量」。
`balance_audio` 更是直接按峰值上限（-1dBFS）夹住 —— 宁可小声，不要爆音。

### 5.1 声音大小不一：两种病，两种药

| 症状 | 病名 | 用什么 |
|---|---|---|
| A 段响、B 段轻（不同素材 / 不同 TTS 段之间差异大） | 段间响度不齐 | **`balance_audio`** |
| 同一段里前轻后响（BGM 副歌炸、口播忽大忽小） | 段内动态过大 | **`compress_audio`** |

**段间配平**（按角色给不同目标，不是一刀切）：

```
balance_audio(dryRun=true)                              # 先看方案
balance_audio()                                         # 人声 -16 / BGM -23 / 音效 -18 LUFS
balance_audio(scope="elements", voiceLufs=-15)          # 只配平人声段，目标 -15
```

它会：读每个源的真实 LUFS 与峰值 → 算增益 → 写回 `volume`。
被峰值卡住时回执写「峰值限制」，说明**这段素材没法更响了**（不是算法保守）。

> 用户手动改时走编辑器右侧「背景音乐」面板：那里直接显示当前响度（`-26.4 LUFS · 峰值 -20dBFS`），
> 下面有「配平到 -23」和「压平动态」两个按钮，点完可以「撤销」。**同一套算法**（`shared/audio.ts`），
> 只是入口不同 —— 别在给用户的说明里只提工具名，会让人以为界面上没有。

**段内压缩**：

```
compress_audio(ratio=3)                    # BGM 默认，压平副歌
compress_audio(scope="tracks")             # 所有音效轨
compress_audio(clear=true)                 # 清掉曲线，恢复原始动态
```

结果是 `gainCurve`（200ms 一个采样点的增益序列）存进工程：**可撤销、可复算、能随工程导出**，
不是导出时的一次性处理。`ratio` 越大越平；`ratio=1` 只补不压（安静段补上来、响的段不动）。

**顺序很重要**：先 `balance_audio` 定整体，再 `compress_audio` 压动态，最后 `ducking` 做人声避让。
反过来先压动态会把「本来就该有的强弱起伏」也压掉，配平又把它拉回来，来回打架。

### 5.2 混音规则

| 规则 | 数值 |
|---|---|
| 人声（TTS/口播）是主角 | BGM 基础音量压到人声的 20–40%（`set_audio(volume=0.25)`） |
| 有人声时自动避让 | **`set_audio(ducking=true)`**：人说话时 BGM 降到 30%，句间自动回升（见 §5.3） |
| 低频克制 | 手机外放听不见低频；选曲别只图低音震撼 |
| 音效不抢戏 | 转场 whoosh 类音效短促（0.2–0.5 秒），别铺满 |
| 放大要有理由 | 超过 1 的数字放大是"救素材"，不是常态；能换源就换源 |

### 5.3 人声避让（ducking）怎么用

不用手工算哪一秒有人声——`set_audio(ducking=true)` 会从**场景字幕**和**场景内音频元素**自动推出人声区间
（一行字幕 = 一句话，句间留出换气口让 BGM 回升），然后在每句话前后做斜坡。

```
set_audio(src="/assets/bgm.mp3", volume=0.25)        # 先定基础音量
set_audio(ducking=true)                              # 再开避让（只传要改的字段，其余沿用）
set_audio(ducking={depth: 0.2, releaseMs: 400})      # 觉得回来太快就拉长 release
set_audio(ducking=false)                             # 关掉
```

| 参数 | 默认 | 什么时候改 |
|---|---|---|
| `depth` | 0.3 | 人声仍被盖住 → 降到 0.2；BGM 掉得太空 → 升到 0.4 |
| `attackMs` | 120 | BGM 压得比人声晚（第一字被盖）→ 降到 80 |
| `releaseMs` | 260 | 句间回升太急、听着"抽气"→ 加到 350–450 |
| `padMs` | 60 | 句首句尾切得太干脆 → 加到 120 |

**不需要避让的情况**：全片无人声（纯音乐片）、或 BGM 本身就极轻。这时别开——开了只是白多一层计算。

## 6. 静音自检（你听不到，必须验）

**配音前先 `tts_check(deep=true)`** —— 它验证地址/key/model/voice/format 全链路，
比跑到第 6 步才发现语音服务没启动省事得多。只探连通用 `tts_check()`（快）。

本工程踩过的坑都在这里，**交付前逐条过**：

1. **成片必须有音轨且非静音**：历史上 `muted` 默认值曾让成片连音轨都不生成且零报错。
   验法：`render_video(dryRun=true)` 报告音频是否超长/缺失；渲染后看文件体积（纯静音 MP4 明显偏小）。
2. `get_asset_info` 量每段音频真实时长；mp3 报告偏长 30–50ms 属正常（编码器 delay），不必修。
3. 音频窗口超出幕长**不会循环也不会报错**，播完静音：场景改短后要回头确认音频窗。
4. BGM 全局轨时长要覆盖全片；片尾 BGM 淡出（选自带淡出的段落或接受硬收）。
5. 改过口播文案必须重新合成并重量——同一段文字两次合成时长可能不同。

## 7. 声音的默认味

| 默认味 | 换成 |
|---|---|
| 每支片同一首电子垫乐 | 按情绪曲线和对标选曲；和上一支换掉 |
| 全片一个音量铺到底 | 按戏剧曲线起落；高潮幕放出来、铺垫幕压低 |
| 每个切点都配音效 | 只给最重要的 1–2 处；其余靠转场画面本身 |
| 落版必配长长的钟声/shimmer | 干净收尾：最后一拍 BGM 收住或直接切黑 |
| BGM 盖过人声 | §5 的 20–40% 基线 |

**例外**：对标或风格本身就是这样（synthwave 就是四踩+铺底），或用户明确要求——那是签名，不是默认味。
