# 用途结构库（拍什么、按什么结构讲）

这份指南只讲**用途**：要传达什么、按什么结构排幕。画面长什么样属于**风格**（`get_styles`）；
单个动作怎么动属于**质感**（`get_guide("craft")`）。同一个用途可配不同风格。

用户给了 goal 后先到这里找对应类型，**只读对应那一节**，把结构模板换算成幕数再写分镜。
结构只是起点，内容全部从用户主题里来。

| 类型 | 一句话 | 典型时长 | 常配风格（仅常见） |
|---|---|---|---|
| A 动效作品集 | 展示功力，手法密集切换 | 12–20 秒 | swiss-editorial、kinetic-brutalist、glitch-digital、comic-pop |
| B 产品宣传 | 用真实界面和卖点讲清产品 | 15–30 秒 | minimal-ui、dark-keynote、flat-vector、isometric-infographic |
| C UI 动效演示 | 一个元素连续变一串状态 | 10–16 秒 | minimal-ui |
| D 金句卡点 | 字就是画面，跟着节拍 | 8–30 秒 | kinetic-brutalist、swiss-editorial、risograph-print |
| E Logo 演绎/片头 | 一个想法落成 logo | 4–8 秒 | cinematic-title、liquid-shader、guochao |
| F 循环动图 | 没有开头结尾，无限播放 | 4–12 秒 | generative-geometry、pixel-game |
| G 数据爆点 | 一个数字/一组对比的冲击 | 6–15 秒 | data-motion、swiss-editorial |
| H 年代回顾 | 按时间讲演进史，分段换媒介 | 45 秒–2 分钟 | mixed-media-era、cinematic-title |
| I 口播讲解/长片 | 按原稿组织图形讲述 | 按确认时长 | 按主题选 |

---

## A 动效作品集（5–7 幕）

Hook（第 0 帧就有强图形动作，`bigtext`/`hero`）→ 2–3 段不同手法（每段 1–2 幕，换版式类型）
→ 加速（幕变短）→ 吸气 → 记忆点 → 落版（名字或一句话，`outro`）。
坑：每幕只有约 2 秒，文字只放 1–3 个词；手法多但配色/运动性格必须贯穿全片，否则成模板拼盘。

## B 产品宣传短片（6–8 幕）

Hook（问题或反差）→ 产品亮相（`hero`，真实截图/logo）→ 卖点 ×N（每卖点一幕：`list`/`bullets`/`stats`，
配一个证据动作——数字滚动或流程走一遍）→ 汇总（`compare`）→ 落版（`outro`/`qr`：logo+slogan+入口）。
15 秒版只保留 1 个卖点。**不编造功能、数据、客户评价**；缺素材就问。坑：截图推近会糊；文字太多；品牌色被改。

## C UI 动效演示（8–12 个状态，自由画布）

全片只一个容器：按钮→加载→对勾→播放器→…… 每个状态一次形变（`update_freeform_element`
连续 anim），卡在节拍上。坑：新旧文字叠帧；循环接缝处位置/速度对不上。

## D 金句卡点（3–6 幕）

文案拆成「一拍一句」，重点词放重拍；整句出完后停够可读时间（字数÷4.5+1.5 秒）。
用 `bigtext`/`quote` + `flash`/`strobe` 卡点。坑：词太多、停留太短。

## E Logo 演绎（2 幕）

预备+爆发（1 幕）→ 成形+定格（1 幕，logo+品牌名停留 ≥ 1.5 秒）。
**必须用真实 logo 文件**（upload_asset），拿不到就问，不用色块冒充。坑：比例/颜色走样；定格太短。

## F 循环动图（1–2 幕）

一次完整的呼吸（聚→散→聚），最后一帧状态 = 第一帧。选曲也要能循环。
坑：接缝跳变一眼就能看出来——首尾元素状态必须完全一致。

## G 数据爆点（2–3 幕）

铺垫（问题或对比方，1 幕）→ 数字滚动 1.5–2.5 秒（`stats`）→ 落定（`flash` 反白 + `shake`）→
一句解释停 ≥ 2.5 秒（`quote`）→ 来源小字。**数字只能来自用户或可靠来源**，不确定就标出来让用户核对。

## H 年代回顾（长片，见 `get_guide("long-form")`）

开场（一个贯穿全片的元素）→ 4–7 个阶段，每段 8–20 秒，**每段用那个年代的媒介语言画**
（自由画布重画）→ 高潮汇合 → 结尾呼应开场。史实（年份/名称/首创者）必须核实。
坑：没有贯穿线就成了风格拼盘。

## I 口播讲解 / 长片

口播稿用户提供（`copySource`），有口播先合成量真实时长再排幕（`get_guide("narration")`）；
超 12 幕或 2 分钟按 `get_guide("long-form")` 分章。长片不必保持短片的高密度，按章变节奏，字体色彩贯穿。
