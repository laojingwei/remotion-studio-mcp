# PM068 跟着节拍弹的球

- 类型：三维场景
- 时长：1920×1080
- 长什么样：一次三维实物展示：一颗球在场景里弹跳，每次落地触发一个音，主光加补光与轮廓光，一个让人想截图的签名镜头。
- 适合：硬件与实体产品、模型展示、抽象装置——需要空间感与材质说服力
- 关键词：三维展示、签名镜头、电影机运动、PBR 材质
- 画风耦合：画风自由
- 出处：@Gorden_Sun · https://x.com/Gorden_Sun/status/2105302007896797351 · prompt-motion.com/customize/gorden-sun-041f56

## 槽位

- 主体：a beat-synced animation of a 3D ball falling through a scene —— 要建的那个主体
- 风格：the quality of a professional Blender piece, with some humor —— 画面语言：美术、年代、媒介质感
- 内容：As the ball falls it bounces off objects in the scene and lights each one up on the beat. The scene changes with each piece of music (several classic instrumental pieces, public domain or composed in code). —— 内容清单
- 画幅：1920×1080 —— 横屏 1920×1080 / 竖屏 1080×1920 / 方形 1080×1080

## 提示词

**这一条**：物理要真（重力、弹性、摩擦），幽默在节奏：先按物理弹，再让它开始不听话。音与落地帧必须严格对齐。

**先定签名镜头**：整片只为那一帧服务——观众会截图的那一帧。先把它写清楚（什么角度、什么光、什么东西在什么位置），再倒推前面的镜头怎么把它送上去。

**相机是电影机，不是轨道球**：每个镜头只用一种有名字的运动（推进、升降、环绕、横移、跟焦），有缓入缓出，**相机任何时刻都不许穿进模型**。

**光与材质**：一盏主光、一盏补光、一盏轮廓光，软阴影；环境反射要有，远处加雾做出纵深；材质的粗糙度各不相同——**任何一块表面都不许看起来像默认材质**。

**动**：物件宁可少动，动就要有质量感（起得慢、落得实、停得住）。结构件的拆合要按真实的机械顺序，别让它凭空拼上。

**禁止**：发光堆砌、镜头抖动、把物件转得像在展示柜里转圈、以及任何一眼看出是模板的东西。

**写法**：用 add_scene(type="scene3d") 建场景，动手前先读 get_guide("scene3d")；相机路径与灯光分两轮调，别一次改十处。

**出片前**：先只调签名镜头那一帧，preview_frames 出图给用户看——三维的失败几乎都在光和材质上，不在构图上。
