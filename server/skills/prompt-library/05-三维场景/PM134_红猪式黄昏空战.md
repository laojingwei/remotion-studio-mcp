## 提示词

**这一条**：手绘感的云、暖夕阳、海面反光。**不要复制受版权保护的角色形象**：做「同一时代与气质的架空飞行器」，交给用户决定替换。

**先定签名镜头**：整片只为那一帧服务——观众会截图的那一帧。先把它写清楚（什么角度、什么光、什么东西在什么位置），再倒推前面的镜头怎么把它送上去。

**相机是电影机，不是轨道球**：每个镜头只用一种有名字的运动（推进、升降、环绕、横移、跟焦），有缓入缓出，**相机任何时刻都不许穿进模型**。

**光与材质**：一盏主光、一盏补光、一盏轮廓光，软阴影；环境反射要有，远处加雾做出纵深；材质的粗糙度各不相同——**任何一块表面都不许看起来像默认材质**。

**动**：物件宁可少动，动就要有质量感（起得慢、落得实、停得住）。结构件的拆合要按真实的机械顺序，别让它凭空拼上。

**禁止**：发光堆砌、镜头抖动、把物件转得像在展示柜里转圈、以及任何一眼看出是模板的东西。

**写法**：用 add_scene(type="scene3d") 建场景，动手前先读 get_guide("scene3d")；相机路径与灯光分两轮调，别一次改十处。

**出片前**：先只调签名镜头那一帧，preview_frames 出图给用户看——三维的失败几乎都在光和材质上，不在构图上。
