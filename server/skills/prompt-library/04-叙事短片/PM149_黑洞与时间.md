## 提示词

**这一条**：视觉从「这台机器自己的环境」里取：终端、主题色、字体。也就是用工具本身的视觉语言当美术设定，别另造一套世界观。

**先写故事，再画**：主角要有一个明确的欲望，三次尝试、以不同的方式逐级失败，然后一个转折，最后落点——并且在落点之后再补一个一秒的反转（观众以为结束了，还有一下）。故事没写完不要开工。

**表演纪律**
- 每个角色在剪影里就能看懂：轮廓、体型、姿态先立住，再加细节。
- 每个动作都要有预备（往反方向先蓄一下）和跟随（停下来之后还有余势）。
- 软的、有弹性的东西要压扁拉伸，硬的东西不许。
- **眼睛先动**，身体后到——这一条决定角色像不像活的。

**镜头**：先写镜头表，一个镜头一个动作、带时长，然后严格按表建。镜头之间靠运动和声音接上，**不要交叉淡化**。

**画面**：整片只用少量颜色（一个主色 + 一个暖色点缀就够），背景宁简不繁——观众看不清动作，全是背景的错。

**禁止**：姿势之间生硬地补间、用发光遮住角色、镜头抖动，以及任何一眼看出是模板的东西。情绪不靠特效，靠节奏和停顿。

**出片前**：把「欲望→三次失败→转折→落点→反转」写成五行先给用户看；再建关键的那一镜（最有戏的那一下），render_preview_clip 看动，确认表演立得住，再铺全片。
