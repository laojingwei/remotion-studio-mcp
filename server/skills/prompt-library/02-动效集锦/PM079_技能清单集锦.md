## 槽位

- 主题：把我的技能逐条亮一遍 —— 这条片子围绕的主题
- 配色：最多三色加黑白
- 时长：25 秒 —— 按片长总控；超过 45 秒就分段做，别一条硬拉
- 节奏：120 BPM —— 每个动作都落在这个拍上，100–128 最常见
- 画幅：1920×1080 —— 横屏 1920×1080 / 竖屏 1080×1920 / 方形 1080×1080

## 提示词

**这一条**：技能清单先写死四到五条，每条配一个图形化证明。「沟通能力强」这种字一个都不许出现——证明不了的就删掉。

**要证明什么**：这是一条炫技片，评判标准只有一条——五段技法首尾相接，没有任何一处靠切换糊过去。

**单一概念**：围绕主题挑一个视觉概念（例如同一条线在三段里变成字、变成体、变成数据），先用一句话把它说死再开工。全片一种字体，配色不超过三色加黑白，镜头语言统一。

**五段等分**（时长除以 5，各段同权，不许某段吃掉别人的时间）
1. 动态字体：字自己在动，不是整块位移。
2. 形状形变：一个形状连续变成下一个形状。
3. 平面转空间：2D 元素转进 3D 空间，用 add_scene(type="scene3d")，动手前先读 get_guide("scene3d")。
4. 数据或界面一瞬：让数字或 UI 成为一次视觉事件，而不是贴一块板。
5. 尾标题：片名落版。

**接力而不是切换**：每一段都由上一段的形状、字或颜色长出来——变形、遮罩、沿路径接走都行，**不要淡化也不要硬切**。最后一帧的构图回到第一帧，让它能无缝循环。

**节奏**：120 BPM，每一拍都有事发生；第一小节最狠，最后半小节落版。

**禁止**：画框、角标、时间码——这三样是一眼看出 AI 做的记号；再加粒子爆散、发光、光晕、抖动、RGB 分离、通用渐变、弹跳动效、超过半秒的静止。

**出片前**：先给「一句话概念 + 逐拍分镜」，只建第 1 段，用 render_preview_clip 看动，确认「接力」真的接上了（上一段的末帧和下一段的首帧能对上），再往下铺。
