## 提示词

**这一条**：情报平台：用真实的仪表盘元素（趋势线、热度榜、地图点）做视觉，数据要像真的——量级、单位、时间轴都要对得上。

**要证明什么**：广度。观众看完该记住"它有很多件事做得很好"，而不是记住其中某一件事——所以要给每项能力同等的时间，不许哪个幕抢戏。

**先列能力清单**：把产品最强的 4–6 件事写成一句话一条，先定清单再画分镜。清单之外的东西一律不拍，宁少不杂。

**贯穿物**：从产品自己身上挑一件东西（光标、某个按钮、logo 里的一笔、一个数据点）当贯穿物，全片只靠它换身份：这一幕是光标，下一幕变成图表里的那条线，再下一幕变成按钮——**不要每幕换新东西**，那样就成了素材拼盘。

**每一幕一个能力**：每幕开头由贯穿物变形成下一个界面元素，幕尾落一个看得懂的结论（一句话，不超过 8 字）。幕与幕用形变或遮罩接，不用淡化。

**界面要活的**：真实界面拆成矢量层，矩形、文字、图标各自成元素，不要贴整张截图往里滑。镜头缓慢推近（整段 1.0→1.04），每幕从上一幕的终点接着推。

**品牌纪律**：一种字体，一个强调色，且强调色只给贯穿物和关键词，其余留白。

**禁止**：粒子爆散、发光、光晕、抖动、RGB 分离、交叉淡化、通用渐变、弹跳动效、超过半秒的静止、任何一眼看出是模板的东西。

**出片前**：先给「能力清单 + 逐拍分镜」，只建第 1 幕，preview_frames 抽帧 + render_preview_clip 看动，节奏对了再铺。
