# PM021 工作室官网集锦

- 类型：动效集锦
- 时长：15 秒 · 1920×1080 · 120 BPM
- 长什么样：一条产品集锦，围绕「我的工作室官网」逐幕展示能力，幕与幕之间用同一个形状接力。
- 适合：产品能力横向铺开、官网首屏循环、展会与社媒投放
- 关键词：产品集锦、能力清单、形变接力、节拍驱动
- 画风耦合：画风部分
- 出处：@andginja · https://x.com/andginja/status/2103492000733618685 · prompt-motion.com/customize/andginja-333d32
- 同稿：另有 1 位作者提交了同一段提示词（@melvynx）——源站允许照抄模板直接交，所以这 2 条源页共用这一份配方

## 槽位

- 产品：我的工作室官网 —— 名字 + 链接，不眼熟就加网址
- 品牌：沿用产品自己的配色与字体 —— 配色与字体，不给就交给调研
- 结尾：一行行动号召 —— 最后一帧压的那句话
- 时长：15 秒 —— 按片长总控；超过 45 秒就分段做，别一条硬拉
- 节奏：120 BPM —— 每个动作都落在这个拍上，100–128 最常见
- 画幅：1920×1080 —— 横屏 1920×1080 / 竖屏 1080×1920 / 方形 1080×1080

## 提示词

**这一条**：产品位改成「把网址贴进来」——先抓真实站点的 logo、截图与文案，再按能力逐幕展示。没有素材就先问用户要，别凭空造页面。

**要证明什么**：广度。观众看完该记住"它有很多件事做得很好"，而不是记住其中某一件事——所以要给每项能力同等的时间，不许哪个幕抢戏。

**先列能力清单**：把产品最强的 4–6 件事写成一句话一条，先定清单再画分镜。清单之外的东西一律不拍，宁少不杂。

**贯穿物**：从产品自己身上挑一件东西（光标、某个按钮、logo 里的一笔、一个数据点）当贯穿物，全片只靠它换身份：这一幕是光标，下一幕变成图表里的那条线，再下一幕变成按钮——**不要每幕换新东西**，那样就成了素材拼盘。

**每一幕一个能力**：每幕开头由贯穿物变形成下一个界面元素，幕尾落一个看得懂的结论（一句话，不超过 8 字）。幕与幕用形变或遮罩接，不用淡化。

**界面要活的**：真实界面拆成矢量层，矩形、文字、图标各自成元素，不要贴整张截图往里滑。镜头缓慢推近（整段 1.0→1.04），每幕从上一幕的终点接着推。

**品牌纪律**：一种字体，一个强调色，且强调色只给贯穿物和关键词，其余留白。

**禁止**：粒子爆散、发光、光晕、抖动、RGB 分离、交叉淡化、通用渐变、弹跳动效、超过半秒的静止、任何一眼看出是模板的东西。

**出片前**：先给「能力清单 + 逐拍分镜」，只建第 1 幕，preview_frames 抽帧 + render_preview_clip 看动，节奏对了再铺。
