# PM179 DistilBook 产品解说 A

- 类型：产品宣传
- 时长：30 秒 · 1920×1080 · 120 BPM
- 长什么样：一条产品宣传片，Distilbook 当贯穿物从界面里长出来，逐幕变形，最后一帧落成 logo。
- 适合：SaaS 上新、功能发布、路演片头——要观众记住「它能干什么」，不是记住某一屏界面
- 关键词：贯穿物、界面矢量分层、小过冲弹簧、克制动效
- 画风耦合：画风部分
- 出处：@sudo_kiran · https://x.com/sudo_kiran/status/2103486573476254201 · prompt-motion.com/customize/sudo-kiran-4f8b59
- 同稿：另有 1 位作者提交了同一段提示词（@sudo_kiran）——源站允许照抄模板直接交，所以这 2 条源页共用这一份配方

## 槽位

- 产品：Distilbook —— 名字 + 链接，不眼熟就加网址
- 品牌：沿用产品自己的配色与字体 —— 配色与字体，不给就交给调研
- 结尾：一行行动号召 —— 最后一帧压的那句话
- 时长：30 秒 —— 按片长总控；超过 45 秒就分段做，别一条硬拉
- 节奏：120 BPM —— 每个动作都落在这个拍上，100–128 最常见
- 画幅：1920×1080 —— 横屏 1920×1080 / 竖屏 1080×1920 / 方形 1080×1080

## 提示词

**这一条**：解说路线的第一版：偏「讲清一个概念」，节奏舒缓，允许旁白。

**要证明什么**：只用一句话——这东西插进用户的工作流之后，哪一步变简单了。观众看完该记住那句话，而不是记住某一屏界面长什么样。

**贯穿物**：从产品自己身上挑一件东西当贯穿物——光标、某个按钮、logo 里的那一笔、一个数据点都行。先给它起名字，再画分镜。每一幕都是它的形变：在界面里出生，逐幕换形状或换身份，最后一帧变成 logo。贯穿物之外，全片只允许一种字体、一个强调色，而且这个强调色**只**给贯穿物和关键词用，其余全部留白。

**三幕**（按 120 BPM 数拍，每一拍都要有事发生）
1. 钩子（第 1 小节）：三到五个字说清问题，大字压屏，然后被贯穿物打断。
2. 中段（3–4 个乐句）：产品最强的三四个瞬间。每一段都从「贯穿物变成下一个界面元素」开始，落在一个看得懂的结论上。
3. 收尾（最后一小节）：把最重的一击压在最重要的那一拍，然后贯穿物化成 logo，压上名字和一句话行动号召。

**界面必须是活的**：真实界面拆成矢量层，矩形、文字、图标各自成元素——**不要贴整张截图往里滑**。光标是真的在点、在拖。镜头用屏幕演示的推近方式，让每一刻都占满画面：整段从 1.0 缓慢推到 1.04，下一幕从上一幕的终点接着推，镜头始终不停。

**动效铁律**：弹簧只允许极小过冲；没有东西凭空出现，要长出来、展开、或者被遮罩揭开；相邻两幕的切点要对上速度（见 get_guide("motion-rules") 的接缝一节）。

**禁止**：粒子爆散、发光、镜头光晕、镜头抖动、RGB 分离、交叉淡化、通用渐变、弹跳动效、超过半秒的静止，以及任何一眼看出是模板的东西。

**出片前**：先给「一句话概念 + 贯穿物是什么 + 逐拍分镜」，只建第 1 幕，用 preview_frames 抽 1–3 帧、render_preview_clip 看动，节奏对了再铺整片。静帧看不出动画问题，别拿静帧验收。
