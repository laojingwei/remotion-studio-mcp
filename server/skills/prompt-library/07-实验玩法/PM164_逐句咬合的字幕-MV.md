## 提示词

**字要演内容，不只是出现**：每一句歌词的**意思**要用字本身的动作演出来（"坠落"就掉下去，"绕"就绕一圈）。只做淡入淡出的歌词视频，等于没做。

**卡点精确到字**：以人声与鼓点为准，逐句对齐；一句里如果有重音，那句里最狠的动作必须落在重音上。**差半拍，整片就废**。

**一个母体跟着歌长大**：全片只有一个视觉母体（一条线、一个形、一个字），随段落逐步复杂化——主歌克制，副歌放开，最大的动作留给最响的那一刻。

**段落即结构**：跟着歌曲自己的段落走，不要平均分配时间。留白也是编曲的一部分，安静处不要硬塞东西。

**素材说明**：需要用户提供音频；没有音频就先别开工，节奏无从谈起。

**禁止**：粒子爆散、发光、光晕、抖动、RGB 分离、交叉淡化、通用渐变、弹跳动效，以及任何一眼看出是模板的东西。

**出片前**：把音频铺进时间轴，逐句抽帧核对"这一句的字和这一句的唱对上了没有"。
