## 提示词

**选题就是第一道题**：从你了解的这个人出发，挑一个他会喜欢的题目——具体到一个场景（一座楼、一条江、一个夜晚），不要挑"成长""时间"这种大词。**大词做不出画面，场景才做得出**。

**先写一句意境，再写分镜**：这句话要同时包含时间、地点和光（例：月下的江面把楼映成两半）。写不出来就换题。

**一条片只讲一个瞬间**：不要讲完一座楼的历史，只讲某个夜里它被看见的那一下。时长压住，宁短不长。

**能力降级说明**：源站的原始要求还包含一个「可交互的深度网页」，**我们只出视频**。所以把"让观众去页面里探索"改成"片尾留一个没讲完的细节"——用悬念代替交互，别假装做出了网页。

**画面纪律**：三色以内，一个主光方向，镜头只做一次推进或一次横移。水、雾、灯光这类效果要克制，越少越像真的。

**禁止**：粒子爆散、发光堆砌、镜头抖动、通用渐变、交叉淡化，以及任何一眼看出是模板的东西。

**出片前**：先交那一句意境和一张关键帧，用户点头再建场景——这种片子的成败在选题，不在执行。
