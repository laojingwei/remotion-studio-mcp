# PM001 旧片改版（换参照）

- 类型：实验玩法
- 时长：1920×1080
- 长什么样：把上一条成片原样拆开，逐拍对齐重做，只换主题、意象与文案，不做换皮。
- 适合：已有片子要换主题重发、同一骨架做系列、把别人的爆款改成自己的题
- 关键词：改版、逐拍对齐、不做换皮、保留节奏
- 画风耦合：画风自由
- 出处：@0xEvinho · https://x.com/0xEvinho/status/2103212966703436195 · prompt-motion.com/customize/0xevinho-3777d8

## 槽位

- 蓝本：我们上一条片 —— 要改的那条片：上一条，或一个链接
- 改造方向：一个加密题材的参照 —— 往哪个方向改
- 画幅：1920×1080 —— 横屏 1920×1080 / 竖屏 1080×1920 / 方形 1080×1080

## 提示词

**先指认蓝本**：改的是哪一条——上一条成片，或者用户给的链接。拿不到原片就先要，凭记忆改必然走样。

**逐拍对齐，再谈改进**：先把原片的节拍表拆出来（第几拍切、第几拍落版、镜头何时推），新片按同一张表建。**结构、节奏、视觉语言三样都不许动**——动了就不是改版，是另做一条。

**换的是这三样**：主题、意象、文案。新主题要能撑住原来的节奏（原来是一个按钮的三次变形，新主题也得有"能变三次"的东西），撑不住就放弃改版、重写。

**不做换皮**：只换颜色和字等于没改。判断标准是——把两条并排放，观众说不出"这是同一个模板"，但能看出"这是同一个手艺"。

**改版的三条自检**：① 遮住 logo 和产品名，还能看出这是同一条片子的骨架吗；② 只说主题、不说片子，新主题自己立得住吗；③ 原片最狠的那一拍，新片有没有同等份量的一拍。

**禁止**：粒子爆散、发光、光晕、抖动、RGB 分离、交叉淡化、通用渐变、弹跳动效、超过半秒的静止。

**出片前**：把「原片节拍表 + 新片节拍表」并排给用户看一眼，两列对不上先别建场景。
