## 提示词

**这一条**：视觉是暖木与黄铜、干净背景。每个音都必须能指到一个具体的碰撞——观众数得出来的因果，才是这条片子的全部乐趣。

**先定规则，再让它跑**：这台机器靠什么推进（碰撞？重力？传送带？），先把规则用一句话写死。**规则定完就不许为了画面好看偷偷作弊**——观众看得出来。

**先作曲，再造机器**：把要听到的东西先写出来（节奏、音符、段落），然后设计机器的尺寸和间距，让物理刚好产出这一版。每个音都必须能指到"是哪个东西撞了哪一下"。

**从简到繁**：开场只有一件东西在动、一个声音；中途加入零件、叠加声部；到峰值前把所有零件都用上；最后收在一个干净的单次击中上。

**画面**：几何化、去装饰。观众要看懂因果，不是看雕花。用统一的线宽与色阶，让"因"和"果"在视觉上区分开。

**禁止**：没有可见来源的音、发光、通用渐变、以及任何一眼看出是技术 demo 的东西。

**出片前**：先跑 5 秒验证「因果对得上」（音和下落的物体同步），对齐了再延长到全片。
