# PM145 ASCII 低频波形

- 类型：实验玩法
- 时长：30 秒 · 1080×1080 · 140 BPM
- 长什么样：一条音乐可视化：UK dubstep 的 ASCII 可视化，画面由鼓点、贝斯与 drop 直接驱动。
- 适合：音乐可视化、单曲宣传、演出现场背景
- 关键词：音乐驱动、段落对应、鼓点可见、drop 峰值
- 画风耦合：画风部分
- 出处：@Rames_Jusso · https://x.com/Rames_Jusso/status/2103200703598776559 · prompt-motion.com/customize/rames-jusso-589f80

## 槽位

- 风格：Rusko and Skream style UK dubstep —— 画面语言：美术、年代、媒介质感
- Visual style：bold geometric shapes and type in two colors, hit hard by the bass —— How it looks.
- 节奏：140 BPM —— 每个动作都落在这个拍上，100–128 最常见
- 时长：30 秒 —— 按片长总控；超过 45 秒就分段做，别一条硬拉
- 画幅：1080×1080 —— 横屏 1920×1080 / 竖屏 1080×1920 / 方形 1080×1080

## 提示词

**这一条**：先写曲（前奏、推进、drop），再让画面只由字符构成：字符密度随鼓点变化，drop 时整屏字符重排一次。别加任何图形元素。

**先有音乐，再有画面**：把曲子写成四段（前奏、推进、drop、收尾），或者拿到成品后按真实段落切分。画面的每一次变化都必须对应到能听见的东西——底鼓、军鼓、贝斯、人声切分。

**每个鼓点都要有可见的因果**：底鼓推一次画面、军鼓切一次构图、贝斯让某个形体变形。**不要做那种全屏随机跳动的频谱条**——那不是可视化，是屏保。

**段落即结构**：前奏克制（只留一两个元素）→ 推进段逐层加入 → drop 是全片峰值（所有元素同时到位，一次，不重复）→ 收尾回落。

**视觉纪律**：单一形体语言（一种几何 + 一种字），配色不超过三色；全片只有一个镜头逻辑，别在 drop 时突然换风格。

**禁止**：粒子爆散、发光堆砌、镜头抖动、RGB 分离、交叉淡化、通用渐变，以及任何一眼看出是模板的东西。

**出片前**：把音频铺进时间轴，逐拍抽帧检查"这一拍画面对上了没有"——音画差半拍，整片就废。
