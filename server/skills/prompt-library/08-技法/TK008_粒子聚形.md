# TK008 粒子聚形

- 类型：单技法
- 时长：19.2 秒一轮（4 个形状 × 4.8 秒，短了变形段不够）
- 长什么样：几千颗发光小点聚成一颗心，停住，再散开沿弧线流过去，聚成一座房子。
- 适合：讲具体的东西：家、关系、一个人、一个汉字的分量
- 关键词：粒子、聚成形状、换形、弧线
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 B3 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：要讲一个**具体的名词**——家、一栋房子、一个人、一个汉字——而且想让观众看到「换了形状，其实是同一批东西」。它靠连续性工作：同一批点从心飞到房子，所以才有「外面变了，里面还是它」的意思。讲抽象概念时不要用，观众会去猜形状。

**原文的骨架**：5000 颗粒子，4 个形状，每个形状 4.8 秒，总循环 19.2 秒。形状的缩放是 短边 × 0.36，中心在画幅的 (50%, 48%)。每个形状内：0 到 2.4 秒完全静止，2.4 到 4.2 秒变形，4.2 到 4.8 秒落定，进度的平滑用 smoothstep。每颗点走二次贝塞尔：起点在旧形状的目标点，终点在新形状的同一个序号的点，控制点取两点中点再沿各自随机角度外推 (0.35 + 0.9 × 幅度)——所以是先炸开再收拢，不是直线平移。

**怎么在我们工具里做**：这条是本批里最吃力的。本工具没有「逐帧独立算 5000 条轨迹」的通道，只能降级：把四个形状各做一张点阵 SVG（心、房子、人、汉字，每张 300 到 600 个点），四张放进同一个 freeform 场景，用透明度与缩放接力。变形段是 1.8 秒 easeInOut：前一张放大到 1.12、透明度 0 到 1 反向；后一张从 0.88 升到 1.0、透明度 0 到 1。中间再压一层 fx kind 取 particles（density 40、speed 调高、透明度 0.5）当飞行中的粒子，用来遮住「两张图交叉」的痕迹。**这是近似**：观众看到的是两团点交替，而不是同一批点各自飞过去；要在近景停 3 秒以上就会看穿。

**时间轴与停顿**：一个形状必须给足 4.8 秒：停 2.4 秒、变形 1.8 秒、落定 0.6 秒。停的这 2.4 秒是让人读出形状的时间，也是这条技法唯一的成本——想快就只能砍形状数量，不能砍停顿。

**颜色与亮度**：心 #F08A8A、房子 #F1C070、人 #A9C6FF、汉字 #F6EBD0；变形时按进度在前后两色之间线性混合。点半径 1.1 到 2.7px，亮度 0.75 + 0.25 × 正弦（0.6 到 1.6 弧度每秒，约 0.1 到 0.25Hz），基础透明度 0.55。20% 的点额外加一层半径 × 3、透明度 0.05 的光晕；拖尾用同一位置在 0、−0.045、−0.09 秒三个时刻的三份副本，透明度 1 / 0.5 / 0.25，半径 1 / 0.8 / 0.6 倍——工具里这三份就是点阵图的三层错位描边。背景 #07080C，中心一层半径 800px 的径向光从 rgba(40,46,66,0.30) 到透明，再撒 220 颗透明度 0.15 到 0.4 的暗星。

**字幕**：每个形状停住时下方出一句，进度 0.3 到 1.0 淡入、2.1 到 2.5 淡出，衬线体，字号 = 短边 × 0.043（1080 下 46px），色 #EDE6D6，最高透明度 0.85。用 set_subtitles 统一管这四句，别手打四个文字元素。

**禁止**：一条 4 秒内换四个形状（变形段被压到 1 秒以下，只剩闪）；用照片或细节多的图形当形状（点阵化后会糊成噪点）；爆炸闪光、彩虹渐变、第二种背景。**还有一条硬边界：要求「同一批粒子」飞出弧线时，本工具做不出，只有形状交叉淡化——这一条必须提前跟需求方说清，不然成片会被判为「没做出来」。**

**验收**：preview_frames 抽 1.8 / 3.3 / 5.0 秒——1.8 秒必须是一颗一眼读得出的心，3.3 秒必须是两团点在交叉（中间态），5.0 秒必须是房子。render_preview_clip 数停顿：每个形状的可读时间是否真有 2.4 秒。
