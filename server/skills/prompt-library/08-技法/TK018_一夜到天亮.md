# TK018 一夜到天亮

- 类型：单技法
- 时长：12 秒一轮（前 9 秒推进，后 3 秒停留，最后 1.2 秒回夜）
- 长什么样：同一片天从深蓝烧成橙红，星一颗颗灭掉，太阳从山后升到半空。
- 适合：结尾、希望、熬过去、重新开始
- 关键词：日出、色温迁移、天亮、循环
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 D4 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：结尾、希望、重新开始、一段熬过去的时间。它必须是时间的流逝，不是一张日出的画——判断标准很简单：首帧和末帧并排，中间每一帧都要连着变，一帧都不能跳。所以它至少 6 秒，短于 4 秒就只剩一次换色。

**怎么在我们工具里做**：add_scene 一幕，add_element 依次叠：背景渐变、星、太阳、远山、近山。背景颜色不要用两个色值直接插值，要走一条四段色阶、每段自己插，这样天才会有深蓝到紫、到橙红、到淡金的层次；两色插值只会得到一条脏灰。整条不需要任何纹理，一加噪点就变成了老照片。

**色阶（四条，各给顶色与底色）**：第一段 #04060f / #0d1430（深夜）；第二段 #0c1233 / #3b2e58（转紫）；第三段 #26305e / #d0766a（地平线烧起来）；第四段 #4f79b5 / #f6c27f（天亮）。一轮 12 秒：前 9 秒匀速走完三段过渡（每段 3 秒），后 3 秒停在第四段；最后 1.2 秒（整轮的 90% 到 100%）用平滑曲线把整幅画面拉回第一段，形成可循环的闭环。这个回拉不能省，没有它循环处就是硬切。

**星**：90 颗，只撒在上方 60% 的画面里，1.2 × 1.2 像素的白色方块，透明度 = (0.3 + z×0.6) × (1 − 天亮程度×1.4)。天亮程度到 0.7 左右星就全灭，不用手动删，乘出来的负值当 0 处理。

**太阳与山**：太阳在横向 62% 处，纵坐标从 86% 升到 50%，用缓出曲线（先快后慢，越接近终点越慢，「升起来」才有重量）。半径 = 短边×0.07，颜色从 #ff8a4a 过渡到 #fff1c8，越亮越白。背后一层 #ffb46a 的光晕，半径取短边的一半，透明度 0.35 × 天亮程度。两层山：远山基线在 74% 处、起伏 ±4%；近山在 82%、起伏 ±3%；波形是两个正弦叠加，短波幅度取长波的 0.3 倍。山的颜色也随天亮上抬，远山从 #0a0f20 到 #3a3550，近山从 #05070e 到 #1d1a28，抬升只有天的六成，所以山是逆光的。

**禁止**：太阳上下弹跳、云飘过、镜头推、色阶只给两色、亮部顶到纯白。这一条的动人之处全在「慢慢」，任何一次突变都会把它变成延时摄影的噱头。

**验收**：preview_frames 抽 0 / 3 / 6 / 9 秒四帧并排，四帧的顶色要能连成一条连续的色带，看不出跳；星必须逐帧变少、最后归零；太阳的纵坐标四帧要明显不同。render_preview_clip 看整轮，第 12 秒回到第 0 秒时不能有闪。
