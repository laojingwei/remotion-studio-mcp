# TK011 墨在纸上晕开

- 类型：单技法
- 时长：10 秒一轮（8–12 秒都成立）
- 长什么样：米色宣纸上四团墨自己往四周洇开，边缘发毛，左下角压着一枚红印章，全程只有墨在长大。
- 适合：中国感、回忆、哀伤、给一段话留白
- 关键词：水墨、晕染、宣纸、印章
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 C1 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：讲中国感、回忆、哀伤，需要一个「慢」的底——墨在纸上自己长，人不需要动。它只做气氛和留白，不承载信息：画面里不该出现长句，最多一枚印章两个字。如果这段要交代事实、数据、对白，这条不成立。

**怎么在我们工具里做**：add_scene 建一幕，纸色用 set_theme 定成米黄 #e9e2d2，纸纹用 upload_asset 上传一张纤维纹理图铺满整幅、全程不动（原文的纸纹种子是 21，同一张纸从头用到尾）。墨不用真的逐像素画：做 4 个「墨团」图片元素，每个元素再拆成 16 个小墨斑，按固定偏移散在同一团里——原文每团就是 16 个子斑，偏移在 ±0.25 个团半径之内、子斑半径是 0.4 到 1.0 倍团半径。子斑多、软边重，边缘才「毛」；子斑少就会看见一圈圈的环。

**四团的位置与出场**（半径以画面短边为 1）：(.30 .45) 半径 0.26、0.2 秒出场；(.62 .38) 半径 0.20、1.5 秒；(.48 .66) 半径 0.16、3.0 秒；(.78 .62) 半径 0.12、4.2 秒。扩散用曲线 g = 1 − e 的 −0.9×年龄 次方：0.8 秒长到目标的 63%，3 秒后基本定型。这条曲线是「洇」的全部手感——起手快、后段几乎停住，绝不能写成线性放大。

**混色**：原文靠正片叠底把墨压进纸里。本工具没有逐层混色，用两步近似：墨团整层透明度压到 0.55，再把纸纹复制一层放在最上面、透明度 0.12。代价是墨色偏浅一档，所以墨用 #1c1c20 而不是灰（原文中心透明度 0.22、0.7 处 0.08、边缘 0）。

**印章与收尾**：红方块 #b3352a，边长 = 短边 × 0.085，定位 x = 宽 × 0.06、y = 高 − 边长 − 高 × 0.07；字 #f3e6d6、字重 700、字号 = 边长 × 0.38，两个字。全程 10 秒一循环；8.6 到 10.0 秒之间把纸纹重新盖上来一次、透明度 0 到 1，等于「换一张纸」，下一轮才不脏。

**禁止**：彩色墨、硬边、墨团淡出（墨只会越长越大越淡，不会收）、镜头推拉、现代无衬线大字。出现任何一条，它就从水墨变成烟雾特效。

**验收**：preview_frames 抽 0.5 / 3.5 / 7 秒——0.5 秒只该有第一团且很小，3.5 秒四团都在但都是软边，7 秒全部定型而纸纹仍清楚；render_preview_clip 看每团边缘有没有同心环、印章是否从头到尾一动不动。
