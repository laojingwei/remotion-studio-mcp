# TK005 字散了再聚

- 类型：单技法
- 时长：9 秒一轮（可循环两轮：A→B→A）
- 长什么样：一句话先散成一把漂浮的点，再聚成另一句话——同一个意思，换了个说法。
- 适合：转念、换个说法、自我修正、「其实不是这样」
- 关键词：散开、聚成、变成、转念
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 A5 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：讲"我原来以为……其实是……"。它把两句话之间的**认知转变**做成一次物质变化：第一句散掉，散掉的每一粒都飞向第二句的位置。所以它天然适合"改口"，不适合并列两个观点。

**怎么在我们工具里做**：一幕，一串点元素（上限 1800 个）。把两句话各自"采样"成点阵：在一张文字图上按步长扫，落在笔画上的位置取一个点。步长 = 字号 ÷ 26（字号越大点越多）。然后让第 i 个点从第一句的第 a 个位置，飞到第二句的第 b 个位置。

**时间轴（9 秒，照抄这个比例）**：
0–2 秒 停在第一句；
2–3.3 秒 散开——点从字形飞向画面外一圈随机位置，用 easeOut（先快后慢，像被吹散）；
3.3–4.9 秒 聚拢——从散布位置飞到第二句的字形位置，每个点错峰（随机延迟最多 0.15 × 1.6 秒），所以是"陆续落定"而不是"整体平移"；
4.9–7.4 秒 停在第二句；
7.4–9 秒 散回第一句，闭环。

**参数**：底 #07070a；点直径约 2–3px（随字号缩放）；起止两端透明度略低、中间飞行段略高；每个点常驻 ±1.2px 的抖动，两个不同频率（2Hz / 1.7Hz），让它看起来是"活的粒子"而不是"像素块"。字号取「宽 × 0.82 ÷ 最长行字数」与「高 × 0.34 ÷ 行数」的较小值；竖屏自动断成两行，行距 1.15 倍字号。

**禁止**：粒子爆散（那是爆炸，不是散开）、飞行轨迹拖尾、颜色分级（一色就够）、点从随机位置出发又落回原位（那就白散了，必须 A→B）。

**验收**：preview_frames 抽 1.5 / 4.0 / 6.0 秒——三帧必须分别读得出"第一句 / 中间态 / 第二句"；render_preview_clip 看聚拢段是不是陆续落定，如果像整体平移，说明错峰没做。
