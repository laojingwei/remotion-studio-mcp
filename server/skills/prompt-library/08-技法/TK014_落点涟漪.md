# TK014 落点涟漪

- 类型：单技法
- 时长：6–10 秒（每 1.15 秒落一滴，够看到两滴同荡）
- 长什么样：深青色水面上，一滴落下，四圈压扁的浅青环一圈比一圈淡地荡开，落点闪一下就没。
- 适合：一句话的影响、余波、来不及收回、话已经说出去了
- 关键词：涟漪、水滴、扩散、余波
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 C4 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：一句话落下去之后的余波——说出去了、来不及了、还在荡。它是「事件之后」的技法，画面里必须先有那个落点（一颗水花、一个字冒出来），再让它荡开；没有落点直接荡，观众不知道是什么掉进去了。

**怎么在我们工具里做**：add_scene 一幕，水底用竖向渐变 #082027 到 #020708。涟漪不是一个动画，是一台「每 1.15 秒落一滴」的节拍器：建 5 组涟漪元素轮着用（一组 = 4 个同心椭圆描边），每 1.15 秒把最老的一组挪到新落点重新开始——元素数量固定，逐帧可复现，不会越积越多。

**落点与环**：落点横坐标在 0.12–0.88 个画面宽之间、纵坐标在 0.25–0.85 个画面高之间，按固定种子取，不能用真随机（否则每次渲染落点都不一样）。一滴出 4 个环，j = 0 到 3，第 j 个环比前一个晚 0.2 秒出生。环横半径 = 年龄 × 短边 × 0.17（1 秒长到短边的 17%），纵半径只有横半径的 0.42——这是俯视水面的透视，做成正圆就变成声波了。

**透明度与消失**：单个环透明度 = max(0, 1 − 年龄 ÷ 4.4) × (1 − 0.2j) × 0.75，颜色 #aae1e6，线宽固定 1，不随半径变粗。所以最外一圈能活 4.4 秒，四个环一圈比一圈淡。落点在 0.25 秒内给一颗 #cdf3f5 光点，半径 10、透明度从 0.8 线性降到 0。

**禁止**：环变粗、环有填充、环从中心「弹」出来（必须从 0 长起）、同时落好几滴、水面加倒影或波纹纹理。涟漪的力量来自「只有一圈在动，其余都在衰」。

**验收**：preview_frames 抽 1.0 / 1.7 / 3.0 秒——1.0 秒应看到刚落的一滴（4 环刚起），1.7 秒环明显变大且更淡，3.0 秒应有两滴同荡；render_preview_clip 看有没有环「跳」一下变大（半径用了离散步长），以及落点是否只在画面中部偏下。
