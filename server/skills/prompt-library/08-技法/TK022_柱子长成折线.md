# TK022 柱子长成折线

- 类型：单技法
- 时长：8.5 秒一个循环（生长 4 秒，停 3.6 秒，淡出 0.9 秒）
- 长什么样：六根柱子从左往右依次拔起，柱顶数字跟着一起跳，全部长完再从最高那根拉出一条折线。
- 适合：讲数据、讲增长、讲一路变多，且数据是单调向上的
- 关键词：图表、生长、折线、数字
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 F1 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：要讲一组「越来越大的数」——次数、年份、增长——又不想上真图表的时候。它靠有序生长讲「一路涨上来」，所以数据本身得单调或接近单调；上下乱跳的数据用它，观众只会记住乱，记不住数。

**版式**：留边很宽：左 10%、右 94%、上 20%、下 80% 围出绘图区；标题放在画面高 11% 处、左对齐。绘图区里只画 4 条水平网格线，颜色 #2c3640、线宽 1，**没有刻度和轴标签**——数字全靠柱顶那一个数。

**柱怎么长**：六根柱，值依次是 12 / 19 / 27 / 33 / 41 / 58，横轴是六个年龄段。柱高按「满格 60」归一：柱高 = 绘图区高 × 值 ÷ 60 × 进度。进度用「先快后慢」的减速缓动，每根 0.8 秒长完，第一根 0.2 秒起，后面每根晚 0.25 秒起——所以最后一根到 2.25 秒才到位，整排像被一只手从左往右推起来。柱宽占格子的 56%，左边留 22%，格子宽 = 绘图区宽 ÷ 6。

**数字怎么跳**：柱顶的数字不是独立动画，它取的是同一个进度：显示值 = round(值 × 进度)。所以数字和柱顶永远贴在一起，不会出现「数字先到、柱子还在爬」。字号 = max(9, 短边 ÷ 24)，横屏 1080 时约 45；数字用等宽字体，位置在柱顶上方 0.5 个字高处。

**折线**：柱全部长完之后才起——2.6 秒开始，1.4 秒内从左到右画完（到 4.0 秒）。线宽 2，颜色 #f1b25c，顶点接的是六根柱子的**最终高度**，不是生长中的高度。这是硬要求：折线在柱还没长满时出现，就会浮在半空，成一条断了的线。

**颜色**：底 #0f1418；普通柱 #5d7fa3；最后一根单独 #f1b25c；标签 #8f9aa5、字号是主字号的 0.9 倍；标题同 #8f9aa5。全套只有蓝灰加一点暖橙，别加第三种色——加了就变成信息图，不是这一段叙事了。

**节奏**：循环 8.5 秒，7.6 到 8.5 秒整组淡出再重来。这个淡出别省，硬切会把「生长」变成「刷新」，意思就反了。

**怎么在我们工具里做**：add_scene 一幕；六根柱各建一个矩形元素，锚点放在底边中点，只动纵向缩放（0 到 1，减速缓动，每根错开 0.25 秒）；数字用文本元素，逐帧按 round(值 × 进度) 取值（帧号 → 时间 → 进度 → 数字，全程确定性）；折线的「描边进度」我们这边没有原生支持，降级用五段直线元素接力——每段在自己的时间窗里从 0 拉到全长，接缝正好落在顶点，视觉上看不出是五段。可以用 preview_frames 卡在 3.3 秒看接缝有没有露馅。

**禁止**：六根同时起长；柱顶用弹跳缓动（这是数据，不是情绪）；柱加圆角或渐变；加图例、加刻度、加第三色；折线接在生长中的柱顶；柱与柱之间做位移（数据只该竖向长）。

**什么时候不成立**：数据超过 8 根（格子宽会小于 4%，数字会撞在一起）；数值之间没有量级差（六根一样高，生长过程就只剩一次平移）；需要读精确刻度（这里只有 4 条无标签网格线，读数只能靠柱顶数字）；数据是负值或需要基线交叉（原文的柱全部从底边往上，没有负方向）。

**验收**：preview_frames 抽 0.8 / 2.2 / 3.5 秒——0.8 秒应该只有两三根在长，2.2 秒六根都到位且折线还没起，3.5 秒折线画到一半；render_preview_clip 看数字有没有领先柱子、折线有没有悬空、整排的推起节奏是不是均匀的 0.25 秒一格。
