# TK012 一根线画完

- 类型：单技法
- 时长：10 秒一轮（画 6.5 秒，停 2.3 秒，淡出）
- 长什么样：一根暖白色的线从左边地平线起笔，先画山脊，再绕出太阳、点出小人，线头带一点橙光一路走到底。
- 适合：讲一个人、一件事的轮廓、从无到有的建立
- 关键词：一笔画、线描、生长、轮廓
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 C2 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：讲一个人的轮廓、一件事的来龙去脉、从无到有。它的全部力量在「一笔不断」——线一断、一变色、一加填充，就退化成普通插画。适合片头六秒左右的一次建立，不适合承载细节，也不适合多人。

**画面结构**：夜蓝底 #121722；线色 #f2efe8；线宽取 1.4 与「短边 ÷ 220」中的较大值，圆头圆角。五组笔画依次接力：地平线（(.04 .72) 到 (.96 .72)）、山脊（八个折点 (.06 .72)(.18 .50)(.27 .60)(.42 .36)(.55 .56)(.66 .47)(.79 .61)(.94 .52)）、太阳（圆心 (.76 .27)、半径 0.07 个短边、48 段）、小人的头（圆心 (.30 .61)、半径 0.02、20 段）、小人的身体手脚（三组短折点，最长一段 0.047 个短边）。按折线长度累加，太阳那段最长，也最慢。

**怎么在我们工具里做**：add_scene 一幕 + 一张透明底线稿（upload_asset）。真正的「按路径长度揭示」本工具没有，用遮罩近似：把线稿切成 5 个图层，每层一张同尺寸矩形遮罩从左推到右，推进顺序按路径顺序，层与层的接缝压在山的转角上、重叠 3%，接缝就看不出来。总推进 6.5 秒，缓动用 easeOut——前快后慢，最后 1 秒几乎停住，像笔慢慢提起来。

**跟随的光点**：笔尖挂一颗暖光点 #f1b25c、半径 14、透明度 0.8，贴在当前遮罩的右缘走，6.6 秒时消失。这是让观众相信「有一支笔在走」的唯一线索，不能省。

**参数与收尾**：全片 10 秒循环，线在 8.8–10.0 秒整体淡出到 0，下一轮重画。画面里不加文字；要写字等线画完再上，字号不超过短边的 0.06。

**禁止**：双线描边、填充色块、线宽随速度变化、线分叉、彩色；也不要让遮罩从两边往中间推——一笔画必须一头进一头出。

**验收**：preview_frames 抽 1 / 4 / 6.6 秒——1 秒应到山脊中段、4 秒应画到太阳一半、6.6 秒全图完成且光点刚灭；render_preview_clip 看线是「长出来」还是「淡出来」，若整条线同时变亮，说明用了透明度动画而不是遮罩。
