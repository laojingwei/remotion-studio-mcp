# TK002 光标打字

- 类型：单技法
- 时长：8–14 秒（台词要打完、删掉、再打一次）
- 长什么样：黑底一行字，一个字一个字打出来，停一下，又一个个删掉，只剩光标在闪。
- 适合：说不出口的话、心里反复改口的独白、没发出去的消息
- 关键词：打字、光标、删掉、独白
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 A2 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：讲"想说但说不出口""打了又删"。它的力量全在**删除**上——只打字不删，就只是个字幕动画；打了再删，才有"改口"的心理。

**怎么在我们工具里做**：一幕，一个文字元素（内容随时间替换）+ 一个光标元素。用一串操作序列驱动：打字每字 0.17 秒，删除每字 0.07 秒（删得比打快，这是心虚的节奏），段间停顿 0.5–1.6 秒，清空 0.4 秒。

**操作序列（照这个结构改台词）**：打字"我其实一直想跟你说" → 停 1.1 秒 → 删 6 个字 → 停 0.5 秒 → 打字"没事。" → 停 1.6 秒 → 删 3 个字 → 停 0.4 秒 → 打字"……" → 停 1.6 秒 → 清空。整段约 12 秒，循环。

**参数**：底 #0b0b0c；字 #ece8df，字重 500，字号取「画面宽 ÷ 10.5」与「画面高 ÷ 7」的较小值，左边距 10%、垂直居中。光标 #f1b25c，宽是字号的 0.07 倍、高 1.1 倍，紧贴最后一个字的右缘 0.12 个字宽；闪烁 1.8Hz，**刚打完的 0.45 秒内常亮**（人打字时光标不会在字刚出现时立刻闪，这个小细节决定像不像）。光标背后一颗同色小光晕，透明度 0.18。

**禁止**：逐字弹跳、字体描边、多行换行（一行装不下就换更短的台词）、背景花纹。这块画面只有一行字和一个光标，多一样东西就散。

**验收**：render_preview_clip 看完整一轮——删除段的字是不是一个个消失（不是整段淡出）、光标是否跟着字移动、打完那一下是否常亮再开始闪。
