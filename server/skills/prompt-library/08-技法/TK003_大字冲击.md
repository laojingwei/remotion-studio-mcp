# TK003 大字冲击

- 类型：单技法
- 时长：5–8 秒（一拍一个词，8 个词左右）
- 长什么样：一个词一个词砸进画面，每个都带一记震动，最新的词最亮最大，最后一句是红的。
- 适合：情绪爆发、金句、副歌、控诉、被逼到墙角
- 关键词：大字、砸下来、跟节拍、冲击
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 A3 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：情绪要炸、要一句话一句地怼上来。它靠"累积"工作——前面的词不消失，只是变暗变小，后面的词压在上面，屏幕越来越满。

**怎么在我们工具里做**：一幕，8 个文字元素，每个词一个。全片一个固定节拍 0.4 秒一个词。每个词在自己的拍点出现，出现瞬间做两件事：缩放从 2.0 收回到 1.0（衰减很快，约 0.06 秒完成），透明度从 0 到 1。**前面出现过的词不回退**，只是把颜色压暗一档。

**震动**：每个拍点给整幅画面 ±6px 的抖，两个不同频率叠（正弦 91 与余弦 77），抖幅按 e 的 -9t 次方衰减——砸下去有一下，然后立刻收干净。不要用缓动的"弹回"，那是柔软的，这里是硬的。

**排版**：每个词有自己的位置（按画面比例给），字号 0.13–0.33 个短边，随词的重要程度递增；竖屏字号乘 0.95、横屏乘 1.45；最新出现的词用白色 #ffffff，旧的降到 #55565c；标红的词最新时 #ff4a32、旧了降到 #a3392a（红不能一直满亮，否则后面砸上来就压不住）。

**地面亮一下**：每次砸，背景从 #08080a 抬到 #2a2a2e 的一半，也是指数衰减——这一下"地面被砸到"的感觉全靠它。

**禁止**：柔和淡入、词与词之间位移、旋转、渐变彩色。任何一个出现，冲击就软了。

**验收**：preview_frames 抽三个相邻拍点——必须看到词在变大变小、旧词变暗、背景在闪；render_preview_clip 听不出节拍也要能看出节拍（这是这条技法的及格线）。
