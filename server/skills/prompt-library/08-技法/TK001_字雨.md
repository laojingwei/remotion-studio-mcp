# TK001 字雨

- 类型：单技法
- 时长：6–12 秒（要有时间堆起来，太短就看不出「积」）
- 长什么样：话像雨一样从上面落下来，落到地上不消失，一层层堆起来，最后压成厚厚一层。
- 适合：被反复说教、听腻的重复、压力一点点累积
- 关键词：字雨、落下、堆积、压迫
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 A1 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：讲"听腻了""被反复说""压力越积越多"。落下来的字在底部堆起来，堆的高度就是压力的量。它不负责讲清一件事，只负责压——所以别拿它做信息传递。

**画面结构**：近黑的底（#050608 到 #0b0e15 竖向渐变），20–26 列字从上往下落。台词拆成单个词或短句，但**每一列只落同一个词**——这样读起来才是"同一句话反复说"，否则就是一堆杂字。

**怎么在我们工具里做**：一幕到底，20–26 个文字元素各自下落，每个元素自己一条位移动画（不要复制粘贴成一堆同帧的贴图，那样会同时落、同时停）。落到底线后不删除，把它钉住、透明度降到 0.32、字号缩到 0.9 倍，变成"堆"的一部分；同一个元素回到顶部重新开始，像循环的雨。

**速度与堆积**：下落速度 v = 画面高 ÷ 300 × (36 + 字号 × 3.2)——大字落得快。堆积每加一层把底线抬高 0.4% 的画面高；抬到 60 层就停（再抬画面会满），堆到 70 个字开始挤掉最早的 8 个。

**参数**：字号分五档，基准是画面短边的 1/17，倍率 0.55 / 0.7 / 0.9 / 1.2 / 1.7；落字颜色约 #d6e0f2，透明度 0.25 加 0.4 乘字号档；堆积字约 #96a4be，透明度 0.32；底部中央一颗暖光点 #f1b25c，半径 14，亮度在 0.55 与 1.0 之间跳，约 5Hz，像有人在喘气。

**节奏**：每落一层给 1 帧顿挫，让人看见"压"这个动作；除此之外全片不要第二个动静，雨的规律本身就是压迫感。

**禁止**：字体弹跳、逐字旋转、彩色、发光描边。这些一出现，压迫就变成了热闹。

**验收**：preview_frames 抽第 1 秒和第 4 秒——第 4 秒底部必须已经有一层清楚可见的堆；render_preview_clip 看落速是否稳定、堆叠是否只涨不塌、有没有字卡在画面中间不动。
