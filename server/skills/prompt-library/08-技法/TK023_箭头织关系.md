# TK023 箭头织关系

- 类型：单技法
- 时长：10 秒（前 5.9 秒长出来，后面留 3 秒读）
- 长什么样：几个圆点先弹出来，圆点之间一条条箭头被画出来，每条箭头旁边挂着一句没说完的话。
- 适合：家里的关系、因果链、责任归属——多主体，且每条关系能一句话说清
- 关键词：节点、箭头、关系、标注
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 F2 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：讲「谁对谁说了什么」——家里的关系、因果、责任归给谁。它天生是多主体的：一条箭头只讲两个人之间的一件事，六条叠起来才是一张网。只有一个人、一件事的时候别用，画面会空得没有理由。

**节点怎么摆**：原文是六个写死的坐标（按画面宽高归一）：我 (0.5, 0.55)、爸爸 (0.22, 0.3)、妈妈 (0.78, 0.3)、奶奶 (0.5, 0.12)、学校 (0.2, 0.82)、工作 (0.8, 0.82)。注意——**这不是力导向布局**，六个位置是手摆的。手摆的好处是每次渲染都一样、不会漂；力导向在这类片子里只会让节点慢慢挪位，看起来很脏，而且标注会跟着抖。

**节点怎么出**：弹出用带回弹的缓动，每个 0.5 秒，按下单顺序每个晚 0.12 秒，第 0.62 秒六个全出。半径 = 短边 × 7.5%；字号 = 短边 ÷ 20 × 0.85 × 弹出进度（字跟着圆一起长大，不是先有大字再有圆）。「我」用 #f1b25c 实心、字 #14100a；其余填充 #161b23、描边 #cfd6e0、线宽 1.2。半径统一，别按重要性放大——这里没有主次，只有远近。

**箭头怎么画**：六条，起点时间 1.0 / 1.8 / 2.6 / 3.4 / 4.2 / 5.2 秒，每条 0.7 秒画完（减速缓动）。连线是**直线**，从源节点边缘（半径处）到目标节点边缘，两端各让出一个半径——箭头不会插进圆里。箭头三角夹角 ±0.4 弧度、边长 9px，跟着线头走。

**那六条关系**：爸爸→我「为你好」、妈妈→我「听话」、奶奶→爸爸「吃苦」、我→学校「要争气」、我→工作「不能软弱」、我→妈妈「说不出口」。最后一条特殊：颜色换 #f1b25c、线改成 5 与 5 的虚线。它是整张图里唯一说不出口的那条，视觉上必须不一样，否则观众读不出重点。

**标注**：字号 = 主字号 × 0.8，放在线的中点、沿法线方向偏移 0.8 个字高，所以字永远在线的一侧而不是压在线身上。颜色 #aab3c0，暖色那条用 #f1b25c。透明度跟着线的进度从 0 到 1——字是「被画出来的」，不是「先浮在那里等线过来」。

**怎么在我们工具里做**：add_scene 一幕；六个圆形元素 + 六个文本元素；六条边用线段元素，长度用缩放从 0 到 1（锚点放在起点）。**因为节点坐标写死，每条线的长度和角度都是常量**，建元素时直接算好写进去，不用逐帧算——这也顺带解决了箭头的旋转问题：角度是固定值，钉在线段终点即可。标注用文本元素，位置按中点法线算好。这套东西不需要粒子、不需要发光。

**节奏**：整段 10 秒，9 到 10 秒整组淡出。前 1 秒只有节点，1 到 5.9 秒边一条条长出来，5.9 到 9 秒停住让人读——这 3 秒是留给标注的，这段时间别加任何新东西。

**禁止**：力导向或弹簧布局（节点会漂）；双向箭头（原文只有单向，来回两条会重叠成一坨）；自环（自己指向自己，这里没有）；把边做成贝塞尔弯曲（直线上挂标注才对得齐）；节点超过 8 个；给边加粗细分级。

**什么时候不成立**：关系超过 8 条（标注会互相压到一起）；需要表现强度或权重（线宽在原文固定 1.4，没有粗细分级，硬要做只能加数字）；关系是真网状（原文是一棵以「我」为中心的星形树，真网状六条线交叉会读不出方向）。

**验收**：preview_frames 抽 1.5 / 3.8 / 6.5 秒——1.5 秒应该只有一两条边，3.8 秒过半，6.5 秒六条全在；render_preview_clip 看标注是不是跟着线头一起长出来、有没有哪条线压进了节点圆里、最后那条虚线是否明显不同。
