# TK020 纸层推移

- 类型：单技法
- 时长：6–15 秒（至少看完五层走一个完整波长）
- 长什么样：五层纸山一层压一层，前面走得快、后面走得慢，中间一间小屋跟着第三层移动。
- 适合：童年、回忆、温柔的段落、睡前故事
- 关键词：剪纸、层叠、视差、纸片
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 E2 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：童年、讲故事、温柔段落、回忆。它动的不是某个物体，是整叠纸的错位——前层快、后层慢，眼睛才读出纵深。所以它必须有一段持续的横移，静止构图里根本看不出层叠，只剩一张插画。

**怎么在我们工具里做**：add_scene 一幕，add_element 依次叠：背景、日、五层纸山、纸纹。画风用 set_theme 定成纸感，纸纹这一层可以用 upload_asset 传一张米色纤维图当纹理，拿不到就跳过，别用噪点凑。背景是竖向渐变 #f4ecdf 到 #dcebe5（米到淡青）。日是一个 #fff8e7 的圆，在横向 72%、纵向 26% 处，半径 = 短边×0.1，带一层暖灰投影（#503c1e、透明度 0.25、模糊 14）——投影朝下，因为这是剪纸，光从上面来。

**五层纸**：颜色从远到近是 #cfe3df、#9fc7c1、#6fa59f、#43807b、#235a57，越近越深而不是越近越亮，纸叠在一起就是变暗的。五层的起伏基线分别在纵向 42%、53%、64%、75%、86%，起伏幅度分别是画面高的 5%、6.2%、7.4%、8.6%、9.8%。每层波形是两个正弦相叠：一个波长长、一个波长短，短波幅度取长波的 0.25 倍，而且五层的波长与相位各不相同，这样五条边不会连锁成同一道浪。

**速度（这条的关键数字）**：横向位移速度 = (6 + 层号×10) × 短边÷300 像素每秒，五层依次是 6、16、26、36、46。最前一层比最后一层快 7 倍多，这个比值决定纵深强弱，缩到 3 倍以内画面就平了。每层都带投影：#142828、透明度 0.35、模糊 10、向上偏移 3 像素（后层被前层挡住，影子落在后层上，所以朝上）。

**物件**：第三层（#6fa59f）挂一间小屋，边长 = 短边×0.07，屋身 #2f6f69，屋顶是同色三角，窗是 #ffd98a 的方块（宽 0.24、高 0.3 倍边长）。小屋必须跟第三层同速移动，横向位置按宽度 1.3 倍的区间取模循环，区间比画面宽出 15%，这样它从左边进来、右边出去时不突兀。最后盖一层纸纹，透明度 0.5、正片叠底。

**禁止**：垂直方向的镜头运动、每层不同速度之外的旋转、彩色渐变、投影朝下（会变成悬浮贴纸）、层数少于 4（少于 4 就没有叠）。也别给五层不同透明度——纸是不透的，纵深靠速度差和颜色差，不靠透明度。

**验收**：preview_frames 抽第 1 秒与第 3 秒，五条山脊线的横向位移必须逐层递减（前层挪得最多），小屋跟着第三条线走，投影在上方。render_preview_clip 看 6 秒，画面应有持续的横向流动，且不该有任何一块纸被另一块突然盖住又露出。
