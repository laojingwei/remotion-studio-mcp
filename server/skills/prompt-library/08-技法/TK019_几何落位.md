# TK019 几何落位

- 类型：单技法
- 时长：6.5 秒一轮（可循环 2–3 轮）
- 长什么样：米白底上，一条线画出来，红圆滚进来，蓝方落下来，黄半圆长出来，然后一起滑走。
- 适合：概念页、章节转场、把复杂的事讲成三步
- 关键词：几何、形状、扁平、色块
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 E1 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：把复杂的事讲清楚、做概念页、做章节转场。它的力量来自「一个动作只给一个形状」——线先画出来，圆滚进来，方块掉下来，半圆长出来，然后全走。画面里没有第二样装饰。所以它只承得住三条以内的信息；要讲五件事就做两遍，别往一屏里塞。

**怎么在我们工具里做**：add_scene 一幕，add_element 放六个元素：底、地平线、圆、方块、半圆、遮罩。画风用 set_theme 定成纯扁平，不要用任何带纹理的样式。底是纯色 #ebe5d6（米白，别用纯白，纯白会让形状的边发飘）。地平线是 #161616 的横线，从横向 6% 起、长 88%，高取短边的 1.2%，最小 2 像素。所有形状都停在这条线上，前后关系靠元素的层级固定，不要靠透明度。

**四段动作（一轮 6.5 秒，照这个时序）**：0 到 0.8 秒，地平线从左往右画出来，宽度从 0 到 88%，缓出；0.4 到 1.7 秒，红圆 #d9432f 从画外左侧滚进来，停在横向 46% 处，半径 = 短边×0.14；1.1 到 2.0 秒，蓝方 #2047c9 从上方落下，边长 20%，用带回弹的缓动（落地会略微过冲再压回，全片只有这一下弹性），停在 3.0 到 3.7 秒之间再转 90 度，用同一条回弹曲线；2.0 到 2.8 秒，黄半圆 #f2b630 从地平线上长出来，半径从 0 涨到短边×0.18，圆心压在地平线上、只画上半部分，位置在横向 24%；4.6 到 5.6 秒，全部元素一起向右滑出，位移 = 画面宽×1.2，缓出，滑完直接重来。

**滚动的那个细节**：红圆是滚的，转角 = 横向位移 ÷ 半径，边移边转。它身上那道宽 0.16 倍半径、高 0.5 倍半径的米白缺口会跟着转，看起来才是在地上滚而不是平移。这是全片唯一允许有「角度」的元素。

**禁止**：颗粒、噪点、光晕、投影、渐变、描边、超过三个形状、形状互相穿透。这一条要干净到「截图下来就是一张海报」。除了滚动的圆，其余位移必须带缓动——匀速看起来像幻灯片里的飞入，一出现整条就廉价了。

**验收**：preview_frames 抽 0.5 / 1.5 / 3.2 / 5.0 秒，四帧里出现的形状数应分别是 1、2、3、3（最后一帧在滑出）；红圆缺口的朝向两帧之间必须不同，同一朝向就说明没做滚动。render_preview_clip 看整轮：方块落地那一下要有顿感，画面上不该有任何一像素杂色。
