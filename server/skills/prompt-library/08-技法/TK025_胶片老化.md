# TK025 胶片老化

- 类型：单技法
- 时长：按整片长度铺，最少 6 秒（短于 6 秒颗粒还没被看出来就结束了）
- 长什么样：紫橙色的黄昏被一层颗粒糊住，画面隔一会儿轻轻跳一下，边缘一道橙色漏光在慢慢呼吸。
- 适合：回忆、旧时光，或者给整条片子统一一层年代感
- 关键词：胶片、颗粒、划痕、漏光
- 画风耦合：绑在媒介上
- 出处：原「技法」代码样片 G1 · data/archive/upgrade-source/02-手法/（原件归档）

## 提示词

**什么时候用**：讲回忆、旧时光，或者给一整条片子统一一层「被时间过过一遍」的质感。它是**加法**：底下的画面照常做，只在最上面糊四层损伤——颗粒、闪烁、划痕、漏光。所以它不改内容，只改年代；内容本身撑不住的时候，靠它救不回来。

**抖动（机械损伤）**：整幅画面每帧上下抖 ±0.7px（幅度 = (随机 − 0.5) × 1.4）。只有 0.7px，看着像放映机抓片不准，不是地震。别超过 2px——超过就从「胶片」变成「手持摄影」，那是另一个技法。

**颗粒**：一张 256×256 的灰度噪点图，按重复方式平铺，每帧平移 0 到 256px 之间的随机量（所以永远看不出接缝），用叠加混合，透明度 0.22。颗粒是这套质感的骨头，没有它，其余三样都像滤镜，不像胶片。

**闪烁与划痕**：全屏压一层黑，透明度每帧随机取 0 到 0.08，这就是老片子那种忽明忽暗，幅度很小但一直在。划痕每帧有 30% 的概率出现：1px 宽、贯穿全高的竖线，颜色 rgba(255,240,220,.25)，x 位置随机。30% 这个数是关键——每帧都有就成了栅栏，10% 又根本看不出来。

**漏光**：一团橙色（#ff7a2a）的径向光，半径 70% 短边，中心在画面高 30% 处，水平位置在 10% 加减 8% 之间慢慢摆（sin(秒 × 0.5)，一个来回约 12.6 秒），透明度 0.22 加减 0.1（sin(秒 × 1.3)，约 4.8 秒一次）。它是整张图里唯一的活物，节奏必须慢。

**底色与暗角**：底图是紫到橙的竖直渐变 #5b3a63 → #f0a36a；一颗 #ffd08a 的大光晕（透明度 0.5）配 #ffe3b0 的实心圆盘（半径 8% 短边）当落日；地平线以下是 #2a1626 的剪影，山脊高度按 h × 0.72 再叠 ±12% 画面的正弦起伏。最后压暗角：从 0.3 短边处开始、到 0.6 倍对角线处，黑从 0 收到 0.6。暗角一上，画面立刻就旧了。

**怎么在我们工具里做**：整套是叠加层。upload_asset 传一张 512×512 的灰度噪点 PNG 和一张暗角 PNG；颗粒层用叠加混合 + 每帧位移；抖动用一个包住全部底层图的组做 y 位移；划痕用 1px 矩形元素，可见性按帧号取模控制（每 10 帧里挑 3 帧亮）；漏光用一张径向渐变 PNG 做位置与透明度动画；暗角常驻不动。**关键适配**：原文用的是每帧随机数，在我们这里必须换成确定性伪随机——用帧号乘一个常数取小数部分当随机值，这样同一帧渲染两次结果一样，导出才不会花。

**禁止**：抖动超过 2px；颗粒每帧换成完全不同的纹理（会闪成雪花，正确做法是同一张图平移）；划痕常亮；用彩色颗粒（颗粒必须无彩）；暗角压到 0.8 以上；给画面加「胶片边框」或齿孔——原文没有，加了就成道具了。

**什么时候不成立**：画面里要读小字字幕（颗粒和暗角会吃掉 5–6px 的字，字幕得 24px 起）；底图本身已经很暗、对比很低（再压暗角就全黑）；需要准确的品牌色（紫橙渐变会整体改色）；4K 输出且要求锐利（颗粒会被放大成一团团）。

**验收**：preview_frames 抽相邻两帧——颗粒纹理和划痕位置必须不同，底图的抖动位移不能超过 1.5px（超了就是手抖不是抓片）；连抽 10 帧数划痕出现次数，应该在 3 帧左右；render_preview_clip 看闪烁是不是一直在微动，而不是隔几秒跳一次。
