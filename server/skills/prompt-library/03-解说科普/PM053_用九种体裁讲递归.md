# PM053 用九种体裁讲递归

- 类型：解说科普
- 时长：60 秒 · 1920×1080
- 长什么样：同一个概念被讲九遍，每一遍换一种截然不同的影片体裁，换体裁这件事本身就是例子。
- 适合：抽象概念科普、需要「恍然大悟」的教学片、技术内容的破圈表达
- 关键词：多体裁、自指结构、每次换一套语言、层层加码
- 画风耦合：画风部分
- 出处：@emollick · https://x.com/emollick/status/2103688362960019567 · prompt-motion.com/customize/emollick-8661a8

## 槽位

- 主题：recursion —— 要讲的东西
- Styles：每次换一种体裁：黑色电影、自然纪录片、八位机游戏、电视购物… —— Genres or looks to switch between.
- 数量：9 —— 段数
- 时长：60 秒 —— 按片长总控；超过 45 秒就分段做，别一条硬拉
- 画幅：1920×1080 —— 横屏 1920×1080 / 竖屏 1080×1920 / 方形 1080×1080

## 提示词

**每一遍都换一套语言**：黑色电影、自然纪录片、八位机游戏、电视购物……**每种体裁都是完整的一套**——自己的字体、配色、节奏和声音，不是同一批画面加滤镜。

**自指是关键**：换体裁这件事本身要变成"递归"的例子（一个体裁里嵌着上一个体裁的画面，再被下一个套住）。**观众要能感到"套娃"在发生**，而不是听你解释套娃。

**每次都要讲完再走**：节奏可以快，但每一遍必须在下一遍开始前把这一遍讲圆，否则观众只会觉得乱。

**加码顺序**：从最朴素的开始，越往后越离谱，最后一遍把所有前八遍收进一个画面里。开场一句话钩子，收尾一句话点题。

**降级说明**：源站把脚本与配音都交给作者自己；我们这边用 tts_narration 按真实音频长度对齐，**每一遍的语气要跟着体裁换**（纪录片低沉、购物台亢奋）。

**禁止**：通用渐变、发光、体裁之间用交叉淡化硬转，以及任何一眼看出是模板的东西。

**出片前**：把九个体裁列成表，标注每个的字体/配色/语速，先给用户看表，再动手。
