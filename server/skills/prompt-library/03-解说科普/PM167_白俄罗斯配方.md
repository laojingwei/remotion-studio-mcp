## 提示词

**这一条**：关键是奶油浮层的形成：先酒后奶油，奶油缓慢下沉再浮起的那一下是全片的高光，别一下倒完。

**从空杯开始**：一个容器、一个固定机位、干净背景，全片不换视角——观众要能随时对比"现在到哪一步了"。

**每种材料都要有三件事**：倒下去的动作、液面上升的过程、旁边一行干净的字（名称 + 刻度）。**刻度必须一眼读完，不许让观众暂停去算**。

**顺序即叙事**：一拍一种材料，材料之间留半拍让液面稳定；先大后小、先基酒后辅料，最后是装饰和一个"欣赏一下"的停顿。

**动效**：倒液用连续形变而不是粒子；液面上升要有真实的体积感（先快后慢）；镜头在最后缓缓推近一点，收在成品上。

**禁止**：素材库里那种剪贴画式的插画、发光、通用渐变、需要暂停才读得清的刻度，以及任何一眼看出是模板的东西。

**出片前**：把「材料清单 + 每种刻度 + 顺序」列出来核对一遍（错一个数就是废片），再建第 1 味看动。
