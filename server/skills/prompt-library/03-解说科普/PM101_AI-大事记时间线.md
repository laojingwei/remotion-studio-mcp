## 提示词

**一条线走到底**：整片只有一条时间线，镜头沿线移动，**不许跳段**——跳了观众就失去"走了多远"的感觉。

**每个节点同一套语法**：年份先落定（大字、压在拍上）→ 事件出现（一个图形或一件实物）→ 一句为什么重要（不超过一屏字）。**所有节点节奏一致**，重复本身就是秩序感。

**选点比画法重要**：挑 12–15 个真正改变了走向的时刻。**日期、人名、成果必须可查**，宁少一个也不要编一个；一句引语都不能凭空造。

**收尾**：镜头停在"现在"，一句话说清当下站在哪，不要展望未来——展望会让事实片变成宣传片。

**画面**：一条线、一种字体、一个强调色。节点用点、刻度、缩略图三种形态循环，别每站换新花样。

**禁止**：发光、通用渐变、库存感图标、交叉淡化，以及任何一眼看出是模板的东西。

**出片前**：把「年份 + 事件 + 一句为什么」列成表给用户核一遍——事实错误是这类片子唯一的致命伤。
