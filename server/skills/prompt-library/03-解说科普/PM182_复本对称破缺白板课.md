## 提示词

**这一条**：观众是物理学生：白板手绘，公式要写对、符号要统一。宁可少讲一个结论，也不要写错一个下标。

**要讲清什么**：一个从没见过它的人，看完能说出它是什么、解决谁的什么问题。

**一张图讲完**：整篇只建一张图（iso 图解场景最合适，先读 get_guide("external-tools")），所有概念都长在这张图上。镜头推近解释局部、再拉远回到全局，观众始终知道自己站在哪。**图例是失败的信号**：标签直接贴在被标的东西上，不要另开一块图例。

**先有画面再有字**：每个概念先给出图形，再给一句说明；一屏只放一句话。字幕按我们的铁律 8–16 字（最多 18），一屏念得完，不带标点。

**结构**（1 分钟）
- 钩子：观众心里本来就有的那个问题，压在第一个画面上。
- 中段 3–5 步：每一步推近一个局部 → 给一个具体例子 → 拉远，让它归位。
- 收尾：一次完整拉远，图闭合，一句话结论。

**动效铁律**：一次只动一样东西，视线始终有落点；箭头和流向按事物真实的流向动；图版布局固定，推拉时不许重排——一重排，观众就丢了位置。

**禁止**：大段文字、项目符号列表、通用渐变、库存感图标、发光、交叉淡化，以及任何一眼看出是模板的东西。

**配音**：先写口播稿，逐句标出这一句屏上是什么，再用 tts_narration 按真实音频长度对齐动画；口播下面垫安静的 BGM，不抢字。

**出片前**：先给「口播稿 + 图版 + 时间轴分镜」，每一段抽一帧看，拥挤、重叠、读不出来就改。
