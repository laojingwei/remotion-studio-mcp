# PM055 五段式版式世界

- 类型：界面版式
- 长什么样：五段互不相干的版式，各自像不同工作室做的，靠段落推进而不是切换。
- 适合：版式能力展示、视觉实验合集、把「设计感」当卖点的品牌片
- 关键词：版式实验、分段推进、每段一个世界、反淡入
- 画风耦合：绑在媒介上

- Contexts：自选 —— What each section is about, or leave it to Opus.

## 提示词

**五段，五个世界**：每一段自己的字体、配色、网格和运动逻辑，像五家不同工作室各做了一段。**不许出现同一套视觉语言**——一统一就变成一条普通片子。

**降级说明**：源站原活是"滚动驱动、可双向拖动"的网页，**我们出的是视频**。所以把"随滚动推进"翻译成"随段落推进"：每段用同一套「内容自下而上被推入」的语法，让观众感到是在往下走，但由时间轴驱动。

**每段自成一篇**：每段要有清楚的开头、中段、收尾（起、转、落各占三分之一），段与段的交界用运动接上，**不要用淡入淡出糊过去**。

**运动纪律**：不许对所有元素都加"上浮淡入"——那是模板味的来源。每段只允许一种主运动（位移、遮罩、缩放、字距），其余元素跟着它走。

**画面**：五段各用一种媒介感（印刷、屏幕、纸张、胶片、金属），材质差异本身就是节奏。

**禁止**：为视差而视差、所有东西淡入、发光、通用渐变，以及任何一眼看出是模板的东西。

**出片前**：五段各出一张静帧并排看——如果五张看起来像同一条片子，重做版式。
