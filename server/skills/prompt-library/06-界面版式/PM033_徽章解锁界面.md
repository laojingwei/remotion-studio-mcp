## 提示词

**这一条**：一比一还原设计稿，只加动不改造型。徽章当实体（有质量、有阻尼地落定），庆祝只播一次，粒子是设计里允许的那种金色粒子。

**先对齐设计稿，再加动**：拿到的设计稿要一比一还原——资产、字重、间距、层级都不许改。**只加动效，不改设计**，改了就不是还原，是重做。

**搭场顺序**：背景与容器先到 → 内容逐块进 → 主体物件最后落定。每一层都有自己的进入方式，不要所有东西一起淡入。

**主体当实体对待**：它有质量。落定时要沉一下、停住，倾斜或旋转按真实的阻尼来（**不弹跳、不过冲**），看起来像被人轻轻放在那里。

**庆祝只播一次**：庆祝动效是全片的峰值，播完就定住，不要循环、不要二次触发——重复的庆祝会立刻显得廉价。

**收尾**：停在一个可以继续操作的状态（我们出的是渲染结果，不承诺真实交互；所以停在"接下来该点哪里"那一帧）。

**禁止**：设计稿里没有的发光、过冲与抖动、任何一眼看出是模板的东西。

**出片前**：先出一帧还原静帧和设计稿并排比对（差一像素都要改），再做动；动完用 render_preview_clip 看落定那一下的手感。
