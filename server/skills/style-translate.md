# 参考风格翻译（style-translate）

> **什么时候读这篇**：用户从编辑器「风格库」面板勾了 **参考风格**（341 条里的编号，如 A1 字雨、
> K12 报纸四格），`get_style_pick()` 回来的 `ids` 里有东西。
> 内置风格（`builtinSlugs`）**不用读这篇**——那个直接 `apply_style(slug)`。
>
> 核心事实：参考风格是一段**画风文字描述 + 一张静帧**，背后是 Canvas 2D 绘制函数。
> 它描述的"字像雨一样落下来"**在我们引擎里没有对应组件**。所以这里的活儿不是"套用"，
> 是**翻译**：把形容词翻成我们能设的字段。翻得对不对，用户看 `probe_style` 的样张就知道了。

## 一、翻译的产物是三样东西，不是一份配置

| 产物 | 落到哪 | 判据 |
|---|---|---|
| **全片底座** | `set_theme`（palette / font / radius / motion） | 只看色与字，不看版式 |
| **每幕版式** | `add_scene` 的 `type` + 道具 | 这一幕该让观众看懂什么变化，就选承载它的版式 |
| **禁忌清单** | 写进 `shot.note`，交付前人工对一遍 | 原文里每句"不要/别/避免"都要有对应的一条 |

**只做第一条 = 换了个配色，片子还是 PPT。** 这是最常见的失败，见第七节。

## 读参考原文的规矩

`get_style_library_prompt` 给你的正文做过三层清洗（原片/源码行、DEMO.md 自指、
实现层章节折叠成〔已省略〕标记）。**这些不是丢内容，是帮你划清界线**：

- 留下的都是视觉语言：长什么样、什么材质配色、动作什么重量、怎么分镜、什么别做——只翻译这些
- 〔已省略〕的章节是原工作流的实现层（demo/ 代码文件清单、构建脚本、交付流程）——
  我们的 Remotion 引擎没有那些文件，**不要去找、不要照做**，也别向用户承诺"能做出它
  那个效果"，那要按降级路径（本篇第八节）处理
- 拿不准一段能不能用：凡是要写代码文件、跑构建、引用外部 md 的，跳过，只留画面描述

## 二、六槽位：从原文里找名词

原文是形容词堆的，我们的引擎只吃名词。照这张表逐行填，填不出来的格子先留空。

| 槽位 | 原文里找什么 | 落到哪 | 常见原文词 |
|---|---|---|---|
| **空间** | 底是纸 / 夜 / 屏幕 / 虚空？ | `palette.background` + `backdrop` | 纸感、米白、深夜、虚空、终端、舞台 |
| **材质** | 墨 / 霓虹 / 金属 / 像素 / 胶片 / 玻璃 | `backdrop` 或场景道具 | 晕开、颗粒、扫描线、金属反光 |
| **色** | 主色 + 一处强调 + 忌色 | `palette.{primary,accent,text,textMuted}` | 朱红、冷蓝、单色、高饱和 |
| **字** | 衬线/无衬线/等宽/手写，字号对比强不强 | `font.{heading,body}` + 版式 | 宋体、哥特、等宽、字重很粗 |
| **运动** | 快慢、是逐字还是整体、有没有粒子 | `motion` + 转场 + 入场 `anim` | 呼吸、噼啪、砸下来、缓缓浮现 |
| **禁忌** | "不要 / 别 / 避免 / 只用一处" | `shot.note` | 忌满屏装饰、忌硬边描边 |

## 三、三种句式，翻法不同

1. **比喻句（"像……一样"）** → 找**喻体的物理属性**，不是找那个东西。
   "话像雨一样落下来"：喻体是雨，属性是「从上往下、加速、堆积、密」。
   我们能落的只有「密」和「下」——用 `marquee`（多行大字滚动，天然密）或 `kinetic`（逐字弹入）。
   **不要**去找"雨"的 `rain` backdrop 就完事，那是氛围不是主视觉。
2. **技法句（"用……画 / 由……组成"）** → 直接对应 `backdrop` 或道具。
   "扫描线 + 色差" → `backdrop: vhs`；"透视网格" → `backdrop: gridflow` 或 `neon` 版式。
3. **否定句（"不要 / 忌"）** → **100% 进禁忌清单**。这是最容易被漏掉、也是用户最容易一眼看出的部分。
   原文写"忌朱红多处"，成片里出现三处朱红，用户会说"这不是我要的味道"——但他不会说清是颜色问题。

## 四、空间：先定背景，再选版式

背景定错，后面全白做。`palette.background` 用 **`#RRGGBB`**，不要写 `white`/`black`。

| 原文说 | background | radius | 配套 |
|---|---|---|---|
| 纸感 / 米白 / 手账 | `#F3EEE2`、`#FAF6EC` 一类暖灰 | 0–2 | 禁渐变、禁发光；`radius` 大就不是纸了 |
| 夜 / 深色 / 舞台 | `#0B0B10`、`#101017`（**别用纯黑 `#000000`**） | 2–6 | 深底上细字会消失，正文对比度 ≥ 4.5:1 |
| 屏幕 / 终端 / 数据 | 深底 + 高明度单色 | 4–8 | 等宽字体；`backdrop: matrix`（深色最出彩） |
| 虚空 / 渐变光 | 中深色 | 6+ | `glow` / `bokeh` / `sparks` |
| 编辑部 / 杂志 | 白 + 黑 + 一个高饱和 | 0 | 大字距收紧 `-0.02em`，靠版式不靠特效 |

## 五、材质：backdrop 的真实选项（17 种）

`set_scene_backdrop` 能垫的（**不占时长、不压字**）：
`glow` `grain` `lightleak` `bokeh` `sparks` `vhs` `spotlight` `gridflow` `rain` `liquid`
`confetti` `snow` `fireworks` `smoke` `matrix`

怎么挑：

- 要「贵 / 高级」→ `liquid`（**不要用 `glow`**，那是"氛围光"，不是"质感"）
- 要做旧 / 纪实 → `grain`（暗角 + 逐帧颗粒，压在画面上也行）
- 要复古 / 故障 → `vhs`
- 要压情绪（困境、亏损、等待）→ `rain` 或 `smoke`；**别用它来做热闹**
- 要科技 / 数据 → `gridflow`、`matrix`
- 要舞台 / 强结论 → `spotlight`
- 要庆祝 → `confetti`（落下）对 `sparks`（向上），别同时上

**一次一两种就够。** 三种以上叠加，画面会变成噪点，而且 `check_project` 的火花审计会挑出来。

## 六、色与字：取三色，不要取七色

从静帧里取色，按**面积**取，不按"好看"取：

- 面积最大的一块 → `background`
- 面积第二大、用来承托内容的 → `surface`
- 面积最小但最跳的那块 → `accent`（一屏只出现一次，见 craft §8 的 60/30/10）
- 文字色从背景推导：浅底用 `#151412`（**不要纯黑**），深底用 `#F2F2F5`

**最常见错误：把静帧里所有辅助色都搬进 palette。** 七种颜色的片子=没有主色，用户会说"乱"。

字：`font.heading` 要有性格、`font.body` 要安静（craft §12）。参考风格原文里若写了"哥特/宋体/等宽"，
直接落；没写就从气质推：编辑感要衬线，科技感要几何无衬线，手工感要手写体。
**换字体后必须 `preview_frames` 抽一帧**确认没掉字。

## 七、运动：motion 是 0/1/2，不是形容词

`set_theme({motion})`：`0` = 完全静态、`1` = 标准（默认）、`2` = 更明显（位移加大 + 轻微回弹 + 数字滚更快）。
**它只影响入场位移/数字滚动/氛围光斑，不改版式与排版。**

| 原文气质 | motion | 转场 | 入场 |
|---|---|---|---|
| 呼吸、缓缓、晕开、安静 | 0–1 | `fade` / `circle`（墨滴晕开就是 `circle`） | 位移小、`ease: out` |
| 标准叙事 | 1 | `wipe` / `slide` | 默认 |
| 噼啪、砸下来、快切 | 2 | `flash` / `wipe` 快版 | `back` 缓动，只给俏皮元素 |

**别用 motion 去表达"手法"。** 字雨、粒子聚形这类"逐帧画出来的动作"不是动效强度能表达的，见下一节。

## 八、翻不过去的怎么办：三条降级路径

341 条里相当一部分描述的是 **Canvas 逐帧绘制**（字雨、粒子聚形、手绘线条生长、像素溶解…）。
我们的引擎是**版式系统**，没有这些组件。这时候不许硬说"做到了"，按顺序选一条：

| 路径 | 做法 | 什么时候用 |
|---|---|---|
| **1. 近似版式** | 找承载同一"变化"的版式：密 → `marquee`；逐字出现 → `kinetic`/`typewriter`/`scramble`；一句砸下来 → `stomp`；逐行升起 → `maskreveal`；一个词被抬 → `highlight` | 首选，最稳 |
| **2. 自由画布** | `freeform` 场景 + 逐个 `add_freeform_element` 写 `anim` 关键帧，自己摆出那个动作 | 近似版式都不像，且这一幕是情绪高点 |
| **3. 只取气质** | 放弃那个动作，只留它的**空间/色/字/禁忌** | 动作是配角，用户其实要的是"那个味道" |

**选完要在回执里说明走的是哪条。** 用户勾了"字雨"，结果拿到一屏 `bigtext`，
不解释他会觉得你没做；说清"引擎里没有逐帧字雨，这一版用 marquee 做密度 + 深色底 + 单色字重"，
他才能判断能不能接受。

## 九、一个完整例子：A1 字雨

原文（去掉 Canvas 代码后只剩这些）：

> 用代码（Canvas 2D）画一段"字雨"的动画：话像雨一样落下来，越积越多。
> 适合讲：被说教、重复的话、压力　关键词：字雨、落下、堆积

六槽位填出来：

| 槽位 | 判断 | 落地 |
|---|---|---|
| 空间 | "压力/被说教" → 压抑，深底 | `background: #0B0B10`，`radius: 2` |
| 材质 | 主体是字本身，不需要氛围层抢戏 | 无 backdrop（或极淡 `grain`） |
| 色 | 单色为主，一处暖色强调 | `text: #EDEDF0`、`textMuted: #7A7A85`、`accent: #E4572E` |
| 字 | 大量重复小字 + 一句大字；无衬线、字重中偏粗 | `heading` 用几何无衬线、`body` 同族更细；中文 `letterSpacing: 0` |
| 运动 | "落"和"积"是逐帧动作，引擎做不了 → 降级路径 1 | `motion: 1`，用 `marquee`（多行滚动=密度）或 `kinetic`（逐字弹入） |
| 禁忌 | 原文没有否定句，但从气质补一条 | note："不要暖色大面积；accent 全片只出现一处" |

出样张：挑一个气质最近的内置风格做基底（深底 → `dark-keynote`），`apply_style` 之后再
`set_theme` 覆盖成上面这套色，然后 `probe_style(slugs:["dark-keynote"])`。
**先套底座再改色**，比从零凑版式快，也比纯 `set_theme` 稳。

## 十、翻译完必须做的两件事

1. **出样张给用户确认**：`probe_style(slugs=[候选1,候选2])` 出**我们引擎的**图，
   别把参考静帧当成片效果发过去（那是两回事，顺序倒了用户会以为已经做好了）。
2. **在回执里交代三件事**：用了哪几条（编号 + 名称）、走了哪条降级路径、禁忌清单是什么。
   用户下一次说"不对"，你才知道是色、是字、还是那个动作没做出来。

## 十一、四条常见失败

| 症状 | 真因 | 修法 |
|---|---|---|
| 换了色，但看着还是 PPT | 只做了槽位「色」，没做「版式」 | 每一幕按"要观众看懂什么变化"重选版式，见 scene-recipes |
| 画面很花 | 七种颜色 + 三种 backdrop | 回到 2+1 与"一次一两种氛围" |
| 用户说"不是这个味道" | 禁忌清单没落地 | 翻回原文找否定句，逐条对 |
| 用户说"太满了/太空了" | 把参考静帧的**信息密度**也照搬了 | 静帧是单帧画面，成片要按幕分配信息（craft §2 节奏模板） |
