# 画面质感指南

回答一个问题：**为什么有的片让人「哇」，有的只是「能动」？** 方法论源自代码动效视频的通用经验（上游：garden-skills/motion-showreel 的 craft.md，已按本工程能力改写）。

分两层看质量：**结构层**（本片讲什么节奏、哪一幕是高潮）先定，**质感层**（每个动作怎么动）再落。
本指南讲质感层；结构与用途的映射见 `get_guide("formats")`。

> 这是**起点不是天花板**：所选风格（`get_styles`）和内容优先。安静的风格变化本来就少，
> 匀速旋转在生成抽象里是对的。全局底线只有「禁止清单」一节。

## 1. 惊艳公式

观众在信息流里给你 1 秒。留住他们的是**意外但合理**，拆开是四个乘数：

| 乘数 | 0 分的样子 | 10 分的样子 |
|---|---|---|
| 变化密度 | 一个画面放 3 秒，元素慢慢淡入 | 每一拍都有东西变形、进场、切换 |
| 运动质感 | 匀速平移、所有元素同时出现 | 弹簧落定、预备动作、过冲、错峰跟随 |
| 签名时刻 | 每幕强度都差不多 | 有一个瞬间让人想倒回去看 |
| 音画同步 | 背景音乐和画面各走各的 | 撞击、切点、重拍都在同一帧上 |

**统一性是隐藏的第五项**：手法再多，颜色、字体、运动性格一致才像「一个作品」；
不一致就是「模板合集」。本工程 `theme.motion`（0/1/2）就是全片运动性格的总开关：
正式叙事片用 1，作品集/卡点用 2，汇报/安静风格用 0——**0 必须能关干净**，
所以 motion=0 时不要再靠特效偷偷加动。

## 2. 节奏模板（换算成幕）

本工程单幕 90–180 帧（3–6 秒），按 fps 30 换算：

| 时长 | 幕数参考 | 结构 |
|---|---|---|
| 6 秒 | 2 幕 | 预备+爆发（1 幕）→ 定格落版（1 幕）。整片只有一个想法 |
| 15 秒 | 4–5 幕 | Hook（第 0 帧就在动）→ 建立（视觉系统亮相）→ 加速 → 记忆点 → 落版 |
| 30 秒 | 7–9 幕 | Hook → 段落一 → 小高潮 → 段落二（换视觉手法）→ 吸气（留半拍静）→ Drop → 落版 |
| 60 秒+ | 15 幕+ | 按章节走，见 `get_guide("long-form")` |

- **30 秒必须有两种不同的速度**：全程同一个速度会让人疲劳。
- **加速不用提 BPM**：段落一段比一段短（5s → 4s → 3s → 2s → 1.5s），最后一段放长给落版。
  转场时长跟着缩。
- **吸气是刻意设计的例外**：drop 前留半拍空白（一幕里元素先收、字幕停），是为了让下一个冲击更强。

## 3. 连续叙事（分镜三问，写进每幕的备注）

讲解、产品、叙事片**不是把口播逐句做成静态标题卡**再包一层淡入。每幕动笔前先答：

1. **变化**：这一幕让观众看懂**什么变化**？用对象的移动、数量、对比、状态呈现，
   文字只负责命名和解释。答不出来 = 这一幕可能只是换页。
2. **承接**：下一幕从上一幕**继承什么**？同一个主体、位置、颜色或图形关系。
   别每幕清空舞台重摆一遍。
3. **同步**：关键变化、幕切换和 BGM 重拍（或口播重音）是否落在同一帧？

**别用伪运动补空白**：背景粒子、呼吸光斑、无目的推镜不能替代信息发展。
先改分镜（让对象真的在变化），再谈缓动和特效。

## 4. 运动质感 → 本工程工具映射

| 手法 | 在本工程怎么做 |
|---|---|
| 错峰进场（stagger） | 列表/步骤类版式自带逐条进场；自由元素用 `anim[].from/to` 写不同起始帧 |
| 弹簧落定 / 过冲 | 关键帧做过冲：终点前放一个超出目标 5–8% 的中间帧再回落（`update_element` 的 anim） |
| 预备动作 | 大动作前一帧先反向收一点（缩小 5% / 后退几帧位移），约占主动作 1/4 时长 |
| 离场比进场快 | 进场 0.4–0.6 秒（12–18 帧），离场 0.2–0.3 秒（6–9 帧） |
| 一次只突出一件事 | 同一帧最多一个主运动；其他元素静止或跟随。全屏特效（punch/shake）出场时不要再加元素级大动作 |
| 停留的镜头也要活 | 主体过程仍在发展时保留必要运动；静止幕可用 pulse/呼吸类低幅度氛围，不要为凑数加漂浮 |
| 数字要跳 | stats/chart 版式自带数字滚动；数字格式化保留前后缀，纯 4 位整数当年份不滚（刻意设计） |
| 快速运动带模糊 | `blur` 特效糊一下再聚焦，或元素滤镜 blur 快速位移时短暂开启 |
| 拖影 | 无原生支持，用元素复制 3–5 份递减透明度沿速度方向排列（自由画布可做，慎用） |
| 步进动画（像素/定格风） | 效果靠风格本身（pixel 系）+ `theme.motion=1`；不要给镜头加步进，会像掉帧 |

## 5. 转场语法

**规则：下一个画面要从上一个画面里的某个元素「长」出来。** 整片选 2–3 种转场，统一成一套语法。

本工程转场入口是 `set_transition`（幕间），配合特效与画中画可以拼出高级语法：

| 语法 | 怎么拼 |
|---|---|
| 匹配剪辑 | 上一幕结尾的主体位置 ≈ 下一幕主体的起始位置（改元素起始坐标对齐） |
| 穿越变焦 | `punch`（放大回弹）或自由元素 scale 动画冲进一个字/一个孔，下一幕从里面展开 |
| 色块淹没 | `flash` 用品牌色（支持 colorable），强调色铺满再退开 |
| 甩镜 | `shake` + 下一幕元素从甩出方向滑入；4–6 帧内完成 |
| 溶解/故障 | `glitch`（复古/科技/故障风专用）、`blur` 糊开再聚焦 |
| 反差切换 | `gray` 去色再回来，或 `flash` 反白——适合段落切换 |
| 遮罩擦除 | 大字/色块元素 `anim` 横扫出画，露出下一幕内容（自由画布） |

- **带字幕的幕转场 ≤ 6 帧**：交叉转场期间上下两幕字幕会同屏，超过 8 帧能看到两行小字压一起（实测约束）。
- **硬切也是一种选择**：音乐卡点片让硬切落在重拍；口播片按语义切，不必每个句号都配转场。
- **复杂转场给够时长**：缓入缓出两头几乎看不出变化，签名转场 0.45–0.6 秒（14–18 帧）起。

## 6. 镜头

本工程没有虚拟相机，但有等效手段：

| 想要 | 怎么做 |
|---|---|
| 慢推（紧张感上升） | 全屏背景元素 scale 1.0→1.08 缓动贯穿整幕；或 `punch` 低强度 |
| 急推（冲击） | `punch` + `shake` + 音效同一帧 |
| 拉远揭示 | 从局部元素 scale 出发拉到全景（自由画布整组元素反向动画） |
| 视差（深度） | 前景/背景元素用不同速度的位移动画（0.6× / 1.4×） |
| 主角要大 | 关键时刻主体占画面高度 1/3 以上；分镜里写明，别默认主体偏小 |

固定机位也可以是一种风格选择（瑞士编辑风），但要**有意为之**并写进 brief。

## 7. 动态排版

- **极端尺寸对比**：巨大的字（画面高度 20–40%）配极小的注释，比所有字都中等大小高级。
- **一屏一句**：同一时刻中文 ≤ 12 字。停留时间：字数 ÷ 4.5 + 1.5 秒（完全显示后起算）。
  快节奏靠**减少字数**，不是压缩停留。
- **左对齐 + 网格**：居中大字是 AI 默认风格的头号标志。试左对齐、出血（字被画面边缘裁掉）。
- **字要有地盘**：字和繁忙画面同屏时给字划禁入区；被遮挡不能超过一个字。
- 中文注意：本工程字幕烧录按字数比例分配幕内时长；`quote` 版心窄，>7 字折行，长句用 `bigtext`。

## 8. 配色

- **2+1**：背景色、主色，再加一个只给「主角」用的强调色。主角一出现观众就知道看哪里。
- **浅色背景被严重低估**：暖灰、米白、纸色更容易做出编辑感，也更能跳出「深色科技风」。
- **反色是现成的 drop**：`flash` 让背景前景互换 1–2 拍，几乎零成本。
- **品牌色优先**：给了品牌色就在其明暗上推导，不凭空发明新色相。`set_theme` 定全片色板。

## 9. 签名时刻菜单（挑一个，放在情绪最高处）

每条标注本工程实现路径；标「自由画布」的需 layoutMode 含 freeform：

| 记忆点 | 实现 |
|---|---|
| 数据爆点 | `stats`/`chart` 数字滚到终值 + `flash` 反白 + `shake` 同帧 |
| 穿越进字 | 自由画布：镜头冲进标题字母的孔（scale 动画），下一幕展开 |
| 分屏复制 | 同一动作 `set_scene_box` 缩成 2→4 格错帧重复（多轨） |
| 媒介切换 | 同一主体从照片 → 矢量 → 手绘（freeform svg 每段重画） |
| 反色落版 | `flash` + `outro` 落版同帧 |
| 一镜到底形变链 | 自由画布：一个形状连续变形 8–12 个状态（`update_freeform_element` 连续 anim） |
| 全片最强一下 | 上述任意，但**只出现一次**；每段都是高潮 = 没有高潮 |

## 10. 禁止清单（AI 默认味及替代）

写 brief 的 `forbidden` 时从下面挑适用的，加这支片子特有的：

| 默认味 | 改成 |
|---|---|
| 深色背景 + 居中大字 + 紫→粉渐变 + 到处发光 | 浅色/品牌色背景；左对齐网格；光只给真正发光的东西 |
| 所有元素同时淡入淡出 | 错峰 + 遮罩/滑入 + 过冲；离场比进场快 |
| 每幕都是「标题卡 + 淡入」 | 连续叙事三问（§3）；答不出「变化」就重写这一幕 |
| 匀速平移 | 缓动收尾（本工程入场动效自带），或改用版式自带的错峰进场 |
| 通用粒子/光斑凑数 | 粒子必须有目的；本工程氛围光斑只在 motion≥1 时出现，够用就不要再加 |
| 满屏小字、长句 | 一屏一句，正文字号 ≥ 画面高度 4% |
| 弹跳（bounce）到处用 | 过冲克制（5–8%），只给俏皮元素 |
| emoji 当图标 | `list_element_library` 里的图标/装饰元素，或抽象图形 |
| 转场全用交叉淡化 | 全片统一 2–3 种转场语法（§5） |

**例外**：品牌规范本身如此（品牌就是深色+霓虹），或用户明确要求——那它是签名，不是默认味。

## 11. 竖屏构图（9:16 专场）

竖屏不是「把横屏裁窄」。手机是竖着拿的，拇指会挡下面，平台 UI 会压两头。

**三个区域**（以 1080×1920 为例）：

```
┌─────────────────┐
│  上留白 20%     │  不放内容（下拉刷新区/状态栏）
│                 │
│   内容核心区    │  60%：一句话 / 一个数字 / 一张图
│                 │
│  下留白 20%     │  不放内容（字幕、平台文案、按钮栏）
└─────────────────┘
  ← 左右各留 8% 安全边距 →
```

规则：

- **内容垂直居中**，别顶天立地——顶到上下 20% 就是会被压掉的地方
- 横向不超过画面宽 86%；长句主动断行，不要靠缩字号塞进去
- 有字幕的幕，内容整体上移 8%（替字幕和平台 UI 让位）
- 一屏大字最多两行，**每行 ≤ 6 字**；超过就是两屏
- 数字页的数字占画面高 8–12%，旁边必须有对照（上一代 / 同行 / 目标）

**四种页面类型的配比**（一分钟以内竖屏片）：

| 类型 | 占比 | 要点 |
|---|---|---|
| 大字页 | 50% | 一屏一个信息，放不下就拆幕 |
| 数字页 | 25% | 数字 + 对照，停留 4 秒起 |
| 图 / 演示页 | 15% | 一句话说明这张图在看什么 |
| 呼吸页（黑场/纯色） | 10% | 转折前清空注意力，0.5–1.5 秒，不要更长 |

节奏三条：**连续两幕不用同一种类型**；**每幕停留 2–5 秒**（数字和图页留更久）；**呼吸页只在大转折前用**，每片 1–2 处，用多了就是拖。

## 11.5 横屏构图（16:9 专场）

横屏不是「把竖屏的版式放大」。竖屏是竖着往下读，横屏是横着扫一眼，
**内容必须横向铺开**，否则就是「左边一坨字，右边一片空」——这是一眼看出「没做过设计」的地方。

**目标**：内容横向占 75–90%，纵向占 30–60%（标题页可以只有 25%）；
居中留白是设计，单边留白是没排完。

内置版式已经按画幅自适应，你不用手动调：

| 版式 | 横屏自动做的事 |
|---|---|
| 标题 | 副标题移到右下（对角构图），标题字号按「一行放得下」自动算 |
| 要点 | 3 条变 3 栏（编号在上、文字在下），4 条 2×2 |
| 数据大字 | 数字再放大一档，3 个撑满整行，每列顶上加发丝线（读成一条数据栏） |
| 图表 | 高度从 30 单位提到 46，宽度铺满；跨数量级用 `scale:"log"`（会标注「对数轴」） |
| 金句 | 收窄居中，字号按「一行放得下」算，避免「付。」两字孤儿行 |
| 垂类封面（life/game/tech/edu/live/shop）、hero | 报头贴顶（标签 + 一条横贯到右边缘的细线）/ 标题居中顶满宽度 / 页脚压底（副标题左、标签右） |
| 榜单清单 | 改目录行：注释推到右边缘，行间发丝线 |
| 团队 | 立成等分列、列内居中、列间竖线 |
| 大字报 | 字号按宽度定（夹 7-16），大字报本来就应顶到两边 |
| 标签云 | 整行两端对齐，大小标签统一容器感（浅底 + 淡描边） |
| 价格档 | 卡片给最小高度，档名/价格/说明上下撑开 |
| 口碑 | 原话当主角（按半幅两行算字号），标题退成灰色小标 |
| 字幕 | 横屏 5.6 单位（比竖屏大一档，两米外也读得清） |

字号按「一行放得下」算时用**等效字数**（中文 1、拉丁字母/数字 0.55、空格 0.3）——
按字符数算会让混排标题白白小一号、右边空一块（`agent` 五个字母才一个半汉字宽）。

**手写 freeform 时的横屏比例**（1080 高为基准，unit = 10.8）：

```
┌──────────────────────────────────────┐
│  上留白 9%                           │
│  ┌──────────────┬─────────────┐      │
│  │ 主内容 55–65% │ 辅助 25–35% │      │  两栏对话，栏间一条发丝线
│  └──────────────┴─────────────┘      │
│  下留白 9%                           │
└──────────────────────────────────────┘
左右各留 7%
```

四条硬规矩：

- **标题一行放得下**：中文一行 12–16 字，超过就降号或拆成主/副标题，别让浏览器折出「两字孤儿行」
- **横向要有第二个元素**：一段文字撑不满时，加右栏（副标题/数字/标签）或铺满整行的图表，而不是把字号放大到像大字报
- **图表占高度 45–55%**，柱子宽度别超过栏宽的 70%（太胖像色块）
- **同一片子里横竖两版要分别看**：版式一样但比例不同，一版好看不代表另一版成立

### 填不满时：补位，不要重写（实测教训）

内置版式给的是**骨架 + 入场动画**（数字滚动、逐条错峰），填充度里缺的那部分，
本来就该由你用 `add_element` 补信息层——这不是版式的缺陷。

真实教训（用户实测报告里的一条自我更正）：有人把 50 幕全改成 `freeform` 手写栅格去填满画面，
结果既**丢了版式自带的数字滚动和错峰入场**，又白写了 50 套坐标。补位实测只要三层：

| 补什么 | 典型参数 |
|---|---|
| 背景氛围层 | `type:"fx", kind:"glow"`（或 SVG 径向光晕，`size 180 / x50 y50`） |
| 顶部 kicker 小标 | `y 15 / size 2.8`，用强调色 |
| 底部结论行 | `y 78 / size 4.2`，用另一种强调色 |

实测内容跨度 27% → 70%，且入场动画全保留。全片一次铺完用
`apply_to_scenes(tool="add_element", applyToAll=true)`，不必逐幕加。

**判断顺序**：遇到「工具做不到 A」，先问**是不是自己的解法绕了远路**，再断定它缺功能。
模板不万能是常识——「模板没自动做到」不等于 bug。

反过来也别走另一个极端：**已经铺满的版式上再加装饰就是加法**。
补位补的是「信息层」（这幕在说什么的一句点睛），不是把空白涂满。

### 怎么自查

`check_project` 查不出「空」，只能抽帧看。判断标准一句话——
**把画面四边往里推 15%，内容还能保持结构吗？** 能，就是构图成立；一推就散，说明内容全挤在中间一小块。

要量化的话跑 `scripts/fill-rate.mjs`（纯 stdlib，给 PNG 路径就出数）：
16:9 建议 **横向 ≥ 75%**；低于基准只是「可能空」，**必须再看图**——
它对低对比的卡片底色会漏报（实测 cards 实际铺到 92%，脚本只测出 58%），
环形图、二维码也天生就该小。

## 12. 字体与动效基准

### 字体

字体是最快的辨识度来源，也是最容易翻车的地方（缺字、掉字、投影发糊）。

- **先定角色再定家族**：标题字（有性格）+ 正文字（安静）。两个都用同一种就是「没设计」
- **中英混排各选一套**：中文黑体配英文衬线（对比感），或中文宋体配英文几何无衬线
- **换字体前必须 `preview_frame` 抽一帧**：确认没有掉字（缺字会显示成方块）、中文标点齐全、字重够（手机上看不清就是把字重加粗，不是把字号加大）
- **字距**：大字标题收紧 `-0.02 ~ -0.04em`；中文大标题不要手动加正字距（会裂开）。本工程 `letterSpacing` 单位是 px，中文标题保持 0
- **行高**：标题 0.95–1.1，正文 1.35–1.6
- **行长**：中文一行 14–22 字，英文 45–75 字符；超过就断行

### 配色比例

- **60 / 30 / 10**：背景 60%、主色 30%、强调色 10%。强调色一屏只出现一次，用在「你希望他看的那一个东西」上
- **对比度**：正文与背景 ≥ 4.5:1，大字 ≥ 3:1。深色底上的细体小字最危险（投屏/手机上直接消失）
- **品牌化只改三个值**：强调色、背景色、标题字体——改完就是一版「像你们公司」的片子，不用重做版式（`set_theme`）

### 动效时长

| 层级 | 时长 | 帧数（30fps） |
|---|---|---|
| 微交互（hover 感、图标响应） | 150–200ms | 5–6 帧 |
| 常规（元素入场、位移） | 300–400ms | 9–12 帧 |
| 场景级（整幕转场、大位移） | 600–800ms | 18–24 帧 |

- 缓动：入场 `out`（快进慢收），出场用 `in`，带回弹的用 `back`（只给俏皮元素）。本工程可选的缓动就是 `linear / in / out / inOut / back`
- **全片只用 2–3 种缓动**，用多了就是杂耍
- `theme.motion=0` 时这些都不要再叠——0 必须能关干净
