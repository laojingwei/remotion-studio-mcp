# 自检与验收

**铁律**：每个产出（brief / 分镜 / 单幕 / 全片）完成后，**先自检 → 按 fail 项修完 → 再向用户汇报**。
直接拿原始结论汇报、不修复就往下做 = 违规。

## 自检怎么做（按能力降级）

1. **独立 reviewer**（能开 subagent / 独立 agent 时最优）：给它「产出 + 本清单 + 关键上下文」，让它逐项回 pass / fail + 证据。
2. **自己逐项核**（没有独立 reviewer 时）：逐条对照，不允许目测一遍就放行。

## 阶段清单

### 接单（brief）
- 必填齐：目标/受众/平台、时长、画幅、风格、配音、素材、交付、截止
- 对标写了「学什么 / 不学什么」
- 禁止清单非空（至少 2 条：最俗的视觉效果 + 不能碰的词/竞品）

### 分镜（storyboard）
- 每幕 `type` 合法、时长合理（常见 90–180 帧）
- **连续叙事三问每幕有答案**：这幕让观众看懂什么变化（change）／从上一幕承接什么（carry）／关键变化与 BGM 重拍或口播重音是否同帧。答不出「变化」的幕先重写（见 `get_guide("craft")` §3）
- 前 1 秒有 hook；全片有一个记忆点（signature，写明用 craft §9 菜单里的哪一手）；结尾有 takeaway 或 CTA
- 不出现连续 3 幕同版式；数据类不超过 2 幕连排
- 30 秒片有两种速度（有段落递减/吸气/Drop）；全片转场语法统一 2–3 种
- 超 12 幕或 2 分钟：已按章分组（name/note 标章），见 `get_guide("long-form")`
- 口播文本（text）是口语短句，不是书面语

### 单幕（build 后逐幕查）
- `preview_frames` 抽首/中/尾三帧：文字不溢出、不重叠、不挡主体
- **抽帧只能验"形"，不能验"字"**：视觉模型读中文小字会错（真实案例：「漏斗」被读成「瘤斗」）。
  排版/溢出/遮挡/比例可以信它；**文字内容、数字、错别字必须自己对着文案核对**，别用 OCR 结论当验收依据。
- 元素不提前退场（`durationInFrames` 没写就别写；写了要对齐场景）
- 字幕和口播对齐（tts_narration 已自动写，改文案后重量）
- 配色/字体和风格一致；禁止清单里的东西没出现

### 全片
- `get_project` 核对：场景数、顺序、无重复副本
- 音频不超场景：`render_video(dryRun=true)` 会报「后面会被截断/静音」
- **运动自检**：抽帧只能验"形"不能验"运动"——连续变化的段落（转场、Drop、签名时刻）
  按相邻帧多抽几帧（`preview_frame` 逐帧偏移）看对象位置/大小是否真的在发展，
  还是只是静态卡换页（AI 默认味的头号标志，见 `get_guide("craft")` §3 伪运动）
- **声音自检**：按 `get_guide("sound")` §6 逐条过（成片有音轨且非静音、BGM 音量压到人声 20–40%、改过文案已重量）
- 转场不突兀：相邻场景 fade/slide 时长一致
- **带字幕的幕转场 ≤ 6 帧**：交叉转场期间上下两幕的字幕会同时出现在底部，>8 帧就能看出两行小字压在一起（实测约束，不是审美选择）
- `check_project` 跑一遍：freeform 元素的提前消失/空 svg/可疑 viewBox/同幕 y 不一致都已内置，按提示修
- 禁止清单逐条过一遍画面（craft §10 的默认味没出现）
- 总时长符合用户要求（±10% 内）

### 交付
- 技术：场景非空、素材都在、音频不超长、字幕时间对齐
- 观感：抽 3 帧看；转场；字幕没有挡住人脸/主体
- 交付：成片路径（绝对路径）、编码 URL、时长、画幅、字幕文件（需要时）

## 常见问题速查

| 现象 | 先查 | 修法 |
|---|---|---|
| 文字溢出/被裁 | preview_frames | 缩短文案、换 `list`/`bullets`、减 items |
| 元素中途消失 | 元素 `durationInFrames` vs 场景时长 | **场景拉长后元素不会自动跟**（落盘的是具体帧数）。`update_element` 把 `durationInFrames` 改到新幕长，或传 `-1` |
| 音频被截断/静音 | dryRun 告警 | 场景时长 = 音频时长 + 0.7s 呼吸位 |
| 字幕挡住主体 | preview_frames | 调 `bottom` / 字号 / `bgOpacity`，或换位置 |
| props 改了没生效 | `get_scene` 回读 | 看 `⚠️ 不认识的 props 字段` 告警，按 schema 改 key |
| 版式空了半屏 | 抽帧 | items 取 2/4 个；或换版式 |
| 视频没声音 | `muted` | `update_element(muted=false)` |
| 音画不同步 | 音频 `from`/`startFrom` | 对齐起点；裁头用 `startFrom` |
| 长片挂暗角越挂越暗 | 特效轨 `durationInFrames` | 特效轨是**区间效果**（从 0 涨到峰再回落）。静态/周期性暗角开循环：`loop=true` + `loopStopAfterSeconds`；或自画一层 radialGradient svg 盖在最上层 |
| 光斑几乎不动 | `theme.motion` | motion=1 的光斑本来就极淡极慢（设计如此，老工程观感不变）；要明显漂移 `set_theme({motion:2})` |
