# 内容打磨（文案决定有没有人听）

版式和动效决定「看起来专不专业」，文案决定「有没有人看完」。这一篇只管后者。

上游参考：演示文稿与广告文案的通用方法（ppt-master / content-craft）+ 中文 AI 痕迹模式库（ai-humanizer-master），已按短视频改写。

## 1. 一句一论点：先搭金字塔

一条片子只允许一个核心结论，其余全是支撑。

```
核心结论（一句话，观众看完能复述的那句）
├── 支撑 1 → 证据（数字 / 事实 / 案例）
├── 支撑 2 → 证据
└── 支撑 3 → 证据
```

自检：把三个支撑全说成「不成立」，结论还站得住吗？站得住说明你没论证，只是在表态。

**前 3 秒用 SCQA 把观众抓住**（对应 `brief.hook`）：

| 要素 | 含义 | 例 |
|---|---|---|
| S 情境 | 大家都认的事实 | 每个人都在剪视频 |
| C 冲突 | 打破平衡的那一下 | 但 80% 的时间花在了没人看的地方 |
| Q 问题 | 由此引出的疑问 | 到底哪一步在决定完播率 |
| A 答案 | 你的结论 | 是前 3 秒那一句话 |

## 2. 屏幕大字：写结论，不写主题

这是提升观感最快的一招。**一屏大字承担这一幕 60% 的信息量。**

| ❌ 主题式 | ✅ 结论式 |
|---|---|
| 市场分析 | 下沉市场贡献 62% 增量，客单价只有一线一半 |
| 项目进展 | 三个模块已上线，支付模块延期两周 |
| 新年计划 | 明年只做一件事：复购率 21% → 35% |
| 团队介绍 | 四个人，合计 30 年行业经验 |

三种可用句式：**数字对比**（A 是 B 的 N 倍）、**因果**（因为 A，所以 B 必须改）、**取舍**（放弃 X，聚焦 Y）。

唯一例外：封面和段落过渡页可以只写名词——那时观众要的是「定位」，不是「结论」。

## 3. 数字要有参照系

孤立数字不构成信息。**一个数字必须配一个对照。**

| ❌ | ✅ |
|---|---|
| 增长 37% | 增长 37%，行业均值 12% |
| 服务 40 家企业 | 服务 40 家，续约率 92% |
| 用户 100 万 | 用户 100 万，月活 34 万 |
| 成本降 20% | 成本降 20%，一年省 480 万 |

三种换算：换成钱（→ 金额）、换成时间（→ 每人每天省 40 分钟）、换成人（→ 每 10 个客户有 7 个）。

## 4. 删字

一屏正文 ≤ 18 字，一幕口播 ≤ 60 字（30 秒片约 135 字）。这是注意力物理限制，不是审美偏好。

| 该删的 | 原因 |
|---|---|
| 显著 / 全面 / 大力 / 进一步 / 持续 / 赋能 / 打造 / 助力 | 形容词零信息量，全部换成数字或事实 |
| 我们认为 / 可以说 / 众所周知 | 废话开场，直接说事 |
| 为了更好地… / 在…的大背景下 | 铺垫占字数不占信息 |
| 完整长句（屏幕上） | 屏幕要短语，口播才要完整句 |
| 每段的「小结」 | 一段一个点，不需要小结 |

改写示例：

> ❌「为了更好地服务客户，我们持续优化了服务流程，全面提升了响应速度，取得了显著成效。」
> ✅「响应时间从 26 小时压到 4 小时。」

## 5. 屏上字和口播不是一回事

| | 屏幕大字 | 口播 |
|---|---|---|
| 给谁 | 眼睛（可能静音） | 耳朵 |
| 长度 | ≤ 18 字，短句/关键词 | 完整句，能念出来 |
| 内容 | 结论、数字、对照 | 背景、取舍理由、具体故事、数字怎么来的 |
| 错误 | 把口播整段搬上屏 | 念屏幕上的字 |

**铁律：口播不要念屏幕上的字。** 观众自己会看，念一遍等于浪费两秒。口播只讲屏上没有的：为什么、怎么来的、踩过什么坑。

口播稿写四件事：这一句在回答什么、能不能一口气念完、有没有具体的东西（数字/场景/人）、有没有一句能让人记住。

## 6. 讲清楚的结构（按用途挑，别自己发明）

- **口播带货**：钩子（痛点/反差）→ 我原来怎么做（共情）→ 转折（发现什么）→ 演示（看得见的变化）→ 证据（数字/对比）→ 行动（明确的下一步）
- **知识讲解**：认知冲突（你以前那样是错的）→ 原理 → 例子 → 反例（什么不算）→ 步骤 → 常见错误 → 小结（三句话）→ 行动（三件事）
- **产品发布**：现状为什么不行 → 我们的解法 → 三个亮点（每点一图胜千言）→ 数据对比 → 价格/时间 → 邀请行动
- **数据复盘**：结论先给 → 指标看板 → 归因（为什么）→ 风险 → 下一步

**每一步都要能回答「所以呢（So what）」**，答不出来就是信息不是观点。

## 7. 七个常见文案病

| 病 | 症状 | 药方 |
|---|---|---|
| 形容词依赖 | 满屏「高效、专业、领先」 | 每个形容词后面补一个数字，补不出来就删 |
| 主语缺失 | 「完成了系统升级」（谁做的？） | 讲清主体，尤其是要资源时 |
| 术语自嗨 | 「打通底层链路赋能业务」 | 换成「数据能直接用了」 |
| 平均用力 | 五个要点占五行一样长 | 最重要的占半屏，其余压成一行 |
| 结论后置 | 讲了 30 秒才说结论 | 结论提到第 2 幕，后面全是论证 |
| 数字无源 | 「据研究显示」 | 写清来源与时间，否则删掉 |
| 无行动 | 结尾只有「谢谢观看」 | 补上「谁、何时、做什么」 |

## 8. 交付前三问

1. **只读所有屏幕大字**，能讲出完整故事吗？断了就是骨架错了，不是文案问题。
2. 每一幕都能回答「所以呢」吗？
3. 如果观众只看 3 秒，你希望他看到哪一幕？那一幕是不是第 1–2 幕？

`save_script` 会做一次机械体检（空洞词、缺参照系的数字、过长句、AI 味），但机器只查得出「像废话」，查不出「没意思」——第 1–3 条只能自己判断。

## 9. 去 AI 味（口播尤其）

**视频比文章更藏不住 AI 味。** 文章可以跳读，视频是念出来的：一句「让我们一起见证」在耳朵里就是三秒钟的尴尬。30 秒的片子里，出现一句套话，观众对整支片子的信任就归零。

`save_script` / `save_storyboard` 会自动跑一遍词面与句式检查，输出在返回里。下面是它查的那些东西，以及为什么查。

### 四个一眼被认出的句式

| 句式 | 例子 | 为什么不行 |
|---|---|---|
| **翻案腔** | 「这不是剪辑技巧，而是注意力问题」 | 先编一个读者本来没有的误解，再推翻它给自己抬价。AI 口播第一签名 |
| **三项排比** | 「不仅省时间，也省钱，更省心」 | 念出来像念稿。两项为限，第三项换说法 |
| **结尾升华** | 「让我们一起，在内容这条路上走得更远」 | 观众要的是下一步做什么，不是愿景 |
| **模糊归因** | 「专家指出，短视频的核心是前 3 秒」 | 没出处的引用等于没说过，还显得在装 |

改法都是同一条：**从正面下判断，先给结论，再补依据。**

> ❌ 这不是技术问题，而是认知问题。真正决定完播率的，从来不是画质。
> ✅ 完播率跟画质没关系，跟前 3 秒那句话有关系。我们测了 40 条，换开头的涨了 3 倍。

### 黑话与官腔（听到就换台）

| 别写 | 写成 |
|---|---|
| 赋能业务增长 | 订单多了三成 |
| 打通底层链路 | 数据能直接用了 |
| 打造一站式解决方案 | 把 5 个流程合到一个页面 |
| 深入推进、持续优化 | 改了什么，结果多少 |
| 高度重视用户体验 | 把加载从 3 秒压到 800 毫秒 |
| 沉淀、颗粒度、对齐、打法、拉通 | 出现两个以上就是空话，换成具体动作 |

同类禁忌：`众所周知 / 在当今 / 随着…的发展 / 毋庸置疑`（开头套话）、`此外 / 与此同时 / 综上所述`（连接词，口播用句号断开就够）、`博大精深 / 源远流长 / 与时俱进`（成语串）、`大家好我是 / 感谢观看 / 以上就是`（报幕口水，删）。

### 屏幕大字的两条洁癖

屏幕上不出现这两样，观感立刻从「随手做」变成「做过设计」：

- **破折号** `—` `——`：大字用换行或色块断开，别用破折号
- **提示性冒号**：「核心是：」「三个方法：」删掉，直接把内容写成大字（时间 `10:30`、比例 `1:1` 不算）

### 配音念不出来的东西

TTS 不是人，它会把括号里的话念出来，也会把 `API` 念成 A-P-I。口播稿里避开这几样：

| 别写 | 原因 |
|---|---|
| `（重点）` `（其实就是懒）` | 配音会把括号内容一起念，或直接跳过 |
| `《原则》` | 书名号念不出来，书名直接写 |
| `ROI` `GMV` `SOP` | 逐字母念，写成读音或中文（接口、成交额） |
| `——` | 念的时候没有对应停顿 |

### 声音五条（脚本查不出来的，自己核）

| # | 检查项 | 30 秒片子的线 |
|---|---|---|
| 1 | 具体数字 | 全片至少 2 个（金额、时长、百分比、数量） |
| 2 | 具体名词 | 至少 1 个真名（人名 / 产品名 / 型号 / 地名） |
| 3 | 不确定性 | 至少 1 处保留（「我试了两次才对」「这类做法不一定都管用」）——别每句都说满 |
| 4 | 节奏变化 | 句子长短要拉开；连着 3 句一样长，念出来就是念稿 |
| 5 | 说话人在场 | 至少 2 处能听出「谁在说」——靠取舍和来路，不靠加「我觉得」 |

第 3、5 条是文章和视频共通的人味来源，也是 AI 最缺的两样：**它从不犹豫，也从不承担。**

### 自检顺序（30 秒能过完）

1. 跑 `save_script` 看体检输出，把 warn 级的先改掉（翻案腔 / 升华 / 模糊归因 / 模板口水）
2. 念一遍：哪句一口气念不完、哪句念着别扭 —— 别扭的那句重写，不要修饰
3. 只读屏幕大字：像不像一句人话（而不是一个名词）
4. 全片有没有一个数字

**不要用「加一点口语词」来装作有人味。**「说实话」「讲真」「你敢信」堆多了，是另一种模板。人味来自具体的事实和明确的取舍，不来自语气词。
