# 内置固定版式名录（归档 · 只在用户点名时查）

> **这一篇是归档，不是选型指南。**
>
> 下面 47 个内置固定版式都带 `agentVisible: false`：`list_scene_types` 默认不列，
> 编辑器里照常能选，老工程照常能播。它们是"现成骨架"——拿它们搭片子，
> 画面会被锁进既有版式，自由发挥的空间就没了。
>
> **默认不要读这一篇，也不要照着它挑版式。** 正常情况下用
> `freeform` / `scene3d` / `iso` / `empty` / 动效类 / 氛围类（见 `scene-recipes`）。
>
> 只有这两种时候才用它：
> 1. 用户明确点名「用标题页 / 用柱状图 / 就要这个版式」——在这里找到对应 type；
> 2. 用户在编辑器里改过某一幕的版式，你被要求接着改同一幕（先 `get_scene` 看它现在是什么）。
>
> 找到 type 后，字段一律用 `list_scene_types(type:"那个 type")` 查（会回一句"这是例外"的提示），
> 不要凭这里的"要点"猜字段名。

## 封面 / 开场
| 类型 | 适用 | 要点 |
|---|---|---|
| title | 开场、章节标题 | 主标题 ≤ 9 字，副标题一句 |
| hero | 发布会/开场冲击力 | 超大标题 + 渐变光斑 |
| aurora | 氛围感最强开场 | 多层霓虹光斑 |
| neon | 科技/赛博 | 网格 + 发光描边 |
| life / game / tech / edu / live / shop | 垂类封面 | 各带主标题 + 副标题 |

## 文字 / 金句
| 类型 | 适用 | 要点 |
|---|---|---|
| bigtext | 态度/情绪/金句 | 一句超大字 |
| quote | 金句 + 出处 | 版心窄，超过 7 字就折行，长句用 bigtext |
| caption | 口播字幕 | 大字幕 + 说话人 |
| stars | 结尾/品牌 | 星点 + 光晕 |

## 列表 / 数据
| 类型 | 适用 | 要点 |
|---|---|---|
| bullets | 2–5 条要点 | 竖屏单列；5 条会显得密 |
| list | 带序号榜单/清单 | 序号自带，别在 title 写 01/02 |
| stats | 2–4 个关键数字 | 3 个已改单列，不再 2+1 |
| chart | 动态柱状图 | 适合趋势；`data[].color` 可单独指定每根柱子颜色（含数值颜色） |
| bars | 2–4 条进度 | 技能/完成度 |
| ring | 百分比圆环 | 成果/进度 |
| table | 3 列 2–3 行 | 表头写死（项目/基础版/进阶版） |
| game-stats | 游戏战绩 | KDA/胜率这类关键数据，items 2–4 条 |

## 对比 / 流程 / 对话
| 类型 | 适用 | 要点 |
|---|---|---|
| compare | 前后对比 | 左右两栏；换行不生效，写短句流 |
| versus | 两强 VS | 中间 VS 徽标 |
| steps | 2–4 步流程 | 竖屏纵向 |
| timeline | 时间节点 | 窄栏，适合节奏条 |
| chat | 对话气泡 | 答疑/案例 |
| countdown | 倒计时 | 直播/促销 |
| gauge | 完成度/达成率/占比 | 数值 0–100，270° 圆弧扫入，中间大数字跟滚 |
| racebars | 榜单/排行/多账号对比 | 自动按值排序，第一名最亮；宽度相对**最大值**而非总和 |
| funnel | 曝光→进播→下单这类流程 | 层按流程顺序传（不排序），层宽用开方刻度，转化率在层间 |
| linechart | 趋势、涨跌走势 | 线从左往右画出来；数据按 x 轴顺序传，3–8 个点 |
| pie | 构成、来源分布 | 环形多切片逐块扫出 + 图例；**单值进度用 ring，别用 pie** |
| delta | 活动前后/规则前后 | before 小而灰、after 大而亮；箭头只表流向，涨跌语义在胶囊 |

## 图片 / 视频 / 商品
| 类型 | 适用 | 要点 |
|---|---|---|
| image | 全屏图 + 压角标题 | 实拍/截图 |
| split | 左文右图（竖屏上图下文） | 产品/教程 |
| gallery | 2–4 张图网格 | 产品/旅行 |
| team | 2–4 位成员 | 头像 + 角色 |
| shop | 商品展示 | 价格/卖点 |
| pricing | 2–3 档价格 | 中间档高亮 |
| rating | 星级 + 用户原话 | 口碑 |
| cards | 卡片网格 | 2–4 张带序号的卡片，功能/亮点展示 |

## 收尾
| 类型 | 适用 | 要点 |
|---|---|---|
| outro | 行动号召 | 一句话 |
| qr | 二维码占位 + 引导 | 引流 |
| tags | 标签云 | 关键词/话题 |

## 布局变体（有对比语义时才有意义）
| 类型 | 适用 | 要点 |
|---|---|---|
| diagonalsplit | 对比、交锋、转折 | 斜线分界自带「势」；并列陈述用 split，别用这个 |
| frameinframe | 讲产品、演示操作 | 截图套浏览器/手机壳；没图也有假网页骨架，工程立起来就能看 |
| layered | 一张重点 + 背书 | 最后一张在最前面（重点写最后）；并列平铺用 cards |

## 这些版式的通用坑
- props 里**类型不认识的字段会被静默丢弃**（现在会点名提示）；改完 `get_scene` 回读确认
- items 必须是对象，key 见 `list_scene_types`；未知 key 静默丢弃
- `timeline` 的 title 会被丢弃，只存 time + text
- 3 个 items 的 stats/cards/bullets 会排成单列/整行，按内容需要选 2 或 4 更平衡
- 长文案优先换 `list` / `bullets`，不要在 `quote` / `compare` 里硬塞

> 数一下：本表 47 个 type（封面上 9 / 文字 4 / 列表 8 / 对比 12 / 图片 8 / 收尾 3 / 布局变体 3），
> 加上 agent 默认可用的 31 个（freeform / empty / scene3d / iso / 动效 15 / 氛围 12 / 插件场景），
> 全库共 78 个内置场景类型。
